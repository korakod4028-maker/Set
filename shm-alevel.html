หัวข้อ 1 · นิยามและลักษณะของ SHM
〰️
การเคลื่อนที่แบบฮาร์มอนิกอย่างง่ายคืออะไร?

การเคลื่อนที่แบบฮาร์มอนิกอย่างง่าย (Simple Harmonic Motion, SHM) คือ การเคลื่อนที่กลับไปมาซ้ำแบบเดิมเป็นคาบ รอบตำแหน่งสมดุล โดยมีเงื่อนไขสำคัญเรื่องแรง

นิยาม
SHM คือการเคลื่อนที่ที่มี แรงดึงกลับ (Restoring Force) แปรผันตรงกับขนาดการกระจัดจากจุดสมดุลเสมอ และมีทิศทางตรงข้ามกับการกระจัดเสมอ
F = −kx

เมื่อ F คือแรงลัพธ์ (N), k คือค่าคงตัวของแรง (N/m), x คือการกระจัดจากจุดสมดุล (m) และเครื่องหมายลบแสดงว่าแรงมีทิศทางตรงข้ามกับ x เสมอ

💡 เทคนิคจำ
ถ้าเจอโจทย์บอกว่า "ความเร่งแปรผันตรงกับการกระจัดแต่ทิศตรงข้าม" (a ∝ −x) ให้สรุปได้ทันทีว่าเป็น SHM
🔑
ปริมาณสำคัญที่ต้องรู้จัก
A
แอมพลิจูด (Amplitude)
การกระจัดสูงสุดจากจุดสมดุล (m)
T
คาบ (Period)
เวลาที่ใช้เคลื่อนที่ครบ 1 รอบ (s)
f
ความถี่ (Frequency)
จำนวนรอบต่อวินาที f = 1/T (Hz)
ω
ความถี่เชิงมุม
ω = 2π/T = 2πf (rad/s)
ตัวอย่าง
ลูกตุ้มแกว่งครบ 20 รอบ ใน 40 วินาที
T = 40/20 = 2 s, f = 1/T = 0.5 Hz, ω = 2π/T = π rad/s
⚠️
เงื่อนไขที่ต้องระวัง
⚠️ ข้อควรระวัง
การเคลื่อนที่เป็นคาบ (Periodic) ไม่ได้แปลว่า เป็น SHM เสมอไป — การเคลื่อนที่เป็นวงกลมสม่ำเสมอก็เป็นคาบ แต่ไม่ใช่ SHM
SHM ต้องมีเงื่อนไข a = −ω²x (ความเร่งแปรผันตรงกับการกระจัดแบบทิศตรงข้ามเท่านั้น) จึงจะเรียกว่า SHM ได้

ตัวอย่างระบบที่เป็น SHM ที่พบบ่อยในข้อสอบ ได้แก่ มวลติดสปริง, ลูกตุ้มอย่างง่ายที่แกว่งมุมเล็ก ๆ (θ < 15°) และวัตถุลอยในของเหลว

หัวข้อ 2 · สมการการกระจัด ความเร็ว ความเร่ง
x(t)
สมการทั่วไปของ SHM (แบบที่ใช้สอบจริง)
นิยาม — ฟอร์มมาตรฐาน
โจทย์ SHM ทั่วไป ไม่ได้เริ่มจับเวลาที่จุดสมดุลเสมอไป จึงต้องใส่ เฟสเริ่มต้น φ (phi) เข้าไปในสมการเพื่อรองรับทุกเงื่อนไขเริ่มต้น สมการนี้คือฟอร์มที่ใช้เป็นหลักในการแก้โจทย์และสอบทุกกรณี
x(t) = A cos(ωt + φ)
v(t) = −Aω sin(ωt + φ)
a(t) = −Aω² cos(ωt + φ) = −ω²x
💡 ทำไมถึงใช้ cos เป็นหลัก ไม่ใช่ sin
เป็นแค่ธรรมเนียมการเขียน (convention) เท่านั้น — จริง ๆ แล้ว sin กับ cos คือฟังก์ชันเดียวกันที่เลื่อนเฟส 90° จึงเขียนแทนกันได้เสมอ (cos θ = sin(θ+90°)) อาจารย์แต่ละท่านอาจเริ่มด้วย sin หรือ cos ก็ได้ ไม่ขัดแย้งกัน ขอแค่ นิยาม φ ให้สอดคล้องกับฟังก์ชันที่เลือกใช้
🔎
ที่มา — v(t) และ a(t) จากอนุพันธ์

ได้ v(t) และ a(t) จากการหาอนุพันธ์ของ x(t) เทียบกับเวลาไปเรื่อย ๆ (อนุพันธ์ของ cos คือ −sin, อนุพันธ์ของ −sin คือ −cos)

x(t) = A cos(ωt + φ)   ← ตำแหน่ง
v(t) = dx/dt = −Aω sin(ωt + φ)   ← ความเร็ว
a(t) = dv/dt = −Aω² cos(ωt + φ) = −ω²x   ← ความเร่ง
⚠️ ความสัมพันธ์หลักที่ต้องจำ
a = −ω²x คือ "ลายเซ็น" ของ SHM เสมอ ไม่ว่าจะเขียนสมการด้วย sin หรือ cos ก็ตาม หากพิสูจน์ได้ว่า a = −ω²x แสดงว่าเป็น SHM แน่นอน
🧮
หา A และ φ จากเงื่อนไขเริ่มต้น (x_i, v_i ที่ t = 0)

โจทย์มักให้ตำแหน่งเริ่มต้น x_i และความเร็วเริ่มต้น v_i มาที่เวลา t = 0 ให้แทน t = 0 ในสมการ x(t) และ v(t) แล้วตั้งเป็นระบบสมการ 2 ตัวแปร (A, φ)

ที่ t = 0:
x(0) = A cos φ = x_i   ...(1)
v(0) = −Aω sin φ = v_i   ...(2)
ขั้นตอนแก้สมการ
หา φ: นำ (2) หาร (1) เพื่อกำจัด A ออก
tan φ = −v_i / (ω x_i)

หา A: ยกกำลังสองแล้วบวก (1) กับ (2) โดยจัดรูปก่อน แล้วใช้เอกลักษณ์ sin²+cos²=1
A = √( x_i² + (v_i/ω)² )
ตัวอย่าง (สไตล์ข้อสอบจริง)
วัตถุ SHM มี ω = 5.00 rad/s เริ่มต้นที่ x_i = 5.00 cm, v_i = −0.100 m/s (=−10.0 cm/s) จงหา A และ φ

tan φ = −v_i/(ω x_i) = −(−10.0)/(5.00 × 5.00) = 10.0/25.0 = 0.400
φ = tan⁻¹(0.400) ≈ 0.121π (หรือประมาณ 21.8°)

A = x_i/cos φ = 5.00/cos(0.121π) ≈ 5.00/0.9285 ≈ 5.39 cm
💡 กรณีพิเศษที่พบบ่อย
• ปล่อยจากจุดปลายสุดโดยไม่มีความเร็วต้น (v_i = 0): φ = 0 → x(t) = A cos(ωt)
• เริ่มที่จุดสมดุลเคลื่อนที่ไปทางบวก (x_i = 0, v_i > 0): φ = −90° → x(t) = A cos(ωt−90°) = A sin(ωt)
📈
ความเร็วสูงสุดและความเร่งสูงสุด

ไม่ว่าเฟสเริ่มต้น φ จะเป็นเท่าใด ขนาดสูงสุดของ v และ a จะไม่เปลี่ยน เพราะ φ มีผลแค่ "เลื่อนกราฟ" ไปตามแกนเวลา ไม่ได้เปลี่ยนขนาดแอมพลิจูดของแต่ละกราฟ

v_max = Aω   (เกิดที่จุดสมดุล x = 0)
a_max = Aω²   (เกิดที่จุดปลายสุด x = ±A)
สูตรลัด — ความเร็วที่ตำแหน่งใด ๆ (ไม่ต้องรู้ φ)
v = ω√(A² − x²)
ตัวอย่าง
A = 0.2 m, ω = 5 rad/s ที่ตำแหน่ง x = 0.12 m
v = 5√(0.2² − 0.12²) = 5√(0.04 − 0.0144) = 5√0.0256 = 5(0.16) = 0.8 m/s
📐
ค่าที่ตำแหน่งพิเศษ
ตำแหน่งการกระจัด xความเร็ว vความเร่ง a
จุดสมดุล0v_max = Aω0
จุดปลายสุด (±A)±A0a_max = Aω²
💡 จำง่าย
เร็วสุดที่จุดกึ่งกลาง (สมดุล) เร่งสุดที่จุดปลาย — สลับกันเสมอ ไม่มีทางเกิดพร้อมกัน (ข้อเท็จจริงนี้จริงเสมอไม่ว่า φ จะเป็นเท่าไร)
หัวข้อ 3 · กราฟ x-t, v-t, a-t และความสัมพันธ์เฟส
📈
กราฟการกระจัด ความเร็ว ความเร่ง เทียบเวลา

กราฟด้านล่างวาดกรณี φ = 0 (ปล่อยวัตถุจากจุดปลายสุดโดยไม่มีความเร็วต้น) ซึ่งเป็นกรณีที่นิยมใช้อธิบายในห้องเรียนมากที่สุด

ความสัมพันธ์เฟส
v(t) นำหน้า x(t) อยู่ 90° (π/2 rad) และ a(t) มีเฟสตรงข้ามกับ x(t) อยู่ 180° (π rad) เสมอ
💡 อ่านกราฟให้ไว
เมื่อกราฟ x เป็นศูนย์ (ตัดแกน) กราฟ v จะอยู่ที่ค่าสูงสุดหรือต่ำสุดพอดี และเมื่อกราฟ x อยู่ที่จุดสูงสุด กราฟ a จะอยู่ที่จุดต่ำสุด (สวนทางกันเสมอ)
🔄
กราฟพลังงานเทียบตำแหน่ง

กราฟพลังงานจลน์ (KE) และพลังงานศักย์ (PE) เทียบกับตำแหวน x มีลักษณะเป็นพาราโบลาสวนทางกัน โดยผลรวมคงที่เสมอ (ดูรายละเอียดในหัวข้อ 6)

หัวข้อ 4 · ลูกตุ้มอย่างง่าย (Simple Pendulum)
🕰️
สูตรคาบของลูกตุ้มอย่างง่าย
เงื่อนไข
ลูกตุ้มจะเคลื่อนที่แบบ SHM ได้ก็ต่อเมื่อ แกว่งด้วยมุมเล็ก ๆ (θ ≤ 15°) เท่านั้น เพราะที่มุมเล็กจะประมาณ sin θ ≈ θ (rad) ได้
T = 2π√(L/g)

f = (1/2π)√(g/L)

เมื่อ L คือความยาวเชือก (m) และ g คือความเร่งเนื่องจากแรงโน้มถ่วง (m/s²)

💡 ข้อสังเกตสำคัญ
คาบของลูกตุ้มอย่างง่าย ไม่ขึ้นกับมวลของลูกตุ้ม และไม่ขึ้นกับแอมพลิจูด (มุมแกว่ง) ขึ้นกับความยาวเชือก L และค่า g เท่านั้น
ตัวอย่าง
ลูกตุ้มยาว 2.5 m แกว่งที่ g = 10 m/s²
T = 2π√(2.5/10) = 2π√0.25 = 2π(0.5) = π ≈ 3.14 s
⛰️
ผลของตำแหน่งที่มีต่อคาบ
⚠️ ข้อควรระวัง — เอาลูกตุ้มไปที่อื่น
เนื่องจาก T ∝ 1/√g หากค่า g เปลี่ยน (เช่น นำไปดวงจันทร์ หรือขึ้นที่สูง) คาบจะเปลี่ยนตาม แม้ L เท่าเดิม
ค่า g บนดวงจันทร์ ≈ g โลก/6 → คาบบนดวงจันทร์จะยาวกว่าบนโลกประมาณ √6 ≈ 2.45 เท่า
ตัวอย่างการเทียบอัตราส่วน
ลูกตุ้มเดียวกัน วัดคาบบนโลกได้ T₁ แล้วนำไปแกว่งบนดาวที่มี g₂ = 4g₁
T₂/T₁ = √(g₁/g₂) = √(1/4) = 1/2 → T₂ = T₁/2 (คาบสั้นลงครึ่งหนึ่ง)
หัวข้อ 5 · ระบบมวลติดสปริง
🔩
มวลติดสปริงในแนวราบ/แนวดิ่ง
ที่มา
จากกฎของฮุก แรงในสปริง F = −kx และจากกฎข้อ 2 ของนิวตัน F = ma
ดังนั้น ma = −kx → a = −(k/m)x ซึ่งอยู่ในรูป a = −ω²x
ω² = k/m  →   ω = √(k/m)

T = 2π√(m/k)

f = (1/2π)√(k/m)
💡 ข้อสังเกตสำคัญ
คาบ T ของมวลติดสปริง ไม่ขึ้นกับแอมพลิจูด และไม่ขึ้นกับ g (ไม่ว่าจะแกว่งในแนวราบหรือแนวดิ่งคาบเท่ากัน) ขึ้นกับมวล m และค่าคงตัวสปริง k เท่านั้น
ตัวอย่าง
สปริง k = 200 N/m ผูกมวล 2 kg แล้วดึงให้ยืดออก 5 cm แล้วปล่อย
T = 2π√(2/200) = 2π√0.01 = 2π(0.1) = 0.2π ≈ 0.63 s
A = 0.05 m, v_max = Aω = A√(k/m) = 0.05×10 = 0.5 m/s
🔗
สปริงต่อกันแบบอนุกรมและขนาน

ต่ออนุกรม (Series)

1/k_รวม = 1/k₁ + 1/k₂

แข็งน้อยลง (k รวมลดลง) → แกว่งช้าลง คาบนานขึ้น

ต่อขนาน (Parallel)

k_รวม = k₁ + k₂

แข็งขึ้น (k รวมเพิ่มขึ้น) → แกว่งเร็วขึ้น คาบสั้นลง

หัวข้อ 6 · พลังงานในการเคลื่อนที่แบบฮาร์มอนิก
⚡
พลังงานจลน์และพลังงานศักย์
KE = ½mv² = ½mω²(A² − x²)
PE = ½kx² = ½mω²x²
E_รวม = KE + PE = ½kA² = ½mω²A²  (คงที่ตลอดการเคลื่อนที่)
หลักการอนุรักษ์พลังงาน
พลังงานรวมของระบบ SHM มีค่าคงที่เสมอ ไม่ว่าจะอยู่ตำแหน่งใด — มีเพียงการแลกเปลี่ยนระหว่าง KE และ PE เท่านั้น
ตำแหน่งKEPEE รวม
จุดสมดุล (x=0)สูงสุด0½mω²A²
จุดปลายสุด (x=±A)0สูงสุด½mω²A²
ตัวอย่าง
มวล 0.5 kg ติดสปริง k = 50 N/m แกว่งด้วย A = 0.1 m
E_รวม = ½kA² = ½(50)(0.1²) = ½(50)(0.01) = 0.25 J

ที่ x = 0.06 m: PE = ½kx² = ½(50)(0.0036) = 0.09 J
KE = E_รวม − PE = 0.25 − 0.09 = 0.16 J
📊
กราฟพลังงานเทียบตำแหน่ง x
💡 อ่านกราฟ
กราฟ PE เป็นพาราโบลาหงายมีจุดต่ำสุดที่ x=0 ส่วนกราฟ KE เป็นพาราโบลาคว่ำมีจุดสูงสุดที่ x=0 ผลรวมของทั้งสองเส้นที่ x ใด ๆ จะเท่ากันเสมอ (เท่ากับ E รวม)
หัวข้อ 7 · วงกลมอ้างอิง (Reference Circle)
⭕
SHM คือเงาของการเคลื่อนที่เป็นวงกลม

SHM สามารถมองเป็น เงาฉาย (projection) ของวัตถุที่เคลื่อนที่เป็นวงกลมด้วยอัตราเร็วเชิงมุมคงที่ ω บนเส้นผ่านศูนย์กลาง

ความหมายทางกายภาพของ ω
ω ในสมการ SHM มีค่าเท่ากับ อัตราเร็วเชิงมุม ของวัตถุสมมติที่เคลื่อนที่เป็นวงกลมรัศมี A ด้วยอัตราเร็วเชิงมุมคงที่ — เมื่อฉายเงาลงบนเส้นผ่านศูนย์กลางจะได้ตำแหน่ง x ตรงกับ SHM ทุกประการ
💡 ประโยชน์ของแนวคิดนี้
ใช้อธิบายเฟส (phase) ของ SHM ได้ง่าย เพราะมุม φ ในสมการ x = A cos(ωt + φ) ก็คือมุมเริ่มต้นบนวงกลมอ้างอิงนั่นเอง
หัวข้อ 8 · สรุปสูตรทั้งหมดของ SHM
📐
สูตรพื้นฐาน
ω = 2π/T = 2πf
x = A cos(ωt + φ)  ,   v = −Aω sin(ωt + φ)  ,   a = −Aω² cos(ωt + φ)
tan φ = −v_i/(ω x_i)  ,   A = √(x_i² + (v_i/ω)²)
a = −ω²x
v = ω√(A² − x²)
v_max = Aω  ,   a_max = Aω²
🔩
สูตรระบบเฉพาะ

มวลติดสปริง

T = 2π√(m/k)
ω = √(k/m)

ลูกตุ้มอย่างง่าย

T = 2π√(L/g)
ω = √(g/L)
⚡

E_รวม = ½kA² = ½mω²A²
KE = ½mv² = ½mω²(A² − x²)
PE = ½kx² = ½mω²x²

เทคนิคการวิเคราะห์โจทย์ SHM แบบผสม
💡 ขั้นตอนแก้โจทย์อย่างเป็นระบบ
1) ระบุก่อนว่าเป็นระบบสปริงหรือลูกตุ้ม เพื่อเลือกสูตรคาบที่ถูกต้อง
2) หาค่า ω จากข้อมูลที่ให้ (จาก T, f หรือคำนวณจาก k/m หรือ g/L)
3) ระบุค่า A จากโจทย์ (ระยะดึง/ระยะยืดสูงสุด/มุมแกว่งสูงสุด)
4) เลือกสูตรที่ตรงกับสิ่งที่โจทย์ถาม (ตำแหน่ง ความเร็ว ความเร่ง หรือพลังงาน)
ตัวอย่างโจทย์ผสม
มวล 4 kg ติดสปริง k = 100 N/m วางบนพื้นราบไม่มีความเสียดทาน ดึงให้ยืดออก 0.2 m แล้วปล่อย
(ก) หาคาบ T = 2π√(m/k) = 2π√(4/100) = 2π(0.2) = 0.4π ≈ 1.26 s
(ข) หา v ที่ x = 0.1 m: ω = √(k/m) = 5 rad/s
    v = ω√(A²−x²) = 5√(0.04−0.01) = 5√0.03 ≈ 0.87 m/s
(ค) หา KE ที่ x = 0.1 m โดยใช้พลังงาน:
    E_รวม = ½kA² = ½(100)(0.04) = 2 J
    PE = ½kx² = ½(100)(0.01) = 0.5 J → KE = 2 − 0.5 = 1.5 J
⚠️
กับดักที่พบบ่อยในข้อสอบ
⚠️ กับดัก 1
ห้ามสับสนระหว่าง "ระยะทางที่เคลื่อนที่ได้ใน 1 คาบ" (= 4A) กับ "แอมพลิจูด" (= A)
⚠️ กับดัก 2
มวลติดสปริงในแนวดิ่ง แม้จุดสมดุลจะเลื่อนลงจากตำแหน่งสปริงธรรมชาติ (เพราะน้ำหนักถ่วง) แต่สูตรคาบ T = 2π√(m/k) ยังใช้ได้เหมือนเดิม เพราะแรงโน้มถ่วงเพียงแค่เลื่อนจุดสมดุล ไม่มีผลต่อค่า k หรือ m
⚠️ กับดัก 3
มุมเฟส φ ในสมการ x = A cos(ωt+φ) ต้องพิจารณาจากเงื่อนไขเริ่มต้น (ตำแหน่งและทิศทางความเร็วที่ t=0) อย่างระมัดระวัง โดยใช้ tan φ = −v_i/(ωx_i) มิฉะนั้นจะได้เครื่องหมายผิด
🎯 แบบฝึกหัดเตรียม A-Level — ระดับ 1→3
