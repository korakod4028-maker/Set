การสร้างไฟล์
📄 คำสั่ง touch
touch file.txt สร้าง ไฟล์ว่างเปล่า (Empty File) ขนาด 0 Bytes — ถ้าไฟล์มีอยู่แล้ว จะไม่ลบข้อมูลเดิม แต่จะไปอัปเดต timestamp (mtime/atime) ของไฟล์แทน
touch a b c สร้างไฟล์หลายไฟล์พร้อมกันได้ในคำสั่งเดียว โดยเว้นวรรคคั่นชื่อไฟล์

💡 touch ไม่ได้มีไว้ "สร้างไฟล์" อย่างเดียว — จุดประสงค์จริงคือแก้ไข timestamp ของไฟล์ (ใช้บ่อยในสคริปต์และ build system เช่น Makefile)

🔁 Brace Expansion — สร้างไฟล์จำนวนมาก
touch my{01..100}file สร้างไฟล์ my01file ถึง my100file รวม 100 ไฟล์ ในคำสั่งเดียว — Shell จะขยาย {01..100} เป็นรายการตัวเลขก่อนส่งให้ touch
touch file{1,3,5} ระบุค่าที่ต้องการแบบเจาะจงด้วย comma แทนช่วงตัวเลข → สร้าง file1 file3 file5
mkdir -p proj/{src,bin,doc} Brace Expansion ใช้ได้กับคำสั่งอื่นด้วย ไม่ใช่แค่ touch — สร้าง 3 โฟลเดอร์ย่อยพร้อมกัน

⚠️ ห้ามเว้นวรรคภายใน {...} เช่น {01.. 100} จะทำให้ Brace Expansion ไม่ทำงาน และ Shell จะมองเป็น argument แปลกๆ แทน

Wildcards — ค้นหา/แสดงรายชื่อไฟล์
🔍 * (Asterisk) และ ? (Question Mark)
* แทนอักขระกี่ตัวก็ได้ (หรือไม่มีเลยก็ได้)
ls my*file → หาไฟล์ที่ขึ้นต้นด้วย my ลงท้ายด้วย file ตรงกลางจะมีกี่ตัวอักษรก็ได้
ls try* → แสดงทุกไฟล์ที่ขึ้นต้นด้วย try เช่น try1, try2, try01, tryABC
? แทนอักขระอะไรก็ได้ แต่เจาะจงแค่ 1 ตัวเท่านั้น
ls try? → แสดงเฉพาะ try1 และ try2 (ไม่รวม try01 เพราะมี 2 ตัวอักษรต่อท้าย ไม่ใช่ 1 ตัว)
[abc] Character class — แทนอักขระ 1 ตัวจากกลุ่มที่ระบุ
ls try[12] → ตรงกับ try1 หรือ try2 เท่านั้น
[0-9] Range — ระบุช่วงอักขระ เช่นตัวเลขหรือตัวอักษร
ls file[0-9] → ตรงกับ file0 ถึง file9
รูปแบบความหมายตัวอย่างที่ตรง
*กี่ตัวก็ได้ / ไม่มีก็ได้my*file → myfile, my123file
?เจาะจง 1 ตัวอักษรtry? → try1, try2 (ไม่ใช่ try01)
[abc]1 ตัวจากกลุ่มที่กำหนดtry[12] → try1, try2
[0-9]1 ตัวจากช่วงที่กำหนดfile[0-9] → file0 ... file9
📁 การสร้างไดเรกทอรีด้วย mkdir
mkdir dirname สร้างไดเรกทอรีใหม่ 1 โฟลเดอร์ในตำแหน่งปัจจุบัน
mkdir -p a/b/c Parents — สร้างโฟลเดอร์ซ้อนกันหลายชั้นในคำสั่งเดียว แม้ a และ a/b จะยังไม่มีอยู่ก็ตาม (ถ้าไม่ใส่ -p จะ error ทันทีเพราะ parent directory ไม่มีอยู่จริง)
mkdir dir1 dir2 สร้างหลายโฟลเดอร์พร้อมกันได้ในคำสั่งเดียว
🗑️ การลบไฟล์และไดเรกทอรีด้วย rm
rm try01 ลบไฟล์เดียวแบบระบุชื่อตรงๆ
rm try1 try2 ลบหลายไฟล์พร้อมกัน โดยระบุชื่อคั่นด้วยช่องว่าง
rm testdir/mytest{01..1000} ลบไฟล์เป็นกลุ่มโดยใช้ Brace Expansion ร่วมกับ rm — ลบ mytest01 ถึง mytest1000 ในคำสั่งเดียว
rm -rf testdir ลบทั้งโฟลเดอร์และไฟล์ข้างในทั้งหมดแบบไม่ถามยืนยัน — ดูรายละเอียด flag ด้านล่าง
rmdir emptydir ลบไดเรกทอรีได้เฉพาะกรณีที่ ว่างเปล่าเท่านั้น — ถ้ามีไฟล์ข้างในจะ error ต้องใช้ rm -r แทน
Flagชื่อเต็มความหมาย
-rRecursiveลบลึกลงไปในโฟลเดอร์ย่อยและไฟล์ข้างในทั้งหมด — จำเป็นเมื่อลบโฟลเดอร์
-fForceบังคับลบทันทีโดยไม่ถามยืนยัน แม้ไฟล์จะ read-only
-iInteractiveถามยืนยันก่อนลบทุกไฟล์ — ใช้เพื่อความปลอดภัยแทน -f
-vVerboseแสดงชื่อไฟล์ทุกไฟล์ที่ถูกลบออกมาให้เห็น

🚨 คำสั่งอันตรายที่สุดใน Linux: rm -rf ไม่มีถังขยะ (Recycle Bin) — ลบแล้วลบเลย กู้คืนไม่ได้ ต้องเช็ก path ให้แน่ใจก่อนกด Enter ทุกครั้ง โดยเฉพาะการรันด้วยสิทธิ์ sudo หรือรันจาก root /

✍️ สร้างไฟล์พร้อมใส่ข้อมูลด้วย vim
vim mynewfile touch ไม่ใช่วิธีเดียวในการสร้างไฟล์ — vim เป็น Text Editor ที่เปิด (หรือสร้างใหม่ถ้ายังไม่มี) ไฟล์และให้พิมพ์ข้อความลงไปได้ทันที

💡 ถ้าไฟล์ที่ระบุยังไม่มีอยู่ vim จะสร้างไฟล์ใหม่ให้อัตโนมัติเมื่อบันทึกด้วย :w หรือ :wq — ก่อนบันทึกไฟล์จะยังไม่ถูกสร้างขึ้นจริงบนดิสก์

🔀 3 โหมดหลักของ vim
Normal
Command / Normal Mode โหมดเริ่มต้นเมื่อเปิด vim — ใช้เคลื่อนไหว cursor, ลบ, copy/paste ไม่ใช่การพิมพ์ข้อความ → กด ESC จากโหมดใดๆ เพื่อกลับมาที่นี่
Insert
Insert Mode (โหมดพิมพ์) โหมดสำหรับพิมพ์/แก้ไขข้อความจริง เข้าสู่โหมดนี้ได้หลายวิธี → i = พิมพ์หน้า cursor | a = พิมพ์หลัง cursor | o = เปิดบรรทัดใหม่ด้านล่าง
Command-line
Command-line Mode เข้าสู่โหมดนี้ด้วยการพิมพ์ : จาก Normal Mode — ใช้สั่งบันทึก, ออก, ค้นหา, แทนที่ข้อความ → :wq = save และ quit | :q! = ออกโดยไม่บันทึก
⌨️ คำสั่งพื้นฐานที่ใช้บ่อย
iเข้า Insert Mode เพื่อเริ่มพิมพ์ข้อความ
ESCออกจาก Insert Mode กลับไป Normal Mode — ต้องกดก่อนพิมพ์คำสั่ง : เสมอ
:wWrite — บันทึกไฟล์ (ไม่ออกจากโปรแกรม)
:qQuit — ออกจากโปรแกรม (ถ้ามีการแก้ไขที่ยังไม่บันทึก จะ error)
:wqบันทึกแล้วออก — คำสั่งที่ใช้บ่อยที่สุด (w = write, q = quit)
:q!ออกโดยไม่บันทึก ทิ้งการแก้ไขทั้งหมด (! = force)
ddลบทั้งบรรทัดที่ cursor อยู่ (ใช้ใน Normal Mode)
yy / pyy = copy บรรทัด (yank), p = paste วางบรรทัด
uUndo — ย้อนกลับการแก้ไขล่าสุด

⚠️ มือใหม่ส่วนใหญ่ "ติดอยู่ใน vim" เพราะลืมกด ESC ก่อนพิมพ์ :wq — ถ้าพิมพ์ตอนอยู่ Insert Mode จะกลายเป็นข้อความในไฟล์แทนคำสั่ง

mkdir -p a/b/cสร้างโฟลเดอร์ซ้อนหลายชั้นในคำสั่งเดียว

ls name?Wildcard ? = เจาะจง 1 ตัวอักษร

rm -i fileลบแบบถามยืนยันก่อนทุกครั้ง — ปลอดภัยกว่า -f

💡 Engineer Tips — ใช้งานจริง
→
ก่อนรัน rm -rf ทุกครั้ง ให้รัน ls ที่ path เดียวกันก่อนเพื่อเช็กว่ากำลังจะลบอะไร — เป็นนิสัยที่ Cloud Engineer ทุกคนต้องมี
→
ใช้ rm -i แทน rm -f เมื่อทำงานกับข้อมูลสำคัญ หรือใช้ alias alias rm='rm -i' เพื่อป้องกันการลบผิดพลาด
→
touch มีประโยชน์มากในการ trigger ให้ build tool เช่น make มองว่าไฟล์ถูกแก้ไขใหม่ (อัปเดต mtime) โดยไม่ต้องแก้เนื้อหาจริง
→
Brace Expansion ({01..100}) เป็นฟีเจอร์ของ Shell (bash) ไม่ใช่ของคำสั่ง — ใช้ร่วมกับ touch, mkdir, rm, cp, mv ได้หมด
→
ถ้าติดอยู่ใน vim ไม่รู้จะออกยังไง กด ESC ก่อนเสมอ แล้วพิมพ์ :q! เพื่อออกแบบไม่บันทึก เป็นทางออกฉุกเฉินที่ใช้ได้เสมอ
