ฟังก์ชันคืออะไร?

ฟังก์ชัน (Function) คือ ความสัมพันธ์พิเศษ ที่สมาชิกแต่ละตัวในโดเมนจับคู่กับสมาชิกใน codomain ได้ เพียงหนึ่งตัวเท่านั้น

นิยาม
ฟังก์ชัน f จากเซต A ไปยังเซต B เขียนแทนด้วย f : A → B
คือความสัมพันธ์ที่ทุก x ∈ A มีค่า f(x) ∈ B ค่าเดียวและชัดเจน

✓ เป็นฟังก์ชัน

ทุก input มี output เพียงหนึ่งค่า
เช่น f(x) = x², f(x) = 2x + 1

1 → 1
2 → 4
3 → 9

✗ ไม่เป็นฟังก์ชัน

มี input ที่ให้ output มากกว่าหนึ่งค่า
เช่น y² = x (ถ้า x=4 ได้ y=2 และ y=−2)

4 → 2
4 → −2 ← ผิด!
💡 Vertical Line Test
ลากเส้นตรงขนานแกน y ตัดกราฟ ถ้าตัดมากกว่า 1 จุด → ไม่เป็นฟังก์ชัน
ถ้าตัดได้ อย่างมาก 1 จุด เสมอ → เป็นฟังก์ชัน
🔣

📋
ความสัมพันธ์ vs ฟังก์ชัน

ฟังก์ชันเป็น ความสัมพันธ์ชนิดพิเศษ — ไม่ใช่ทุก Relation จะเป็น Function

Relation: เซตของคู่อันดับ (x, y) ที่ x ∈ A, y ∈ B
Function: Relation ที่ x แต่ละตัวจับคู่กับ y ได้เพียงค่าเดียว
⚠️ ข้อควรระวัง
ค่า y ซ้ำกันได้ (many-to-one เป็น function)
แต่ค่า x ซ้ำกันไม่ได้ (one-to-many ไม่เป็น function)
เช่น {(1,2),(2,2),(3,2)} → ฟังก์ชัน ✓
เช่น {(1,2),(1,3),(2,4)} → ไม่เป็นฟังก์ชัน ✗
หัวข้อ 2 · โดเมน (Domain) และเรนจ์ (Range)
📦
โดเมน (Domain) คือ D_f
นิยาม
โดเมนของ f คือ เซตของค่า x ทั้งหมดที่ฟังก์ชันหาค่าได้ (ไม่ติดขัด)
ถ้าไม่ระบุ โดเมนเป็น ℝ ทั้งหมด ยกเว้นจุดที่ทำให้ฟังก์ชันไม่นิยาม
กฎหาโดเมน — จุดที่ต้องระวัง

1. ตัวส่วนไม่เป็น 0

f(x) = 1/(x−2) → x ≠ 2

D_f = ℝ \ {2}

2. ใต้รากที่สอง ≥ 0

f(x) = √(x−3) → x−3 ≥ 0

D_f = [3, ∞)

3. ใต้รากที่สองและตัวส่วน

f(x) = √(x+1)/(x−2)

x ≥ −1 และ x ≠ 2
D_f = [−1,2)∪(2,∞)

4. log: argument > 0

f(x) = log(x−1) → x−1 > 0

D_f = (1, ∞)
ตัวอย่าง — หาโดเมนของ f(x) = √(4 − x²)
ต้องการให้ 4 − x² ≥ 0
x² ≤ 4
−2 ≤ x ≤ 2
D_f = [−2, 2]
🎯
เรนจ์ (Range) คือ R_f
นิยาม
เรนจ์ของ f คือ เซตของค่า f(x) ทั้งหมดที่เป็นไปได้ เมื่อ x วิ่งอยู่บนโดเมน
⚠️ เรนจ์ ≠ Codomain
Codomain คือเซตเป้าหมายที่กำหนดไว้ (เช่น ℝ)
เรนจ์คือค่า y ที่เกิดขึ้นจริง ซึ่ง R_f ⊆ Codomain เสมอ
เช่น f(x) = x² : codomain = ℝ แต่ R_f = [0, ∞)
ตัวอย่างหาเรนจ์
f(x) = x² + 1, D_f = ℝ
x² ≥ 0 เสมอ → x² + 1 ≥ 1 เสมอ
R_f = [1, ∞)

f(x) = 2x − 3, D_f = ℝ
f เป็นฟังก์ชันเชิงเส้น ค่า y เป็นได้ทุกจำนวนจริง
R_f = ℝ
💡 เทคนิคหาเรนจ์เร็ว
ให้ y = f(x) แล้วแก้สมการหา x ในเทอม y
หา เงื่อนไขของ y ที่ทำให้ x มีค่าอยู่ในโดเมน
เงื่อนไขนั้นคือเรนจ์
ตัวอย่าง — f(x) = (x+1)/(x−2)
ให้ y = (x+1)/(x−2)
y(x−2) = x+1
yx − 2y = x + 1
x(y−1) = 2y + 1
x = (2y+1)/(y−1)
x มีค่าได้ทุกค่าเมื่อ y ≠ 1
R_f = ℝ \ {1}
หัวข้อ 3 · ประเภทของฟังก์ชัน
1️⃣
ฟังก์ชันหนึ่งต่อหนึ่ง (One-to-One / Injective)
นิยาม
f เป็นฟังก์ชัน one-to-one ก็ต่อเมื่อ
x₁ ≠ x₂ ⇒ f(x₁) ≠ f(x₂)
(หรือ f(x₁) = f(x₂) ⇒ x₁ = x₂)
💡 Horizontal Line Test
ลากเส้นตรงขนานแกน x ตัดกราฟ ถ้าตัดได้ อย่างมาก 1 จุด เสมอ → เป็น one-to-one

✓ One-to-One

f(x) = 2x + 3
f(x) = x³
f(x) = eˣ

✗ ไม่ใช่ One-to-One

f(x) = x²
f(x) = |x|
f(x) = sin(x)
↠
ฟังก์ชันทั่วถึง (Onto / Surjective)
นิยาม
f : A → B เป็น onto ก็ต่อเมื่อ R_f = B
คือทุก y ∈ B มี x ∈ A ที่ทำให้ f(x) = y
ตัวอย่าง
f : ℝ → ℝ, f(x) = 2x + 1 เป็น onto เพราะทุก y ∈ ℝ
มี x = (y−1)/2 ∈ ℝ ที่ทำให้ f(x) = y ✓

f : ℝ → ℝ, f(x) = x² ไม่เป็น onto เพราะ y = −1 ไม่มี x จริงที่ทำให้ f(x) = −1
⟷
ฟังก์ชันหนึ่งต่อหนึ่งและทั่วถึง (Bijective)
นิยาม
f เป็น bijection ก็ต่อเมื่อ f เป็น one-to-one และ onto พร้อมกัน
สำคัญมาก: ฟังก์ชันผกผัน f⁻¹ มีได้ก็ต่อเมื่อ f เป็น bijection

สรุปประเภทฟังก์ชัน

ประเภทOne-to-oneOnto
Injective✓✗
Surjective✗✓
Bijective✓✓

ตัวอย่าง Bijection

f : ℝ → ℝ
f(x) = 3x − 5
(เชิงเส้น slope ≠ 0)

one-to-one ✓ และ onto ✓

📊
ฟังก์ชันคู่และฟังก์ชันคี่
นิยาม
ฟังก์ชันคู่ (Even Function): f(−x) = f(x) สำหรับทุก x ∈ D_f
กราฟสมมาตรกับแกน y

ฟังก์ชันคี่ (Odd Function): f(−x) = −f(x) สำหรับทุก x ∈ D_f
กราฟสมมาตรกับจุดกำเนิด (0,0)

Even Functions

f(x) = x²
f(x) = x⁴
f(x) = |x|
f(x) = cos(x)

Odd Functions

f(x) = x
f(x) = x³
f(x) = sin(x)
f(x) = 1/x
ตัวอย่าง — ตรวจสอบ f(x) = x³ − x
f(−x) = (−x)³ − (−x) = −x³ + x = −(x³ − x) = −f(x)
∴ f(x) = x³ − x เป็น ฟังก์ชันคี่ ✓
หัวข้อ 4 · การกระทำเชิงพีชคณิตของฟังก์ชัน
➕
การบวก ลบ คูณ หารฟังก์ชัน

ถ้า f และ g มีโดเมนร่วมกัน สามารถนิยามฟังก์ชันใหม่ได้ดังนี้

(f + g)(x) = f(x) + g(x)
(f − g)(x) = f(x) − g(x)
(f · g)(x) = f(x) · g(x)
(f/g)(x) = f(x)/g(x) เมื่อ g(x) ≠ 0
โดเมนของฟังก์ชันที่ได้
D_(f+g) = D_(f−g) = D_(f·g) = D_f ∩ D_g
D_(f/g) = D_f ∩ D_g ลบค่า x ที่ทำให้ g(x) = 0 ออก
ตัวอย่าง
ให้ f(x) = √x และ g(x) = x − 3
D_f = [0,∞), D_g = ℝ, D_f ∩ D_g = [0,∞)

(f + g)(x) = √x + x − 3, D = [0,∞)
(f/g)(x) = √x/(x−3), D = [0,∞) \ {3} = [0,3)∪(3,∞)
📏
ค่าสัมบูรณ์ของฟังก์ชัน |f(x)|
นิยาม
|f(x)| = f(x) เมื่อ f(x) ≥ 0
|f(x)| = −f(x) เมื่อ f(x) < 0

กราฟ y = |f(x)| ได้จากการ พลิกส่วนที่ต่ำกว่าแกน x ขึ้นมาเหนือแกน x

ตัวอย่าง — y = |x − 2|
y = x − 2 เมื่อ x ≥ 2
y = −(x−2) = 2 − x เมื่อ x < 2
กราฟรูป V โดยจุดยอดอยู่ที่ (2, 0)
⚠️ สมการที่มีค่าสัมบูรณ์
|f(x)| = k (k > 0) → f(x) = k หรือ f(x) = −k
|f(x)| = k (k < 0) → ไม่มีคำตอบ
|f(x)| < k (k > 0) → −k < f(x) < k
หัวข้อ 5 · ฟังก์ชันผกผัน (Inverse Function)
🔄
นิยามฟังก์ชันผกผัน f⁻¹
นิยาม
ถ้า f : A → B เป็น bijection แล้ว f⁻¹ : B → A นิยามโดย
f⁻¹(y) = x ก็ต่อเมื่อ f(x) = y
⚠️ สำคัญมาก — เงื่อนไขมีผกผัน
f มีผกผันได้ก็ต่อเมื่อ f เป็น bijection (one-to-one และ onto)
ถ้า f ไม่ใช่ one-to-one ต้องจำกัดโดเมนก่อน เช่น f(x) = x², x ≥ 0
ตัวอย่าง — หา f⁻¹ ของ f(x) = 2x + 5
ขั้นที่ 1: ให้ y = 2x + 5
ขั้นที่ 2: แก้หา x: x = (y − 5)/2
ขั้นที่ 3: สลับตัวแปร: f⁻¹(x) = (x − 5)/2

ตรวจสอบ: f(f⁻¹(x)) = 2·(x−5)/2 + 5 = (x−5) + 5 = x ✓
💡 วิธีหาฟังก์ชันผกผัน 3 ขั้นตอน
1. ให้ y = f(x)
2. แก้สมการหา x ในเทอม y
3. เขียน f⁻¹(x) โดยเปลี่ยน y เป็น x
📐
สมบัติของฟังก์ชันผกผัน
f(f⁻¹(x)) = x สำหรับทุก x ∈ D_{f⁻¹}
f⁻¹(f(x)) = x สำหรับทุก x ∈ D_f

D_{f⁻¹} = R_f
R_{f⁻¹} = D_f
กราฟของฟังก์ชันผกผัน
กราฟ y = f⁻¹(x) ได้จากการ สะท้อนกราฟ y = f(x) ผ่านเส้น y = x
(สลับแกน x และ y)
⚠️ f⁻¹(x) ≠ 1/f(x)
f⁻¹ คือ inverse function (ฟังก์ชันผกผัน)
1/f(x) คือ reciprocal (ส่วนกลับ) ซึ่งต่างกันโดยสิ้นเชิง!
ตัวอย่าง — f(x) = (3x−1)/(x+2)
ให้ y = (3x−1)/(x+2)
y(x+2) = 3x−1
yx + 2y = 3x − 1
yx − 3x = −2y − 1
x(y−3) = −2y − 1
x = (−2y−1)/(y−3) = (2y+1)/(3−y)
f⁻¹(x) = (2x+1)/(3−x), x ≠ 3
หัวข้อ 6 · ฟังก์ชันประกอบ (Composite Function)
🔗
นิยามฟังก์ชันประกอบ g∘f
นิยาม
(g∘f)(x) = g(f(x))
อ่านว่า "g compose f" หรือ "g ประกอบ f"
ทำ f ก่อน แล้วค่อยทำ g
โดเมนของ g∘f
D_{g∘f} = {x ∈ D_f | f(x) ∈ D_g}
คือ x ต้องอยู่ใน D_f และ f(x) ต้องอยู่ใน D_g ด้วย
ตัวอย่าง
ให้ f(x) = 2x + 1 และ g(x) = x²

(g∘f)(x) = g(f(x)) = g(2x+1) = (2x+1)²= 4x² + 4x + 1
(f∘g)(x) = f(g(x)) = f(x²) = 2x² + 1

g∘f ≠ f∘g โดยทั่วไป (การประกอบไม่สลับที่ได้!)
⚠️ ลำดับการประกอบสำคัญมาก
(g∘f)(x) แปลว่า "ใส่ x เข้า f ก่อน ผลที่ได้ค่อยใส่เข้า g"
อ่านจากขวาไปซ้าย: g∘f → ทำ f ก่อน ทำ g ทีหลัง
🔁
ฟังก์ชันผกผันกับฟังก์ชันประกอบ
f∘f⁻¹ = I (ฟังก์ชันเอกลักษณ์)
f⁻¹∘f = I
(g∘f)⁻¹ = f⁻¹∘g⁻¹
ตัวอย่าง — ใช้ผกผันเพื่อตรวจสอบ
f(x) = 3x − 2, f⁻¹(x) = (x+2)/3

(f∘f⁻¹)(x) = f((x+2)/3) = 3·(x+2)/3 − 2 = (x+2) − 2 = x ✓
(f⁻¹∘f)(x) = f⁻¹(3x−2) = ((3x−2)+2)/3 = 3x/3 = x ✓
💡 เทคนิค A-Level — หา f จากฟังก์ชันประกอบ
ถ้าโจทย์ให้ g∘f และ g แล้วถาม f:
f(x) = g⁻¹((g∘f)(x))

ถ้าให้ f∘g และ f แล้วถาม g:
g(x) = f⁻¹((f∘g)(x))
ตัวอย่าง — หา f เมื่อ (f∘g)(x) = 4x² − 1 และ g(x) = 2x
(f∘g)(x) = f(g(x)) = f(2x) = 4x² − 1
ให้ u = 2x → x = u/2
f(u) = 4(u/2)² − 1 = 4·u²/4 − 1 = u² − 1
f(x) = x² − 1 ✓
หัวข้อ 7 · กราฟของฟังก์ชัน
📈
การเลื่อนและสะท้อนกราฟ

จากกราฟ y = f(x) สามารถสร้างกราฟใหม่ได้โดยการแปลง

การแปลงสมการใหม่ผลต่อกราฟ
เลื่อนขึ้น ky = f(x) + kขยับขึ้น k หน่วย
เลื่อนลง ky = f(x) − kขยับลง k หน่วย
เลื่อนขวา hy = f(x − h)ขยับขวา h หน่วย
เลื่อนซ้าย hy = f(x + h)ขยับซ้าย h หน่วย
สะท้อนแกน xy = −f(x)พลิกตามแกน x
สะท้อนแกน yy = f(−x)พลิกตามแกน y
ยืดแนวตั้ง a เท่าy = a·f(x)สูงขึ้น a เท่า (a>1)
ยืดแนวนอน b เท่าy = f(x/b)กว้างขึ้น b เท่า (b>1)
⚠️ เลื่อนซ้ายขวา — ตรงข้ามกับที่คาด!
y = f(x − 2) เลื่อนกราฟขวา 2 หน่วย (ไม่ใช่ซ้าย)
y = f(x + 3) เลื่อนกราฟซ้าย 3 หน่วย (ไม่ใช่ขวา)
ตัวอย่าง — y = (x−2)² + 3
เริ่มจาก y = x²
→ เลื่อนขวา 2: y = (x−2)²
→ เลื่อนขึ้น 3: y = (x−2)² + 3
จุดยอด (vertex) อยู่ที่ (2, 3)
📊
กราฟฟังก์ชันพื้นฐาน

y = x (เชิงเส้น)

เส้นตรงผ่านจุดกำเนิด slope = 1
D = ℝ, R = ℝ

y = x² (พาราโบลา)

หน้าตาเป็น U เปิดขึ้น
D = ℝ, R = [0,∞)

y = √x

แขนงครึ่งบนของ x = y²
D = [0,∞), R = [0,∞)

y = 1/x (ไฮเปอร์โบลา)

สองกิ่งในควอดรันต์ที่ 1, 3
D = ℝ\{0}, R = ℝ\{0}

y = |x|

รูป V จุดยอดที่ origin
D = ℝ, R = [0,∞)

y = x³

ผ่านจุดกำเนิด one-to-one
D = ℝ, R = ℝ

ฟังก์ชันขั้นบันได (Step Function) และ Floor/Ceiling
ฟังก์ชัน Floor ⌊x⌋
⌊x⌋ = จำนวนเต็มที่มากที่สุดที่ไม่เกิน x (ปัดลง)
⌊3.7⌋ = 3, ⌊−2.3⌋ = −3, ⌊5⌋ = 5
ฟังก์ชัน Ceiling ⌈x⌉
⌈x⌉ = จำนวนเต็มที่น้อยที่สุดที่ไม่ต่ำกว่า x (ปัดขึ้น)
⌈3.2⌉ = 4, ⌈−2.7⌉ = −2, ⌈5⌉ = 5
ข้อสังเกตสำคัญ
⌊x⌋ = ⌈x⌉ ก็ต่อเมื่อ x เป็นจำนวนเต็ม
⌊x⌋ + 1 = ⌈x⌉ เมื่อ x ไม่ใช่จำนวนเต็ม
n ≤ x < n+1 → ⌊x⌋ = n
