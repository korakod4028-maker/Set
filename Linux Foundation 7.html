📚 Command Reference 🔀 cp vs mv 📋 Cheat Sheet ✏️ Quiz 13 ข้อ
Copying Files
📄 คำสั่ง cp (Copy)
cp file1 dir/ คัดลอกไฟล์ ไปยังโฟลเดอร์ปลายทาง — ไฟล์ต้นฉบับยังอยู่เหมือนเดิม
cp file1 dir/newname คัดลอก + เปลี่ยนชื่อ ในคำสั่งเดียว — ไฟล์ปลายทางจะชื่อ newname
cp f1 f2 f3 dir/ คัดลอกหลายไฟล์พร้อมกัน — อาร์กิวเมนต์ตัวสุดท้ายต้องเป็นโฟลเดอร์ปลายทางเสมอ
cp -R srcdir newdir Recursive — คัดลอกทั้งโฟลเดอร์ ต้องใส่ -R เสมอ มิฉะนั้น cp จะไม่คัดลอกโฟลเดอร์เลย

⚠️ กับดักข้อสอบ: ลืมใส่ -R ตอน cp โฟลเดอร์ = คำสั่งจะ error หรือข้ามโฟลเดอร์นั้นไปเฉยๆ

🎯 Wildcards — ตัวช่วยเลือกไฟล์แบบกลุ่ม
? แทนอักขระ 1 ตัวเท่านั้น
cp my?file dir/ จับคู่ my1file, myafile แต่ไม่จับ my12file
* แทนอักขระกี่ตัวก็ได้ หรือไม่มีเลยก็ได้
cp three* dir/ คัดลอกทุกไฟล์ที่ขึ้นต้นด้วย three

ผสม * และ ? ในคำสั่งเดียวกันได้ เช่น log*.txt หรือ file?.* เพื่อคุมรูปแบบให้แม่นยำขึ้น

Moving Files
🚚 คำสั่ง mv (Move)
mv file1 dir/ ย้ายไฟล์ ไปยังโฟลเดอร์ปลายทาง — ไฟล์ต้นฉบับหายไปจากที่เดิม
mv file1 dir/newname ย้าย + เปลี่ยนชื่อ ในคำสั่งเดียว
mv olddir newdir เปลี่ยนชื่อโฟลเดอร์ — ใช้ได้เมื่อ newdir ยังไม่มีอยู่จริงในระบบ
mv dir1 dir2 ถ้า dir2 มีอยู่แล้ว — dir1 ทั้งโฟลเดอร์จะถูกย้ายไปซ้อนอยู่ข้างใน dir2

💚 ข้อดีของ mv: ย้ายโฟลเดอร์ได้ทันที ไม่ต้องใส่ -R เหมือนคำสั่ง cp

⚠️ mv ทับไฟล์ปลายทางที่ชื่อซ้ำกันโดยไม่ถามยืนยัน (ในหลาย distro) — ใช้ mv -i เพื่อให้ระบบถามก่อนเขียนทับ

Extra Commands
🛠️ คำสั่งและเทคนิคเสริม
tree [dir]แสดงโครงสร้างไฟล์/โฟลเดอร์แบบกิ่งไม้ (Recursive) — เหมาะใช้ตรวจผลลัพธ์หลัง cp/mv
clearล้างหน้าจอ Terminal ให้ว่างเปล่า (ไม่ลบ history — กด Arrow Up ย้อนดูคำสั่งเก่าได้)
cat f1 > f2Redirection — อ่านเนื้อหาจาก f1 แล้วเขียนทับลงใน f2 (คล้ายคัดลอกเนื้อหา แต่ไม่ใช่คำสั่ง cp โดยตรง)
diff f1 f2เปรียบเทียบเนื้อหาสองไฟล์ว่าต่างกันตรงไหน

⚠️ cat f1 > f2 เขียนทับไฟล์ปลายทางทั้งหมดโดยไม่ถาม ถ้าต้องการต่อท้ายแทนการเขียนทับ ให้ใช้ >> แทน

จำให้แม่น: ถ้ารัน diff แล้วหน้าจอไม่มีข้อความใดๆ เลย (No output) แปลว่าไฟล์ทั้งสองมีเนื้อหาเหมือนกัน 100% — จุดนี้ข้อสอบชอบออกบ่อย

💡 Engineer Tips — ใช้งานจริง
→
ใช้ cp -i / mv -i บน Production เสมอ เพื่อให้ระบบถามยืนยันก่อนเขียนทับไฟล์ — ป้องกันข้อมูลหายจากการพิมพ์ผิด
→
ใช้ cp -v / mv -v (verbose) เพื่อดูว่ากำลังคัดลอก/ย้ายไฟล์ไหนอยู่ระหว่างทำงาน
→
cp -p คงค่า permission, owner, timestamp เดิมไว้ — สำคัญมากตอน deploy ไฟล์ config บนเซิร์ฟเวอร์จริง
→
cp -u คัดลอกเฉพาะไฟล์ที่ใหม่กว่าไฟล์ปลายทาง หรือปลายทางยังไม่มีไฟล์นั้น
→
ใช้ mkdir -p path/to/dir เตรียมโฟลเดอร์ปลายทางซ้อนหลายชั้นก่อน cp/mv ในคำสั่งเดียว
→
งานจริงย้ายไฟล์ข้ามเครื่อง ให้ต่อยอดไปใช้ scp หรือ rsync -av src/ dest/ ซึ่งทรงพลังกว่า cp ธรรมดามาก
⚖️ ตารางเปรียบเทียบ cp vs mv
ประเด็นcpmv
ต้นฉบับยังอยู่เหมือนเดิมหายไปจากตำแหน่งเดิม
คัดลอก/ย้ายโฟลเดอร์ต้องใส่ -R เสมอย้ายได้ทันที ไม่ต้องใส่ -R
เปลี่ยนชื่อได้ (ตอนคัดลอก)ได้ (ใช้งานหลักอย่างหนึ่ง)
ปลายทางมีอยู่แล้วต้นทางซ้อนเข้าไปข้างในต้นทางซ้อนเข้าไปข้างใน (เหมือนกัน)
📁 พฤติกรรมเมื่อโฟลเดอร์ปลายทาง "มี" หรือ "ไม่มี" อยู่แล้ว
cp -R src newdirกรณีตัวอย่าง — src มีไฟล์ a.txt อยู่ข้างใน
✅ newdir ยังไม่มีอยู่
newdir/
└── a.txt
⚠️ newdir มีอยู่แล้ว
newdir/
└── src/
    └── a.txt

⚠️ จุดที่สับสนบ่อยที่สุด: ถ้าปลายทางมีโฟลเดอร์ชื่อเดียวกันอยู่แล้ว ผลลัพธ์จะซ้อนลึกลงไปอีกชั้น ไม่ใช่การรวมเนื้อหาแบบตรงๆ ให้ตรวจสอบด้วย ls หรือ tree ก่อนรันคำสั่งเสมอ

กติกาเดียวกันนี้ใช้กับ mv dir1 dir2 ด้วย — ถ้า dir2 มีอยู่แล้ว dir1 จะถูกย้ายไปซ้อนข้างใน กลายเป็น dir2/dir1/...

📋 Cheat Sheet ฉบับสมบูรณ์
cp f1 dir/คัดลอกไฟล์ไปยังโฟลเดอร์ปลายทาง
cp f1 dir/newคัดลอก + เปลี่ยนชื่อในคำสั่งเดียว
cp f1 f2 f3 dir/คัดลอกหลายไฟล์ — ตัวสุดท้ายต้องเป็นโฟลเดอร์
cp -R src newRecursive คัดลอกทั้งโฟลเดอร์
cp -iถามยืนยันก่อนเขียนทับ (interactive)
cp -vแสดงผล verbose ระหว่างคัดลอก
cp -pคงค่า permission/owner/timestamp เดิม
cp -uคัดลอกเฉพาะไฟล์ที่ใหม่กว่าปลายทาง
mv f1 dir/ย้ายไฟล์ — ต้นฉบับหายจากที่เดิม
mv old newเปลี่ยนชื่อไฟล์/โฟลเดอร์ (new ยังไม่มีอยู่)
mv -iถามยืนยันก่อนเขียนทับ
?Wildcard แทนอักขระ 1 ตัว
*Wildcard แทนอักขระกี่ตัวก็ได้ / ไม่มีก็ได้
tree [dir]แสดงโครงสร้างไฟล์แบบกิ่งไม้ (Recursive)
clearล้างหน้าจอ Terminal
cat f1 > f2เขียนทับเนื้อหา f1 ลงใน f2 (Redirection)
cat f1 >> f2ต่อท้ายเนื้อหา f1 เข้าไปใน f2
