Host, Client & Server

💻
Host คืออะไร?
อุปกรณ์ทุกชนิดที่เชื่อมต่อกับเครือข่ายและสามารถ ส่ง (Send) หรือ รับข้อมูล (Receive) ได้ มี IP Address เพื่อระบุตัวตน
= End Device = Node
📦
ตัวอย่าง Host
Computer · Laptop · Smartphone · Tablet · Printer · Server · IP Camera · Smart TV · IP Phone
ทุกอย่างที่ต่อ Network ได้
🔑 Cisco Exam Key Points — Host
01Host = อุปกรณ์ที่เชื่อมต่อเครือข่ายและส่ง–รับข้อมูลได้
02หน้าที่หลักของ End Device: Originate Data และ Interface Between Humans & Network
03ทุก Host มี IP Address ใช้ระบุตัวตนในเครือข่าย

2.0–2.4

Network Devices & Their Roles

🔀
Router
เชื่อมต่อ เครือข่ายต่างวง เข้าหากัน (LAN ↔ Internet) เลือกเส้นทางที่ดีที่สุดสำหรับข้อมูล (Best Path)
Layer 3 — Routes Between Networks
🔌
Switch
เชื่อมอุปกรณ์ ภายใน LAN เดียวกัน ส่งข้อมูลตาม MAC Address ไม่ broadcast ทุก port
Layer 2 — LAN Central Hub
📶
Wireless Access Point (AP)
สร้างและกระจาย Wi-Fi Signal ให้อุปกรณ์ไร้สายเชื่อมต่อเครือข่าย — เชื่อมต่อกับ Switch เพื่อเข้า LAN
Wireless Bridge
🛡️
Firewall
กรองและควบคุมการเข้าถึงเครือข่าย — อนุญาต/ปฏิเสธ Traffic ตาม Rule ป้องกัน Hacker
Security — Permit / Deny
🏠
Integrated Router
Router ตามบ้านที่รวม Router + Switch + Wireless AP + DHCP + NAT + Firewall ไว้เครื่องเดียว
All-in-One Home Device
📠
Modem
แปลงสัญญาณดิจิทัลเป็นสัญญาณที่ ISP ใช้ (และกลับกัน) — Cable Modem, DSL Modem, Fiber ONT
Signal Conversion
Device Layer Primary Role Connects Key Feature
Router Layer 3 Route between networks LAN ↔ WAN/Internet IP Routing, NAT
Switch Layer 2 Forward frames in LAN Devices in same LAN MAC Address Table
Access Point Layer 2 Wireless connectivity Wi-Fi devices ↔ LAN SSID, WPA3
Firewall Layer 3–7 Security filtering Inside ↔ Outside ACL, Stateful Inspection
Modem Layer 1 Signal conversion Home Network ↔ ISP Modulation/Demodulation

2.3

ISP & Internet Connectivity

🌍
ISP คืออะไร?
Internet Service Provider — ผู้ให้บริการอินเทอร์เน็ต เชื่อมบ้าน/บริษัทเข้าสู่ Internet ตัวอย่างไทย: AIS Fibre, True Online, 3BB, NT
🦴
Internet Backbone
โครงข่ายหลักที่เชื่อม ISP ทั่วโลกเข้าด้วยกัน ใช้ Fiber Optic เป็นหลัก ทั้งใต้ดินและใต้ทะเล
วิธีเชื่อมต่อ สื่อกลาง ความเร็ว Always-On จุดเด่น ข้อจำกัด
🔵 Fiber Optic Fiber Optic Cable สูงสุด (Gbps) ✓ เร็ว เสถียร Latency ต่ำ ให้บริการเฉพาะพื้นที่มีโครงข่าย
📺 Cable Coaxial Cable สูง (100M–1G) ✓ ใช้สายเคเบิลทีวีเดิม ความเร็วลดเมื่อ User แน่น
📞 DSL Telephone Line ปานกลาง ✓ ใช้โทรศัพท์พร้อมเน็ตได้ ไกล Central Office = ช้า
📱 Cellular 4G / 5G Tower สูง (5G) ✓ ใช้งานได้ทุกที่มีสัญญาณ จำกัด Data ตามแพ็กเกจ
🛰️ Satellite ดาวเทียม + Dish ปานกลาง ✓ ใช้พื้นที่ห่างไกลได้ ค่าติดตั้งสูง ต้องมี LOS
☎️ Dial-up Telephone Line ต่ำมาก (56Kbps) ✗ ราคาถูก ช้ามาก ต้องหมุนโทรก่อน
📞 DSL — การแบ่งช่องสัญญาณ
