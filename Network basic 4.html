Category 5e (UTP)

สายทองแดง 4 คู่บิดเกลียว (8 เส้น) ราคาถูก รองรับ 1 Gbps ระยะ ~100 เมตร ใช้หัวต่อ RJ-45

📺

Coaxial Cable

ตัวนำกลาง + ฉนวน + ชั้นโลหะป้องกันสัญญาณรบกวน ใช้กับ Cable TV และอินเทอร์เน็ตบางระบบ

💡

Fiber-Optic

ส่งข้อมูลด้วยแสง เร็วมาก ระยะไกล ไม่โดน EMI รบกวน ใช้เป็น Backbone / ISP

ทำไมสาย UTP ต้องบิดเกลียว?
ลด EMI (Electromagnetic Interference) และ Crosstalk (สัญญาณรบกวนระหว่างคู่สาย)
4.3
Wireless Networks
มาตรฐาน IEEE 802.11, SSID, Network Mode และความปลอดภัย
IEEE

สร้างมาตรฐาน

กำหนดมาตรฐาน 802.3 (Ethernet) และ 802.11 (Wi-Fi)

Wi-Fi Alliance

ทดสอบอุปกรณ์

ทดสอบและรับรองว่าอุปกรณ์จากหลายผู้ผลิตใช้งานร่วมกันได้ (Wi-Fi Certified)

มาตรฐานชื่อเล่นความถี่จุดเด่น
802.11b—2.4 GHzความเร็วต่ำ (รุ่นเก่า)
802.11g—2.4 GHzเร็วกว่า b
802.11nWi-Fi 42.4/5 GHzใช้ MIMO เร็วขึ้น
802.11acWi-Fi 55 GHzความเร็วสูง
802.11axWi-Fi 62.4/5 GHzรองรับผู้ใช้จำนวนมาก
🏷️

SSID

  • Service Set Identifier = ชื่อเครือข่าย Wi-Fi
  • สูงสุด 32 ตัวอักษร
  • Case-sensitive (ตัวเล็ก/ใหญ่ต่างกัน)
  • ไม่ควรใช้ยี่ห้อ/รุ่น Router เป็นชื่อ
🎚️

Network Mode

  • Single Standard = รองรับอุปกรณ์บางรุ่นเท่านั้น
  • Mixed Mode = รองรับหลายมาตรฐานพร้อมกัน
  • Exam tip: มีอุปกรณ์หลายมาตรฐาน → เลือก Mixed Mode เสมอ
🚫 ซ่อน SSID ≠ ปลอดภัย
การปิด SSID Broadcast ช่วยลดการเชื่อมต่อโดยบังเอิญเท่านั้น เครื่องมือวิเคราะห์เครือข่ายยังตรวจจับได้ ต้องใช้ WPA2/WPA3 ร่วมด้วยเสมอ
มาตรฐานความปลอดภัยสถานะ
WEPล้าสมัย ถูกเจาะได้ง่าย — ไม่ควรใช้
WPAดีกว่า WEP แต่ล้าสมัยแล้ว
WPA2 Personalมาตรฐานหลักสำหรับบ้านทั่วไป
WPA3 Personalปลอดภัยที่สุดในปัจจุบัน (ถ้าอุปกรณ์รองรับ)

Home Networking — Comprehensive Review
ข้อดีของ WLAN, MAC Filtering, Guest Network และ Wired vs Wireless

🚶 Mobility

ใช้งานได้ทุกที่ในระยะสัญญาณ

📈 Scalability

เพิ่มอุปกรณ์ใหม่ได้ง่าย

🔧 Flexibility

ย้ายอุปกรณ์/จัดผังห้องใหม่ได้สะดวก

💰 Cost Savings

ไม่ต้องเดินสาย LAN ทุกห้อง

⚡ Reduced Install Time

ติดตั้งเร็วกว่าการเดินสาย

🏚️ Reliability

เหมาะกับพื้นที่เดินสายยาก เช่น อาคารเก่า

MAC Address Filtering เพิ่มการควบคุมการเข้าถึงได้ระดับหนึ่ง แต่ MAC Address สามารถปลอมแปลง (Spoofing) ได้ จึงไม่ควรใช้เป็นมาตรการหลัก ต้องใช้ร่วมกับ WPA2/WPA3 เสมอ
👥 Guest Network
แยกผู้มาเยือนออกจากอุปกรณ์หลัก — แขกใช้อินเทอร์เน็ตได้ แต่เข้าไม่ถึง Printer, NAS, PC ภายในบ้าน
Wired (Ethernet)

เสถียรกว่า

Latency ต่ำ ไม่ถูกรบกวนง่าย เหมาะกับ Server และเกมที่ต้องการความเสถียร

Wireless (Wi-Fi)

สะดวกกว่า

Latency สูงกว่าเล็กน้อย อาจถูกรบกวนจากสิ่งแวดล้อม เหมาะกับมือถือ/โน้ตบุ๊ก
