1 · Big Picture

Host ตัดสินใจส่ง Packet อย่างไร

IP + Subnet Mask ของตัวเอง → เทียบกับ Destination IP เครือข่ายเดียวกัน → ARP หา MAC ปลายทาง → ส่ง Frame ตรงผ่าน Switch คนละเครือข่าย → ARP หา MAC ของ Default Gateway → Router ส่งต่อทีละ Hop
🔧 แก้จากต้นฉบับ: ผู้ตัดสินว่าปลายทางอยู่ใน LAN หรือไม่คือ Host ต้นทาง ไม่ใช่ Router (Module 12.3 เขียนว่า "Router รู้อย่างไร")

3 · Gateway · MAC · ARP

Default Gateway

IP ของ Router Interface ที่อยู่เครือข่ายเดียวกับ Host · ตั้งผิด = คุยใน LAN ได้ แต่ออกนอก Network ไม่ได้

ARP

รู้ IP แต่ไม่รู้ MAC → ส่ง Broadcast "Who has x.x.x.x?" → เจ้าของตอบ Unicast กลับ แล้วเก็บใน ARP Cache ➕

Switch ➕

เรียน Source MAC → ใส่ MAC Table · ปลายทางที่ไม่รู้จักหรือ Broadcast จะ Flood ออกทุก Port

6 · IPv6
128 bits · Hex · 8 Hextet | Rule 1: ตัด 0 นำหน้า | Rule 2: :: แทน 0 ติดกัน (ใช้ได้ครั้งเดียว) 2001:0DB8:0000:AB00:0000:0000:0000:1234 → 2001:DB8:0:AB00::1234 2001:db8:0:0:ab00:0:0:0 → 2001:db8:0:0:ab00::
🔧 แก้/เติม: ให้ใช้ :: กับกลุ่มศูนย์ที่ ยาวที่สุด (เท่ากัน เลือกซ้ายสุด) · IPv6 ไม่มี Broadcast ใช้ Multicast · ไม่ใช้ ARP แต่ใช้ ICMPv6 Neighbor Discovery · Link-local fe80::/10, Global 2000::/3 ➕
อยู่ร่วมกัน: Dual-stack (ใช้คู่กัน) · Tunneling (IPv6 ใน IPv4) · Translation (NAT64)
