🧭 ภาพรวม

นิยาม — ปฏิยานุพันธ์
F เป็นปฏิยานุพันธ์ของ f ถ้า F′(x) = f(x) ทุก x ในโดเมน
∫ f(x) dx = F(x) + C (ปริพันธ์ไม่จำกัดเขต)

∫ = เครื่องหมายปริพันธ์ · f(x) = ตัวถูกปริพันธ์ (integrand) · dx = ตัวแปรที่ปริพันธ์ · C = ค่าคงตัว

ปริพันธ์จำกัดเขต = พื้นที่ใต้กราฟ

แบ่งช่วง [a, b] เป็นแท่งสี่เหลี่ยมกว้าง Δx สูง yk แล้วรวมพื้นที่ เมื่อ Δx → 0 ได้ปริพันธ์จำกัดเขต

A ≈ Σ yk·Δx
∫ab f(x) dx = limΔx→0 Σ f(xk)·Δx
ต่างกันตรงไหน
ไม่จำกัดเขต → ได้ ฟังก์ชัน + C  |  จำกัดเขต → ได้ ตัวเลข (ไม่มี C)

🔁 การแทนค่า (u-substitution)

ขั้นตอน
1) เลือก u = ส่วน "ข้างใน" (ในราก/ในวงเล็บ/ตัวส่วน) ที่อนุพันธ์ของมันปรากฏอยู่ด้วย
2) หา du = u′ dx
3) เขียนอินทิกรัลใหม่เป็น ∫ … du แล้วอินทิเกรต
4) แทน u กลับเป็น x
ตัวอย่าง 3
∫ x²√(x³ − 4) dx
ให้ u = x³ − 4 → du = 3x² dx → x² dx = du/3
= (1/3) ∫ u^(1/2) du = (1/3)(2/3)u^(3/2) + C
= (2/9)(x³ − 4)^(3/2) + C
ตัวอย่าง 4
∫ 2x sin(x² − 1) dx
ให้ u = x² − 1 → du = 2x dx
= ∫ sin u du = −cos u + C = −cos(x² − 1) + C
ตัวอย่าง 5 — ได้ ln
∫ (3x² + x)/(3 − x² − 2x³) dx
ให้ u = 3 − x² − 2x³ → du = −(2x + 6x²) dx = −2(3x² + x) dx
= −(1/2) ∫ du/u = −(1/2) ln|3 − x² − 2x³| + C
เทคนิค
ถ้าตัวหน้า du ขาดค่าคงตัว ให้คูณ/หารชดเชย เช่น x² dx = du/3 · ถ้า "ตัวเศษ = อนุพันธ์ของตัวส่วน" ผลคือ ln|ตัวส่วน|

📏 ปริพันธ์จำกัดเขต

นิยาม
∫ab f(x) dx = lim Σ f(xk)Δxk เมื่อลิมิตหาค่าได้และไม่ขึ้นกับวิธีแบ่ง/การเลือกจุด (a = ลิมิตล่าง, b = ลิมิตบน)
แทนค่าแล้ว "เปลี่ยนลิมิต" ด้วย
เมื่อใช้ u = g(x) ให้เปลี่ยนลิมิตเป็น u = g(a) ถึง u = g(b) แล้วไม่ต้องแทนกลับเป็น x
ตัวอย่าง 6
∫−12 2x√(x²+1) dx
u = x² + 1, du = 2x dx
x = −1 → u = 2 ; x = 2 → u = 5
= ∫25 u^(1/2) du = [(2/3)u^(3/2)]25
= (2/3)(5√5 − 2√2)
ตัวอย่าง 7
∫12 (3x²+2)/√(x³+2x+1) dx
u = x³ + 2x + 1, du = (3x² + 2) dx
x = 1 → u = 4 ; x = 2 → u = 13
= ∫413 u^(−1/2) du = [2√u]413 = 2(√13 − 2)
พลาดบ่อย
เปลี่ยนตัวแปรแล้วลืมเปลี่ยนลิมิต · สลับลิมิตแล้วลืมเครื่องหมาย: ∫ab = −∫ba

🏛️ ทฤษฎีบทหลักมูลของแคลคูลัส (FTC)

บทที่ 1 — อนุพันธ์ของปริพันธ์
f ต่อเนื่องบน [a, b], c ∈ [a, b], F(x) = ∫cx f(t) dt ⇒ F′(x) = f(x)
d/dx ∫cx f(t) dt = f(x)
บทที่ 2 — คำนวณปริพันธ์จำกัดเขต
ถ้า F′(x) = f(x) บน [a, b]
∫ab f(x) dx = F(b) − F(a)

3 รูปแบบของการหา d/dx ของปริพันธ์
