ลิมิตคืออะไร?

ลิมิต (Limit) คือค่าที่ฟังก์ชัน เข้าใกล้ เมื่อตัวแปรเข้าใกล้ค่าใดค่าหนึ่ง (ไม่จำเป็นต้องเท่ากับค่านั้น)

นิยาม
limx→a f(x) = L
หมายความว่า เมื่อ x เข้าใกล้ a (แต่ x ≠ a) ค่า f(x) จะเข้าใกล้ L
ตัวอย่าง
limx→2 (x² + 1) = 2² + 1 = 5
limx→0 (sin x / x) = 1 (ลิมิตพิเศษที่ต้องจำ)
💡 แนวคิดหลัก
ลิมิตถามว่า f(x) "มุ่งหน้าไปที่ไหน" ไม่ใช่ "มีค่าเท่าไหร่" ณ จุดนั้น
f(a) อาจไม่มีค่า แต่ limx→a f(x) อาจมีค่าก็ได้
📐
สมบัติของลิมิต

ถ้า limx→a f(x) = L และ limx→a g(x) = M แล้ว:

lim [f(x) ± g(x)] = L ± M
lim [f(x) · g(x)] = L · M
lim [f(x) / g(x)] = L / M (M ≠ 0)
lim [c · f(x)] = c · L
lim [f(x)]ⁿ = Lⁿ
💡 วิธีหาลิมิตเบื้องต้น
ขั้นที่ 1: ลองแทนค่า x = a ตรง ๆ ก่อนเสมอ
ขั้นที่ 2: ถ้าได้รูปแบบ 0/0 → ลองแยกตัวประกอบหรือคูณด้วย conjugate
ขั้นที่ 3: ถ้ายังไม่ได้ → ใช้กฎของโลปีตาล (L'Hôpital)
⚠️
รูปแบบไม่กำหนด (Indeterminate Forms)
รูปแบบที่ต้องระวัง
รูปแบบเหล่านี้ต้องดำเนินการเพิ่มเติม ห้ามสรุปทันที:

0/0   ∞/∞   0·∞   ∞−∞   0⁰   1^∞   ∞⁰
ตัวอย่าง — รูปแบบ 0/0
limx→3 (x²−9)/(x−3)

แทนตรง: (9−9)/(3−3) = 0/0 → รูปแบบไม่กำหนด
แยกตัวประกอบ: (x−3)(x+3)/(x−3) = x+3
limx→3 (x+3) = 3+3 = 6
ตัวอย่าง — กฎโลปีตาล (L'Hôpital)
ถ้าได้รูปแบบ 0/0 หรือ ∞/∞ ให้หาอนุพันธ์ของเศษและส่วนแยกกัน:

limx→0 sin(x)/x → 0/0
= limx→0 cos(x)/1 = cos(0)/1 = 1
↔
ลิมิตข้างซ้ายและข้างขวา
นิยาม
limx→a⁻ f(x) = ลิมิตข้างซ้าย (x เข้าใกล้ a จากด้านซ้าย)
limx→a⁺ f(x) = ลิมิตข้างขวา (x เข้าใกล้ a จากด้านขวา)
เงื่อนไขที่ลิมิตมีค่า
limx→a f(x) มีค่า (= L) ก็ต่อเมื่อ
limx→a⁻ f(x) = limx→a⁺ f(x) = L

ถ้าลิมิตข้างซ้าย ≠ ลิมิตข้างขวา → ลิมิตไม่มีค่า
ตัวอย่าง — ฟังก์ชันนิยามเป็นช่วง
f(x) = { x+1 เมื่อ x < 2 ; x²−1 เมื่อ x ≥ 2 }

limx→2⁻ f(x) = 2+1 = 3
limx→2⁺ f(x) = 2²−1 = 3
ลิมิตซ้าย = ลิมิตขวา = 3 → limx→2 f(x) = 3
📊
ลิมิตที่อนันต์
lim x→∞
x เข้าใกล้ ∞
พิจารณาพฤติกรรมของ f(x) เมื่อ x ใหญ่มาก ๆ
c/xⁿ
x→∞ → 0
ค่าคงที่หารด้วย xⁿ (n>0) → 0 เสมอ
deg เปรียบ
เศษส่วน ∞/∞
เทียบดีกรีสูงสุดของเศษกับส่วน
สัมประสิทธิ์
deg เท่ากัน
ลิมิต = สัมประสิทธิ์หลักของเศษ / ส่วน
ตัวอย่าง — ลิมิตที่อนันต์
limx→∞ (3x²+2x) / (5x²−1)

deg เศษ = deg ส่วน = 2 → ลิมิต = สัมประสิทธิ์นำ = 3/5
คำตอบ: 3/5
หลักการหาร: หารเศษและส่วนด้วย xⁿ (n = deg สูงสุด)
lim (3x²+2x)/(5x²−1) = lim (3+2/x)/(5−1/x²) = (3+0)/(5−0) = 3/5
หัวข้อ 2 · ความต่อเนื่องของฟังก์ชัน
🔗
นิยามความต่อเนื่อง
นิยาม — f ต่อเนื่องที่ x = a ก็ต่อเมื่อเงื่อนไขทั้ง 3 ข้อต่อไปนี้เป็นจริง
1. f(a) มีค่า (ฟังก์ชันมีนิยามที่ x = a)
2. limx→a f(x) มีค่า (ลิมิตมีอยู่)
3. limx→a f(x) = f(a) (ลิมิตเท่ากับค่าฟังก์ชัน)
💡 วิธีจำ
"ต่อเนื่อง" คือ วาดกราฟได้โดยไม่ยกดินสอขึ้น — ไม่มีรู ไม่มีกระโดด ไม่มีช่องว่าง
❌
ประเภทของความไม่ต่อเนื่อง

ความไม่ต่อเนื่องแบบถอดออกได้

ลิมิตมีค่า แต่ f(a) ไม่มีค่าหรือ f(a) ≠ ลิมิต
(มีรูในกราฟ แต่อุดได้)

f(x) = (x²−4)/(x−2)
ไม่นิยามที่ x=2 แต่ลิมิต = 4

ความไม่ต่อเนื่องแบบกระโดด

ลิมิตข้างซ้าย ≠ ลิมิตข้างขวา
(กราฟกระโดด)

f(x) = { 1, x<0 ;
2, x≥0 }

ความไม่ต่อเนื่องแบบอนันต์

ลิมิตข้างใดข้างหนึ่งหรือทั้งสองเป็น ±∞
(มีเส้นกำกับ)

f(x) = 1/x
limx→0⁺ = +∞

การตรวจสอบ

ฟังก์ชันที่มักต่อเนื่องทุกที่:

  • พหุนาม: ต่อเนื่องทุก ℝ
  • เอกซ์โพเนนเชียล: ต่อเนื่องทุก ℝ
  • ตรีโกณมิติ: ต่อเนื่องในโดเมน
  • เศษส่วน: ไม่ต่อเนื่องที่ส่วน = 0
📌
ทฤษฎีค่ากลาง (Intermediate Value Theorem)
ทฤษฎี IVT
ถ้า f ต่อเนื่องบน [a, b] และ k เป็นค่าระหว่าง f(a) กับ f(b)
แล้ว มี c ∈ (a, b) อย่างน้อยหนึ่งตัว ที่ทำให้ f(c) = k
ประยุกต์ — พิสูจน์รากของสมการ
พิสูจน์ว่า x³ + x − 1 = 0 มีราก ∈ (0, 1)

ให้ f(x) = x³ + x − 1 (ต่อเนื่องทุกที่)
f(0) = 0 + 0 − 1 = −1 < 0
f(1) = 1 + 1 − 1 = 1 > 0
โดย IVT: มี c ∈ (0,1) ที่ f(c) = 0 ✓

อนุพันธ์คืออะไร?

อนุพันธ์คือ อัตราการเปลี่ยนแปลง ของฟังก์ชัน หรือ ความชันของเส้นสัมผัส ณ จุดใดจุดหนึ่ง

นิยามจากลิมิต (First Principles)
f'(x) = limh→0 [f(x+h) − f(x)] / h
ตัวอย่าง — หา f'(x) จากนิยาม เมื่อ f(x) = x²
f'(x) = limh→0 [(x+h)² − x²] / h
= limh→0 [x² + 2xh + h² − x²] / h
= limh→0 [2xh + h²] / h
= limh→0 [2x + h]
= 2x

กฎผลคูณและผลหาร
กฎผลคูณ (Product Rule)
ถ้า h(x) = f(x) · g(x) แล้ว
h'(x) = f'(x)g(x) + f(x)g'(x)
ตัวอย่าง — Product Rule
h(x) = x² · sin x
h'(x) = 2x · sin x + x² · cos x
กฎผลหาร (Quotient Rule)
ถ้า h(x) = f(x) / g(x) แล้ว
h'(x) = [f'(x)g(x) − f(x)g'(x)] / [g(x)]²
💡 วิธีจำกฎผลหาร
"Lo d-Hi minus Hi d-Lo over Lo-squared"
→ (ส่วน × อนุพันธ์เศษ − เศษ × อนุพันธ์ส่วน) / ส่วน²
ตัวอย่าง — Quotient Rule
h(x) = (x² + 1) / (x − 1)
h'(x) = [2x(x−1) − (x²+1)(1)] / (x−1)²
= [2x²−2x − x²−1] / (x−1)²
= (x²−2x−1) / (x−1)²
⛓️
กฎลูกโซ่ (Chain Rule)
กฎลูกโซ่ — สำคัญมาก!
ถ้า h(x) = f(g(x)) แล้ว
h'(x) = f'(g(x)) · g'(x)
💡 วิธีจำ
"อนุพันธ์ฟังก์ชันนอก × อนุพันธ์ฟังก์ชันใน"
d/dx [f(g(x))] = f'(g(x)) · g'(x)
ตัวอย่าง — Chain Rule
h(x) = (3x² + 1)⁵
ฟังก์ชันนอก: uⁿ → อนุพันธ์ = nu^(n−1)
ฟังก์ชันใน: u = 3x² + 1 → อนุพันธ์ = 6x
h'(x) = 5(3x²+1)⁴ · 6x = 30x(3x²+1)⁴
ตัวอย่าง — Chain Rule ซ้อนกัน
h(x) = sin(e^(x²))
h'(x) = cos(e^(x²)) · e^(x²) · 2x
= 2x · e^(x²) · cos(e^(x²))

อนุพันธ์โดยปริยาย (Implicit Differentiation)

ใช้เมื่อฟังก์ชันอยู่ในรูป F(x, y) = 0 (หา y ออกมาชัด ๆ ไม่ได้)

วิธีการ
1. หาอนุพันธ์ทั้งสองข้างเทียบกับ x
2. ทุกครั้งที่หาอนุพันธ์ y ให้คูณด้วย dy/dx
3. จัดรูปเพื่อหา dy/dx
ตัวอย่าง
x² + y² = 25
หาอนุพันธ์ทั้งสองข้าง: 2x + 2y(dy/dx) = 0
จัดรูป: dy/dx = −2x / 2y = −x/y

📈
ฟังก์ชันเพิ่มและลด
หลักการ
f เพิ่มบนช่วง (a, b) ↔ f'(x) > 0 สำหรับทุก x ∈ (a, b)
f ลดบนช่วง (a, b) ↔ f'(x) < 0 สำหรับทุก x ∈ (a, b)
ตัวอย่าง
f(x) = x³ − 3x² − 9x + 5
f'(x) = 3x² − 6x − 9 = 3(x²−2x−3) = 3(x−3)(x+1)

f'(x) = 0 ที่ x = 3 และ x = −1
f เพิ่ม: (−∞, −1) และ (3, ∞)
f ลด: (−1, 3)
⛰️
ค่าสูงสุด–ต่ำสุด (Extrema)

ทดสอบด้วยอนุพันธ์อันดับหนึ่ง

  • f'(c) = 0 → c เป็น critical point
  • f' เปลี่ยนจาก + → − → ค่าสูงสุดท้องถิ่น
  • f' เปลี่ยนจาก − → + → ค่าต่ำสุดท้องถิ่น

ทดสอบด้วยอนุพันธ์อันดับสอง

  • f'(c) = 0 และ f''(c) < 0 → ค่าสูงสุดท้องถิ่น
  • f'(c) = 0 และ f''(c) > 0 → ค่าต่ำสุดท้องถิ่น
  • f'(c) = 0 และ f''(c) = 0 → ไม่สรุปได้ (ต้องดูเพิ่ม)
⚠️ ค่าสุดขีดสัมบูรณ์บนช่วงปิด [a, b]
ตรวจเฉพาะสามจุด: ปลายช่วง a, b และจุดวิกฤต c ใน (a, b)
เปรียบค่า f(a), f(b), f(c) — ใหญ่สุดคือ max, เล็กสุดคือ min
🏗️
โจทย์ Optimization (หาค่าเหมาะสมที่สุด)
💡 ขั้นตอนการทำ Optimization
1. ตั้งตัวแปร และเขียนนิพจน์ที่ต้องการ Optimize
2. ใช้เงื่อนไขที่กำหนดลดตัวแปรให้เหลือตัวเดียว
3. หาอนุพันธ์และกำหนดให้เท่ากับ 0
4. ยืนยันว่าเป็น max หรือ min ด้วยการทดสอบ
โจทย์ — กล่องพื้นที่ผิวน้อยที่สุด
กล่องสี่เหลี่ยมจัตุรัสไม่มีฝา ปริมาตร 32 ลบ.ม. หาขนาดที่ทำให้ใช้วัสดุน้อยที่สุด

ให้ฐานด้าน x, ความสูง h
ปริมาตร: x²h = 32 → h = 32/x²
พื้นที่ผิว: S = x² + 4xh = x² + 4x(32/x²) = x² + 128/x
S'(x) = 2x − 128/x² = 0 → x³ = 64 → x = 4
h = 32/16 = 2
คำตอบ: ฐาน 4×4, สูง 2 หน่วย
🔍
จุดโค้งงอ และความโค้งของกราฟ
ความโค้ง
f''(x) > 0 → กราฟโค้งขึ้น (concave up) — รูปถ้วย U
f''(x) < 0 → กราฟโค้งลง (concave down) — รูปถ้วยคว่ำ ∩

จุดที่ f''(x) = 0 และเครื่องหมายเปลี่ยน → จุดโค้งงอ (Inflection Point)

วิธีการ
1. ตั้ง u = ฟังก์ชันข้างใน
2. หา du = (...) dx
3. แทนค่าในปริพันธ์ให้อยู่ในรูป u
4. หาปริพันธ์แล้วแทน u กลับ

ให้ u = x²+1 → du = 2x dx
= ∫ u⁵ du = u⁶/6 + C
= (x²+1)⁶/6 + C
ตัวอย่าง — ตรีโกณมิติ
∫ sin(3x) dx

ให้ u = 3x → du = 3dx → dx = du/3
= ∫ sin(u) · (du/3) = −cos(u)/3 + C
= −cos(3x)/3 + C

การหาปริพันธ์โดยการแยกส่วน (Integration by Parts)
สูตร
∫ u dv = uv − ∫ v du

เลือก u และ dv โดยใช้หลัก LIATE:
Logarithm → Inverse trig → Algebraic → Trig → Exponential
(เลือก u จากซ้ายไปขวา)
ตัวอย่าง
∫ x · eˣ dx

เลือก u = x (Algebraic), dv = eˣ dx
→ du = dx, v = eˣ
= x·eˣ − ∫ eˣ dx
= x·eˣ − eˣ + C = eˣ(x−1) + C
หัวข้อ 7 · ปริพันธ์จำกัดเขต
📏
ทฤษฎีบทพื้นฐานของแคลคูลัส (FTC)
FTC ส่วนที่ 1 (สำคัญมาก)
ถ้า F'(x) = f(x) แล้ว
∫ab f(x) dx = F(b) − F(a)
ตัวอย่าง
∫13 (2x + 1) dx

F(x) = x² + x
= F(3) − F(1) = (9+3) − (1+1) = 12 − 2 = 10
💡 เทคนิค — ไม่ต้องใส่ +C
ในปริพันธ์จำกัดเขต ไม่ต้องเขียน + C เพราะ C จะหักล้างกัน:
[F(b)+C] − [F(a)+C] = F(b) − F(a)

∫aa f(x) dx = 0
∫ab f(x) dx = −∫ba f(x) dx
∫ab [f(x)±g(x)] dx = ∫abf(x)dx ± ∫abg(x)dx
∫ab c·f(x) dx = c·∫abf(x) dx

การแทนที่ u ในปริพันธ์จำกัดเขต
💡 สำคัญ — ต้องเปลี่ยนขอบเขตด้วย!
เมื่อแทน u ในปริพันธ์จำกัดเขต ต้องเปลี่ยน x=a และ x=b ให้เป็น u
แล้วคำนวณโดยไม่ต้องแทน u กลับเป็น x
ตัวอย่าง
∫01 2x(x²+1)³ dx

u = x²+1, du = 2x dx
เมื่อ x=0: u=1 | เมื่อ x=1: u=2
= ∫12 u³ du = [u⁴/4]12 = 16/4 − 1/4 = 15/4

📐
พื้นที่ใต้กราฟ
หลักการ
พื้นที่ระหว่างกราฟ y = f(x) กับแกน x บนช่วง [a, b]
A = ∫ab |f(x)| dx
⚠️ ระวังกราฟที่อยู่ต่ำกว่าแกน x
ถ้าส่วนหนึ่งของกราฟต่ำกว่าแกน x (f(x) < 0) ปริพันธ์จะให้ค่าลบ
ต้องแยกช่วงและใช้ค่าสัมบูรณ์:
A = ∫ (บนแกน x) f(x)dx − ∫ (ต่ำกว่าแกน x) f(x)dx
ตัวอย่าง
หาพื้นที่ระหว่าง f(x) = x² − 4 กับแกน x บน [0, 4]

f(x) = 0 ที่ x = 2
บน [0,2]: f(x) < 0
บน [2,4]: f(x) > 0

A = −∫02(x²−4)dx + ∫24(x²−4)dx
= −[x³/3−4x]02 + [x³/3−4x]24
= −(8/3−8) + (64/3−16−8/3+8) = 16/3 + 40/3 = 56/3
🏞️
พื้นที่ระหว่างสองกราฟ
สูตร
A = ∫ab [f(x) − g(x)] dx
โดย f(x) ≥ g(x) บนช่วง [a, b]
ตัวอย่าง
หาพื้นที่ระหว่าง y = x และ y = x²

หาจุดตัด: x = x² → x(x−1) = 0 → x = 0, 1
บน [0,1]: x ≥ x²
A = ∫01 (x − x²) dx = [x²/2 − x³/3]01 = 1/2 − 1/3 = 1/6

วิธี Disk/Washer
หมุนรอบแกน x: V = π ∫ab [f(x)]² dx
หมุนรอบแกน y: V = π ∫cd [g(y)]² dy
ตัวอย่าง
หาปริมาตรของทรงหมุนที่เกิดจากการหมุนบริเวณใต้ y = √x บน [0, 4] รอบแกน x

V = π ∫04 (√x)² dx = π ∫04 x dx
= π [x²/2]04 = π · 8 = 8π
