บทที่ 1 · ธรรมชาติของแสงเชิงคลื่น
💡
แสงคือคลื่นแม่เหล็กไฟฟ้า

แสง (Light) เป็น คลื่นแม่เหล็กไฟฟ้า (Electromagnetic Wave) ชนิดหนึ่ง เกิดจากสนามไฟฟ้าและสนามแม่เหล็กที่สั่นตั้งฉากกันและตั้งฉากกับทิศการเคลื่อนที่ จึงเป็น คลื่นตามขวาง (Transverse Wave)

นิยาม
แสงเป็นคลื่นแม่เหล็กไฟฟ้าที่ไม่ต้องอาศัยตัวกลางในการเคลื่อนที่ สามารถเดินทางผ่านสุญญากาศได้ ด้วยอัตราเร็ว c = 3 × 10⁸ m/s
c = fλ
c = อัตราเร็วแสงในสุญญากาศ (m/s)
f = ความถี่ (Hz)
λ = ความยาวคลื่น (m)
💡 เทคนิคจำ
เมื่อแสงเดินทางจากตัวกลางหนึ่งไปอีกตัวกลางหนึ่ง ความถี่ f คงที่เสมอ แต่ ความยาวคลื่น λ และอัตราเร็ว v เปลี่ยนไปตามดัชนีหักเห
🌈
สเปกตรัมคลื่นแม่เหล็กไฟฟ้า

คลื่นแม่เหล็กไฟฟ้าครอบคลุมช่วงความถี่กว้างมาก แสงที่ตามองเห็น (Visible Light) เป็นเพียงส่วนเล็ก ๆ ของสเปกตรัมทั้งหมด

ชนิดคลื่นความยาวคลื่น (โดยประมาณ)ความถี่ (โดยประมาณ)
รังสีแกมมา (γ)< 10⁻¹² m> 10²⁰ Hz
รังสีเอกซ์ (X-ray)10⁻¹² – 10⁻⁸ m10¹⁶ – 10²⁰ Hz
รังสีอัลตราไวโอเลต (UV)10⁻⁸ – 4×10⁻⁷ m~10¹⁵ Hz
แสงที่ตามองเห็น4×10⁻⁷ – 7×10⁻⁷ m4×10¹⁴ – 7.5×10¹⁴ Hz
รังสีอินฟราเรด (IR)7×10⁻⁷ – 10⁻³ m~10¹²–10¹⁴ Hz
ไมโครเวฟ10⁻³ – 10⁻¹ m~10⁹–10¹¹ Hz
คลื่นวิทยุ> 10⁻¹ m< 10⁹ Hz
ลำดับความยาวคลื่นแสงที่ตามองเห็น (ยาว → สั้น)
แดง → ส้ม → เหลือง → เขียว → น้ำเงิน → คราม → ม่วง
(จำง่าย ๆ: สีแดงมี λ มากที่สุด สีม่วงมี λ น้อยที่สุดในกลุ่มแสงที่ตามองเห็น)
🔀
หลักการซ้อนทับและอาพันธภาพ (Coherence)
หลักการซ้อนทับ (Superposition Principle)
เมื่อคลื่นตั้งแต่สองขบวนขึ้นไปเคลื่อนที่มาพบกัน ณ จุดใดจุดหนึ่ง การกระจัดรวมที่จุดนั้นเท่ากับผลบวกของการกระจัดของแต่ละคลื่น

การแทรกสอดของแสงที่สังเกตเห็นชัดเจนและคงที่ (สังเกตแถบสว่าง-มืดได้) ต้องอาศัยแหล่งกำเนิดที่ อาพันธ์กัน (Coherent Sources)

⚠️ เงื่อนไขแหล่งกำเนิดอาพันธ์
1. มีความถี่เท่ากัน (และความยาวคลื่นเท่ากัน)
2. มีผลต่างเฟสคงตัว (คงที่ตลอดเวลา) ไม่เปลี่ยนแปลงแบบสุ่ม

ในทางปฏิบัติ มักใช้แหล่งกำเนิดเดียวแล้วแบ่งลำแสงออกเป็นสองทาง (เช่น ผ่านสลิตคู่ หรือฟิล์มบาง) เพื่อให้ได้แหล่งกำเนิดอาพันธ์
บทที่ 2 · การแทรกสอดของแสง (Young's Double-Slit)
🔬
การทดลองของยัง (Young's Experiment)

โทมัส ยัง (Thomas Young) ให้แสงอาพันธ์ผ่านสลิตคู่ (Double Slit) ที่มีระยะห่างระหว่างสลิต d ทำให้เกิดแถบสว่าง-มืดสลับกันบนฉากที่วางห่างออกไปเป็นระยะ D

คลื่นจาก S₁ และ S₂ เดินทางไปพบกันที่จุดต่าง ๆ บนฉาก หากมีความต่างระยะทาง (Path Difference) ที่เหมาะสม จะเกิดการแทรกสอดแบบเสริมหรือหักล้าง

➕
เงื่อนไขการแทรกสอด
ความต่างระยะทาง (Path Difference)
Δ = d sinθ เมื่อ θ คือมุมจากแนวกลางไปยังจุดที่พิจารณา

แถบสว่าง (Constructive)

d sinθ = nλ
n = 0, ±1, ±2, ...

คลื่นทั้งสองมาถึงพร้อมเฟสตรงกัน (ต่างเฟส 0, 2π, 4π, ...)

แถบมืด (Destructive)

d sinθ = (n + ½)λ
n = 0, ±1, ±2, ...

คลื่นทั้งสองมาถึงแบบหักล้างพอดี (ต่างเฟส π, 3π, ...)

⚠️ n = 0 คือแถบกลาง
แถบสว่างกลาง (Central Bright Fringe) อยู่ตรงกลางฉากพอดี (θ = 0) เพราะระยะทางจาก S₁ และ S₂ เท่ากัน (Δ = 0)
📏
สูตรระยะบนฉาก (มุมเล็ก)

เมื่อ D ≫ d (ฉากอยู่ไกลมากเทียบกับระยะสลิต) จะได้ sinθ ≈ tanθ ≈ y/D

ตำแหน่งแถบสว่างที่ n:   yₙ = nλD / d
ระยะห่างระหว่างแถบสว่างที่ติดกัน:   Δy = λD / d
ตัวอย่างโจทย์
แสงความยาวคลื่น 600 nm ผ่านสลิตคู่ห่างกัน 0.2 mm ฉากอยู่ห่าง 1.5 m
จงหาระยะห่างระหว่างแถบสว่างที่ติดกัน

วิธีทำ: Δy = λD/d = (600×10⁻⁹ × 1.5) / (0.2×10⁻³) = 4.5×10⁻³ m = 4.5 mm
💡 เทคนิค A-Level
ถ้าโจทย์ให้ระยะ y บนฉากแทนมุม θ ให้ใช้ d·y/D แทน d sinθ ได้ทันที (มุมเล็ก) แต่ถ้ามุม θ มีค่ามาก ต้องใช้ d sinθ ตรง ๆ ห้ามประมาณ
บทที่ 3 · การเลี้ยวเบนของแสงผ่านช่องเดี่ยว
🌊
การเลี้ยวเบน (Diffraction) คืออะไร

เมื่อแสงเคลื่อนที่ผ่านช่องแคบ (Single Slit) หรือขอบสิ่งกีดขวาง แสงจะอ้อมและกระจายออกจากแนวเส้นตรงเดิม ปรากฏการณ์นี้เรียกว่า การเลี้ยวเบน

หลักการฮอยเกนส์ (Huygens' Principle)
ทุกจุดบนหน้าคลื่นทำหน้าที่เป็นแหล่งกำเนิดคลื่นใหม่ (Wavelet) ที่แผ่ออกไปทุกทิศทาง หน้าคลื่นถัดไปคือเส้นสัมผัสของคลื่นย่อยทั้งหมด

เมื่อแสงผ่านช่องเดี่ยวกว้าง a คลื่นย่อยจากจุดต่าง ๆ ภายในช่องจะแทรกสอดกันเอง ทำให้เกิดแถบมืด-สว่างบนฉาก แต่รูปแบบจะสลับกับกรณีสลิตคู่

⬛
เงื่อนไขแถบมืดของช่องเดี่ยว
⚠️ ข้อควรระวัง — สลับกับสลิตคู่!
สำหรับช่องเดี่ยว เงื่อนไข a sinθ = mλ คือแถบมืด (ตรงข้ามกับสลิตคู่ที่ d sinθ = nλ คือแถบสว่าง)
แถบมืด (Dark Fringe):   a sinθ = mλ,   m = ±1, ±2, ±3, ...
(m ≠ 0 เพราะ θ = 0 คือกึ่งกลางแถบสว่างหลัก ไม่ใช่แถบมืด)
ทำไมกึ่งกลางจึงสว่างที่สุด
ที่ θ = 0 คลื่นย่อยทุกจุดในช่องเดินทางระยะเท่ากันไปถึงฉาก จึงเสริมกันหมด เกิดแถบสว่างกลาง (Central Maximum) ที่สว่างและกว้างที่สุด
📐
ความกว้างแถบสว่างกลาง

แถบสว่างกลางมีความกว้างเป็นสองเท่าของแถบสว่างรอง เพราะถูกขนาบด้วยแถบมืดที่ m = +1 และ m = −1

ความกว้างครึ่งหนึ่งของแถบกลาง (จากกึ่งกลางถึงแถบมืดแรก):   y₁ = λD / a
ความกว้างเต็มของแถบสว่างกลาง:   2y₁ = 2λD / a
💡 เปรียบเทียบช่องเดี่ยวกับสลิตคู่
• ช่องแคบลง (a เล็กลง) → แถบเลี้ยวเบนกว้างขึ้น (สังเกตการเลี้ยวเบนชัดขึ้น)
• สลิตคู่ให้แถบสว่าง-มืดที่มีความกว้างเท่ากันทุกแถบ ต่างจากช่องเดี่ยวที่แถบกลางกว้างเป็นพิเศษ
บทที่ 4 · เกรตติงเลี้ยวเบน (Diffraction Grating)
📊
เกรตติงคืออะไร

เกรตติง (Grating) คือแผ่นที่มีช่องแคบจำนวนมากเรียงขนานกันอย่างสม่ำเสมอ (อาจมีเป็นพัน-หมื่นเส้นต่อเซนติเมตร) ใช้แยกแสงออกเป็นสเปกตรัมได้คมชัดกว่าสลิตคู่มาก

ระยะห่างระหว่างช่อง (Grating Spacing)
d = 1 / N เมื่อ N คือจำนวนช่อง (เส้น) ต่อหน่วยความยาว
ตัวอย่าง
เกรตติงมี 5,000 เส้น/cm
d = 1/N = 1/5000 cm = 2×10⁻⁴ cm = 2×10⁻⁶ m
✨
เงื่อนไขแถบสว่าง (เหมือนสลิตคู่)
d sinθ = nλ,   n = 0, 1, 2, 3, ...

สมการมีรูปแบบเดียวกับสลิตคู่ แต่เพราะมีช่องจำนวนมากแทรกสอดพร้อมกัน ทำให้ได้แถบสว่างที่คมชัด แคบ และสว่างจ้ากว่ามาก ส่วนบริเวณระหว่างแถบสว่างจะมืดสนิทเกือบทั้งหมด

💡 มุมเบี่ยงเบนสูงสุด
เนื่องจาก sinθ ≤ 1 เสมอ ดังนั้นจำนวนแถบสว่างสูงสุด (n สูงสุด) ที่สังเกตได้คือค่า n ที่ทำให้ nλ ≤ d หรือ n ≤ d/λ
ตัวอย่างโจทย์
เกรตติง d = 2×10⁻⁶ m ใช้แสง λ = 500 nm จงหาจำนวนแถบสว่างสูงสุดที่เป็นไปได้ (nสูงสุด)

วิธีทำ: n ≤ d/λ = (2×10⁻⁶)/(500×10⁻⁹) = 4
ดังนั้น n สูงสุด = 4 (เกิดแถบสว่างที่ n = 0, ±1, ±2, ±3, ±4)
🌈
การประยุกต์ — สเปกโตรมิเตอร์

เนื่องจากมุมเบี่ยงเบน θ ขึ้นกับ λ (ที่ n เดียวกัน แสงความยาวคลื่นต่างกันจะเบี่ยงเบนมุมต่างกัน) เกรตติงจึงใช้แยกแสงผสม (เช่น แสงขาว) ออกเป็นสเปกตรัมสีต่าง ๆ ได้ โดยแสงสีม่วง (λ น้อย) เบี่ยงเบนน้อยกว่าแสงสีแดง (λ มาก) ที่ n เดียวกัน

บทที่ 5 · การแทรกสอดในฟิล์มบาง (Thin-Film Interference)
🫧
ฟิล์มบางคืออะไร

เมื่อแสงตกกระทบฟิล์มบาง (เช่น ฟองสบู่ คราบน้ำมันบนน้ำ เลนส์เคลือบผิว) แสงบางส่วนจะสะท้อนที่ผิวบน และบางส่วนจะทะลุเข้าไปสะท้อนที่ผิวล่าง แล้วออกมารวมกับแสงที่สะท้อนผิวบน เกิดการแทรกสอด

🔄
การเปลี่ยนเฟสเมื่อสะท้อน
กฎการเปลี่ยนเฟส 180° (π)
เมื่อแสงสะท้อนจากตัวกลางที่มีดัชนีหักเหมากกว่า (สะท้อนจากตัวกลางหนาแน่นกว่าทางแสง) จะเกิดการเปลี่ยนเฟส 180°
เมื่อสะท้อนจากตัวกลางที่มีดัชนีหักเหน้อยกว่า จะไม่เปลี่ยนเฟส
กรณีทั่วไป — ฟองสบู่ในอากาศ
อากาศ (n≈1) → ฟิล์ม (n>1): สะท้อนผิวบน เปลี่ยนเฟส π
ฟิล์ม (n>1) → อากาศ (n≈1): สะท้อนผิวล่าง ไม่เปลี่ยนเฟส
→ มีการเปลี่ยนเฟสสุทธิ 1 ครั้ง ระหว่างสองรังสีที่สะท้อนออกมา
📐
เงื่อนไขการแทรกสอด (กรณีเปลี่ยนเฟส 1 ครั้ง)

ความต่างระยะทางเชิงแสงจากการเดินทางในฟิล์ม คือ 2nt (t = ความหนาฟิล์ม, n = ดัชนีหักเหของฟิล์ม) เมื่อรวมกับการเปลี่ยนเฟส π ที่ผิวบน จะได้เงื่อนไข:

แสงเสริม (สว่าง)

2nt = (m + ½)λ
m = 0, 1, 2, ...

แสงหักล้าง (มืด)

2nt = mλ
m = 0, 1, 2, ...
⚠️ ข้อควรระวัง
สูตรนี้ใช้ได้เมื่อมีการเปลี่ยนเฟสสุทธิเพียง 1 ครั้ง (กรณีทั่วไป เช่น ฟองสบู่ในอากาศ หรือฟิล์มเคลือบเลนส์ที่มี n น้อยกว่ากระจก) ถ้าโจทย์มีการเปลี่ยนเฟสสุทธิ 0 หรือ 2 ครั้ง (n ทั้งสองด้านเรียงจากมากไปน้อยหรือน้อยไปมากเหมือนกัน) เงื่อนไขสว่าง-มืดจะสลับกัน — ต้องอ่านโจทย์ให้ละเอียดเสมอ
ตัวอย่างโจทย์
ฟองสบู่ (n = 1.33) หนา 300 nm ถูกแสงขาวตกกระทบตั้งฉาก ความยาวคลื่นใดในช่วงที่ตามองเห็นจะสะท้อนออกมาสว่างที่สุด (สมมติ m = 0)?

วิธีทำ: 2nt = (0+½)λ → λ = 4nt = 4×1.33×300 nm = 1,596 nm (อยู่นอกช่วงตามองเห็น ลอง m=1)
2nt = (1+½)λ → λ = 2nt×2/3 = (2×1.33×300×2)/3 ≈ 532 nm (สีเขียว อยู่ในช่วงที่ตามองเห็น ✓)
บทที่ 6 · โพลาไรเซชันของแสง (Polarization)
📶
แสงโพลาไรส์คืออะไร

เนื่องจากแสงเป็นคลื่นตามขวาง สนามไฟฟ้าสามารถสั่นได้ในทุกทิศทางที่ตั้งฉากกับทิศการเคลื่อนที่ แสงธรรมชาติ (เช่น แสงอาทิตย์) มีสนามไฟฟ้าสั่นแบบสุ่มในทุกทิศทาง เรียกว่า แสงไม่โพลาไรส์ (Unpolarized Light)

นิยาม
แสงโพลาไรส์ (Polarized Light) คือแสงที่สนามไฟฟ้าสั่นอยู่ในระนาบเดียวเท่านั้น
⚠️ ข้อควรจำ
มีเพียงคลื่นตามขวางเท่านั้นที่เกิดโพลาไรเซชันได้ คลื่นตามยาว (เช่น คลื่นเสียง) ไม่สามารถโพลาไรส์ได้
🎞️
โพลารอยด์และกฎของมาลัส (Malus's Law)

โพลารอยด์ (Polaroid) เป็นแผ่นกรองที่ยอมให้แสงสั่นในทิศเดียว (แนวแกนของโพลารอยด์) ผ่านไปได้เท่านั้น

I = I₀ cos²θ

เมื่อ I₀ = ความเข้มแสงหลังผ่านโพลารอยด์แผ่นแรก, θ = มุมระหว่างแกนโพลารอยด์แผ่นที่สองกับแผ่นแรก, I = ความเข้มแสงหลังผ่านโพลารอยด์แผ่นที่สอง

ตัวอย่างโจทย์
แสงไม่โพลาไรส์ความเข้ม I₀ ผ่านโพลารอยด์แผ่นแรก (เหลือ I₀/2) แล้วผ่านแผ่นที่สองซึ่งวางทำมุม 60° กับแผ่นแรก จงหาความเข้มแสงที่ออกมา

วิธีทำ: หลังแผ่นแรก I₁ = I₀/2
หลังแผ่นที่สอง I₂ = I₁cos²(60°) = (I₀/2)(0.5)² = I₀/8
💡 เทคนิคจำ
แสงไม่โพลาไรส์ผ่านโพลารอยด์แผ่นแรกเสมอ จะเหลือความเข้มครึ่งหนึ่ง (I₀/2) ไม่ว่าแกนโพลารอยด์จะวางในทิศใด เพราะเป็นค่าเฉลี่ยของ cos²θ ตลอดทุกทิศทางสุ่ม
🪞
มุมโพลาไรส์ (Brewster's Angle)
นิยาม
มุมโพลาไรส์ (θ_B) คือมุมตกกระทบที่ทำให้แสงสะท้อนโพลาไรส์เต็มที่ โดยรังสีสะท้อนและรังสีหักเหตั้งฉากกันพอดี
tanθ_B = n₂ / n₁

เมื่อ n₁ = ดัชนีหักเหตัวกลางที่แสงตกกระทบ, n₂ = ดัชนีหักเหตัวกลางที่สอง

ตัวอย่างโจทย์
แสงตกกระทบผิวน้ำ (n = 1.33) จากอากาศ (n = 1) จงหามุมโพลาไรส์

วิธีทำ: tanθ_B = 1.33/1 = 1.33 → θ_B = tan⁻¹(1.33) ≈ 53.1°
