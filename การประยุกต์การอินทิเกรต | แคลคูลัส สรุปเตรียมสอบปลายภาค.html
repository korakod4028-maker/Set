ทฤษฎีบทหลักของแคลคูลัส

ถ้า f ต่อเนื่องบนช่วง [a, b] และ F เป็นปฏิยานุพันธ์ของ f (นั่นคือ F′(x) = f(x)) แล้ว

∫ba f(x) dx = F(b) − F(a)
ตัวอย่าง
∫31 2x dx = [x²] จาก 1 ถึง 3 = 3² − 1² = 8
📋
คุณสมบัติที่ต้องจำ
คุณสมบัติสูตร
ค่าคงที่ 1∫ba 1 dx = b − a
ดึงค่าคงที่ออก∫ba k·f(x) dx = k ∫ba f(x) dx
บวก / ลบ∫ba [f(x) ± g(x)] dx = ∫ba f dx ± ∫ba g dx
แยกช่วง∫ba f dx = ∫ca f dx + ∫bc f dx
ขอบเขตเท่ากัน∫aa f(x) dx = 0
สลับขอบเขต∫ba f dx = − ∫ab f dx
💡 เทคนิค
ถ้า f เป็นฟังก์ชันคู่: ∫a−a f dx = 2 ∫a0 f dx
ถ้า f เป็นฟังก์ชันคี่: ∫a−a f dx = 0
⚠️ ระวัง
∫ba f(x)·g(x) dx ไม่เท่ากับ (∫ba f dx)(∫ba g dx) — คุณสมบัติบวก/ลบใช้ได้ แต่ไม่มีสมบัติคูณแบบนี้
หัวข้อ 2 · การหาพื้นที่
📈
พื้นที่ระหว่างเส้นโค้งกับแกน X
สูตร
ถ้า y = f(x) ≥ 0 บนช่วง [a, b]
A = ∫ba f(x) dx

ถ้า f(x) ติดลบบางช่วง พื้นที่จริงต้องเป็นบวก ให้แยกช่วงที่ f ≥ 0 กับ f ≤ 0 แล้วอินทิเกรต |f(x)| ทีละช่วง

ตัวอย่าง: พื้นที่ใต้ y = x² จาก x = 0 ถึง 3
A = ∫30 x² dx = [x³/3] จาก 0 ถึง 3 = 27/3 = 9 ตารางหน่วย
🔀
พื้นที่ระหว่างเส้นโค้งสองเส้น
สูตร
ถ้า f(x) ≥ g(x) บนช่วง [a, b]
A = ∫ba [f(x) − g(x)] dx
  1. วาดกราฟทั้งสองเส้น แล้วระบายบริเวณที่โจทย์ถาม
  2. หาจุดตัด (ให้ f(x) = g(x)) เพื่อได้ขอบเขต a, b
  3. ดูว่าในช่วงนั้นเส้นไหนอยู่ บน เส้นไหนอยู่ ล่าง
  4. ตั้ง A = ∫ (บน − ล่าง) dx แล้วคำนวณ
ตัวอย่าง: พื้นที่ปิดล้อมด้วย y = x และ y = x²
จุดตัด: x = x² → x = 0 หรือ x = 1
ในช่วง (0, 1) เส้น y = x อยู่บน y = x²
A = ∫10 (x − x²) dx = [x²/2 − x³/3] จาก 0 ถึง 1 = 1/2 − 1/3 = 1/6
⚠️ ระวัง
ถ้าเส้นโค้งตัดกันกลางช่วง เส้นบน/ล่างจะสลับกัน ต้องแยกอินทิกรัลเป็นช่วงๆ ไม่งั้นส่วนที่ติดลบจะหักล้างกัน
หัวข้อ 3 · ปริมาตรทรงตัน: วิธีแบบจาน (Disk)
💿
หลักการ

หมุนพื้นที่รอบแกน แล้วหั่นทรงตันเป็นแผ่นบางๆ ตั้งฉากกับแกนหมุน แต่ละแผ่นเป็นจาน (วงกลมตัน) ปริมาตรจานหนึ่งแผ่น = π × (รัศมี)² × ความหนา

หมุนรอบแกน x

V = π ∫ba [f(x)]² dx

หมุนรอบแกน y

V = π ∫ba [f(y)]² dy
เมื่อไหร่ใช้จาน
พื้นที่ที่หมุนติดแกนหมุนตลอดช่วง ทรงตันที่ได้ไม่มีรูตรงกลาง
✏️
ตัวอย่างจากสไลด์ (ละเอียด)
ตัวอย่าง 1: y = 16 − x² และ y = 0 หมุนรอบแกน x
ขั้น 1: หาขอบเขตพื้นที่ถูกล้อมด้วยพาราโบลากับแกน x ให้ 16 − x² = 0 → x² = 16 → x = ±4 ดังนั้นอินทิเกรตจาก −4 ถึง 4
ขั้น 2: หารัศมีหั่นเป็นแผ่นตั้งฉากแกน x พื้นที่ติดแกน x จึงใช้จาน รัศมี = ระยะจากแกน x ถึงเส้นโค้ง = y = 16 − x²
ขั้น 3: ตั้งอินทิกรัลV = π ∫4−4 (16 − x²)² dx (อย่าลืมยกกำลังสอง)
ขั้น 4: กระจายกำลังสอง(16 − x²)² = 16² − 2(16)(x²) + (x²)² = 256 − 32x² + x⁴
ขั้น 5: หาปฏิยานุพันธ์∫4−4 (256 − 32x² + x⁴) dx = [256x − (32/3)x³ + x⁵/5] จาก −4 ถึง 4
ขั้น 6: แทนค่ากราฟสมมาตร จึงคิดครึ่งเดียวแล้วคูณ 2:
ที่ x = 4: 256(4) − (32/3)(64) + 1024/5 = 1024 − 2048/3 + 1024/5
ทอนเป็นส่วน 15: (15360 − 10240 + 3072)/15 = 8192/15
คูณ 2 ได้ 16384/15
V = 16384π/15 ≈ 1092.3
⚠️ สไลด์เฉลย 256π/3
เพราะไม่ได้ยกกำลังสองในขั้น 3 สไลด์จึงคิดเป็น π∫(16 − x²)dx ซึ่งผิดสูตร
ตัวอย่าง 2: y = 2√x, y = 0, x = 9
(a) หมุนรอบแกน x — รัศมีพื้นที่ติดแกน x → จาน รัศมี = 2√x → ยกกำลังสอง (2√x)² = 4x
(a) คำนวณV = π ∫90 4x dx = π [2x²] จาก 0 ถึง 9 = π(2·81 − 0) = 162π
(b) หมุนรอบเส้น x = 9 — เลือกตัวแปรเส้นหมุนเป็นแนวตั้ง แผ่นที่หั่นจะเป็นแนวนอน จึงอินทิเกรตตาม dy ต้องเขียน x ในรูป y: y = 2√x → √x = y/2 → x = y²/4
(b) ขอบเขตที่ x = 0 → y = 0, ที่ x = 9 → y = 2√9 = 6 ดังนั้น y จาก 0 ถึง 6
(b) รัศมีจุดบนโค้งอยู่ที่ x = y²/4 เส้นหมุนอยู่ที่ x = 9 ระยะห่าง = 9 − y²/4 (ลองแทน y = 0 ได้ 9 = ระยะจากจุดกำเนิดถึงเส้น x = 9 ถูกต้อง)
(b) กระจายและอินทิเกรต(9 − y²/4)² = 81 − (9/2)y² + y⁴/16
V = π ∫60 (81 − (9/2)y² + y⁴/16) dy = π [81y − (3/2)y³ + y⁵/80] จาก 0 ถึง 6
แทน y = 6: 486 − 324 + 97.2 = 259.2
V = 259.2π = 1296π/5
หัวข้อ 4 · ปริมาตรทรงตัน: วิธีแบบวงแหวน (Washer / Ring)
🍩
หลักการ

เหมือนวิธีจาน แต่พื้นที่ไม่ติดแกนหมุน ทำให้มีรูตรงกลาง แต่ละแผ่นเป็นวงแหวน ปริมาตร = ปริมาตรวงกลมใหญ่ − ปริมาตรวงกลมเล็ก

หมุนรอบแกน x

V = π ∫ba ([R(x)]² − [r(x)]²) dx

หมุนรอบแกน y

V = π ∫ba ([R(y)]² − [r(y)]²) dy
R และ r
R = รัศมีนอก (ขอบพื้นที่ที่ไกลจากแกนหมุน)
r = รัศมีใน (ขอบพื้นที่ที่ใกล้แกนหมุน)
⚠️ จำให้ขึ้นใจ
ต้องยกกำลังสอง แต่ละรัศมีก่อน แล้วค่อยลบ: R² − r² ไม่ใช่ (R − r)²
✏️
ตัวอย่างจากสไลด์ (ละเอียด)
ตัวอย่าง 1: y = 1 และ y = 3 − x²/2 หมุนรอบแกน x
ขั้น 1: หาจุดตัด3 − x²/2 = 1 → x²/2 = 2 → x² = 4 → x = ±2
ขั้น 2: ดูว่าเป็นจานหรือวงแหวนพื้นที่อยู่ระหว่าง y = 1 (ล่าง) กับพาราโบลา (บน) ขอบล่างคือ y = 1 ไม่ใช่ y = 0 จึงไม่ติดแกน x → มีรู → วงแหวน
ขั้น 3: หา R และ rR (ไกลแกน x) = 3 − x²/2 (พาราโบลา)
r (ใกล้แกน x) = 1
ขั้น 4: ตั้งและกระจายV = π ∫2−2 [(3 − x²/2)² − 1²] dx
(3 − x²/2)² = 9 − 3x² + x⁴/4 (เพราะ 2·3·x²/2 = 3x²)
ลบ 1: 8 − 3x² + x⁴/4
ขั้น 5: อินทิเกรตและแทนค่า[8x − x³ + x⁵/20] ที่ x = 2: 16 − 8 + 32/20 = 9.6
สมมาตร คูณ 2 = 19.2
V = 19.2π = 96π/5
ตัวอย่าง 2: y = x, y = 4, x = 1
วาดรูปก่อนสามเหลี่ยมมีจุดยอด (1,1), (1,4), (4,4) ที่แต่ละ x (1 ถึง 4) พื้นที่อยู่ระหว่าง y = x (ล่าง) กับ y = 4 (บน)
(a) หมุนรอบ y = 5 — หา R, rเส้นหมุน y = 5 อยู่เหนือพื้นที่ วัดระยะลงมา:
ถึง y = 4: 5 − 4 = 1 (ใกล้ → r)
ถึง y = x: 5 − x (ไกล → R)
(a) คำนวณV = π ∫41 [(5 − x)² − 1²] dx, (5 − x)² − 1 = 25 − 10x + x² − 1 = 24 − 10x + x²
[24x − 5x² + x³/3]: ที่ 4 = 96 − 80 + 64/3 = 112/3, ที่ 1 = 24 − 5 + 1/3 = 58/3
ผลต่าง = 54/3 → V = 18π
(b) หมุนรอบแกน y — เลือกตัวแปรแกน y เป็นแนวตั้ง แผ่นเป็นแนวนอน ใช้ dy ที่แต่ละ y (1 ถึง 4) พื้นที่อยู่ระหว่าง x = 1 (ซ้าย) และ x = y (ขวา จาก y = x)
(b) หา R, r และคำนวณระยะจากแกน y: R = y (ไกล), r = 1 (ใกล้)
V = π ∫41 (y² − 1) dy = π [y³/3 − y] จาก 1 ถึง 4
ที่ 4: 64/3 − 4 = 52/3, ที่ 1: 1/3 − 1 = −2/3
ผลต่าง = 52/3 + 2/3 = 18 → V = 18π
🔎 ตรวจคำตอบ
ทั้ง (a) และ (b) ได้ 18π เท่ากัน ตรงกับทฤษฎีของพัปปุส เพราะจุดศูนย์กลางของสามเหลี่ยมอยู่ห่างจากเส้นหมุนทั้งสองเท่ากัน คือ 2 หน่วย (2π × 2 × พื้นที่ 4.5 = 18π)

หลักการ

หั่นพื้นที่เป็นแถบบางๆ ขนานกับแกนหมุน เมื่อหมุนแถบหนึ่งแถบจะได้เปลือกทรงกระบอก ปริมาตร ≈ (เส้นรอบวง) × (ความสูง) × (ความหนา)

V = 2π ∫ba (รัศมีเปลือก) × (ความสูงเปลือก) d(ตัวแปร)

หมุนรอบแกน y

V = 2π ∫ba x·f(x) dx

ระหว่างสองเส้น: ความสูง = f(x) − g(x)

หมุนรอบแกน x

V = 2π ∫ba y·f(y) dy

ความสูงวัดตามแนวนอน

💡 หมุนรอบเส้น x = k
รัศมีเปลือก = |x − k| (ระยะจากเส้นหมุนถึงแถบ)
✏️
ตัวอย่าง (ละเอียด)
ตัวอย่าง 1: y = x², y = 0, 0 ≤ x ≤ 2 หมุนรอบแกน y
ขั้น 1: วาดแถบตั้งแถบบางตั้งตรงที่ตำแหน่ง x กว้าง dx สูงจาก y = 0 ถึง y = x² แถบนี้ขนานกับแกน y (แกนหมุน) → ใช้เปลือก
ขั้น 2: หารัศมีและความสูงรัศมีเปลือก = ระยะจากแกน y ถึงแถบ = x
ความสูงเปลือก = x² − 0 = x²
ขั้น 3: ตั้งและคำนวณV = 2π ∫20 (x)(x²) dx = 2π ∫20 x³ dx = 2π [x⁴/4] จาก 0 ถึง 2 = 2π(16/4) = 8π
ตัวอย่าง 2: พื้นที่เดิม หมุนรอบเส้น x = 3
เปลี่ยนแค่รัศมีเส้นหมุนอยู่ที่ x = 3 แถบที่ตำแหน่ง x ห่างจากเส้นหมุน 3 − x (ความสูงยังเป็น x²)
ตั้งและคำนวณV = 2π ∫20 (3 − x)x² dx = 2π ∫20 (3x² − x³) dx = 2π [x³ − x⁴/4] จาก 0 ถึง 2 = 2π(8 − 4) = 8π
ตัวอย่าง 3: ระหว่าง y = x และ y = x² หมุนรอบแกน y
หาจุดตัดและความสูงx = x² → x = 0, 1 ในช่วงนี้ y = x อยู่บน ความสูง = x − x²; รัศมี = x
ตั้งและคำนวณV = 2π ∫10 x(x − x²) dx = 2π ∫10 (x² − x³) dx = 2π(1/3 − 1/4) = 2π(1/12) = π/6

จานตั้งฉากแกนหมุนติดแกนหมุน ไม่มีรูπ∫ R² dx

เปลือกขนานแกนหมุนฟังก์ชันกลับยาก หรือหมุนรอบแกนตั้งฉากกับตัวแปร2π∫ y·h dy

ถ้าหมุนรอบแกน y ตัวแปรจะสลับกัน: จาน/วงแหวนใช้ dy ส่วนเปลือกใช้ dx เลือกวิธีที่เขียนฟังก์ชันได้ง่าย ไม่ต้องกลับฟังก์ชัน

✅
เช็กลิสต์ทำข้อสอบ
  1. วาดกราฟก่อนเสมอ ระบายพื้นที่ แล้วขีดเส้นแกนหมุน
  2. หาจุดตัด เพื่อได้ขอบเขตการอินทิเกรต
  3. ถามตัวเองว่า "มีรูตรงกลางไหม" มี = วงแหวน ไม่มี = จาน
  4. รัศมี = ระยะจากเส้นหมุนถึงขอบพื้นที่ (ถ้าไม่ใช่แกน ต้องลบหรือบวกค่าคงที่)
  5. ยกกำลังสองรัศมี และอย่าลืม π (หรือ 2π ในวิธีเปลือก)
  6. ใช้สมมาตรช่วยลดงาน และตรวจว่าคำตอบเป็นบวก
