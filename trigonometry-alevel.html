หน่วยวัดมุม: องศาและเรเดียน

ในตรีโกณมิติระดับ A-Level เราวัดมุมได้สองหน่วย

องศา (Degree)

วงกลมเต็ม = 360°
ครึ่งวงกลม = 180°
มุมฉาก = 90°

เรเดียน (Radian)

วงกลมเต็ม = 2π rad
ครึ่งวงกลม = π rad
มุมฉาก = π/2 rad

สูตรแปลงหน่วย
องศา → เรเดียน: rad = องศา × π/180
เรเดียน → องศา: องศา = rad × 180/π
ตัวอย่าง
60° → rad: 60 × π/180 = π/3
3π/4 rad → องศา: (3π/4) × 180/π = 135°
💡 ตารางมุมสำคัญ — ต้องจำ!
องศา0°30°45°60°90°120°135°150°180°
เรเดียน0π/6π/4π/3π/22π/33π/45π/6π
🔵
ความยาวส่วนโค้งและพื้นที่เซกเตอร์
สูตรสำคัญ (θ เป็นเรเดียน)
ความยาวส่วนโค้ง: l = rθ
พื้นที่เซกเตอร์: A = ½r²θ
ตัวอย่าง
วงกลมรัศมี 6 cm มุมที่จุดศูนย์กลาง 2π/3 rad
ความยาวส่วนโค้ง = 6 × 2π/3 = 4π cm
พื้นที่เซกเตอร์ = ½ × 6² × 2π/3 = 12π cm²
⚠️ ข้อควรระวัง
สูตร l = rθ และ A = ½r²θ ใช้ได้ เฉพาะเมื่อ θ เป็นเรเดียน เท่านั้น
ถ้าโจทย์ให้มาเป็นองศา ต้องแปลงก่อนเสมอ!
🔄
มุมในทิศทางต่าง ๆ

ในระบบพิกัดฉาก เราวัดมุมจากแกน x บวกตามเข็มนาฬิกาย้อน (ทวนเข็ม = บวก)

มุมแฝด (Co-terminal)

มุมที่ต่างกัน 360° (หรือ 2π) จะมีค่าตรีโกณมิติเท่ากัน

sin(θ + 360°n) = sin θ
n ∈ ℤ

มุมอ้างอิง (Reference Angle)

มุมเฉียบพลันที่เกิดระหว่างแขนสุดท้ายกับแกน x เสมอเป็นค่าบวก

240° → ref = 60°
(คิวแดนต์ 3)

หัวข้อ 3 · วงกลมหนึ่งหน่วย
⭕
นิยามด้วยวงกลมหนึ่งหน่วย
นิยาม
วงกลมหนึ่งหน่วย (Unit Circle) คือวงกลมที่มีจุดศูนย์กลางอยู่ที่ (0,0) และรัศมี = 1

สำหรับจุดใดจุดหนึ่ง (x, y) บนวงกลมที่ทำมุม θ กับแกน x บวก:
x = cos θ และ y = sin θ
มุมพิเศษบนวงกลมหนึ่งหน่วย
θ0°30°45°60°90°180°270°360°
cos θ1√3/2√2/21/20-101
sin θ01/2√2/2√3/210-10
🔁
ค่าตรีโกณมิติของมุมสัมพัทธ์

ใช้มุมอ้างอิง (Reference Angle) เพื่อหาค่าตรีโกณมิติของมุมใดก็ได้

sin(180° - θ) = sin θ    sin(180° + θ) = -sin θ    sin(360° - θ) = -sin θ
cos(180° - θ) = -cos θ    cos(180° + θ) = -cos θ    cos(360° - θ) = cos θ
tan(180° - θ) = -tan θ    tan(180° + θ) = tan θ    tan(360° - θ) = -tan θ
sin(-θ) = -sin θ     cos(-θ) = cos θ     tan(-θ) = -tan θ
💡 มุมเสริม (90° ± θ)
sin(90° - θ) = cos θ       sin(90° + θ) = cos θ
cos(90° - θ) = sin θ       cos(90° + θ) = -sin θ
เมื่อบวก/ลบกับ 90° → sin↔cos สลับกัน!
⚠️ กฎ 90° vs 180°
บวก/ลบกับ 90° → เปลี่ยน sin ↔ cos แล้วดูเครื่องหมายตามคิวแดรนต์
บวก/ลบกับ 180° หรือ 360° → ฟังก์ชันเดิม เปลี่ยนแค่เครื่องหมายตามคิวแดรนต์
หัวข้อ 4 · กราฟฟังก์ชันตรีโกณมิติ
📈
กราฟ y = sin x และ y = cos x

y = sin x

  • คาบ (Period) = 2π
  • แอมพลิจูด = 1
  • ช่วง: -1 ≤ y ≤ 1
  • ผ่านจุดกำเนิด (0, 0)
  • เป็นฟังก์ชันคี่: sin(-x) = -sin x

y = cos x

  • คาบ (Period) = 2π
  • แอมพลิจูด = 1
  • ช่วง: -1 ≤ y ≤ 1
  • ผ่านจุด (0, 1)
  • เป็นฟังก์ชันคู่: cos(-x) = cos x
รูปทั่วไป y = a sin(bx + c) + d
แอมพลิจูด = |a| (ความสูงสูงสุด-ต่ำสุดจากกึ่งกลาง)
คาบ = 2π/|b|
Phase shift (เลื่อนซ้าย-ขวา) = -c/b
Vertical shift (เลื่อนขึ้น-ลง) = d
ตัวอย่าง
y = 3 sin(2x - π/3) + 1
แอมพลิจูด = 3, คาบ = 2π/2 = π
Phase shift = (π/3)/2 = π/6 (เลื่อนขวา), Vertical shift = +1
ค่าสูงสุด = 3 + 1 = 4, ค่าต่ำสุด = -3 + 1 = -2
📉
กราฟ y = tan x และ y = cot x

y = tan x

  • คาบ = π
  • ช่วง: ℝ (ทุกค่าจริง)
  • Asymptote ที่ x = π/2 + nπ
  • เป็นฟังก์ชันคี่

y = cot x

  • คาบ = π
  • ช่วง: ℝ
  • Asymptote ที่ x = nπ
  • เป็นฟังก์ชันคี่
⚠️ Asymptote (เส้นกำกับ)
tan x ไม่นิยามเมื่อ cos x = 0 นั่นคือ x = π/2 + nπ (n ∈ ℤ)
cot x ไม่นิยามเมื่อ sin x = 0 นั่นคือ x = nπ (n ∈ ℤ)
หัวข้อ 5 · เอกลักษณ์และสูตรตรีโกณมิติ
🧩
เอกลักษณ์พื้นฐาน (Pythagorean Identities)
sin²θ + cos²θ = 1      (หลัก — ต้องจำ!)
1 + tan²θ = sec²θ      (หาร sin²+cos²=1 ด้วย cos²θ)
1 + cot²θ = csc²θ      (หาร sin²+cos²=1 ด้วย sin²θ)
💡 เทคนิค — จำแค่ตัวแรก สองตัวล่างหาเองได้
sin²θ + cos²θ = 1
÷ cos²θ ทั้งสองข้าง → tan²θ + 1 = sec²θ
÷ sin²θ ทั้งสองข้าง → 1 + cot²θ = csc²θ
➕
สูตรผลบวกและผลต่างมุม
sin(A ± B) = sin A cos B ± cos A sin B
cos(A ± B) = cos A cos B ∓ sin A sin B
tan(A ± B) = (tan A ± tan B) / (1 ∓ tan A tan B)
ตัวอย่าง — หา sin 75°
sin 75° = sin(45° + 30°)
= sin45°cos30° + cos45°sin30°
= (√2/2)(√3/2) + (√2/2)(1/2)
= √6/4 + √2/4 = (√6 + √2)/4
✌️
สูตรมุมสองเท่า (Double Angle)
sin 2θ = 2 sin θ cos θ

cos 2θ = cos²θ - sin²θ
       = 2cos²θ - 1
       = 1 - 2sin²θ

tan 2θ = 2tan θ / (1 - tan²θ)
💡 สูตรครึ่งมุม (Half Angle) — ใช้บ่อยใน A-Level
cos²θ = (1 + cos 2θ) / 2
sin²θ = (1 - cos 2θ) / 2
ใช้แก้ sin²θ หรือ cos²θ ให้เป็นมุมเดี่ยวเพื่อหาปริพันธ์ หรือพิสูจน์เอกลักษณ์
🔀
สูตรผลคูณ → ผลบวก (Product-to-Sum)
sin A cos B = ½[sin(A+B) + sin(A-B)]
cos A sin B = ½[sin(A+B) - sin(A-B)]
cos A cos B = ½[cos(A+B) + cos(A-B)]
sin A sin B = ½[cos(A-B) - cos(A+B)]
สูตรผลบวก → ผลคูณ (Sum-to-Product)
sin P + sin Q = 2 sin((P+Q)/2) cos((P-Q)/2)
sin P - sin Q = 2 cos((P+Q)/2) sin((P-Q)/2)
cos P + cos Q = 2 cos((P+Q)/2) cos((P-Q)/2)
cos P - cos Q = -2 sin((P+Q)/2) sin((P-Q)/2)
หัวข้อ 6 · กฎไซน์และกฎโคไซน์
📐
กฎไซน์ (Law of Sines)
กฎไซน์
ในสามเหลี่ยม ABC ที่มีด้าน a, b, c ตรงข้ามกับมุม A, B, C ตามลำดับ:
a / sin A = b / sin B = c / sin C = 2R

โดย R คือรัศมีวงกลมล้อมรอบสามเหลี่ยม

💡 ใช้กฎไซน์เมื่อ
รู้ AAS (มุม-มุม-ด้าน) หรือ ASA (ด้าน-มุม-ด้าน สลับ) หรือ
รู้ SSA (ด้าน-ด้าน-มุม ไม่ใช่มุมประกอบ) — ระวัง "กรณีคลุมเครือ"!
ตัวอย่าง
สามเหลี่ยม ABC: A = 40°, B = 75°, a = 10 cm หา b
C = 180° - 40° - 75° = 65°
b/sin75° = 10/sin40° → b = 10 × sin75°/sin40° ≈ 15.04 cm
📏
กฎโคไซน์ (Law of Cosines)
a² = b² + c² - 2bc cos A
b² = a² + c² - 2ac cos B
c² = a² + b² - 2ab cos C
💡 ใช้กฎโคไซน์เมื่อ
รู้ SAS (ด้าน-มุม-ด้าน) หรือ SSS (ด้านสามด้าน)
กฎโคไซน์เป็นการขยาย ทฤษฎีบทพีทาโกรัส สำหรับสามเหลี่ยมทั่วไป
ตัวอย่าง — หามุมจากสามด้าน (SSS)
a = 7, b = 8, c = 10 → หามุม C
cos C = (a² + b² - c²)/(2ab) = (49 + 64 - 100)/(2×7×8)
cos C = 13/112 ≈ 0.1161 → C ≈ 83.3°
📐
สูตรพื้นที่สามเหลี่ยม
พื้นที่ = ½ ab sin C = ½ bc sin A = ½ ac sin B
สูตรเฮรอน (Heron's Formula): s = (a+b+c)/2
พื้นที่ = √(s(s-a)(s-b)(s-c))
ตัวอย่าง
a = 5, b = 7, C = 60°
พื้นที่ = ½ × 5 × 7 × sin60° = ½ × 35 × (√3/2) = 35√3/4
หัวข้อ 7 · สมการตรีโกณมิติ
🔓
แนวทางแก้สมการตรีโกณมิติ
ขั้นตอนหลัก
1. แปลงสมการให้อยู่ในรูปฟังก์ชันตรีโกณมิติเดียว
2. หามุมพื้นฐานจากวงกลมหนึ่งหน่วยหรือตาราง
3. หาคำตอบทั้งหมดในคิวแดรนต์ที่เหมาะสม
4. เขียนคำตอบทั่วไปโดยบวก/ลบคาบ
sin θ = k → θ = arcsin(k) + 2πn หรือ θ = π - arcsin(k) + 2πn
cos θ = k → θ = ±arccos(k) + 2πn
tan θ = k → θ = arctan(k) + πn
ตัวอย่างที่ 1 — แก้ 2sin²θ - sin θ - 1 = 0, 0° ≤ θ ≤ 360°
แยกตัวประกอบ: (2sin θ + 1)(sin θ - 1) = 0
sin θ = -1/2 หรือ sin θ = 1

sin θ = 1 → θ = 90°
sin θ = -1/2 → θ = 210° หรือ θ = 330°
คำตอบ: θ = 90°, 210°, 330°
ตัวอย่างที่ 2 — แก้ cos 2θ = cos θ, 0 ≤ θ ≤ 2π
ใช้ cos 2θ = 2cos²θ - 1:
2cos²θ - 1 = cos θ
2cos²θ - cos θ - 1 = 0
(2cos θ + 1)(cos θ - 1) = 0
cos θ = -1/2 → θ = 2π/3, 4π/3
cos θ = 1 → θ = 0, 2π
คำตอบ: θ = 0, 2π/3, 4π/3, 2π
⚠️
รูปแบบ a sin θ + b cos θ
แปลงเป็นรูป R sin(θ + φ)
a sin θ + b cos θ = R sin(θ + φ)
โดย R = √(a² + b²) และ tan φ = b/a
ตัวอย่าง
3 sin θ + 4 cos θ = R sin(θ + φ)
R = √(9 + 16) = √25 = 5
tan φ = 4/3 → φ = arctan(4/3) ≈ 53.13°
ดังนั้น 3 sin θ + 4 cos θ = 5 sin(θ + 53.13°)
ค่าสูงสุด = 5 เมื่อ θ + 53.13° = 90° → θ ≈ 36.87°

ฟังก์ชันผกผัน (Inverse Trigonometric)

arcsin (sin⁻¹)

โดเมน: [-1, 1]
เรนจ์: [-π/2, π/2]

arccos (cos⁻¹)

โดเมน: [-1, 1]
เรนจ์: [0, π]

arctan (tan⁻¹)

โดเมน: ℝ
เรนจ์: (-π/2, π/2)

ข้อควรระวัง

arcsin(sin θ) = θ เฉพาะเมื่อ θ ∈ [-π/2, π/2]
