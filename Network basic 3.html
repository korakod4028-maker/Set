5 เทคโนโลยีหลัก Cellular / Wi-Fi / Bluetooth / NFC / GPS 20 ข้อฝึกหัด Cheat Sheet พร้อมสอบ
1แนวคิดหลัก: สมาร์ตโฟนในยุคปัจจุบัน
💡สมาร์ตโฟน 1 เครื่องมี วงจรรับ–ส่งสัญญาณ (Radio) หลายชุด ที่ทำงานพร้อมกันในความถี่ต่างกัน ได้แก่ Cellular, Wi-Fi, Bluetooth, NFC และ GPS
✅ตัวอย่าง: Google Maps (GPS) + หูฟัง Bluetooth + อินเทอร์เน็ต 5G + รับ SMS ทำได้ พร้อมกันทั้งหมด เพราะแต่ละอย่างใช้ Radio คนละตัว
⚠️ข้อสอบ Cisco ชอบถาม: อุปกรณ์จะเลือกใช้ Wi-Fi ก่อนเสมอ ถ้าไม่มี Wi-Fi จึงสลับมาใช้ Cellular Data โดยอัตโนมัติ
2ตารางเปรียบเทียบเทคโนโลยีทั้งหมด

Cellular (5G/4G/3G)โทร, SMS, อินเทอร์เน็ตมือถือหลายกิโลเมตร✔ ใช้✘ ไม่ใช้สูง
Wi-Fi (WLAN)อินเทอร์เน็ตความเร็วสูง20–100 เมตร✔ ใช้✘ ไม่ใช้ปานกลาง
Bluetoothเชื่อมต่ออุปกรณ์เสริม, เสียง~10–100 เมตร✘ ไม่จำเป็น✘ ไม่ใช้ต่ำ
NFCแตะจ่ายเงิน, บัตร4–10 ซม.✘ ไม่จำเป็น✘ ไม่ใช้ต่ำมาก
GPSระบุตำแหน่ง, นำทางทั่วโลก✘ ไม่ใช้✔ ใช้ต่ำ–ปานกลาง

✅เปิดใช้ WPA2 หรือ WPA3 บน Router และ Access Point ทุกตัว ปิดการใช้งาน WEP ทันทีหากพบในระบบ

⭐GPS ใช้ดาวเทียม — ไม่ได้ใช้อินเทอร์เน็ต ข้อสอบมักหลอกให้สับสนระหว่าง GPS กับ Wi-Fi
⭐Bluetooth = ใช้พลังงานต่ำ, ระยะสั้น, ทดแทนสาย, Pair ได้สูงสุด 8 เครื่อง, ต้อง Pairing ก่อนใช้ครั้งแรก
⭐NFC ระยะ 4–10 ซม. ใช้แตะจ่ายเงิน (Apple Pay, Google Pay, บัตรเครดิต Contactless)
⭐Wi-Fi ต้องอยู่ในระยะของ Access Point (AP) เสมอ — Hotspot คือพื้นที่ที่มีสัญญาณ ไม่ใช่ตัวอุปกรณ์
⭐ลำดับ: Wi-Fi ก่อน → Cellular สลับอัตโนมัติเมื่อไม่มี Wi-Fi
⭐WEP ห้ามใช้ — เลือก WPA2 หรือ WPA3 เสมอ WEP ถูกถอดรหัสได้ง่ายมาก
⭐วิวัฒนาการ: GSM → 3G → 4G → LTE → 5G แต่ละรุ่นเร็วขึ้นและ Latency ต่ำลง
⭐สมาร์ตโฟนมี Radio หลายชุด จึงใช้หลายเทคโนโลยีพร้อมกันได้
2สรุปย่อแต่ละเทคโนโลยี
📡 Cellular Network
›GSM – 2G, โทร + SMS เท่านั้น
›3G – อินเทอร์เน็ต, ความเร็วต่ำ
›4G – เร็ว, ดู YouTube, Video Call
›LTE – Long Term Evolution (4G ขั้นสูง)
›5G – เร็วสุด, IoT, Latency ต่ำมาก
›เชื่อมต่อผ่าน Cell Tower (เสาสัญญาณ)
📶 Wi-Fi
›ระยะ 20–100 เมตร
›ต้องรู้ SSID + Passphrase
›เชื่อมต่อผ่าน Access Point (AP)
›SSID ซ่อน → ต้องเพิ่มเครือข่ายเอง
›เคยเชื่อมแล้ว → Auto-connect ครั้งต่อไป
›อุปกรณ์เลือก Wi-Fi ก่อน Cellular เสมอ
🎧 Bluetooth
›ระยะ ~10–100 เมตร (ขึ้นอยู่กับ Class)
›พลังงาน: ต่ำมาก (Low Power)
›ทดแทนสาย: หูฟัง, เมาส์, คีย์บอร์ด
›ต้อง Pairing ก่อนใช้ครั้งแรก
›สูงสุด 8 เครื่องพร้อมกัน
›Discoverable Mode + PIN สำหรับ Pairing
📲 NFC
›ชื่อเต็ม: Near Field Communication
›ระยะ: 4–10 เซนติเมตรเท่านั้น
›ใช้: จ่ายเงิน, สแกนบัตร, เปิดประตู
›วิธีใช้: แตะ/แนบชิดกัน
›ไม่ต้องใช้อินเทอร์เน็ต
🛰️ GPS
›ชื่อเต็ม: Global Positioning System
›รับสัญญาณจาก ดาวเทียม (รับทางเดียว)
›ความแม่นยำ: ~10 เมตร
›ไม่ใช้อินเทอร์เน็ตเลย
›ใช้ใน: Google Maps, Grab, Food Delivery
🔒 ความปลอดภัย Wi-Fi
›WEP – ห้ามใช้ ถูกแฮกได้ง่ายมาก
›WPA2 – มาตรฐานขั้นต่ำที่ Cisco กำหนด
›WPA3 – ล่าสุด ปลอดภัยที่สุด
›ใช้ VPN บน Wi-Fi สาธารณะ
›ห้ามส่งข้อมูลแบบ Plaintext
