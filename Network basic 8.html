🌐 Network Basics 6 — หา Network Address & ดูว่า IP อยู่ Network เดียวกันไหม

Module 8 (IPv4 Addressing · Networks and Hosts) · เตรียมสอบ + ใช้งานจริงในสาย Network Engineer
แก่นของบท: IPv4 = 32 bits = 4 Octets = Network Portion + Host Portion. Subnet Mask คือตัวบอกว่า "Network จบตรงไหน"

1. พื้นฐาน IPv4

  • Logical Address ระบุ Host บน Network · ต้อง Unique ภายใน Local Network
  • กำหนดให้ Network Interface (NIC) ไม่ใช่ตัวเครื่องลอย ๆ — Server 2 NIC = 2 IP
  • ทุก Packet มี Source IP + Destination IP (ให้ Reply กลับถูกที่)
  • แต่ละ Octet = 0–255 · IPv4 = 32 bits · IPv6 = 128 bits

2. Subnet Mask 3 แบบหลัก

MaskCIDRNetworkHostตัวอย่าง
255.0.0.0/8Octet 12–410.5.4.100 → 10.0.0.0
255.255.0.0/16Octet 1–23–4172.16.4.100 → 172.16.0.0
255.255.255.0/24Octet 1–3410.5.4.100 → 10.5.4.0
เพิ่มเติม: /24 = จำนวน bit 1 ต่อเนื่องจากซ้ายใน Mask (24 bits = 255.255.255.0) — ใน CCNA/งานจริงจะเห็นเขียนแบบ 192.168.1.50/24 บ่อยกว่าเขียน Mask เต็ม

3. วิธีหา Network Address (4 ขั้น)

  1. ดู Subnet Mask
  2. นับว่า Network กี่ Octet (นับ 255)
  3. เก็บส่วน Network ไว้
  4. เปลี่ยน Host Portion เป็น 0
10.5.4.100 / 255.255.255.0
10.5.4 | 100   →  Network Address = 10.5.4.0

4. วิธีเช็กว่า "Network เดียวกัน" ไหม

Host-A  10.5.4.100/24  → Network = 10.5.4.0
10.5.4.1    ✅  (10.5.4 ตรง)
10.5.4.99   ✅
10.5.100.4  ❌  (Octet 3 ต่าง)
10.5.0.1    ❌
10.0.0.98   ❌
กฎ: Network Portion เหมือนกัน + Host Portion ไม่ซ้ำ = อยู่ Network เดียวกัน (IP ต่างกันได้ ขอแค่ Network Portion ตรง)
ระวัง: ต้องเทียบเฉพาะ Octet ที่เป็น Network ตาม Mask — /16 เทียบแค่ 2 Octet แรก ไม่ใช่ 3

5. 🧠 เพิ่มให้ครบแบบ Engineer: ทำไมถึงทำแบบนี้ได้ (AND Operation)

จริง ๆ แล้ว Network Address = IP AND Subnet Mask (ทีละ bit) — "เปลี่ยน Host เป็น 0" เป็นแค่ทางลัดที่ใช้ได้เมื่อ Mask ตัดตรง Octet 
192.168.5.130  = 11000000.10101000.00000101.10000010
255.255.255.128= 11111111.11111111.11111111.10000000
AND            = 11000000.10101000.00000101.10000000
               = 192.168.5.128   (Mask /25 ตัดกลาง Octet!)
ในสอบ Module นี้มีแค่ /8 /16 /24 แต่งานจริง (Subnetting) จะเจอ /25–/30 — ใช้ AND หรือ Calculator แท็บถัดไป

6. ค่าอื่นที่ได้จาก Network Address (ของใหม่)

ค่าวิธีได้ตัวอย่าง 192.168.1.0/24

7. ข้าม Network ต้องใช้อะไร

  • Network เดียวกัน → คุยกันตรง ผ่าน Switch (Switch ส่งตาม MAC; Host ใช้ ARP หา MAC)
  • คนละ Network → ต้องผ่าน Router (Routing) · Host ต้องตั้ง Default Gateway (IP ของ Router ใน Network ตัวเอง)
  • Router สนใจแค่ "Network ปลายทางอยู่ทางไหน" ไม่ต้องจำทุก Host = Hierarchical Addressing
  • Physical Network เดียวมีหลาย Logical Network ได้ (เช่น 192.168.18.x กับ 192.168.5.x) แต่จะคุยข้ามกันก็ต้อง Routing
📌 ปรับความเข้าใจ: ในสรุปเดิมเขียนว่า "Network Portion ไม่ตรง = สื่อสารไม่ได้" — ที่ถูกคือ "สื่อสารตรงไม่ได้" ต้องมี Router/Gateway ตัวกลาง ถ้าตั้ง IP ผิด Network (เช่น ย้าย PC ไปเสียบ Network อื่นแต่ยังใช้ IP เดิม) ก็จะติดต่อใครไม่ได้เพราะ Gateway ไม่อยู่ใน Network เดียวกับ PC

  1. ตั้ง PC1 = 192.168.1.10/24, PC2 = 192.168.1.20/24 ต่อ Switch เดียวกัน → ping ผ่าน
  2. เปลี่ยน PC2 เป็น 192.168.2.20/24 → ping ไม่ผ่าน (คนละ Network ไม่มี Router)
  3. เพิ่ม Router: Gi0/0 = 192.168.1.1/24, Gi0/1 = 192.168.2.1/24 ตั้ง Default Gateway ให้ PC ทั้งสอง → ping ผ่าน

  5. ลองตั้ง Mask เป็น /16 กับ PC หนึ่งเครื่อง แล้ว ping หา → ผลเป็นอย่างไร? (คิดก่อนทดสอบ: Mask ไม่ตรงกันทำให้ 2 ฝั่งเห็น "Network" ไม่เหมือนกัน)

📋 Cheat Sheet

IPv4 = 32 bits = 4 Octets = Network + Host
/8  255.0.0.0     → จำ 1 Octet
/16 255.255.0.0   → จำ 2 Octet
/24 255.255.255.0 → จำ 3 Octet
Network Addr  = IP AND Mask  (Host bits = 0)
Broadcast     = Host bits = 1
Usable hosts  = 2^h − 2
Same network  = Network Portion เหมือนกัน
Different net = ต้องใช้ Router + Default Gateway
IPv4 = Logical + Hierarchical   (IPv6 = 128 bits)
ต้องมี IP: Server 2 NIC, Printer NIC ในตัว, IP Phone
ไม่ต้อง: PDA ต่อ PC, Web camera ต่อ Host, Wireless mouse
🎯 ประโยคเดียวก่อนทำโจทย์: ดู Mask → นับ Octet ของ Network → เอาส่วน Network ไปเทียบ → Host เป็น 0 = Network Address
