แนวคิดหลัก

การส่งข้อมูล

  • Unicast 1→1 : Source IP เป็น Unicast เสมอ
  • Broadcast 1→ทุกเครื่องใน Broadcast Domain
  • Multicast 1→กลุ่มที่สมัคร (224.0.0.0/4)
  • Limited = 255.255.255.255 ; Directed = broadcast ของ Network ปลายทาง เช่น 192.168.10.255

Broadcast Domain

  • Switch flood ไปทุกพอร์ตใน VLAN ยกเว้นพอร์ตขาเข้า
  • Router ไม่ส่ง Broadcast ข้าม Interface → เป็นขอบเขต
  • ตัวอย่าง: ARP Request, DHCP Discover
  • ใหญ่เกินไป → Network ช้า + อุปกรณ์ช้า

Subnetting

  • ยืม Host bits มาเป็น Subnet bits
  • Subnet = 2n (n = บิตที่ยืม)
  • Host ใช้ได้ = 2h − 2
  • ประโยชน์: ลด Broadcast, เพิ่ม Performance, คุม Security, จำกัดผลกระทบ

การจัดสรร Public IP

IANA → RIR → ISP → องค์กร

RIR มี 5 แห่ง: AfriNIC, APNIC, ARIN, LACNIC, RIPE NCC ; ไทยอยู่ใน APNIC

จุดที่ต้องแก้ / เพิ่มเติมจากสรุปเดิม

  • เลขข้อในเฉลย Q1–Q2 ไม่ตรงกับลำดับที่เรียง (เช่น Q1 ตอบ "ข้อ 2,4" แต่ข้อที่ถูกถูกจัดเป็นข้อ 1,2) ตอนสอบจริงให้ตอบตามเนื้อหา ไม่ใช่จำเลขข้อ
  • ช่วง Unicast "1.1.1.1–223.255.255.255" เป็นการเขียนแบบย่อของ Cisco ความจริงคือ 1.0.0.0–223.255.255.255 หักช่วงสงวนออก (127/8 อยู่ในช่วงนี้แต่เป็น Loopback)
  • Private IP "ไม่ Route" ที่ถูกคือ Router ภายในองค์กร Route ได้ แต่ Internet/ISP ไม่ Route ออกนอก ต้องใช้ NAT (ส่วนใหญ่เป็น PAT) หรือ VPN
  • Directed Broadcast เดิมไม่ได้บอกว่า Router สมัยใหม่ปิดไว้ (Cisco IOS: no ip directed-broadcast เป็นค่าเริ่มต้น) เพราะถูกใช้โจมตีแบบ Smurf
  • Multicast ไม่ได้จำกัดเอง Switch ที่ไม่มี IGMP snooping จะ flood Multicast เหมือน Broadcast
  • สูตร 2h − 2 มีข้อยกเว้น: /31 ใช้ได้ 2 เครื่อง (ลิงก์ point-to-point, RFC 3021) และ /32 คือ 1 Host (loopback ของ Router, route เฉพาะเครื่อง)
  • Cloud: AWS และ Azure สงวน 5 address ต่อ Subnet (GCP 4) ดังนั้น /28 ใน AWS ใช้ได้ 11 ไม่ใช่ 14 ; และ 169.254.169.254 คือ Metadata service ของ Cloud ไม่ใช่ปัญหา DHCP
  • IPv6 เทียบเท่า: ::1 = Loopback, fe80::/10 = Link-local, ff00::/8 = Multicast, fc00::/7 = ULA (คล้าย Private) ; IPv6 ไม่มี Broadcast ใช้ Multicast แทน และใช้ NDP แทน ARP
  • กรณี Broadcast ของ DHCP: DHCP Discover ส่งจาก 0.0.0.0 ไป 255.255.255.255 (ข้อยกเว้นของกฎ "Source เป็น Unicast ที่ใช้งานได้")
