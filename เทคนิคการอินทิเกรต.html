5.1 · อินทิเกรตทีละส่วน (By Parts)

สูตร
∫ u dv = uv − ∫ v du
💡 เลือก u อย่างไรไล่ลำดับ L-I-A-T-E : ลอการิทึม → ตรีโกณผกผัน → พีชคณิต (xⁿ) → ตรีโกณ → เอกซ์โพเนนเชียล ตัวไหนมาก่อนให้เป็น u ส่วนที่เหลือเป็น dv

ตัวอย่าง 1: ∫ x ln x dx

u = ln x , dv = x dx → du = dx/x , v = x²/2 ∫ x ln x dx = (x²/2) ln x − ½∫ x dx = (x²/2) ln x − x²/4 + C

ตัวอย่าง 2: ∫ x sin2x dx

u = x , dv = sin2x dx → du = dx , v = −½cos2x ∫ x sin2x dx = −(x/2)cos2x + ½∫cos2x dx = −(x/2)cos2x + ¼ sin2x + C

ตัวอย่าง 3: ∫ x²e²ˣ dx (ทำซ้ำ 2 รอบ)

รอบ 1: u = x², dv = e²ˣdx → x²e²ˣ/2 − ∫ x e²ˣ dx รอบ 2: ∫ x e²ˣ dx = x e²ˣ/2 − e²ˣ/4 ∴ ∫ x²e²ˣ dx = e²ˣ ( x²/2 − x/2 + 1/4 ) + C

ตัวอย่าง 4: ∫ eᵃˣ sin bx dx , ∫ e²ˣ cos3x dx (วนกลับมาเป็นตัวเดิม)

⚠️ เทคนิคทำ by parts 2 รอบ จะได้ I กลับมาปรากฏอีกข้างของสมการ → ย้ายข้างแล้วแก้หา I (อย่าลืมสลับ u,dv ให้เป็นกลุ่มเดิมทั้ง 2 รอบ)
∫ eᵃˣ sin bx dx = eᵃˣ( a sin bx − b cos bx )/(a²+b²) + C ∫ e²ˣ cos3x dx = e²ˣ( 2cos3x + 3sin3x )/13 + C

5.2.1 · ฟังก์ชันตรีโกณมิติ sin–cos

รูปแบบเงื่อนไขวิธี
∫ sinⁿx cosᵐx dxm หรือ n เป็นเลขคี่บวกแยกตัวที่เป็นคี่ออก 1 ตัว (เหลือเป็น du) ที่เหลือแปลงด้วย sin²+cos²=1
∫ sinⁿx cosᵐx dxm, n เป็นเลขคู่บวกใช้ sin²x=(1−cos2x)/2 , cos²x=(1+cos2x)/2
∫ sin mx cos nx , cos mx cos nx , sin mx sin nxm ≠ nแปลงผลคูณเป็นผลบวก (ด้านล่าง)
sin mx cos nx = ½[ sin(m+n)x + sin(m−n)x ] cos mx cos nx = ½[ cos(m+n)x + cos(m−n)x ] sin mx sin nx = ½[ cos(m−n)x − cos(m+n)x ]

∫ cos³x dx (คี่)

u = sin x , du = cos x dx ∫ (1 − sin²x) cos x dx = ∫ (1 − u²) du = sin x − sin³x/3 + C

∫ sin³2x cos⁴2x dx (คี่)

u = cos2x , du = −2 sin2x dx = −½∫ (1−u²)u⁴ du = −½( u⁵/5 − u⁷/7 ) = cos⁷2x/14 − cos⁵2x/10 + C

∫ sin²3x dx (คู่)

= ∫ (1 − cos6x)/2 dx = ½[ x − sin6x/6 ] + C = x/2 − sin6x/12 + C

∫ sin²x cos⁴x dx (คู่ — เฉลยเพิ่ม)

sin²x cos²x = ¼ sin²2x → integrand = ⅛ sin²2x (1 + cos2x) = ⅛·(1−cos4x)/2 + ⅛ sin²2x cos2x ∫ = x/16 − sin4x/64 + sin³2x/48 + C

∫ sin3x cos2x dx (ผลคูณ→ผลบวก — เฉลยเพิ่ม)

= ½∫ ( sin5x + sin x ) dx = −cos5x/10 − ½cos x + C

5.2.2 · tan, cot, sec, csc

กรณีรูปแบบวิธี
1tanᵐx , cotᵐxแยก tan²x = sec²x−1 (cot²x = csc²x−1) แล้ว u = tan x (หรือ cot x)
2secⁿx , cscⁿx (n คู่)แยก sec²x ออก 1 ตัว ที่เหลือ sec² = 1+tan² ; u = tan x
3tanᵐ secⁿ (n คู่)เหมือนกรณี 2
4tanᵐ secⁿ (m คี่)แยก sec x tan x ออก ที่เหลือ tan² = sec²−1 ; u = sec x
5secⁿx (n คี่)by parts
6tanᵐ secⁿ (m คู่, n คี่)แปลงเป็น secᵏ แล้ว by parts แบบกรณี 5

∫ tan³x dx

= ∫ tan x (sec²x − 1) dx = ∫ tan x d(tan x) − ∫ tan x dx = ½tan²x − ln|sec x| + C

∫ cot⁴3x dx (เฉลยเพิ่ม)

cot⁴ = cot²·csc² − csc² + 1 ∫ = −cot³3x/9 + cot3x/3 + x + C

∫ csc⁶x dx (เฉลยเพิ่ม)

csc⁶ = (1+cot²x)² csc²x , u = cot x , du = −csc²x dx ∫ = −( cot x + 2cot³x/3 + cot⁵x/5 ) + C

∫ tan⁵(x/2) sec⁴(x/2) dx

u = tan(x/2) , du = ½ sec²(x/2) dx = 2∫ u⁵(1+u²) du = tan⁶(x/2)/3 + tan⁸(x/2)/4 + C

∫ tan⁵x sec⁷x dx

u = sec x , du = sec x tan x dx , tan⁴ = (u²−1)² = ∫ (u²−1)² u⁶ du = sec¹¹x/11 − 2sec⁹x/9 + sec⁷x/7 + C

∫ sec³x dx และ ∫ tan²x sec³x dx

∫ sec³x dx = ½ sec x tan x + ½ ln|sec x + tan x| + C สูตรลดกำลัง: ∫ secⁿx dx = secⁿ⁻²x tan x/(n−1) + (n−2)/(n−1) ∫ secⁿ⁻²x dx tan²x sec³x = sec⁵x − sec³x ∫ = ¼sec³x tan x − ⅛ sec x tan x − ⅛ ln|sec x + tan x| + C

5.3 · แทนด้วยฟังก์ชันตรีโกณมิติ

มีรากแบบแทนสามเหลี่ยม
√(a²−x²)x = a sinθด้านตรงข้าม x , ด้านเอียง a , ชิด √(a²−x²)
√(a²+x²)x = a tanθตรงข้าม x , ชิด a , ด้านเอียง √(a²+x²)
√(x²−a²)x = a secθด้านเอียง x , ชิด a , ตรงข้าม √(x²−a²)
💡 ขั้นตอนแทน x → อินทิเกรตเป็นฟังก์ชันของ θ → วาดสามเหลี่ยมเพื่อแปลงกลับเป็น x (ใช้ sin2θ = 2sinθcosθ เมื่อเจอมุมสองเท่า)

① ∫ dx/√(4+x²)

x = 2tanθ , dx = 2sec²θ dθ , √(4+x²) = 2secθ = ∫ secθ dθ = ln|secθ + tanθ| + C = ln|√(4+x²) + x| + C'

② ∫ x²/√(9−x²) dx

x = 3sinθ , dx = 3cosθ dθ → 9∫ sin²θ dθ = (9/2)(θ − sinθ cosθ) = (9/2) sin⁻¹(x/3) − (x/2)√(9−x²) + C

③ ∫ dx/√(2x−x²) (เติมกำลังสอง)

2x − x² = 1 − (x−1)² → u = x−1 : ∫ du/√(1−u²) = sin⁻¹(x−1) + C

④ ∫ dx/(4x²+4x+2)

4x²+4x+2 = (2x+1)² + 1 , u = 2x+1 , du = 2dx = ½∫ du/(u²+1) = ½ tan⁻¹(2x+1) + C
สูตรลัด (ไม่ใช่เรื่องใหม่)
∫ du/(u²+a²) = (1/a) tan⁻¹(u/a) + C ∫ du/√(a²−u²) = sin⁻¹(u/a) + C

5.4 · แยกเศษส่วนย่อย (Partial Fractions)

⚠️ ก่อนแยกต้องให้ดีกรีของเศษ น้อยกว่า ส่วน ถ้าเท่ากันหรือมากกว่าให้ หารยาวก่อน เช่น (x⁴−10x²+3x+1)/(x²−4) = x²−6 + (3x−23)/(x²−4)
กรณีตัวประกอบของ Q(x)รูปที่แยก
1เชิงเส้นไม่ซ้ำ (ax+b)A/(ax+b)
2เชิงเส้นซ้ำ (ax+b)ᵖA₁/(ax+b) + A₂/(ax+b)² + … + Aₚ/(ax+b)ᵖ
3กำลังสองแยกต่อไม่ได้ x²+px+q(Ax+B)/(x²+px+q)
💡 หาค่าคงที่(1) แทนค่า x ที่ทำให้ตัวประกอบเป็น 0 (2) เทียบสัมประสิทธิ์ ใช้ผสมกันได้

กรณี 1: ∫ (x+7)/(x²+8x+15) dx

(x+7)/((x+3)(x+5)) = A/(x+3) + B/(x+5) → x+7 = A(x+5)+B(x+3) x=−5 : 2 = −2B → B = −1 ; x=−3 : 4 = 2A → A = 2 ∫ = 2ln|x+3| − ln|x+5| + C

กรณี 2: ∫ (x³−1)/(x²(x−2)³) dx

= A/x + B/x² + C/(x−2) + D/(x−2)² + E/(x−2)³ A=3/16 , B=1/8 , C=−3/16 , D=5/4 , E=7/4 ∫ = (3/16)ln|x| − 1/(8x) − (3/16)ln|x−2| − 5/(4(x−2)) − 7/(8(x−2)²) + C

กรณี 3: ∫ (x²−2x−3)/((x−1)(x²+2x+2)) dx (เฉลยเพิ่ม)

= A/(x−1) + (Bx+C)/(x²+2x+2) → A = −4/5 , B = 9/5 , C = 7/5 (9x+7)/5 = (9/10)(2x+2) − 2/5 แล้ว x²+2x+2 = (x+1)²+1 ∫ = −(4/5)ln|x−1| + (9/10)ln(x²+2x+2) − (2/5)tan⁻¹(x+1) + C
ข้อสุดท้ายในสไลด์∫ (x−2)/(x(x²−4x+5)²) dx ใช้รูป A/x + (Bx+C)/(x²−4x+5) + (Dx+E)/(x²−4x+5)² (ตัวประกอบกำลังสองที่ซ้ำ ต้องมีเศษเป็น Ax+B ทุกเทอม)
