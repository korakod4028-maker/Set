6.0
Introduction to Network Media
ทำไม Network Engineer ต้องเข้าใจเรื่องสื่อกลาง

🏥 ตัวอย่างจาก Cisco: ห้องผู้ป่วยในโรงพยาบาล

อุปกรณ์การแพทย์ 15–20 เครื่องในห้องผู้ป่วยเชื่อมต่อแบบ Wireless แต่ที่เคาน์เตอร์พยาบาล Desktop Computer ปิด Wi-Fi แล้วยังใช้งานระบบโรงพยาบาลได้ปกติ — เพราะเชื่อมผ่าน Ethernet Cable (UTP) นี่คือเหตุผลที่ต้องเข้าใจสื่อกลางทุกประเภท ไม่ใช่แค่ Wi-Fi

Network Media คืออะไร: สื่อกลางที่ข้อมูลใช้เดินทางจาก Source ไปยัง Destination

เปรียบเทียบง่าย ๆ: ข้อมูล = รถยนต์  |  Media = ถนน — ไม่มีถนน รถวิ่งไม่ได้ / ไม่มี Media ข้อมูลก็ส่งไม่ได้

1. Copper Media

สายทองแดง ส่งข้อมูลด้วย Electrical Impulses (สัญญาณไฟฟ้า)

  • Twisted-Pair (UTP/STP)
  • Coaxial
💡

2. Fiber Optic

สายใยแก้ว ส่งข้อมูลด้วย Pulses of Light (พัลส์แสง) ไม่ใช้ไฟฟ้า

  • Single-mode
  • Multi-mode
📡

3. Wireless

ไม่มีสาย ส่งข้อมูลด้วยการ Modulation บน Electromagnetic Waves

  • Wi-Fi, Bluetooth
  • Cellular (4G/5G)
สื่อกลางวิธีส่งข้อมูลตัวอย่าง

6.0 — Selection Criteria
4 ปัจจัยในการเลือก Network Media
Cisco ย้ำเสมอว่าอย่าดูแค่ความเร็ว ต้องพิจารณาให้ครบทั้ง 4 ข้อ
📏

1. Distance

ระยะทางสูงสุดที่สื่อกลางส่งสัญญาณได้โดยคุณภาพยังดี เช่น UTP ≈100 m, Fiber หลายกิโลเมตร

🏭

2. Environment

สภาพแวดล้อมที่ติดตั้ง เช่น โรงงานที่มี EMI สูง ควรเลี่ยง Copper แล้วใช้ Fiber แทน

📊

3. Amount of Data / Speed

ปริมาณข้อมูลและความเร็วที่ต้องการ เช่น Office 1 Gbps, Data Center 100–400 Gbps

💰

4. Cost

งบประมาณในการติดตั้ง UTP ถูกที่สุด ตามด้วย Coaxial ส่วน Fiber แพงที่สุดแต่ประสิทธิภาพสูงสุด

⚠️ จุดที่ข้อสอบชอบหลอก: "Type of data ที่จะส่ง" ไม่ใช่ หนึ่งใน 4 เกณฑ์ เพราะสื่อกลางทั้ง 3 ชนิดส่งข้อมูลดิจิทัล (digital data) ได้เหมือนกันหมด สิ่งที่ต่างกันคือ "วิธีเข้ารหัสสัญญาณ" (ไฟฟ้า/แสง/คลื่น) ไม่ใช่ "ประเภทข้อมูล" — ถ้าเจอโจทย์ "which is NOT a criterion" แล้วมีตัวเลือก type of data มา ให้ตอบว่านั่นคือข้อที่ไม่ใช่เกณฑ์
6.1
Twisted-Pair Cable (UTP / STP)
สื่อกลางที่ใช้มากที่สุดใน Ethernet LAN

🧵 โครงสร้าง

สายทองแดง 8 เส้น แบ่งเป็น 4 คู่ แต่ละคู่ถูก บิดเกลียว (twist) เพื่อลด EMI และ Crosstalk (สัญญาณรบกวนระหว่างคู่สาย)

🔌 หัวต่อ

ใช้หัวต่อ RJ45 เข้าหัวตามมาตรฐาน T568A หรือ T568B ซึ่งจะเรียนละเอียดในบทถัดไป

UTP

Unshielded Twisted Pair

ไม่มีฟอยล์หุ้ม ราคาถูกที่สุด นิยมที่สุดในบ้าน โรงเรียน สำนักงานทั่วไป

STP

Shielded Twisted Pair

มี Foil Shield ป้องกัน EMI ได้ดีกว่า เหมาะกับโรงงานหรือห้องเครื่องที่มีสัญญาณรบกวนสูง แลกมากับราคาที่แพงกว่า

Ethernet ใช้เป็นหลัก

6.1
Coaxial Cable
สายทองแดงรุ่นเก่าแก่ที่สุดชนิดหนึ่ง มีแกนนำสัญญาณเดี่ยว

🔌 หัวต่อ

BNC และ F-Type

📍 ใช้ที่ไหน

Cable TV, Internet Cable, Satellite, CCTV — ไม่นิยมใน LAN ปัจจุบัน

⚖️ จุดเด่น

กัน EMI ได้ดีกว่า UTP เพราะมี Metal Shield ห่อหุ้ม เหมาะกับสัญญาณความถี่สูง

ข้อเสีย: สายหนา ติดตั้งยากกว่า UTP และแทบไม่ถูกใช้ใน LAN สมัยใหม่แล้ว แต่ยังพบได้บ่อยในระบบ Cable TV / Satellite / CCTV
6.1
Fiber-Optic Cable
สื่อกลางที่ Cisco ให้ความสำคัญมากที่สุด — เร็วที่สุด ไกลที่สุด

🧬 ทำจากอะไร

แกน (Core) ทำจาก Glass หรือ Plastic — ขนาดเล็กมาก ใกล้เคียงเส้นผมมนุษย์ ล้อมด้วย Cladding และ Jacket

💡 หลักการทำงาน

LED/Laser ยิงแสงเข้า Core → Cladding สะท้อนแสงกลับเข้า Core เสมอ (Total Internal Reflection) → Receiver ปลายทางแปลงแสงกลับเป็นข้อมูล

🔌 หัวต่อทั่วไป

LC, SC, ST — ใช้ในงาน Data Center และ ISP

6.1 — Wireless
Wireless Media (โดยสรุป)
ไม่มีสาย ใช้คลื่นแม่เหล็กไฟฟ้า
📶

Wi-Fi

เชื่อมต่ออุปกรณ์ภายในบ้าน/ออฟฟิศ ผ่าน Access Point คลื่นความถี่ 2.4GHz/5GHz

📱

Cellular (4G/5G)

เชื่อมต่ออุปกรณ์พกพาผ่านเสาสัญญาณโทรศัพท์มือถือ ครอบคลุมพื้นที่กว้าง

🔵

Bluetooth

เชื่อมต่อระยะสั้น พลังงานต่ำ ใช้กับอุปกรณ์รอบตัว เช่น หูฟัง เมาส์

ข้อควรระวัง: Wireless สะดวกแต่ความเร็ว/ความเสถียรผันผวนตามสภาพแวดล้อม สิ่งกีดขวาง และจำนวนอุปกรณ์ที่แชร์คลื่นเดียวกัน — ในงานที่ต้องการความเสถียรสูง (Server, Data Center) มักเลือกใช้สายแทน
