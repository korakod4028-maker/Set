บทที่ 5: วงจรอันดับหนึ่ง (First-Order Circuits)

เน้นบทนี้เป็นหลัก เพราะบทที่ 1–3 ถูกนำไปออกสอบเก็บคะแนนไปแล้ว ส่วนบทที่ 4 (ตัวเก็บประจุ/ตัวเหนี่ยวนำ) เป็นพื้นฐานที่ต้องใช้ในบทนี้โดยตรง

τ = RC หรือ τ = L/R — ตัวเลขตัวเดียวที่ตัดสินเกรดข้อสอบข้อนี้

CORE หัวใจของบทที่ 5

Definition วงจรอันดับหนึ่ง (First-Order Circuit) คือวงจรที่มีตัวเก็บพลังงานตัวเดียว (C หรือ L หนึ่งตัว หรือหลายตัวที่ลดรูปเป็นตัวเดียวได้) ทำให้สมการของวงจรเป็นสมการเชิงอนุพันธ์อันดับหนึ่ง คำตอบจึงอยู่ในรูป เอ็กซ์โพเนนเชียล เสมอ
vC = [vC(0) − voc] exp(−t/τ) + voc
iL = [iL(0) − isc] exp(−t/τ) + isc

ตรงตามสูตรในหนังสือ "การวิเคราะห์วงจรไฟฟ้า 1" — สังเกตว่าค่าสุดท้าย (steady-state ที่ t→∞) ของวงจร RC เรียกว่า voc (แรงดันวงจรเปิด) และของวงจร RL เรียกว่า isc (กระแสวงจรลัด) เพราะหาได้จากการมองวงจรที่ขั้ว C หรือ L แล้วคิดเป็นแรงดัน/กระแสวงจรเปิด-ลัดของวงจรเทวินิน/นอร์ตันที่เหลือ

3 สิ่งที่ต้องหาให้ได้ก่อนตอบ

  1. x(0) — ค่าเริ่มต้น: วิเคราะห์วงจรที่ t < 0 (สภาวะอยู่ตัว/steady state) แทน C ด้วยวงจรเปิด และ L ด้วยวงจรลัด แล้วหาค่า vC(0) หรือ iL(0)
  2. voc หรือ isc — ค่าสุดท้าย: วิเคราะห์วงจรที่ t > 0 เมื่อเข้าสภาวะอยู่ตัวใหม่ (นานพอ) แทน C ด้วยวงจรเปิดอีกครั้ง แล้วหาแรงดันคร่อมขั้วนั้น (คือ voc) หรือแทน L ด้วยวงจรลัดอีกครั้ง แล้วหากระแสที่ไหลผ่าน (คือ isc) — ถ้าไม่มีแหล่งกำเนิดอิสระเหลืออยู่ ค่านี้จะเป็น 0 (source-free)
  3. τ — ค่าคงตัวเวลา: หาความต้านทานเทวินิน Rth ที่ขั้วของ C หรือ L (ปลดแหล่งอิสระออก แต่ห้ามปลดแหล่งไม่อิสระ) แล้วคำนวณ τ = RthC หรือ τ = L/Rth
ระวัง — จุดที่เสียคะแนนบ่อยที่สุด เมื่อวงจรมีแหล่งจ่ายไม่อิสระ (dependent source) จะหา Rth จากการรวมความต้านทานตรง ๆ ไม่ได้ เพราะ isc = 0 เสมอ (ไม่มีแหล่งอิสระให้เกิดกระแสลัดวงจร) ต้องป้อนกระแสทดสอบ itest = 1 A เข้าไปที่ขั้ว a-b แล้วหา vtest จากนั้น Rth = vtest/itest

แผนภาพเปรียบเทียบ 2 วิธีหา Rth

สถานการณ์วิธีหา Rth
มีแต่แหล่งอิสระ (independent source)ปิดแหล่งแรงดัน (ลัดวงจร), เปิดแหล่งกระแส (วงจรเปิด) แล้วมองความต้านทานรวมจากขั้ว
มีแหล่งไม่อิสระ (dependent source) ปนอยู่ปลดเฉพาะแหล่งอิสระ แล้วป้อนกระแสทดสอบ 1 A เข้าขั้ว a-b หา vab แล้วคำนวณ Rth = vab/1
Tip — จำสูตรเดียวใช้ได้ทั้ง RC และ RL สูตร vC ใช้กับวงจร RC และสูตร iL ใช้กับวงจร RL — ส่วนกระแส/แรงดันอื่น ๆ ในวงจร (เช่น i ผ่านตัวต้านทานตัวใดตัวหนึ่ง) ก็มีรูปแบบเลขชี้กำลังแบบเดียวกัน แต่ให้คำนวณค่าเริ่มต้นและค่าสุดท้ายของปริมาณนั้นจากวงจรจริง ณ เวลานั้น ๆ โดยตรง ไม่ใช่ยกค่า voc หรือ isc ของ C/L มาใช้ตรง ๆ

5.1–5.3 วงจร RC

รูปทั่วไปของวงจร RC ที่มีแหล่งจ่าย — วิเคราะห์ 3 ขั้นตอนเดียวกับหลักการทั่วไป

5.1 วงจร RC ที่มีแหล่งกำเนิดไฟฟ้ากระแสตรง

ใช้ผลตอบสนองสมบูรณ์ = ผลตอบสนองธรรมชาติ + ผลตอบสนองบังคับ ได้สูตรทั่วไป:

vC(t) = [vC(0) − voc] e^(−t/τ) + voc ,   τ = RthC

5.2 วงจร RC ที่ไม่มีแหล่งกำเนิดอิสระ (source-free)

เมื่อไม่มีแหล่งอิสระเหลืออยู่เลยในช่วง t > 0 ตัวเก็บประจุจะคายประจุจนแรงดันเข้าสู่ 0 นั่นคือ voc = 0 เสมอ ทำให้สูตรง่ายลงเหลือ:

vC(t) = vC(0)·e^(−t/τ)

5.3 ค่าคงตัวทางเวลา τ (Time Constant)

ความหมายของ τ τ คือเวลาที่ทำให้ผลตอบสนองเปลี่ยนไป 63.2% ของระยะทางทั้งหมด (จากค่าเริ่มต้น (0) ไปค่าสุดท้าย voc หรือ isc) — ยิ่ง τ มาก วงจรยิ่งตอบสนองช้า โดยทั่วไปถือว่าวงจร "เข้าสู่สภาวะอยู่ตัว" แล้วเมื่อเวลาผ่านไป 5τ

5.4–5.5 วงจร RL

รูปทั่วไปของวงจร RL — สมมาตรกับ RC โดยสลับบทบาท v↔i และ C↔L

5.4 วงจร RL ที่มีแหล่งกำเนิดไฟฟ้ากระแสตรง

iL(t) = [iL(0) − isc] e^(−t/τ) + isc ,   τ = L/Rth

5.5 วงจร RL ที่ไม่มีแหล่งกำเนิดอิสระ

iL(t) = iL(0)·e^(−t/τ)

5.6–5.7 ผลตอบสนอง & เงื่อนไขเริ่มต้น

กฎเหล็ก — ความต่อเนื่อง แรงดันตัวเก็บประจุ และ กระแสตัวเหนี่ยวนำ เปลี่ยนแปลงแบบทันทีทันใดไม่ได้ (ไม่กระโดด) ดังนั้น vC(0⁻) = vC(0⁺) และ iL(0⁻) = iL(0⁺) เสมอ — แต่ กระแสผ่าน C และ แรงดันคร่อม L กระโดดได้ตามปกติ ห้ามสับสน!

ขั้นตอนละเอียดสำหรับหาค่าเริ่มต้น (t < 0)

  1. วาดวงจรที่ t < 0 โดยสมมติว่าสวิตช์อยู่ในตำแหน่งเดิมมานานแล้ว (สภาวะอยู่ตัว/DC steady state)
  2. แทนตัวเก็บประจุด้วยวงจรเปิด (เพราะกระแสผ่าน C ในสภาวะอยู่ตัว = 0)
  3. แทนตัวเหนี่ยวนำด้วยวงจรลัด (เพราะแรงดันคร่อม L ในสภาวะอยู่ตัว = 0)
  4. วิเคราะห์วงจรตัวต้านทานล้วนที่เหลือด้วย KCL/KVL/แรงดันโนด เพื่อหา vC(0⁻) หรือ iL(0⁻)
  5. ใช้เงื่อนไขความต่อเนื่อง → ได้ vC(0⁺) = vC(0⁻) หรือ iL(0⁺) = iL(0⁻)

5.6 ผลตอบสนองต่อสัญญาณเข้าที่มีค่าคงที่ (step input)

เมื่อแหล่งจ่ายเป็นค่าคงที่ (DC) ทั้งก่อนและหลังสวิตช์ทำงาน ผลตอบสนองจะเป็นเลขชี้กำลังธรรมดาตามสูตรมาตรฐานด้านบน ไม่มีเทอมอื่นแทรก

5.8 ผลตอบสนองต่อสัญญาณเข้าที่ไม่คงที่

หากแหล่งจ่ายเป็นฟังก์ชันของเวลา (เช่น sin, exponential) ต้องแก้สมการเชิงอนุพันธ์เต็มรูปแบบ (ผลเฉลยทั่วไป = ผลตอบสนองธรรมชาติ + ผลตอบสนองบังคับเฉพาะรูปสัญญาณ) — สำหรับข้อสอบระดับนี้ มักเจอเฉพาะ step input เป็นหลัก ให้เน้นเทคนิค 3 ขั้นตอนให้แม่นก่อน

ตัวอย่าง โจทย์ตัวอย่างแบบเต็มขั้นตอน

ตัวอย่างที่ 1 — วงจร RC ที่มีแหล่งไม่อิสระ (ใช้เทวินิน)

โจทย์: ig = 1 A, R1 = 12 Ω, R2 = 3 Ω, R3 = 6 Ω, C = 0.1 F, vg = 12 V สวิตช์เปลี่ยนสถานะที่ t = 0 หา vC(t) เมื่อ t > 0

ขั้น 1 — หา vC(0): ที่ t<0 แทน C ด้วยวงจรเปิด ไม่มีกระแสผ่าน R2,R3 จึงเหลือ ig ผ่าน R1//R3

Req = R1//R3 = (12×6)/(12+6) = 4 Ω vC(0) = Req·ig = 4×1 = 4 V

ขั้น 2 — หา voc: ที่ t>0 ปลดแหล่งกระแส ig ออก (สวิตช์ตัดวงจรนั้นแล้ว) เหลือ vg ผ่าน R2 แบ่งแรงดันให้ R3

voc = R3/(R2+R3) · vg = 6/(3+6) × 12 = 8 V

ขั้น 3 — หา τ: ปลดแหล่ง vg ด้วยการลัดวงจร มองจากขั้ว C จะเห็น R2//R3

Rth = R2//R3 = (3×6)/(3+6) = 2 Ω τ = RthC = 2 × 0.1 = 0.2 s

สรุปคำตอบ:

vC(t) = (4 − 8)e^(−t/0.2) + 8 = 8 − 4e^(−5t)  V

ตรวจสอบ: t=0 → 4V ✓ , t=5τ=1s → ≈8V ✓ (เข้าใกล้ค่าสุดท้ายตามสัดส่วน 63%/95%/99%)

ตัวอย่างที่ 2 — วงจร RL ที่มีแหล่งไม่อิสระ (ใช้กระแสทดสอบหา Rth)

โจทย์: ig = 1 A, R1 = 3 Ω, R2 = 6 Ω, L = 0.3 H, แหล่งไม่อิสระ 3i (ควบคุมโดยกระแส i ผ่าน R1) วงจรอยู่ตัวก่อน t=0 แล้วสวิตช์เปิด หา i(t) ผ่าน R2 เมื่อ t>0

ขั้น 1 — หา iL(0): ก่อน t=0 สวิตช์ยังต่ออยู่ที่ตำแหน่งเดิม และ L ถูกแทนด้วยวงจรลัด ทำให้ไม่มีแรงดันคร่อม R2 และไม่มีกระแสผ่าน R2 (i(0)=0) จึงไม่มีกระแสผ่าน R1 ด้วย (แหล่งไม่อิสระ 3i(0)=0)

iL(0) = ig = 1 A   (กระแสทั้งหมดไหลลัดผ่าน L)

ขั้น 2 — หา isc: เมื่อสวิตช์เปิดแล้ว ไม่มีแหล่งอิสระเหลืออยู่ในวงจร (ig ถูกตัดออกไปแล้ว) → เป็นวงจร source-free

isc = 0 A

ขั้น 3 — หา Rth: มีแหล่งไม่อิสระ 3i ปนอยู่ ต้องป้อนกระแสทดสอบ ith = 1 A เข้าขั้ว a-b แล้วใช้ Super Node เขียนสมการโนด vth:

(vth − 3i)/R1 + vth/R2 − ith = 0 ,   i = vth/R2 แทนค่า R1=3, R2=6, ith=1 → vth = 3 V Rth = vth/ith = 3/1 = 3 Ω
τ = L/Rth = 0.3/3 = 0.1 s

สรุปคำตอบ:

iL(t) = (1−0)e^(−t/0.1) + 0 = e^(−10t)  A

หา vL ด้วย vL = L·diL/dt = −3e^(−10t) V จากนั้นหากระแส i ผ่าน R2 (ขนานกับ L จึงมีแรงดันเท่ากัน):

i(t) = vL/R2 = −0.5e^(−10t)  A
สังเกตแบบแผนโจทย์ในชีทของ Mix โจทย์แบบฝึกหัดข้อ 19–21 ในเอกสารล้วนใช้แพทเทิร์นเดียวกัน: (1) มีแหล่งไม่อิสระที่ควบคุมด้วยกระแสสาขาใดสาขาหนึ่ง (2) ต้องใช้ Super Node หรือกระแสทดสอบหา Rth (3) คำตอบสุดท้ายมักมีรูป v หรือ i = ค่าคงที่ ± ค่าคงที่·exp(−t/τ) — ฝึกไล่ 3 ขั้นตอนให้คล่องจนไม่ต้องคิดว่าจะเริ่มตรงไหน

CHEAT SHEET สูตรทั้งหมดในหน้าเดียว

สูตรพื้นฐานที่ต้องใช้ร่วมกับบทที่ 5 เสมอ

กฎของโอห์ม (Ohm's Law)
v = iR   หรือ   i = v/R
ตัวต้านทานอนุกรม/ขนาน
อนุกรม: Req = R1+R2+... ขนาน: Req = R1R2/(R1+R2)
ตัวแบ่งแรงดัน (Voltage Divider)
v1 = R1/(R1+R2) · vs

ใช้เมื่อ R1, R2 ต่ออนุกรมกันคร่อมแหล่งแรงดัน vs — แรงดันตกคร่อมตัวต้านทานตัวที่สนใจ เป็นสัดส่วนกับค่าความต้านทานของตัวมันเองหารด้วยผลรวม

ตัวแบ่งกระแส (Current Divider)
i1 = R2/(R1+R2) · is

ใช้เมื่อ R1, R2 ต่อขนานกันรับแหล่งกระแส is — สังเกตว่ากระแสที่ไหลผ่านตัวต้านทานตัวที่สนใจ (R1) เป็นสัดส่วนกับความต้านทานอีกตัวหนึ่ง (R2) ไม่ใช่ของตัวเอง (สลับกับสูตรแบ่งแรงดัน)

ตัวเก็บประจุ (Capacitor)
iC = C · dvC/dt vC(t) = vC(0) + (1/C)∫iC dt พลังงาน: w = ½CvC²

vC ต่อเนื่องเสมอ แต่ iC กระโดดได้ทันที

ตัวเหนี่ยวนำ (Inductor)
vL = L · diL/dt iL(t) = iL(0) + (1/L)∫vL dt พลังงาน: w = ½LiL²

iL ต่อเนื่องเสมอ แต่ vL กระโดดได้ทันที

ทริคใช้ v=L di/dt และ i=C dv/dt ในบทที่ 5 เมื่อรู้สมการ iL(t) หรือ vC(t) แบบเอ็กซ์โพเนนเชียลแล้ว มักต้องหาปริมาณคู่กันต่อ (vL จาก iL หรือ iC จาก vC) — ให้ diff เอ็กซ์โพเนนเชียลตรง ๆ:
ถ้า iL(t) = A·e^(−t/τ)  ⟹  vL(t) = L·diL/dt = −(LA/τ)·e^(−t/τ) ถ้า vC(t) = A·e^(−t/τ)  ⟹  iC(t) = C·dvC/dt = −(CA/τ)·e^(−t/τ)
สังเกตว่าอนุพันธ์ของ e^(−t/τ) แค่คูณด้วย (−1/τ) เท่านั้น รูปฟังก์ชันเลขชี้กำลังไม่เปลี่ยน — จุดสังเกตนี้ช่วยตรวจคำตอบตัวเองได้ไว

สูตรวงจรอันดับหนึ่ง (บทที่ 5)

RL Circuit
iL(t) = [iL(0)−isc]e^(−t/τ) + isc τ = L/Rth t<0: L → short circuit
หา Rth เมื่อมีแหล่งไม่อิสระ
1. ปลดแหล่งอิสระทั้งหมด (V→short, I→open) 2. ป้อน i_test = 1 A เข้าขั้ว a-b (คงแหล่งไม่อิสระไว้) 3. หา v_test ด้วย Node/Mesh (ระวัง Super Node ถ้ามีแหล่งควบคุมแรงดันคร่อมสองโนด) 4. R_th = v_test / i_test
เช็คลิสต์ก่อนส่งกระดาษคำตอบ
  • เขียน vC(0⁺)=vC(0⁻) หรือ iL(0⁺)=iL(0⁻) ชัดเจนในกระดาษคำตอบ (อาจารย์บางท่านให้คะแนนขั้นตอนนี้แยก)
  • ตรวจหน่วยของ τ ต้องเป็นวินาทีเสมอ (R×C หรือ L/R)
  • เช็คเครื่องหมายของกระแส/แรงดันให้ตรงกับทิศทางอ้างอิงที่กำหนดในโจทย์
  • แทน t=0 กลับเข้าคำตอบสุดท้าย ต้องได้ค่าเท่ากับ x(0) ที่คำนวณไว้ (self-check)
  • แทน t→∞ (หรือ t=5τ) ต้องได้ค่าใกล้เคียง voc หรือ isc
  • อย่าสับสนสูตรแบ่งแรงดัน (ใช้ R ของตัวเอง) กับสูตรแบ่งกระแส (ใช้ R ของอีกตัว) — สลับกันบ่อยที่สุด

ฝึกทำ แบบฝึกหัดทบทวนก่อนสอบ

1. วงจร RC ที่ไม่มีแหล่งกำเนิดอิสระ (source-free) ค่า voc จะเท่ากับเท่าใดเสมอ?
2. เมื่อวิเคราะห์วงจรที่ t < 0 (สภาวะอยู่ตัว) ตัวเหนี่ยวนำ (L) ควรแทนด้วยอะไร?
3. ถ้าวงจรมีแหล่งกำเนิดไม่อิสระ (dependent source) เหตุใดจึงหา Rth จาก voc/isc โดยตรงไม่ได้?
4. วงจร RC มี vC(0)=4V, voc=8V, τ=0.2s สมการ vC(t) คือข้อใด?
5. ปริมาณใดที่ "ต่อเนื่อง" (ห้ามกระโดดทันที) ที่ t=0?
6. เวลาผ่านไปกี่เท่าของ τ จึงถือว่าวงจรเข้าสู่สภาวะอยู่ตัวใหม่โดยประมาณ?

8. τ = RthC ใช้กับวงจรชนิดใด และ τ = L/Rth ใช้กับวงจรชนิดใด?
