การวิเคราะห์วงจรไฟฟ้า 1 · สรุปเตรียมสอบ

บทที่ 3–5: ทฤษฎีบทวงจร, C/L และวงจรอันดับหนึ่ง

เน้นบทที่ 5 (วงจรอันดับหนึ่ง) เป็นหลักเพราะข้อสอบมักออกเยอะที่สุด แต่รวมบทที่ 3 (ทฤษฎีบทวงจรไฟฟ้า) และบทที่ 4 (ตัวเก็บประจุ/ตัวเหนี่ยวนำ) มาให้ด้วย เพราะเป็นเครื่องมือและพื้นฐานที่ใช้ในบทที่ 5 โดยตรง

τ = RC หรือ τ = L/R — ตัวเลขตัวเดียวที่ตัดสินเกรดข้อสอบข้อนี้
ถึงตัวเองก่อนเข้าห้องสอบ — จากคะแนน 11.89/20 สู่เป้าหมายเต็ม 26

เนื้อหามันไม่ยาก เธอทำได้อยู่แล้ว ไม่ต้องไปท่องจำเทคนิคแปลก ๆ หรือสูตรลัดที่ไม่เข้าใจที่มา — แค่ใช้สามัญสำนึกไล่ตาม physical meaning ของวงจรจริง ๆ ทีละสเต็ปก็พอแล้ว ที่พลาดรอบที่แล้วไม่ใช่เพราะไม่รู้ทฤษฎี แต่เพราะรีบ ข้ามขั้นตอน หรือท่องสูตรมาใช้มั่ว ๆ โดยไม่ทันดูว่าวงจรจริงมันเป็นแบบนั้นหรือเปล่า

  • ใจเย็น ๆ ไล่ตามขั้นตอนเสมอ — เจอโจทย์วงจรอันดับหนึ่ง ให้ทำ 3 ขั้นตอนตามสเต็ป (x(0) → voc/isc → τ) ไปทีละอย่าง อย่าข้ามไปเดาคำตอบเพราะ "รู้สึกว่าน่าจะประมาณนี้"
  • ก่อนใช้สูตรแบ่งแรงดัน/แบ่งกระแส อย่าเพิ่งท่องสูตร ให้มองภาพวงจรจริงก่อน — ถามตัวเองด้วยสามัญสำนึกว่ากระแสไหลผ่าน R ตามลำดับจริงไหม หรือ R สองตัวมันคร่อมขั้วเดียวกันอยู่ ไม่ต้องจำเคสพิเศษ แค่มองตามหลักฟิสิกส์จริงของวงจรก็ตอบได้เองอยู่แล้ว
  • เขียนทุกขั้นลงกระดาษ อย่าคิดในหัวล้วน ๆ แม้จะรู้สึกว่า "เบสิคขนาดนี้ไม่ต้องเขียนก็ได้" เพราะจุดพลาดส่วนใหญ่มาจากขั้นตอนเบสิคที่รีบข้าม ไม่ใช่ตรงที่ยาก
  • เผื่อเวลาตรวจทาน — เช็ก t=0 กับ t→∞ ว่าตรงกับ x(0) และ voc/isc ที่คำนวณไว้ไหม ก่อนส่งกระดาษ

ช้าแต่ชัวร์ ดีกว่าเร็วแต่พลาดจุดง่าย ๆ — สู้ ๆ นะ 💪

บทที่ 3 ทฤษฎีบทวงจรไฟฟ้า (Circuit Theorems)

บทนี้เป็นเครื่องมือหลักที่ใช้หา vC(0), voc, isc, Rth ในบทที่ 5 — ถ้าทำบทนี้ไม่แม่น จะติดขัดตอนวิเคราะห์วงจรอันดับหนึ่งทันที

3.1 การแปลงแหล่งกำเนิด (Source Transformation)

หลักการ แหล่งแรงดัน vs ต่ออนุกรมกับ R หนึ่งตัว สามารถแปลงเป็นแหล่งกระแส is ต่อขนานกับ R ตัวเดิมได้ โดยที่วงจรภายนอกมองเห็นผลเหมือนเดิมทุกประการ
is = vs / R   ⇄   vs = is · R

ใช้ลดรูปวงจรให้ง่ายก่อนวิเคราะห์ โดยเฉพาะเมื่อโจทย์ให้ผสมกันทั้งแหล่งแรงดันและแหล่งกระแส

3.2 การทับซ้อน (Superposition)

  1. เปิดใช้งานแหล่งอิสระทีละตัว (ตัวอื่นปิด: แหล่งแรงดัน→ลัดวงจร, แหล่งกระแส→วงจรเปิด)
  2. คำนวณผลตอบสนอง (v หรือ i ที่ต้องการ) จากแหล่งนั้นตัวเดียว
  3. ทำซ้ำจนครบทุกแหล่งอิสระ
  4. รวมผลตอบสนองทั้งหมดเข้าด้วยกัน (บวกพีชคณิต โดยระวังเครื่องหมาย)
ระวัง Superposition ใช้ได้กับวงจรเชิงเส้น (linear) เท่านั้น และห้ามปิดแหล่งไม่อิสระ (dependent source) เด็ดขาด ต้องคงไว้ในทุกขั้นตอน

3.3 ทฤษฎีบทของเทวินิน (Thevenin's Theorem)

ใจความ วงจรใด ๆ ที่มองจากขั้ว a-b สามารถแทนที่ด้วยแหล่งแรงดัน vth ต่ออนุกรมกับ Rth ตัวเดียวได้เสมอ
  1. หา vth = voc (แรงดันวงจรเปิดที่ขั้ว a-b เมื่อปลดโหลดออก)
  2. หา Rth โดยปลดแหล่งอิสระทั้งหมดแล้วมองความต้านทานจากขั้ว a-b (หรือใช้กระแสทดสอบถ้ามีแหล่งไม่อิสระ)
vth = voc  ,  Rth = voc/isc

3.4 ทฤษฎีบทของนอร์ตัน (Norton's Theorem)

ใจความ วงจรเดียวกันสามารถแทนที่ด้วยแหล่งกระแส iN ต่อขนานกับ RN ได้เช่นกัน ซึ่งเป็นแค่วงจรเทวินินที่ถูกแปลงแหล่งกำเนิด (3.1) นั่นเอง
iN = isc  ,  RN = Rth  (ค่าเดียวกัน)

ความสัมพันธ์: iN = vth/Rth — นี่คือที่มาของตัวแปร voc และ isc ที่ใช้ในสูตรบทที่ 5 โดยตรง

3.5 การถ่ายโอนกำลังสูงสุด (Maximum Power Transfer)

Rload = Rth  ⟹  Pmax = vth² / (4Rth)

โหลดจะได้รับกำลังไฟฟ้าสูงสุดเมื่อค่าความต้านทานโหลดเท่ากับ Rth ของวงจรที่มองเห็นจากขั้วโหลดพอดี

เชื่อมกับบทที่ 5 เวลาโจทย์บทที่ 5 ให้วงจรซับซ้อน ให้ใช้เทวินิน/นอร์ตัน (3.3–3.4) ลดรูปวงจรที่เหลือ (ไม่รวม C หรือ L) ให้เป็น vth+Rth ตัวเดียวก่อนเสมอ แล้วค่อยต่อ C หรือ L กลับเข้าไปวิเคราะห์ต่อ — เป็นเทคนิคที่ตัวอย่างในบทที่ 5 ใช้ซ้ำทุกข้อ

บทที่ 4 ตัวเก็บประจุและตัวเหนี่ยวนำ (Capacitors and Inductors)

4.1–4.3 ตัวเก็บประจุ (Capacitor)

นิยาม ตัวเก็บประจุเก็บพลังงานในรูปสนามไฟฟ้า ความสัมพันธ์ระหว่างประจุกับแรงดันคือ Q = Cv
iC(t) = C · dvC/dt
vC(t) = vC(t0) + (1/C)∫t0t iC dτ พลังงานสะสม: wC = ½ C vC²
การต่อสูตร Ceq
อนุกรม1/Ceq = 1/C1 + 1/C2 + ... (เหมือน R ขนาน)
ขนานCeq = C1 + C2 + ... (เหมือน R อนุกรม)
จำสลับกับ R ให้แม่น ตัวเก็บประจุ "สลับ" กับตัวต้านทาน: C อนุกรมใช้สูตรแบบ R ขนาน และ C ขนานใช้สูตรแบบ R อนุกรม เพราะปริมาณที่เก็บ (ประจุ) สะสมต่างจากกระแสที่ไหลผ่าน

4.4–4.6 ตัวเหนี่ยวนำ (Inductor)

นิยาม ตัวเหนี่ยวนำเก็บพลังงานในรูปสนามแม่เหล็ก ความสัมพันธ์ระหว่างฟลักซ์กับกระแสคือ λ = Li
vL(t) = L · diL/dt
iL(t) = iL(t0) + (1/L)∫t0t vL dτ พลังงานสะสม: wL = ½ L iL²
การต่อสูตร Leq
อนุกรมLeq = L1 + L2 + ... (เหมือน R อนุกรม)
ขนาน1/Leq = 1/L1 + 1/L2 + ... (เหมือน R ขนาน)

สังเกตว่า L รวมตัวแบบเดียวกับ R (ไม่สลับเหมือน C)

4.7 สถานะอยู่ตัวในวงจรไฟฟ้ากระแสตรง (DC Steady State)

หัวใจสำคัญที่สุดของบทที่ 5 เมื่อวงจร DC อยู่ในสภาวะอยู่ตัวมานานพอ (แรงดัน/กระแสไม่เปลี่ยนแปลงตามเวลาอีกต่อไป):
dvC/dt = 0  ⟹  iC = 0  ⟹  C ทำตัวเป็นวงจรเปิด diL/dt = 0  ⟹  vL = 0  ⟹  L ทำตัวเป็นวงจรลัด
นี่คือที่มาของขั้นตอนแรกในวิธีทำบทที่ 5 (การหา vC(0) และ iL(0)) โดยตรง — ไปดูต่อได้ที่แท็บ "บทที่ 5: วิธีทำ 3 ขั้นตอน"
ตัวอย่างเชื่อมโยง ถ้าโจทย์ให้ C = 0.1 F ต่อขนานกับ R และ iC(t) = 0.5e−5t A ที่ผ่านมันในช่วง t>0 สามารถหา vC(t) กลับได้จาก vC = vC(0) + (1/C)∫iCdt หรือถ้ารู้ vC(t) อยู่แล้ว ให้ diff กลับหา iC = C·dvC/dt แทน — ใช้สลับไปมาได้เสมอ 2 ทาง

CORE หัวใจของบทที่ 5

Definition วงจรอันดับหนึ่ง (First-Order Circuit) คือวงจรที่มีตัวเก็บพลังงานตัวเดียว (C หรือ L หนึ่งตัว หรือหลายตัวที่ลดรูปเป็นตัวเดียวได้) ทำให้สมการของวงจรเป็นสมการเชิงอนุพันธ์อันดับหนึ่ง คำตอบจึงอยู่ในรูป เอ็กซ์โพเนนเชียล เสมอ
vC = [vC(0) − voc] exp(−t/τ) + voc
iL = [iL(0) − isc] exp(−t/τ) + isc

ตรงตามสูตรในหนังสือ "การวิเคราะห์วงจรไฟฟ้า 1" — สังเกตว่าค่าสุดท้าย (steady-state ที่ t→∞) ของวงจร RC เรียกว่า voc (แรงดันวงจรเปิด) และของวงจร RL เรียกว่า isc (กระแสวงจรลัด) เพราะหาได้จากการมองวงจรที่ขั้ว C หรือ L แล้วคิดเป็นแรงดัน/กระแสวงจรเปิด-ลัดของวงจรเทวินิน/นอร์ตันที่เหลือ

3 สิ่งที่ต้องหาให้ได้ก่อนตอบ

  1. x(0) — ค่าเริ่มต้น: วิเคราะห์วงจรที่ t < 0 (สภาวะอยู่ตัว/steady state) แทน C ด้วยวงจรเปิด และ L ด้วยวงจรลัด แล้วหาค่า vC(0) หรือ iL(0)
  2. voc หรือ isc — ค่าสุดท้าย: วิเคราะห์วงจรที่ t > 0 เมื่อเข้าสภาวะอยู่ตัวใหม่ (นานพอ) แทน C ด้วยวงจรเปิดอีกครั้ง แล้วหาแรงดันคร่อมขั้วนั้น (คือ voc) หรือแทน L ด้วยวงจรลัดอีกครั้ง แล้วหากระแสที่ไหลผ่าน (คือ isc) — ถ้าไม่มีแหล่งกำเนิดอิสระเหลืออยู่ ค่านี้จะเป็น 0 (source-free)
  3. τ — ค่าคงตัวเวลา: หาความต้านทานเทวินิน Rth ที่ขั้วของ C หรือ L (ปลดแหล่งอิสระออก แต่ห้ามปลดแหล่งไม่อิสระ) แล้วคำนวณ τ = RthC หรือ τ = L/Rth
ระวัง — จุดที่เสียคะแนนบ่อยที่สุด เมื่อวงจรมีแหล่งจ่ายไม่อิสระ (dependent source) จะหา Rth จากการรวมความต้านทานตรง ๆ ไม่ได้ เพราะ isc = 0 เสมอ (ไม่มีแหล่งอิสระให้เกิดกระแสลัดวงจร) ต้องป้อนกระแสทดสอบ itest = 1 A เข้าไปที่ขั้ว a-b แล้วหา vtest จากนั้น Rth = vtest/itest

แผนภาพเปรียบเทียบ 2 วิธีหา Rth

สถานการณ์วิธีหา Rth
มีแต่แหล่งอิสระ (independent source)ปิดแหล่งแรงดัน (ลัดวงจร), เปิดแหล่งกระแส (วงจรเปิด) แล้วมองความต้านทานรวมจากขั้ว
มีแหล่งไม่อิสระ (dependent source) ปนอยู่ปลดเฉพาะแหล่งอิสระ แล้วป้อนกระแสทดสอบ 1 A เข้าขั้ว a-b หา vab แล้วคำนวณ Rth = vab/1
Tip — จำสูตรเดียวใช้ได้ทั้ง RC และ RL สูตร vC ใช้กับวงจร RC และสูตร iL ใช้กับวงจร RL — ส่วนกระแส/แรงดันอื่น ๆ ในวงจร (เช่น i ผ่านตัวต้านทานตัวใดตัวหนึ่ง) ก็มีรูปแบบเลขชี้กำลังแบบเดียวกัน แต่ให้คำนวณค่าเริ่มต้นและค่าสุดท้ายของปริมาณนั้นจากวงจรจริง ณ เวลานั้น ๆ โดยตรง ไม่ใช่ยกค่า voc หรือ isc ของ C/L มาใช้ตรง ๆ

จุดเสียคะแนนตัวจริง Node Voltage vs Mesh Current เจอแหล่งกำเนิด

ตอนหา Rth ด้วยกระแสทดสอบ (itest = 1 A) ในวงจรที่มีแหล่งไม่อิสระ ส่วนใหญ่ที่เสียคะแนนไม่ใช่เพราะตั้งสมการผิดวิธี แต่เพราะใส่ค่าแหล่งกำเนิดผิดจังหวะ / ผิดเครื่องหมาย — หัวข้อนี้สรุปกฎที่ต้องจำให้แม่นที่สุด

กฎหลัก: จับคู่ "ชนิดของแหล่ง" กับ "ชนิดของตัวแปรที่แก้"

วิธีวิเคราะห์ตัวแปรที่แก้เจอแหล่ง...ทำยังไง
Node VoltageV ที่แต่ละโหนดแหล่งกระแสใส่ค่ากระแสนั้นเข้า/ออกจากโหนดใน KCL ได้เลย ไม่ต้องเขียนเป็น V/R
Mesh CurrentI ของแต่ละเมชแหล่งแรงดันใส่ค่าแรงดันนั้นเข้า KVL ได้เลย ไม่ต้องเพิ่มตัวแปร
ทำไมถึงใส่ตรง ๆ ได้ เพราะตัวแปรที่กำลังแก้ (V ของโหนด หรือ I ของเมช) ตรงกับปริมาณที่แหล่งกำเนิดชนิดนั้นควบคุมพอดี จึงไม่ต้องมีสมการเสริม — แหล่งกระแสบอกกระแสมาให้ตรง ๆ (Node ต้องการกระแส) และแหล่งแรงดันบอกแรงดันมาให้ตรง ๆ (Mesh ต้องการแรงดัน)

แต่ถ้า "สลับข้าง" ต้องเพิ่ม Supernode / Supermesh

Node Voltage เจอแหล่งแรงดัน ถ้าแหล่งแรงดันลอยอยู่ระหว่าง 2 โหนดที่ไม่มีตัวไหนเป็นกราวด์ → เกิด Supernode
1. รวม 2 โหนดเป็นก้อนเดียว เขียน KCL รวมสมการเดียว (กระแสเข้า-ออกทุกกิ่งที่แตะขอบก้อน) 2. เพิ่มสมการเสริม: V₁ − V₂ = Vsource
Mesh Current เจอแหล่งกระแส ถ้าแหล่งกระแสถูกใช้ร่วมกันโดย 2 เมช (ไม่ได้อยู่ขอบนอกวงจร) → เกิด Supermesh
1. รวม 2 เมชเป็นก้อนเดียว เขียน KVL รวมสมการเดียว (ข้ามกิ่งที่มีแหล่งกระแสนั้นไป) 2. เพิ่มสมการเสริม: I₁ − I₂ = Isource

จุดที่พลาดบ่อยที่สุด (จากโจทย์จริง) — เช็ก 2 ข้อนี้ทุกครั้ง

พลาดแบบที่ 1 — เอา R มาหารกิ่งที่มีแหล่งกระแสอุดมคติ ถ้ากิ่งหนึ่งมี "แหล่งกระแสอุดมคติ" ต่ออนุกรมกับ R แล้วเข้าโหนดที่กำลังแก้ กระแสในกิ่งนั้นถูกบังคับให้เท่ากับค่าแหล่งกระแสพอดีเสมอ ไม่ว่า R จะเท่าไหร่
❌ ผิด: (Va − Ith) / R ← เอา R มาหารทั้งที่ไม่เกี่ยว ✅ ถูก: −Ith ← ใส่ค่ากระแสเข้า KCL ตรง ๆ ไม่ต้องหารด้วยอะไร
R ตัวนั้นมีผลแค่กับแรงดันคร่อมตัวมันเอง (ใช้ตอนย้อนกลับไปหา V ที่ขั้ว a-b ทีหลัง) ไม่ได้มีผลต่อค่ากระแสที่ไหลในกิ่งเลย
พลาดแบบที่ 2 — ใส่เครื่องหมายแหล่งไม่อิสระผิดขั้ว ก่อนใส่ค่าแหล่งควบคุม (เช่น 2i, 2i2) ลง KCL/KVL ต้องดูขั้ว +/− ของมันในรูปวงจรก่อนเสมอ ว่าอยู่ด้านไหน แล้วเขียนศักย์ของโหนดที่ติดกับมันให้ตรงเครื่องหมาย — สลับ + กับ − ตรงนี้จุดเดียว คำตอบท้ายสุดพังทั้งข้อ ทั้งที่วิธีคิดถูกทุกขั้นตอน
ขั้ว + อยู่บน (ต่อกราวด์ด้านล่าง) ⟹ ศักย์โหนดนั้น = +2i₂ กระแสไหลออกจาก Va ผ่าน R เข้าหาโหนดนั้น ⟹ (Va − 2i₂) / R

ตัวอย่างสรุป (โจทย์หา Rth ที่เพิ่งฝึกไป)

วงจร: 2i₂ (แหล่งแรงดันพึ่งพา ขั้ว + บน) — 3Ω — โหนด a (Va) — 5Ω ลงกราวด์ (i₂ = Va/5) — 2.5Ω — แหล่งกระแสทดสอบ ith=1A ลงกราวด์

  1. ใช้ Node Voltage เพราะแหล่งทดสอบเป็นแหล่งกระแส เข้าโหนด a โดยตรง → ใส่ −ith ใน KCL ได้เลย ไม่ต้องหารด้วย 2.5Ω
  2. เช็กขั้ว 2i₂: + อยู่บน ต่อกราวด์ด้านล่าง ⟹ กิ่ง 3Ω คือ (Va − 2i₂)/3 (เครื่องหมายลบ ไม่ใช่บวก)
  3. เขียน KCL ที่โหนด a: (Va − 2i₂)/3 + Va/5 − ith = 0
  4. แทน i₂ = Va/5 แล้วกระจาย ต้องคงเครื่องหมายลบไว้: Va/3 − (2/3)(Va/5) + Va/5 = 1
  5. แก้สมการ: 6Va/15 = 1 ⟹ Va = 2.5 V
  6. Rth = Va / ith = 2.5/1 = 2.5 Ω
วิธีตรวจทานก่อนส่งกระดาษ (ทำได้ใน 10 วินาที)
  • วนดูทุกกิ่งที่มีแหล่งกระแสต่ออนุกรมกับ R เข้าโหนด — เขียนแค่ ± ค่ากระแส ห้ามมี /R ต่อท้าย
  • วนดูทุกแหล่งควบคุม (dependent source) ในสมการ — ชี้นิ้วที่ขั้ว +/− ในรูปจริง เทียบกับเครื่องหมายที่เขียนในสมการทีละคู่
  • ถ้ามีแหล่งแรงดันคั่นระหว่าง 2 โหนดที่ไม่ใช่กราวด์ → ต้องมี supernode equation คู่กันเสมอ (V₁−V₂=Vs) ถ้าไม่มีแปลว่าลืม
  • ถ้ามีแหล่งกระแสคั่นระหว่าง 2 เมช → ต้องมี supermesh equation คู่กันเสมอ (I₁−I₂=Is)

5.1–5.3 วงจร RC

รูปทั่วไปของวงจร RC ที่มีแหล่งจ่าย — วิเคราะห์ 3 ขั้นตอนเดียวกับหลักการทั่วไป

5.1 วงจร RC ที่มีแหล่งกำเนิดไฟฟ้ากระแสตรง

ใช้ผลตอบสนองสมบูรณ์ = ผลตอบสนองธรรมชาติ + ผลตอบสนองบังคับ ได้สูตรทั่วไป:

vC(t) = [vC(0) − voc] e^(−t/τ) + voc ,   τ = RthC

5.2 วงจร RC ที่ไม่มีแหล่งกำเนิดอิสระ (source-free)

เมื่อไม่มีแหล่งอิสระเหลืออยู่เลยในช่วง t > 0 ตัวเก็บประจุจะคายประจุจนแรงดันเข้าสู่ 0 นั่นคือ voc = 0 เสมอ ทำให้สูตรง่ายลงเหลือ:

vC(t) = vC(0)·e^(−t/τ)

5.4–5.5 วงจร RL

รูปทั่วไปของวงจร RL — สมมาตรกับ RC โดยสลับบทบาท v↔i และ C↔L

5.6–5.7 ผลตอบสนอง & เงื่อนไขเริ่มต้น

กฎเหล็ก — ความต่อเนื่อง แรงดันตัวเก็บประจุ และ กระแสตัวเหนี่ยวนำ เปลี่ยนแปลงแบบทันทีทันใดไม่ได้ (ไม่กระโดด) ดังนั้น vC(0⁻) = vC(0⁺) และ iL(0⁻) = iL(0⁺) เสมอ — แต่ กระแสผ่าน C และ แรงดันคร่อม L กระโดดได้ตามปกติ ห้ามสับสน!

ขั้นตอนละเอียดสำหรับหาค่าเริ่มต้น (t < 0)

  1. วาดวงจรที่ t < 0 โดยสมมติว่าสวิตช์อยู่ในตำแหน่งเดิมมานานแล้ว (สภาวะอยู่ตัว/DC steady state)
  2. แทนตัวเก็บประจุด้วยวงจรเปิด (เพราะกระแสผ่าน C ในสภาวะอยู่ตัว = 0)
  3. แทนตัวเหนี่ยวนำด้วยวงจรลัด (เพราะแรงดันคร่อม L ในสภาวะอยู่ตัว = 0)
  4. วิเคราะห์วงจรตัวต้านทานล้วนที่เหลือด้วย KCL/KVL/แรงดันโนด เพื่อหา vC(0⁻) หรือ iL(0⁻)
  5. ใช้เงื่อนไขความต่อเนื่อง → ได้ vC(0⁺) = vC(0⁻) หรือ iL(0⁺) = iL(0⁻)

5.6 ผลตอบสนองต่อสัญญาณเข้าที่มีค่าคงที่ (step input)

เมื่อแหล่งจ่ายเป็นค่าคงที่ (DC) ทั้งก่อนและหลังสวิตช์ทำงาน ผลตอบสนองจะเป็นเลขชี้กำลังธรรมดาตามสูตรมาตรฐานด้านบน ไม่มีเทอมอื่นแทรก

5.8 ผลตอบสนองต่อสัญญาณเข้าที่ไม่คงที่

หากแหล่งจ่ายเป็นฟังก์ชันของเวลา (เช่น sin, exponential) ต้องแก้สมการเชิงอนุพันธ์เต็มรูปแบบ (ผลเฉลยทั่วไป = ผลตอบสนองธรรมชาติ + ผลตอบสนองบังคับเฉพาะรูปสัญญาณ) — สำหรับข้อสอบระดับนี้ มักเจอเฉพาะ step input เป็นหลัก ให้เน้นเทคนิค 3 ขั้นตอนให้แม่นก่อน

ตัวอย่าง โจทย์ตัวอย่างแบบเต็มขั้นตอน

ตัวอย่างที่ 1 — วงจร RC ที่มีแหล่งไม่อิสระ (ใช้เทวินิน)

โจทย์: ig = 1 A, R1 = 12 Ω, R2 = 3 Ω, R3 = 6 Ω, C = 0.1 F, vg = 12 V สวิตช์เปลี่ยนสถานะที่ t = 0 หา vC(t) เมื่อ t > 0

ขั้น 1 — หา vC(0): ที่ t<0 แทน C ด้วยวงจรเปิด ไม่มีกระแสผ่าน R2,R3 จึงเหลือ ig ผ่าน R1//R3

Req = R1//R3 = (12×6)/(12+6) = 4 Ω vC(0) = Req·ig = 4×1 = 4 V
คำถามที่เจอบ่อย — ทำไม vC(0) ต้องรวม R ก่อน แต่ voc ใช้แบ่งแรงดันตรง ๆ ได้เลย?

แม้ทั้งสองวงจรจะ "มี R อยู่ 2 ตัว" เหมือนกัน แต่โครงสร้างการต่อไม่เหมือนกัน กุญแจคือดูว่า R ทั้งสองตัวอนุกรมกันเป็นลูปเดียว (แบ่งแรงดันได้) หรือขนานคร่อมขั้วเอาต์พุตเดียวกัน (ต้องรวมก่อน)

กรณี voc (รูปที่ 5.26): วงจรคือ vg → R2 → โหนด → R3 → กราวด์ → ย้อนกลับเข้า vg เป็นลูปเดียว กระแสตัวเดียวไหลผ่าน R2 แล้วต่อเนื่องผ่าน R3 ครบวงจร R2 กับ R3 จึงอนุกรมกันจริง และขั้วที่วัด voc ก็คือคร่อม R3 พอดี ซึ่งเป็นแค่ "ส่วนหนึ่ง" ของลูปนั้น จึงใช้สูตรแบ่งแรงดันตรง ๆ ได้เลย

กรณี vC(0) (รูปที่ 5.24): R1 และ R3 ต่างคร่อมขั้วเอาต์พุตเดียวกันทั้งคู่ ไม่มีตัวไหนอยู่ "ระหว่างทาง" ให้กระแสไหลผ่านเป็นลำดับ (ไม่ใช่ R1→R3) มันจึงขนานกัน ไม่ใช่อนุกรม เพราะไม่มีโหลดภายนอกต่ออยู่ (ขั้วเปิดวงจรรอ C) กระแสทั้งหมดจาก ig จึงไหลวนแบ่งกันระหว่าง R1 กับ R3 (current divider) แล้วแรงดันตกคร่อมทั้งคู่จะเท่ากันเพราะขนานกัน — ค่านั้นคือ vC(0) ต้องรวม R1//R3 = Req ก่อน แล้วใช้โอห์มลอว์ v = ig·Req ตรง ๆ

เช็กไว: ก่อนใช้สูตรแบ่งแรงดัน ให้ถาม 2 ข้อนี้

  • มี R ตัวอื่นคร่อมขั้วเอาต์พุตเดียวกันกับตัวที่จะวัดหรือเปล่า? → มี = ขนานกัน ต้องรวมก่อน (แบบ vC(0))
  • กระแสไหลเป็นลำดับเดียวผ่าน R ตัวแรกแล้วเข้า R ตัวที่สองในลูปเดียวหรือเปล่า? → ใช่ = อนุกรม ใช้แบ่งแรงดันได้เลย (แบบ voc)

ขั้น 2 — หา voc: ที่ t>0 ปลดแหล่งกระแส ig ออก (สวิตช์ตัดวงจรนั้นแล้ว) เหลือ vg ผ่าน R2 แบ่งแรงดันให้ R3

voc = R3/(R2+R3) · vg = 6/(3+6) × 12 = 8 V

ขั้น 3 — หา τ: ปลดแหล่ง vg ด้วยการลัดวงจร มองจากขั้ว C จะเห็น R2//R3

Rth = R2//R3 = (3×6)/(3+6) = 2 Ω τ = RthC = 2 × 0.1 = 0.2 s

สรุปคำตอบ:

vC(t) = (4 − 8)e^(−t/0.2) + 8 = 8 − 4e^(−5t)  V

ตรวจสอบ: t=0 → 4V ✓ , t=5τ=1s → ≈8V ✓ (เข้าใกล้ค่าสุดท้ายตามสัดส่วน 63%/95%/99%)

ตัวอย่างที่ 2 — วงจร RL ที่มีแหล่งไม่อิสระ (ใช้กระแสทดสอบหา Rth)

โจทย์: ig = 1 A, R1 = 3 Ω, R2 = 6 Ω, L = 0.3 H, แหล่งไม่อิสระ 3i (ควบคุมโดยกระแส i ผ่าน R1) วงจรอยู่ตัวก่อน t=0 แล้วสวิตช์เปิด หา i(t) ผ่าน R2 เมื่อ t>0

ขั้น 1 — หา iL(0): ก่อน t=0 สวิตช์ยังต่ออยู่ที่ตำแหน่งเดิม และ L ถูกแทนด้วยวงจรลัด ทำให้ไม่มีแรงดันคร่อม R2 และไม่มีกระแสผ่าน R2 (i(0)=0) จึงไม่มีกระแสผ่าน R1 ด้วย (แหล่งไม่อิสระ 3i(0)=0)

iL(0) = ig = 1 A   (กระแสทั้งหมดไหลลัดผ่าน L)

ขั้น 2 — หา isc: เมื่อสวิตช์เปิดแล้ว ไม่มีแหล่งอิสระเหลืออยู่ในวงจร (ig ถูกตัดออกไปแล้ว) → เป็นวงจร source-free

isc = 0 A

ขั้น 3 — หา Rth: มีแหล่งไม่อิสระ 3i ปนอยู่ ต้องป้อนกระแสทดสอบ ith = 1 A เข้าขั้ว a-b แล้วใช้ Super Node เขียนสมการโนด vth:

(vth − 3i)/R1 + vth/R2 − ith = 0 ,   i = vth/R2 แทนค่า R1=3, R2=6, ith=1 → vth = 3 V Rth = vth/ith = 3/1 = 3 Ω
τ = L/Rth = 0.3/3 = 0.1 s

สรุปคำตอบ:

iL(t) = (1−0)e^(−t/0.1) + 0 = e^(−10t)  A

หา vL ด้วย vL = L·diL/dt = −3e^(−10t) V จากนั้นหากระแส i ผ่าน R2 (ขนานกับ L จึงมีแรงดันเท่ากัน):

i(t) = vL/R2 = −0.5e^(−10t)  A
สังเกตแบบแผนโจทย์ในชีทของ Mix โจทย์แบบฝึกหัดข้อ 19–21 ในเอกสารล้วนใช้แพทเทิร์นเดียวกัน: (1) มีแหล่งไม่อิสระที่ควบคุมด้วยกระแสสาขาใดสาขาหนึ่ง (2) ต้องใช้ Super Node หรือกระแสทดสอบหา Rth (3) คำตอบสุดท้ายมักมีรูป v หรือ i = ค่าคงที่ ± ค่าคงที่·exp(−t/τ) — ฝึกไล่ 3 ขั้นตอนให้คล่องจนไม่ต้องคิดว่าจะเริ่มตรงไหน

vC ต่อเนื่องเสมอ แต่ iC กระโดดได้ทันที

ตัวเหนี่ยวนำ (Inductor)
vL = L · diL/dt iL(t) = iL(0) + (1/L)∫vL dt พลังงาน: w = ½LiL²

iL ต่อเนื่องเสมอ แต่ vL กระโดดได้ทันที

ทริคใช้ v=L di/dt และ i=C dv/dt ในบทที่ 5 เมื่อรู้สมการ iL(t) หรือ vC(t) แบบเอ็กซ์โพเนนเชียลแล้ว มักต้องหาปริมาณคู่กันต่อ (vL จาก iL หรือ iC จาก vC) — ให้ diff เอ็กซ์โพเนนเชียลตรง ๆ:
ถ้า iL(t) = A·e^(−t/τ)  ⟹  vL(t) = L·diL/dt = −(LA/τ)·e^(−t/τ) ถ้า vC(t) = A·e^(−t/τ)  ⟹  iC(t) = C·dvC/dt = −(CA/τ)·e^(−t/τ)
สังเกตว่าอนุพันธ์ของ e^(−t/τ) แค่คูณด้วย (−1/τ) เท่านั้น รูปฟังก์ชันเลขชี้กำลังไม่เปลี่ยน — จุดสังเกตนี้ช่วยตรวจคำตอบตัวเองได้ไว

สูตรวงจรอันดับหนึ่ง (บทที่ 5)

RC Circuit
vC(t) = [vC(0)−voc]e^(−t/τ) + voc τ = RthC t<0: C → open circuit
RL Circuit
iL(t) = [iL(0)−isc]e^(−t/τ) + isc τ = L/Rth t<0: L → short circuit
หา Rth เมื่อมีแหล่งไม่อิสระ
1. ปลดแหล่งอิสระทั้งหมด (V→short, I→open) 2. ป้อน i_test = 1 A เข้าขั้ว a-b (คงแหล่งไม่อิสระไว้) 3. หา v_test ด้วย Node/Mesh (ระวัง Super Node ถ้ามีแหล่งควบคุมแรงดันคร่อมสองโนด) 4. R_th = v_test / i_test
เช็คลิสต์ก่อนส่งกระดาษคำตอบ
  • เขียน vC(0⁺)=vC(0⁻) หรือ iL(0⁺)=iL(0⁻) ชัดเจนในกระดาษคำตอบ (อาจารย์บางท่านให้คะแนนขั้นตอนนี้แยก)
  • ตรวจหน่วยของ τ ต้องเป็นวินาทีเสมอ (R×C หรือ L/R)
  • เช็คเครื่องหมายของกระแส/แรงดันให้ตรงกับทิศทางอ้างอิงที่กำหนดในโจทย์
  • แทน t=0 กลับเข้าคำตอบสุดท้าย ต้องได้ค่าเท่ากับ x(0) ที่คำนวณไว้ (self-check)
  • แทน t→∞ (หรือ t=5τ) ต้องได้ค่าใกล้เคียง voc หรือ isc
  • อย่าสับสนสูตรแบ่งแรงดัน (ใช้ R ของตัวเอง) กับสูตรแบ่งกระแส (ใช้ R ของอีกตัว) — สลับกันบ่อยที่สุด
