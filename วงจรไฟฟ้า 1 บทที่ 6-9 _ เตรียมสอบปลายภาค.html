📖 8.4-8.6 กำลังเชิงซ้อน สามเหลี่ยม PF

วงจรอยู่ในสถานะอยู่ตัวที่ t = 0⁻ (สวิตช์ปิดมานาน) สวิตช์เปิดที่ t = 0 จงหา v ในช่วง t > 0
ดูเฉลย 1) t=0⁻: L ลัดวงจร, C เปิดวงจร โนด v: −3 + v/4 + v/12 + (v−24)/6 = 0 → ×12: 6v = 84 → v(0) = 14 V
  i_L(0) = 3 − 14/4 = −0.5 A (i_L ไม่ใช่ 0 และเป็นกระแสผ่านตัวเหนี่ยวนำ)
2) t>0: ฝั่งขวาถูกตัดออก · 3A ∥ 4Ω → เทเวนิน 12 V อนุกรม 4Ω → RLC อนุกรม
  LC·v″ + RC·v′ + v = 12 → 0.2v″ + 0.8v′ + v = 12 → v″ + 4v′ + 5v = 60
3) s² + 4s + 5 = 0 → s = −2 ± j1 (หน่วงขาด) → vₙ = e^(−2t)(A₁cos t + A₂sin t)
4) v_f = 60/5 = 12
5) v(0) = 14 → 12 + A₁ = 14 → A₁ = 2
  v′(0) = i_L(0)/C = −0.5/0.2 = −2.5 และ v′(0) = −2A₁ + A₂ → A₂ = 1.5
v = 12 + e^(−2t)(2cos t + 1.5 sin t) V

โจทย์ 6 · RLC ขนาน หน่วงวิกฤติ

สวิตช์ปิดมานาน เปิดที่ t = 0 จงหา i_L(t) และ v(t) สำหรับ t > 0
ดูเฉลย t=0⁻: L ลัดวงจรทั้ง C และ 1Ω → v(0)=0, i_L(0) = 24/6 = 4 A
t>0: RLC ขนานไม่มีแหล่ง: α = 1/(2RC) = 2, ω₀ = 1/√(LC) = 2 → α = ω₀ หน่วงวิกฤติ
สมการของ i_L: LC·i″ + (L/R)·i′ + i = 0 → i″ + 4i′ + 4i = 0 → s = −2 ซ้ำ
i_L = (A₁ + A₂t)e^(−2t) · i_L(0)=4 → A₁ = 4
i_L′(0) = v(0)/L = 0 และ i_L′(0) = A₂ − 2A₁ → A₂ = 8
i_L = (4 + 8t)e^(−2t) A
v = L·di_L/dt = [8 − 2(4+8t)]e^(−2t) = −16t·e^(−2t) V (v(0)=0 ✓)

โจทย์ 7 · เทเวนินแบบเฟสเซอร์

V_s = 60∠0° V (RMS) จงหาวงจรสมมูลเทเวนินที่ขั้ว a-b แล้วหากระแสและกำลังเมื่อต่อตัวต้านทาน 5 Ω ที่ขั้ว a-b
ดูเฉลย V_th (เปิดขั้ว a-b ไม่มีกระแสผ่าน j10): ตัวแบ่งแรงดัน
V_th = 60 × (−j10)/(10 − j10) = 60 × (1−j)/2 = 30(1−j) = 42.4∠−45° V
Z_th (ลัดวงจรแหล่งแรงดัน): Z_th = j10 + (10 ∥ −j10)
10 ∥ −j10 = (−j100)/(10−j10) = 5 − j5 → Z_th = 5 + j5 Ω
ต่อ 5 Ω: I = V_th/(Z_th + 5) = 30(1−j)/(10+j5) = 1.2 − j3.6 = 3.79∠−71.6° A
P = |I|²R = 14.4 × 5 = 72 W
(เสริม: Z_L = 5 − j5 Ω จะได้กำลังสูงสุด |V_th|²/(4R_th) = 1800/20 = 90 W)

โจทย์ 8 · สามเฟสมีอิมพีแดนซ์สาย
