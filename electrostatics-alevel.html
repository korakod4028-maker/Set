⚡
ประจุไฟฟ้าคืออะไร?

ประจุไฟฟ้า (Electric Charge) คือสมบัติพื้นฐานของอนุภาคมูลฐาน มีสองชนิด คือ ประจุบวก (+) และ ประจุลบ (−)

ประจุชนิดเดียวกัน → ผลักกัน  |  ประจุต่างชนิดกัน → ดึงดูดกัน

ประจุรวมในระบบปิดจะคงที่เสมอ ประจุไม่สามารถสร้างขึ้นใหม่หรือทำลายได้ จะมีแต่การถ่ายโอนเท่านั้น
🔌
การถ่ายโอนประจุ

การขัดสี (Triboelectric)

เมื่อวัตถุสองชิ้นถูกัน อิเล็กตรอนจะถ่ายโอนจากวัตถุหนึ่งไปอีกวัตถุ ทำให้เกิดประจุสุทธิ

ตัวอย่าง: ยางถูผ้าขนสัตว์ → ยางมีประจุลบ ผ้าขนสัตว์มีประจุบวก

การเหนี่ยวนำ (Induction)

วัตถุมีประจุนำมาใกล้ตัวนำ ทำให้ประจุในตัวนำแยกออกจากกัน โดยไม่ต้องสัมผัสกัน

ประจุรวมของตัวนำยังคงเป็นศูนย์

⚠️ ข้อควรระวัง
วัตถุที่ เป็นกลางทางไฟฟ้า มีจำนวนโปรตอน = จำนวนอิเล็กตรอน จึงมีประจุสุทธิ = 0 การที่วัตถุ "มีประจุ" หมายความว่ามีอิเล็กตรอนมากกว่าหรือน้อยกว่าโปรตอน
ตัวอย่าง
วัตถุ A มีประจุ +3 μC และ B มีประจุ −5 μC นำมาสัมผัสกันแล้วแยกออก
ประจุรวม = +3 + (−5) = −2 μC
ประจุแต่ละก้อน = −2 ÷ 2 = −1 μC ทั้งคู่ (ถ้าขนาดเท่ากัน)
⚙️
ตัวนำ, ฉนวน และสารกึ่งตัวนำ
ประเภทตัวอย่างการนำประจุ
ตัวนำ (Conductor)โลหะ, กราไฟต์ดีมาก
ฉนวน (Insulator)ยาง, แก้ว, พลาสติกแทบไม่นำ
สารกึ่งตัวนำ (Semiconductor)ซิลิกอน, เจอร์เมเนียมปานกลาง
หัวข้อ 2 · กฎของคูลอมบ์ (Coulomb's Law)
⚛️
กฎของคูลอมบ์
นิยาม
แรงระหว่างประจุสองตัวแปรผันตรงกับผลคูณของขนาดประจุ และแปรผกผันกับกำลังสองของระยะห่าง
F = k · |q₁q₂| / r²

โดยที่:
k = 9×10⁹ N·m²/C² (ค่าคงที่คูลอมบ์)
q₁, q₂ = ขนาดประจุ (หน่วย C)
r = ระยะห่างระหว่างประจุ (หน่วย m)
F = แรงระหว่างประจุ (หน่วย N)
💡 ค่าคงที่ k กับ ε₀
k = 1 / (4πε₀) โดย ε₀ = 8.85×10⁻¹² C²/(N·m²) คือสภาพยอมของอากาศ (permittivity of free space)
ตัวอย่างที่ 1 — หาแรง
ประจุ q₁ = +2 μC และ q₂ = −3 μC อยู่ห่างกัน 30 cm
F = (9×10⁹ × 2×10⁻⁶ × 3×10⁻⁶) / (0.3)²
F = (9×10⁹ × 6×10⁻¹²) / 0.09
F = 54×10⁻³ / 0.09 = 0.6 N (ดึงดูดกัน เพราะต่างชนิด)
ตัวอย่างที่ 2 — แรงลัพธ์จาก 3 ประจุ
ประจุ A = +4 μC อยู่ที่ x = 0, B = −2 μC อยู่ที่ x = 3 m, C = +2 μC อยู่ที่ x = 6 m
หาแรงลัพธ์บน B:
F_AB = 9×10⁹ × 4×10⁻⁶ × 2×10⁻⁶ / 3² = 8×10⁻³ N (ดึงดูด → ทิศทาง −x)
F_CB = 9×10⁹ × 2×10⁻⁶ × 2×10⁻⁶ / 3² = 4×10⁻³ N (ดึงดูด → ทิศทาง +x)
F_net = 8×10⁻³ − 4×10⁻³ = 4×10⁻³ N ในทิศ −x
⚠️ ข้อควรระวัง — ทิศทางแรง
กฎคูลอมบ์ให้ขนาดแรงเสมอ (ไม่มีเครื่องหมาย) ทิศทางแรงต้องพิจารณาจากชนิดของประจุ: ชนิดเดียวกัน = ผลัก, ต่างชนิด = ดึงดูด
📐
หลักการซ้อนทับ (Superposition Principle)

แรงลัพธ์บนประจุใดๆ คือ ผลรวมเวกเตอร์ ของแรงจากทุกประจุอื่น

F⃗_net = F⃗₁ + F⃗₂ + F⃗₃ + ...
💡 เทคนิค A-Level
เมื่อประจุวางตามแนวเส้นตรง ให้กำหนดทิศบวกก่อน แล้วใส่เครื่องหมาย (+/−) ตามทิศ จากนั้นรวมพีชคณิต แต่ถ้าไม่อยู่แนวเดียวกัน ต้องใช้การแตกเวกเตอร์ตามแนวแกน X-Y
หัวข้อ 3 · สนามไฟฟ้า (Electric Field)
🧲
นิยามสนามไฟฟ้า
นิยาม
สนามไฟฟ้า ณ จุดใดๆ คือ แรงต่อหนึ่งหน่วยประจุทดสอบบวก ที่วางไว้ที่จุดนั้น
E⃗ = F⃗ / q₀

หรือสำหรับประจุจุด Q:
E = k · |Q| / r²

หน่วย: N/C หรือ V/m
💡 ทิศทางสนามไฟฟ้า
ทิศสนามไฟฟ้าชี้ออกจากประจุบวก และชี้เข้าหาประจุลบ ทิศของ E⃗ คือทิศที่ประจุทดสอบ บวก จะเคลื่อนที่
📏
สนามไฟฟ้าสม่ำเสมอ (Uniform Electric Field)

สนามไฟฟ้าระหว่างแผ่นตัวนำขนานมีค่าสม่ำเสมอทุกจุด

E = V / d

โดยที่:
V = ความต่างศักย์ระหว่างแผ่น (V)
d = ระยะห่างระหว่างแผ่น (m)
E = ขนาดสนามไฟฟ้า (V/m)
ตัวอย่าง
แผ่นตัวนำขนานห่างกัน 5 cm มีความต่างศักย์ 200 V
E = 200 / 0.05 = 4,000 V/m
⚠️ ทิศสนามไฟฟ้าระหว่างแผ่นขนาน
สนามไฟฟ้าชี้จากแผ่นที่มีศักย์ สูง (บวก) ไปยังแผ่นที่มีศักย์ ต่ำ (ลบ) เสมอ
🔢
หลักการซ้อนทับของสนามไฟฟ้า

สนามไฟฟ้าลัพธ์คือผลรวมเวกเตอร์ของสนามจากทุกประจุ

E⃗_net = E⃗₁ + E⃗₂ + E⃗₃ + ...
💡 จุดที่สนามไฟฟ้าเป็นศูนย์
ระหว่างประจุสองตัวที่ชนิดเดียวกัน จะมีจุดที่ E = 0 เสมอ (อยู่ระหว่างกลาง ถ้าขนาดเท่ากัน) ระหว่างประจุต่างชนิดกัน จะไม่มีจุดที่ E = 0 อยู่ระหว่างประจุทั้งสอง
หัวข้อ 4 · ศักย์ไฟฟ้าและความต่างศักย์
🌀
ศักย์ไฟฟ้า (Electric Potential)
นิยาม
ศักย์ไฟฟ้า ณ จุดใดๆ คือ พลังงานศักย์ต่อหนึ่งหน่วยประจุทดสอบบวก ณ จุดนั้น (อ้างอิงที่ศักย์ = 0 ที่อนันต์)
V = W / q₀ = k · Q / r

หน่วย: โวลต์ (V) หรือ J/C

ความต่างศักย์: ΔV = V_B − V_A = −W_AB / q₀
ตัวอย่าง
ประจุจุด Q = +5 μC จงหาศักย์ที่จุด P ซึ่งอยู่ห่างออกไป 0.3 m
V = 9×10⁹ × 5×10⁻⁶ / 0.3 = 150,000 V = 150 kV
💡 ความแตกต่างระหว่าง E และ V
E คือปริมาณเวกเตอร์ (มีทิศทาง) ส่วน V คือปริมาณสเกลาร์ (ไม่มีทิศทาง)
ศักย์จากหลายประจุสามารถรวมกันด้วยพีชคณิตธรรมดา: V_net = V₁ + V₂ + V₃ + ...
⚡
งานและพลังงานกับความต่างศักย์
W = q · ΔV = q(V_B − V_A)

ΔKE = −ΔPE = q · ΔV

(สำหรับอนุภาคที่เคลื่อนที่อิสระในสนามไฟฟ้า)
ตัวอย่าง
อิเล็กตรอน (q = −1.6×10⁻¹⁹ C) เคลื่อนจากจุด A (V = 0) ไป B (V = 100 V)
W = qΔV = −1.6×10⁻¹⁹ × (100−0) = −1.6×10⁻¹⁷ J
(งานเป็นลบ → ต้องใช้แรงภายนอกผลัก → อิเล็กตรอนเคลื่อนที่ฝืนสนาม)
⚠️ จำไว้ — ทิศที่ประจุต่างชนิดเคลื่อน
ประจุบวก: เคลื่อนจากศักย์สูง → ศักย์ต่ำ โดยธรรมชาติ (งานบวก)
ประจุลบ: เคลื่อนจากศักย์ต่ำ → ศักย์สูง โดยธรรมชาติ (งานบวก)
〰️
เส้นแรงไฟฟ้าและพื้นผิวสมศักย์
เส้นแรงไฟฟ้า (Field Lines)พื้นผิวสมศักย์ (Equipotential)
มีทิศทาง ชี้จาก + ไป −ไม่มีทิศทาง
ตั้งฉากกับพื้นผิวตัวนำตั้งฉากกับเส้นแรงไฟฟ้าเสมอ
เส้นชิด = สนามแรงV คงที่บนพื้นผิวนี้
ไม่ตัดกันการเคลื่อนบนพื้นผิว: W = 0
หัวข้อ 5 · ตัวเก็บประจุ (Capacitor)
🔋
ความจุไฟฟ้า (Capacitance)
นิยาม
ความจุไฟฟ้าคืออัตราส่วนระหว่างประจุที่เก็บได้ต่อความต่างศักย์
C = Q / V

หน่วย: ฟารัด (F) หรือ C/V

สำหรับตัวเก็บประจุแบบแผ่นขนาน:
C = ε₀ · A / d

A = พื้นที่แผ่น (m²), d = ระยะห่าง (m)
ตัวอย่าง
ตัวเก็บประจุ 10 μF ต่อกับแบตเตอรี่ 12 V
Q = CV = 10×10⁻⁶ × 12 = 120 μC = 1.2×10⁻⁴ C
🔗
การต่อตัวเก็บประจุ

ต่ออนุกรม

1/C_eq = 1/C₁ + 1/C₂ + ...

Q เท่ากันทุกตัว
V รวม = V₁ + V₂ + ...

ความจุรวมน้อยกว่าความจุตัวเล็กที่สุด

ต่อขนาน

C_eq = C₁ + C₂ + ...

V เท่ากันทุกตัว
Q รวม = Q₁ + Q₂ + ...

ความจุรวมมากกว่าความจุตัวใหญ่ที่สุด

ตัวอย่าง — อนุกรม
C₁ = 6 μF, C₂ = 3 μF ต่ออนุกรม
1/C_eq = 1/6 + 1/3 = 1/6 + 2/6 = 3/6 → C_eq = 2 μF
ตัวอย่าง — ขนาน
C₁ = 4 μF, C₂ = 6 μF ต่อขนาน
C_eq = 4 + 6 = 10 μF
💡 เทคนิคจำ
ตัวเก็บประจุกับตัวต้านทาน — สูตรต่อสลับกัน!
ตัวต้านทานอนุกรม: R_eq = R₁ + R₂ (บวกตรงๆ)
ตัวเก็บประจุอนุกรม: 1/C_eq = 1/C₁ + 1/C₂ (บวกส่วนกลับ)
🧱
ไดอิเล็กตริก (Dielectric)

ไดอิเล็กตริกคือฉนวนที่แทรกระหว่างแผ่นตัวเก็บประจุ ทำให้ความจุเพิ่มขึ้น

C = κ · ε₀ · A / d

κ = ค่าคงที่ไดอิเล็กตริก (κ ≥ 1)
💡 ผลของไดอิเล็กตริก
เมื่อต่อกับแบตเตอรี่อยู่: V คงที่ → Q และ C เพิ่มขึ้น
เมื่อตัดแบตเตอรี่ออก: Q คงที่ → V ลดลง C เพิ่มขึ้น พลังงานลดลง
หัวข้อ 6 · พลังงานไฟฟ้าสถิต
⚡
พลังงานที่เก็บในตัวเก็บประจุ
U = ½ QV = ½ CV² = Q² / (2C)

หน่วย: จูล (J)
ตัวอย่าง
ตัวเก็บประจุ 50 μF ต่อกับแรงดัน 100 V
U = ½ × 50×10⁻⁶ × (100)² = ½ × 50×10⁻⁶ × 10,000 = 0.25 J
💡 จำทั้งสามรูปแบบ
รู้ Q และ V → U = ½QV
รู้ C และ V → U = ½CV²
รู้ Q และ C → U = Q²/(2C)
🔥
พลังงานของระบบประจุจุด
U = k · q₁q₂ / r

(สำหรับประจุสองตัว มีเครื่องหมาย)
⚠️ U มีเครื่องหมาย!
ประจุเดียวกัน (q₁q₂ > 0): U > 0 → ต้องใช้งานนำมาประกอบ
ประจุต่างชนิด (q₁q₂ < 0): U < 0 → ระบบเสถียร ต้องใช้งานแยกออก
ตัวอย่าง
ประจุ +3 μC และ −5 μC อยู่ห่างกัน 20 cm
U = 9×10⁹ × 3×10⁻⁶ × (−5×10⁻⁶) / 0.2
U = 9×10⁹ × (−15×10⁻¹²) / 0.2 = −0.675 J
📊
สรุปสูตรทั้งหมด
ปริมาณสัญลักษณ์สูตรหน่วย
ประจุQQ = CV = neC
แรงคูลอมบ์FF = kq₁q₂/r²N
สนามไฟฟ้าEE = F/q = kQ/r²= V/dN/C หรือ V/m
ศักย์ไฟฟ้าVV = kQ/r = W/qV
ความจุCC = Q/V = ε₀A/dF
พลังงานUU = ½CV² = Q²/2CJ
