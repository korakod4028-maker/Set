✨
หน่วยจินตภาพ i

สมการ x² + 1 = 0 ไม่มีคำตอบในจำนวนจริง เพราะไม่มีจำนวนจริงใดยกกำลังสองแล้วได้ค่าลบ นักคณิตศาสตร์จึงนิยาม หน่วยจินตภาพ i ขึ้นมาเพื่อแก้ปัญหานี้

นิยาม
i คือจำนวนที่สอดคล้องกับ i² = −1 หรือกล่าวได้ว่า i = √(−1)
ตัวอย่าง — รากที่สองของจำนวนลบ
√(−9) = √(9 × −1) = √9 × √(−1) = 3i
√(−20) = √(20) × i = 2√5 · i
⚠️ ข้อควรระวัง
กฎ √a · √b = √(ab) ใช้ได้เฉพาะเมื่อ a, b ≥ 0 เท่านั้น ห้ามใช้กฎนี้ตรง ๆ กับจำนวนลบสองตัว เช่น √(−4)·√(−9) ≠ √36 (ต้องเปลี่ยนเป็นรูป i ก่อนคูณเสมอ: 2i·3i = 6i² = −6)
🧮
รูปแบบมาตรฐาน a + bi
นิยาม
จำนวนเชิงซ้อน z เขียนในรูปแบบมาตรฐานได้เป็น z = a + bi เมื่อ a, b ∈ ℝ
เรียก a ว่า ส่วนจริง เขียนแทนด้วย Re(z) และเรียก b ว่า ส่วนจินตภาพ เขียนแทนด้วย Im(z)
ตัวอย่าง
z = 3 − 4i → Re(z) = 3, Im(z) = −4

จำนวนจริง

ถ้า b = 0 จะได้ z = a ซึ่งคือจำนวนจริงธรรมดา ดังนั้น ℝ ⊂ ℂ

จำนวนจินตภาพแท้

ถ้า a = 0 และ b ≠ 0 จะได้ z = bi เรียกว่าจำนวนจินตภาพแท้ (pure imaginary)

💡 ระบบจำนวน
ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ — จำนวนเชิงซ้อน (ℂ) เป็นระบบจำนวนที่กว้างที่สุดที่เราเรียนในระดับมัธยม
⚖️
ความเท่ากันของจำนวนเชิงซ้อน
นิยาม
a + bi = c + di ก็ต่อเมื่อ a = c และ b = d (ส่วนจริงเท่ากัน และส่วนจินตภาพเท่ากัน พร้อมกัน)
ตัวอย่าง
ถ้า (2x − 1) + (y + 3)i = 5 + 2i แล้ว
2x − 1 = 5 → x = 3
y + 3 = 2 → y = −1
⚠️ ข้อควรระวัง
หลักการนี้ใช้ได้เมื่อทั้งสองข้างเขียนในรูปมาตรฐาน a+bi แล้วเท่านั้น (จัดรูปให้เรียบร้อยก่อนเทียบสัมประสิทธิ์เสมอ)
🔁
กำลังของ i

เนื่องจาก i² = −1 ทำให้กำลังของ i มีรูปแบบวนซ้ำทุก 4 รอบ

i¹i²i³i⁴
i−1−i1
💡 เทคนิคหา iⁿ อย่างรวดเร็ว
นำ n หารด้วย 4 แล้วดูเศษ:
เศษ 1 → i    เศษ 2 → −1    เศษ 3 → −i    เศษ 0 → 1
ตัวอย่าง
หาค่า i²³
23 ÷ 4 = 5 เศษ 3 → i²³ = i³ = −i ✓
หัวข้อ 2 · การบวก ลบ คูณ หาร
➕
การบวกและการลบ
นิยาม
บวก/ลบส่วนจริงกับส่วนจริง และส่วนจินตภาพกับส่วนจินตภาพ แยกกัน
(a + bi) + (c + di) = (a+c) + (b+d)i
(a + bi) − (c + di) = (a−c) + (b−d)i
ตัวอย่าง
(3 + 4i) + (1 − 2i) = 4 + 2i
(3 + 4i) − (1 − 2i) = 2 + 6i
✖️
การคูณ
นิยาม
กระจายแบบพหุนามปกติ (FOIL) แล้วแทน i² = −1
(a+bi)(c+di) = ac + adi + bci + bdi²
= (ac − bd) + (ad + bc)i
ตัวอย่าง
(2 + 3i)(1 − 4i) = 2 − 8i + 3i − 12i²
= 2 − 8i + 3i + 12 = 14 − 5i
💡 เทคนิค
ไม่จำเป็นต้องท่องสูตร (ac−bd)+(ad+bc)i ให้ขึ้นใจ แค่กระจายแบบพหุนามตามปกติ แล้วจำไว้ว่า i² = −1 เสมอ
➗
การหาร
หลักการ
คูณทั้งเศษและส่วนด้วย สังยุคของตัวส่วน เพื่อกำจัด i ออกจากส่วน (ทำให้ส่วนเป็นจำนวนจริง)
a+bi ───── × c−di = (ac+bd) + (bc−ad)i c+di c−di c² + d²
ตัวอย่าง
(3 + 2i) / (1 − i)  →  คูณด้วย (1+i)/(1+i)
เศษ: (3+2i)(1+i) = 3+3i+2i+2i² = 3+5i−2 = 1+5i
ส่วน: (1−i)(1+i) = 1−i² = 1+1 = 2
ผลลัพธ์ = (1+5i)/2 = 1/2 + 5/2 i
📐
สมบัติของการดำเนินการ

จำนวนเชิงซ้อนมีสมบัติการสลับที่ การเปลี่ยนหมู่ และการแจกแจง เช่นเดียวกับจำนวนจริง

สลับที่ (Commutative)

z₁+z₂ = z₂+z₁
z₁z₂ = z₂z₁

เปลี่ยนหมู่ (Associative)

(z₁+z₂)+z₃ = z₁+(z₂+z₃)
⚠️ ข้อควรระวัง
จำนวนเชิงซ้อนไม่มีการเรียงลำดับ (ไม่สามารถบอกได้ว่า z₁ > z₂ เมื่อ z₁, z₂ ไม่ใช่จำนวนจริงทั้งคู่) ดังนั้นอสมการของจำนวนเชิงซ้อนที่ไม่ใช่จำนวนจริงจึงไม่มีความหมาย
หัวข้อ 3 · สังยุคและค่าสัมบูรณ์
z̄
สังยุคเชิงซ้อน (Conjugate)
นิยาม
สังยุคของ z = a+bi เขียนแทนด้วย z̄ (อ่านว่า z-bar) นิยามเป็น z̄ = a − bi (เปลี่ยนเครื่องหมายส่วนจินตภาพ)
ตัวอย่าง
z = 3 − 4i → z̄ = 3 + 4i
z = 5i → z̄ = −5i
สมบัติสำคัญของสังยุค
z + z̄ = 2Re(z)  (เป็นจำนวนจริงเสมอ)
z − z̄ = 2Im(z)·i
z · z̄ = a² + b² = |z|²  (เป็นจำนวนจริงและไม่เป็นลบเสมอ)
(z₁ + z₂)‾ = z̄₁ + z̄₂
(z₁ · z₂)‾ = z̄₁ · z̄₂
💡 ทำไมต้องใช้สังยุค
z · z̄ ให้ผลลัพธ์เป็นจำนวนจริงเสมอ นี่คือเหตุผลที่เราคูณด้วยสังยุคเมื่อต้องการกำจัด i ออกจากตัวส่วนในการหาร
|z|
ค่าสัมบูรณ์ / มอดุลัส (Modulus)
นิยาม
ค่าสัมบูรณ์ของ z = a+bi คือระยะห่างจากจุดกำเนิดถึงจุด (a,b) บนระนาบเชิงซ้อน
|z| = √(a² + b²)
ตัวอย่าง
z = 3 − 4i → |z| = √(3² + (−4)²) = √(9+16) = √25 = 5
(สังเกตความสัมพันธ์แบบสามเหลี่ยม 3-4-5)
สมบัติสำคัญของมอดุลัส
|z|² = z · z̄
|z₁ · z₂| = |z₁| · |z₂|
|z₁ / z₂| = |z₁| / |z₂|   (z₂ ≠ 0)
|z̄| = |z|
ตัวอย่างการใช้สมบัติ
z₁ = 3+4i (|z₁|=5), z₂ = 1+i (|z₂|=√2)
z₁z₂ = (3+4i)(1+i) = 3+3i+4i+4i² = −1+7i
|z₁z₂| = √(1+49) = √50 = 5√2 = |z₁|·|z₂| ✓
🧩
โจทย์ประยุกต์ที่พบบ่อย
ตัวอย่าง — หาจำนวนเชิงซ้อนจากเงื่อนไข
กำหนด z = x + yi โดยที่ |z| = 5 และ Re(z) = 3 จงหา z ที่เป็นไปได้ทั้งหมด

x = 3 → 3² + y² = 25 → y² = 16 → y = ±4
ดังนั้น z = 3+4i หรือ z = 3−4i
⚠️ ข้อควรระวัง
|z| เป็นจำนวนจริงที่ไม่เป็นลบเสมอ ห้ามเขียน |z| เป็นจำนวนเชิงซ้อนหรือจำนวนลบเด็ดขาด
หัวข้อ 4 · ระนาบอาร์กองด์และรูปเชิงขั้ว
📍
ระนาบอาร์กองด์ (Argand Plane)

เราแทนจำนวนเชิงซ้อน z = a+bi ด้วยจุด (a, b) บนระนาบ โดยแกนนอนเป็นแกนจริง และแกนตั้งเป็นแกนจินตภาพ

การแทนจุด
z = a + bi ↔ จุด (a, b)   และ |z| = √(a²+b²) คือระยะจากจุดกำเนิด (0,0) ถึงจุด (a,b)
θ
รูปเชิงขั้ว (Polar Form)
นิยาม
z = r(cos θ + i sin θ) เมื่อ r = |z| เรียกว่า มอดุลัส และ θ เรียกว่า อาร์กิวเมนต์ (มุมที่วัดจากแกนจริงบวก ทวนเข็มนาฬิกา)
r = |z| = √(a²+b²)    cos θ = a/r    sin θ = b/r
ตัวอย่าง — แปลงเป็นรูปเชิงขั้ว
z = 1 + i
r = √(1²+1²) = √2
cos θ = 1/√2, sin θ = 1/√2 → θ = 45° = π/4
ดังนั้น z = √2 (cos 45° + i sin 45°)
ตัวอย่าง — มุมในควอดรันต์ที่ 2
z = −1 + i√3
r = √(1+3) = 2
cos θ = −1/2, sin θ = √3/2 → θ อยู่ควอดรันต์ 2 → θ = 120° = 2π/3
ดังนั้น z = 2 (cos 120° + i sin 120°)
⚠️ ข้อควรระวัง — เลือกควอดรันต์ให้ถูก
ห้ามใช้ θ = arctan(b/a) ตรง ๆ โดยไม่ดูเครื่องหมายของ a และ b เพราะ arctan ให้คำตอบในช่วง (−90°, 90°) เท่านั้น ต้องพิจารณาว่าจุด (a,b) อยู่ควอดรันต์ใดก่อนเสมอ
💡 อาร์กิวเมนต์หลัก (Principal Argument)
นิยมกำหนดให้ −π < θ ≤ π (หรือ −180° < θ ≤ 180°) เพื่อให้อาร์กิวเมนต์มีค่าเดียวไม่ซ้ำซ้อน เขียนแทนด้วย Arg(z)
หัวข้อ 5 · การคูณ-หารเชิงขั้ว และทฤษฎีบทเดอมัวร์
×
การคูณและการหารในรูปเชิงขั้ว
การคูณ
z₁z₂ = r₁r₂ [cos(θ₁+θ₂) + i sin(θ₁+θ₂)]
คูณมอดุลัส แต่ "บวก" อาร์กิวเมนต์
การหาร
z₁/z₂ = (r₁/r₂) [cos(θ₁−θ₂) + i sin(θ₁−θ₂)]
หารมอดุลัส แต่ "ลบ" อาร์กิวเมนต์
ตัวอย่าง
z₁ = 2(cos30° + i sin30°), z₂ = 3(cos60° + i sin60°)
z₁z₂ = 6(cos90° + i sin90°) = 6(0 + i) = 6i
z₁/z₂ = (2/3)(cos(−30°) + i sin(−30°))
ⁿ
ทฤษฎีบทของเดอมัวร์ (De Moivre's Theorem)
ทฤษฎีบท
ถ้า z = r(cos θ + i sin θ) และ n เป็นจำนวนเต็ม แล้ว
zⁿ = rⁿ (cos nθ + i sin nθ)

ทฤษฎีบทนี้ได้จากการใช้กฎการคูณเชิงขั้วซ้ำ ๆ กัน n ครั้ง (บวกมุม θ ทีละครั้ง)

ตัวอย่าง
z = 2(cos 30° + i sin 30°) จงหา z³
z³ = 2³ (cos(3×30°) + i sin(3×30°)) = 8(cos 90° + i sin 90°) = 8(0+i) = 8i
💡 ประโยชน์ของเดอมัวร์
ใช้หาเลขยกกำลังสูง ๆ ของจำนวนเชิงซ้อนได้ง่ายกว่าการคูณตรง ๆ มาก เช่น (1+i)¹⁰ จะแปลงเป็นรูปเชิงขั้วก่อนแล้วยกกำลังจะเร็วกว่าการคูณ (1+i) สิบครั้ง
ตัวอย่าง — เลขยกกำลังสูง
หา (1+i)⁸
1+i = √2(cos45° + i sin45°)
(1+i)⁸ = (√2)⁸ (cos(8×45°) + i sin(8×45°)) = 16(cos360° + i sin360°) = 16(1+0) = 16
หัวข้อ 6 · รากที่ n ของจำนวนเชิงซ้อน
√ⁿ
สูตรหารากที่ n
ทฤษฎีบท
ถ้า z = r(cos θ + i sin θ) แล้ว รากที่ n ของ z มีทั้งหมด n ค่า หาได้จาก
zₖ = r^(1/n) [cos((θ+2kπ)/n) + i sin((θ+2kπ)/n)]
เมื่อ k = 0, 1, 2, ..., n−1
💡 แนวคิด
เพราะมุม θ, θ+2π, θ+4π, ... ต่างก็ชี้ตำแหน่งเดียวกันบนวงกลม การบวก 2kπ ก่อนหารด้วย n จึงทำให้ได้รากที่ต่างกัน n ค่า ก่อนที่จะวนกลับมาซ้ำ
🌀
ตัวอย่าง — รากที่สาม (รากที่สามของ 1)
โจทย์
จงหารากที่สามทั้งหมดของ 1

1 = 1(cos 0° + i sin 0°) → r=1, θ=0°

k=0: cos(0°) + i sin(0°) = 1
k=1: cos(120°) + i sin(120°) = −1/2 + (√3/2)i
k=2: cos(240°) + i sin(240°) = −1/2 − (√3/2)i
💡 การกระจายตัวของราก
รากที่ n ทั้ง n ค่านี้จะอยู่ห่างกันเป็นมุม 360°/n เท่า ๆ กัน บนวงกลมรัศมี r^(1/n) เสมอ (เป็นจุดยอดของรูปหลายเหลี่ยมด้านเท่า n ด้าน)
🔎
ตัวอย่าง — รากที่สองของจำนวนเชิงซ้อน
โจทย์
จงหารากที่สองของ z = 4i

4i = 4(cos 90° + i sin 90°) → r=4, θ=90°

r^(1/2) = 2
k=0: θ = 90°/2 = 45° → 2(cos45°+isin45°) = √2 + √2 i
k=1: θ = (90°+360°)/2 = 225° → 2(cos225°+isin225°) = −√2 − √2 i
ตรวจคำตอบ
(√2 + √2 i)² = 2 + 2(√2)(√2)i + 2i² = 2 + 4i − 2 = 4i ✓
หัวข้อ 7 · สมการพหุนามเชิงซ้อน
📜
ทฤษฎีบทหลักมูลของพีชคณิต
ทฤษฎีบท (Fundamental Theorem of Algebra)
สมการพหุนามดีกรี n (n ≥ 1) มีคำตอบในระบบจำนวนเชิงซ้อนเสมอ และมีคำตอบทั้งหมด n คำตอบ เมื่อนับรวมคำตอบซ้ำ

นี่คือเหตุผลสำคัญที่เราต้องขยายระบบจำนวนจริงไปเป็นจำนวนเชิงซ้อน — เพื่อให้สมการพหุนามทุกสมการมีคำตอบครบ

🪞
ทฤษฎีบทรากสังยุค (Conjugate Root Theorem)
ทฤษฎีบท
ถ้าพหุนามมีสัมประสิทธิ์เป็นจำนวนจริงทุกพจน์ และ z = a+bi (b≠0) เป็นคำตอบหนึ่งของสมการ แล้ว z̄ = a−bi ก็เป็นคำตอบด้วยเสมอ (คำตอบเชิงซ้อนเกิดเป็นคู่สังยุคกันเสมอ)
⚠️ ข้อควรระวัง
ทฤษฎีบทนี้ใช้ได้เฉพาะเมื่อสัมประสิทธิ์ของพหุนามเป็นจำนวนจริงเท่านั้น ถ้าสัมประสิทธิ์เป็นจำนวนเชิงซ้อน คำตอบไม่จำเป็นต้องเกิดเป็นคู่สังยุค
√
สมการกำลังสองที่มีค่าจำแนกเป็นลบ
สูตร
ax² + bx + c = 0  →  x = (−b ± √(b²−4ac)) / 2a
ถ้า b²−4ac < 0 คำตอบจะเป็นจำนวนเชิงซ้อนคู่สังยุคกันเสมอ
ตัวอย่าง
แก้สมการ x² − 4x + 13 = 0
ค่าจำแนก = 16 − 52 = −36
x = (4 ± √(−36))/2 = (4 ± 6i)/2 = 2 ± 3i

สมการ x³ − 5x² + 11x − 15 = 0 มีคำตอบหนึ่งคือ x = 3

ขั้นที่ 1: หารพหุนามด้วย (x−3)
x³ − 5x² + 11x − 15 = (x−3)(x² − 2x + 5)

ขั้นที่ 2: แก้ x² − 2x + 5 = 0
ค่าจำแนก = 4 − 20 = −16
x = (2 ± √(−16))/2 = (2 ± 4i)/2 = 1 ± 2i

สรุป: คำตอบทั้งสามคือ x = 3, x = 1+2i, x = 1−2i ✓ (ครบ 3 คำตอบตามดีกรีของสมการ และคำตอบเชิงซ้อนเป็นคู่สังยุคกัน)
💡 กลยุทธ์การแก้โจทย์
ถ้าโจทย์บอกคำตอบเชิงซ้อนตัวหนึ่งมาให้ (เช่น 1+2i) ให้สังยุค (1−2i) เป็นคำตอบทันทีโดยไม่ต้องคำนวณเพิ่ม แล้วใช้ทั้งสองตัวสร้างตัวประกอบกำลังสอง (x−(1+2i))(x−(1−2i)) = x²−2x+5 เพื่อหาคำตอบที่เหลือได้ง่ายขึ้น
