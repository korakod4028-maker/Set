1.1
The Connected World
อินเทอร์เน็ตและโลกที่เชื่อมต่อกัน

🌐 อินเทอร์เน็ต = Network of Networks

อินเทอร์เน็ตไม่มีเจ้าของ ไม่ใช่ของรัฐบาล บริษัท หรือคนใดคนหนึ่ง แต่เกิดจากการเชื่อมเครือข่ายจำนวนมากทั่วโลกเข้าหากัน

🏠

Small Home Network

เครือข่ายในบ้านขนาดเล็ก เชื่อมมือถือ คอม Smart TV และ Printer ผ่าน Wi-Fi Router เข้าอินเทอร์เน็ต

🏢

SOHO Network

Small Office / Home Office — ใช้แชร์ไฟล์ แชร์ Printer เชื่อมต่อระบบบริษัท เหมาะกับร้านค้า คาเฟ่ หรือทำงานจากบ้าน

🏗️

Medium to Large Network

เครือข่ายระดับองค์กร เช่น มหาวิทยาลัย ธนาคาร โรงพยาบาล มีอุปกรณ์นับร้อยถึงนับพันเครื่อง

🌍

World Wide Web (Internet)

เกิดจากการเชื่อม Local Networks ทั้งหมดทั่วโลกเข้าหากัน เป็นเครือข่ายที่ใหญ่ที่สุดในโลก

1.1 — IoT
Internet of Things
ทุกอุปกรณ์สามารถเชื่อมอินเทอร์เน็ตและส่งข้อมูลได้

Mobile Devices

  • Smartphone (GPS, กล้อง, Internet)
  • Tablet
  • Smartwatch (วัดชีพจร, นับก้าว)
  • Smart Glasses (HUD)

Connected Home

  • Smart TV / Gaming Console
  • Security System (กล้อง, ล็อค)
  • Smart Appliances (ตู้เย็น, เตาอบ)

Other Connected Devices

  • RFID Tag (ติดตามสินค้า)
  • Sensor / Actuator (เกษตรอัตโนมัติ)
  • Medical Devices (Pacemaker, ปั๊มอินซูลิน)

1.3
Bandwidth & Throughput
ความเร็วเครือข่าย — ทฤษฎี vs ความจริง
Bandwidth

ความเร็วสูงสุด

ตามทฤษฎี เปรียบเหมือนขนาดของถนน (จำนวนเลน)


= โปร 100 Mbps ที่ซื้อมา

Throughput

ความเร็วจริง

ใช้งานจริง ต่ำกว่า Bandwidth เสมอ เพราะ delay, congestion, errors


= ความเร็วที่วัดได้จริง ~70 Mbps

Latency = ความหน่วง (เวลาที่ข้อมูลใช้เดินทาง Source → Destination)
Latency ต่ำ = ดี — สำคัญมากสำหรับ เกมออนไลน์, Video Call, Cloud Computing
หน่วยค่าใช้กับ
bpsbits per secondความเร็วพื้นฐาน
Kbps10³ bps = 1,000 bpsDial-up เก่า
Mbps10⁶ bps = 1,000,000 bpsบ้าน/สำนักงาน
Gbps10⁹ bpsData Center, Backbone
Tbps10¹² bpsUndersea Cable, ISP Backbone
⚠️ สำคัญมาก: Mbps vs MB/s
b เล็ก = bit  |  B ใหญ่ = Byte  |  1 Byte = 8 bits

สูตร: MB/s = Mbps ÷ 8
ตัวอย่าง: เน็ต 100 Mbps → โหลดจริงสูงสุด 100÷8 = 12.5 MB/s

1.4 — Network Quality
Network Reliability Concepts

🔁 Fault Tolerance

ระบบยังทำงานได้แม้บางส่วนจะเสีย มี path สำรองให้ข้อมูลเดินทางอ้อม

🛡️ Redundancy

มีระบบสำรอง / เส้นทางสำรอง เพื่อป้องกัน Single Point of Failure

📶 Reliability

ความเสถียรของเครือข่ายโดยรวม Network Engineer ดูแลให้ระบบไม่ล่ม

🕸️ Internet เปรียบเหมือนใยแมงมุม
แม้บางส่วนเสีย ข้อมูลสามารถหาเส้นทางอื่นได้เสมอ — นี่คือหลักการ Fault Tolerance ที่ออกแบบมาตั้งแต่ยุค Cold War
