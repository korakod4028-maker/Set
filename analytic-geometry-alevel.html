บทที่ 1 · จุดในระบบพิกัดฉาก
📏
ระยะทางระหว่างจุดสองจุด

ใช้ทฤษฎีบทพีทาโกรัสหาความยาวเส้นตรงที่เชื่อมจุดสองจุดบนระนาบพิกัด

สูตร
กำหนดจุด P₁(x₁, y₁) และ P₂(x₂, y₂)
d = √[(x₂ − x₁)² + (y₂ − y₁)²]
ตัวอย่าง
A(1, 2), B(4, 6)
d = √[(4−1)² + (6−2)²] = √(9 + 16) = √25 = 5
💡 เทคนิค A-Level
ถ้าโจทย์ถามรูปสามเหลี่ยมมุมฉาก/รูปสี่เหลี่ยมจัตุรัส ให้หาความยาวด้านทุกด้านด้วยสูตรระยะทางแล้วเทียบค่ากำลังสอง (Converse of Pythagorean) แทนการวาดรูปเดา
⊙
จุดกึ่งกลางและจุดแบ่งส่วนของเส้นตรง
จุดกึ่งกลาง (Midpoint)
M = ( (x₁+x₂)/2 , (y₁+y₂)/2 )
ตัวอย่าง
A(2, 3), B(8, 7)
M = ((2+8)/2, (3+7)/2) = (5, 5)
จุดแบ่งส่วนเส้นตรงตามอัตราส่วน m : n
จุด P ที่แบ่ง A(x₁,y₁) ถึง B(x₂,y₂) ในอัตราส่วน AP : PB = m : n
P = ( (n·x₁ + m·x₂)/(m+n) , (n·y₁ + m·y₂)/(m+n) )
ตัวอย่าง
A(0, 0), B(10, 5) แบ่งในอัตราส่วน 2:3 (จาก A ไป B)
P = ( (3·0+2·10)/5, (3·0+2·5)/5 ) = (4, 2)
/
ความชันของเส้นตรง (Slope)
สูตร
m = (y₂ − y₁) / (x₂ − x₁) เมื่อ x₁ ≠ x₂
m > 0
เอียงขึ้น
เส้นตรงเอียงจากซ้ายล่างไปขวาบน
m < 0
เอียงลง
เส้นตรงเอียงจากซ้ายบนไปขวาล่าง
m = 0
แนวนอน
เส้นขนานแกน x (y = ค่าคงที่)
m หาไม่ได้
แนวตั้ง
เส้นขนานแกน y (x = ค่าคงที่)
⚠️ เงื่อนไขขนาน/ตั้งฉาก
เส้นตรงขนานกัน: m₁ = m₂
เส้นตรงตั้งฉากกัน: m₁ · m₂ = −1
บทที่ 2 · สมการเส้นตรง
✏️
รูปแบบสมการเส้นตรง

ผ่านจุดและความชัน

ทราบจุด (x₁, y₁) และความชัน m

y − y₁ = m(x − x₁)

ความชัน–จุดตัดแกน y

ทราบความชัน m และจุดตัดแกน y คือ c

y = mx + c

ผ่านสองจุด

ทราบจุด (x₁,y₁) และ (x₂,y₂)

(y−y₁)/(x−x₁) = (y₂−y₁)/(x₂−x₁)

รูปทั่วไป

A, B, C เป็นค่าคงที่ (A, B ไม่เป็นศูนย์พร้อมกัน)

Ax + By + C = 0
ตัวอย่าง
เส้นตรงผ่าน (1, 2) และ (3, 8)
m = (8−2)/(3−1) = 3
y − 2 = 3(x − 1) → y = 3x − 1 → 3x − y − 1 = 0
📐
ระยะห่างจากจุดถึงเส้นตรง
สูตร
ระยะจากจุด P(x₀, y₀) ถึงเส้นตรง Ax + By + C = 0
d = |Ax₀ + By₀ + C| / √(A² + B²)
ตัวอย่าง
หาระยะจาก (3, 4) ถึงเส้น 3x + 4y − 10 = 0
d = |3(3)+4(4)−10| / √(9+16) = |9+16−10|/5 = 15/5 = 3
💡 ระยะห่างระหว่างเส้นขนานสองเส้น
ถ้า Ax+By+C₁=0 และ Ax+By+C₂=0 ขนานกัน
d = |C₁ − C₂| / √(A²+B²)
∠
มุมระหว่างเส้นตรงสองเส้น
สูตร
ถ้าเส้นตรงสองเส้นมีความชัน m₁ และ m₂
tan θ = |(m₁ − m₂) / (1 + m₁m₂)|
⚠️ ข้อควรระวัง
สูตรนี้ใช้ไม่ได้เมื่อเส้นใดเส้นหนึ่งเป็นเส้นตั้งฉากกับแกน x (ความชันหาไม่ได้) — กรณีนี้ต้องพิจารณาจากรูปเรขาคณิตโดยตรง
บทที่ 3 · ภาคตัดกรวย: วงกลม
⭕
สมการวงกลม

วงกลม คือ เซตของจุดทุกจุดที่อยู่ห่างจากจุดคงที่จุดหนึ่ง (จุดศูนย์กลาง) เป็นระยะทางเท่ากัน (รัศมี)

รูปแบบมาตรฐาน
วงกลมศูนย์กลาง (a, b) รัศมี r
(x − a)² + (y − b)² = r²
กรณีศูนย์กลางที่จุดกำเนิด: x² + y² = r²
ตัวอย่าง
วงกลมศูนย์กลาง (2, −3) รัศมี 5
(x − 2)² + (y + 3)² = 25
🔧
รูปแบบทั่วไปของวงกลม
รูปทั่วไป
x² + y² + Dx + Ey + F = 0
แปลงกลับด้วยการทำให้เป็นกำลังสองสมบูรณ์ (completing the square)
ศูนย์กลาง = ( −D/2 , −E/2 )
รัศมี r = √[ (D/2)² + (E/2)² − F ]
ตัวอย่าง
x² + y² − 6x + 4y − 12 = 0
(x² − 6x + 9) + (y² + 4y + 4) = 12 + 9 + 4
(x − 3)² + (y + 2)² = 25
ศูนย์กลาง (3, −2) รัศมี 5
⚠️ ข้อควรระวัง
ถ้าค่าทางขวามือหลังทำกำลังสองสมบูรณ์ (r²) ออกมาเป็นลบ แสดงว่าไม่มีวงกลมจริงเกิดขึ้น (ไม่มีคำตอบ)
📍
ตำแหน่งจุดและเส้นสัมผัสวงกลม

ตำแหน่งของจุด (x₀,y₀)

แทนค่าในสมการวงกลม (x₀−a)²+(y₀−b)² เทียบกับ r²

เส้นสัมผัสวงกลม

ที่จุด (x₁,y₁) บนวงกลม (x−a)²+(y−b)²=r²:
(x₁−a)(x−a) + (y₁−b)(y−b) = r²

ค่าที่ได้ตำแหน่งของจุด
< r²อยู่ภายในวงกลม
= r²อยู่บนวงกลม
> r²อยู่ภายนอกวงกลม
บทที่ 4 · ภาคตัดกรวย: พาราโบลา
〜
นิยามและส่วนประกอบ
นิยาม
พาราโบลา คือ เซตของจุดที่มีระยะห่างจากจุดคงที่ (โฟกัส) เท่ากับระยะห่างจากเส้นตรงคงที่ (ไดเรกตริกซ์) เสมอ
V
จุดยอด (Vertex)
จุดกึ่งกลางระหว่างโฟกัสกับไดเรกตริกซ์
F
โฟกัส (Focus)
จุดคงที่ที่พาราโบลาโค้งเข้าหา
p
ระยะโฟกัส
ระยะจากจุดยอดถึงโฟกัส
📊
รูปแบบมาตรฐาน (จุดยอดที่จุดกำเนิด)
สมการแกนสมมาตรทิศเปิดโฟกัสไดเรกตริกซ์
y² = 4pxแกน xp>0 เปิดขวา / p<0 เปิดซ้าย(p, 0)x = −p
x² = 4pyแกน yp>0 เปิดขึ้น / p<0 เปิดลง(0, p)y = −p
ความยาวลาตัสเรกตัม (Latus Rectum)
เส้นตรงผ่านโฟกัสตั้งฉากกับแกนสมมาตร ยาว |4p|
ตัวอย่าง
y² = 12x → 4p = 12 → p = 3
โฟกัส (3, 0), ไดเรกตริกซ์ x = −3, ลาตัสเรกตัมยาว 12
➡️
พาราโบลาที่เลื่อนจุดยอดไปที่ (h, k)
(y − k)² = 4p(x − h)   แกนสมมาตรขนานแกน x
(x − h)² = 4p(y − k)   แกนสมมาตรขนานแกน y
ตัวอย่าง
(y − 1)² = 8(x − 2)
จุดยอด (2, 1), 4p = 8 → p = 2 → โฟกัส (4, 1), ไดเรกตริกซ์ x = 0
💡 เทคนิค — แปลงจากรูป y = ax² + bx + c
ทำกำลังสองสมบูรณ์ให้อยู่ในรูป (x−h)² = 4p(y−k) แล้วจึงหา p, จุดยอด, โฟกัส
บทที่ 5 · ภาคตัดกรวย: วงรี
🥚
นิยามและส่วนประกอบ
นิยาม
วงรี คือ เซตของจุดที่ผลรวมของระยะห่างจากจุดคงที่สองจุด (โฟกัสทั้งสอง) มีค่าคงที่เสมอ
a
กึ่งแกนเอก
ระยะจากศูนย์กลางถึงจุดยอด (a > b)
b
กึ่งแกนโท
ระยะจากศูนย์กลางถึงจุดปลายแกนโท
c
ระยะโฟกัส
ระยะจากศูนย์กลางถึงโฟกัสแต่ละจุด
e
ความเยื้องศูนย์กลาง
e = c/a เมื่อ 0 < e < 1
📊
รูปแบบมาตรฐาน (ศูนย์กลางที่จุดกำเนิด)
ความสัมพันธ์หลัก
c² = a² − b²   (เมื่อ a > b เสมอ)
สมการแกนเอกจุดยอดโฟกัส
x²/a² + y²/b² = 1แกน x(±a, 0)(±c, 0)
x²/b² + y²/a² = 1แกน y(0, ±a)(0, ±c)
ตัวอย่าง
x²/25 + y²/9 = 1
a² = 25 → a = 5,   b² = 9 → b = 3
c² = 25 − 9 = 16 → c = 4
จุดยอด (±5, 0), โฟกัส (±4, 0), e = 4/5
⚠️ ข้อควรระวัง
เลข a² ต้องอยู่ใต้ตัวแปรที่มีค่ามากกว่าเสมอ (a > b) — สังเกตว่าแกนเอกอยู่ในแนวแกนไหนจากตัวส่วนที่มากกว่า ไม่ใช่จากตำแหน่งของ x หรือ y
➡️
วงรีที่เลื่อนศูนย์กลางไปที่ (h, k)
(x−h)²/a² + (y−k)²/b² = 1   แกนเอกขนานแกน x (a > b)
(x−h)²/b² + (y−k)²/a² = 1   แกนเอกขนานแกน y (a > b)
ตัวอย่าง
(x−1)²/16 + (y+2)²/4 = 1
ศูนย์กลาง (1, −2), a=4, b=2, c=√12=2√3
จุดยอด (1±4, −2) = (5,−2), (−3,−2)
บทที่ 6 · ภาคตัดกรวย: ไฮเพอร์โบลา
⧖
นิยามและส่วนประกอบ
นิยาม
ไฮเพอร์โบลา คือ เซตของจุดที่ค่าสัมบูรณ์ของผลต่างระยะห่างจากจุดคงที่สองจุด (โฟกัสทั้งสอง) มีค่าคงที่เสมอ

เส้นประ คือ เส้นกำกับ (asymptotes) ที่กิ่งทั้งสองของไฮเพอร์โบลาเข้าใกล้เมื่อค่า x หรือ y มีขนาดใหญ่มาก

📊
รูปแบบมาตรฐาน (ศูนย์กลางที่จุดกำเนิด)
ความสัมพันธ์หลัก
c² = a² + b²
สมการแกนตามขวางจุดยอดโฟกัสเส้นกำกับ
x²/a² − y²/b² = 1แกน x(±a, 0)(±c, 0)y = ±(b/a)x
y²/a² − x²/b² = 1แกน y(0, ±a)(0, ±c)y = ±(a/b)x
ตัวอย่าง
x²/9 − y²/16 = 1
a² = 9 → a = 3, b² = 16 → b = 4
c² = 9 + 16 = 25 → c = 5
จุดยอด (±3, 0), โฟกัส (±5, 0), เส้นกำกับ y = ±(4/3)x
⚠️ ข้อควรระวัง — ต่างจากวงรี!
ในไฮเพอร์โบลา a ไม่จำเป็นต้องมากกว่า b เสมอไป (a คือตัวส่วนใต้พจน์บวก) และใช้ c² = a² + b² (บวก) ไม่ใช่ลบเหมือนวงรี
💡 ความเยื้องศูนย์กลาง
e = c/a และสำหรับไฮเพอร์โบลาเสมอ e > 1
➡️
ไฮเพอร์โบลาที่เลื่อนศูนย์กลางไปที่ (h, k)
(x−h)²/a² − (y−k)²/b² = 1   แกนตามขวางขนานแกน x
(y−k)²/a² − (x−h)²/b² = 1   แกนตามขวางขนานแกน y
ตัวอย่าง
(x+2)²/4 − (y−1)²/9 = 1
ศูนย์กลาง (−2, 1), a=2, b=3, c=√13
จุดยอด (−2±2, 1) = (0,1), (−4,1)
