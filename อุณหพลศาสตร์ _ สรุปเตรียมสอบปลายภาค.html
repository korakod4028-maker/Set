📏 การขยายตัวเชิงความร้อน

ΔL = α·Lᵢ·ΔT
ΔL ความยาวที่เปลี่ยน (m) · α สัมประสิทธิ์ขยายตัวเชิงเส้น (°C⁻¹) · Lᵢ ความยาวเริ่มต้น (m) · ΔT = Tf−Ti อุณหภูมิที่เปลี่ยน (°C)
ΔA = δ·Aᵢ·ΔT , δ = 2α
ΔA พื้นที่ที่เปลี่ยน (m²) · δ สัมประสิทธิ์ขยายตัวเชิงพื้นที่ (°C⁻¹) · Aᵢ พื้นที่เริ่มต้น (m²)
ΔV = β·Vᵢ·ΔT , β = 3α
ΔV ปริมาตรที่เปลี่ยน (m³) · β สัมประสิทธิ์ขยายตัวเชิงปริมาตร (°C⁻¹) · Vᵢ ปริมาตรเริ่มต้น (m³)
ตัวอย่าง (สไลด์)
รางเหล็ก 30.000 m, α = 11×10⁻⁶ /°C, ΔT = 40 °C
ΔL = (11×10⁻⁶)(30)(40) = 0.013 m → Lf = 30.013 m
ถ้าปลายยึดแน่น: σ = Y·ΔL/L₀ = (20×10¹⁰)(0.013/30) = 8.7×10⁷ N/m²
ลดอุณหภูมิ 40 °C → ΔL = −0.013 m (ขนาดเท่ากัน หดแทนขยาย)

🔥 ความร้อน Q

ความร้อนจำเพาะ (T เปลี่ยน): Q = mcΔT = ncΔT
Q ความร้อน (J หรือ cal) · m มวล (kg หรือ g) · c ความจุความร้อนจำเพาะ (J/kg·°C หรือ cal/g·°C) · n จำนวนโมล (mol) แล้ว c ต้องเป็นแบบต่อโมล (J/mol·K) · ΔT (°C หรือ K)
ความร้อนแฝง (สถานะเปลี่ยน, T คงที่): Q = mL
Q ความร้อน (J หรือ cal) · m มวล (kg หรือ g) · L ความร้อนแฝง (J/kg หรือ cal/g) · หน่วย m กับ L ต้องใช้ระบบเดียวกัน
ตัวอย่าง: น้ำแข็ง 100 g, −30 °C → ไอน้ำ 120 °C
cน้ำแข็ง=0.5, cน้ำ=1, cไอ=0.5 cal/g·°C · Lละลาย=80, Lกลายเป็นไอ=540 cal/g
ช่วงสูตรQ (cal)
A: −30→0 °CmcΔT1,500
B: ละลายmL8,000
C: 0→100 °CmcΔT10,000
D: กลายเป็นไอmL54,000
E: 100→120 °CmcΔT6,000
รวม79,500
ระวัง
ช่วง E ในสไลด์คิด 0.5×120 = 6,000 แต่ ΔT ของไอน้ำจริงคือ 100→120 = 20 °C (จะได้ 1,000 cal และรวม 74,500 cal) อาจารย์อาจเฉลยตามสไลด์ ถามอาจารย์ให้ชัวร์ก่อนสอบ

⚛️ พลังงานภายใน U

อะตอมเดี่ยว (He, Ne, Ar): U = (3/2)nRT   f = 3
อะตอมคู่ (H₂, N₂, O₂): U = (5/2)nRT   f = 5
หลายอะตอม ไม่เป็นเส้นตรง (H₂O, NH₃, CH₄): U = 3nRT   f = 6
f = ระดับความเสรี (ไม่มีหน่วย) = เลื่อนที่ 3 + หมุน (0 / 2 / 3) ทั่วไป U = (f/2)nRT · เดี่ยว: เลื่อนที่อย่างเดียว · คู่: หมุนเพิ่ม 2 แกน · หลายอะตอม: หมุนเพิ่ม 3 แกน
สไลด์พิมพ์ผิด (หน้า 23)
บรรทัดที่ 3 สไลด์เขียน "กรณีแก๊สอะตอมคู่ U = 3nRT" ซ้ำกับบรรทัดที่ 2 ที่ถูกคือ แก๊สหลายอะตอม
U พลังงานภายใน (J) · n จำนวนโมล (mol) · R ค่าคงที่แก๊ส = 8.314 J/mol·K · T อุณหภูมิสัมบูรณ์ (K เท่านั้น! K = °C + 273)
หัวใจ
U ของแก๊สอุดมคติขึ้นกับ T อย่างเดียว → ΔU = nCVΔT ใช้ได้ ทุกกระบวนการ

🧮 งาน W และกฎข้อที่ 1

W = −∫P dV (งานที่กระทำ "ต่อ" ระบบ)
W งาน (J) · P ความดัน (Pa = N/m²) · V ปริมาตร (m³) · Vi, Vf ปริมาตรเริ่ม/สุดท้าย (m³) · ถ้า P คงที่ W = −P(Vf−Vi)
ΔU = Q + W
ΔU = U2−U1 พลังงานภายในที่เปลี่ยน (J) · Q ความร้อนที่เข้าระบบ (J) · W งานที่กระทำต่อระบบ (J)

🔧 ความจุความร้อนโมลาร์

CP = CV + R
CP ความจุความร้อนต่อโมลที่ P คงที่ · CV ที่ V คงที่ (ทั้งคู่หน่วย J/mol·K) · R = 8.314 J/mol·K
อะตอมเดี่ยว: CV=(3/2)R≈12.5 · CP=(5/2)R≈20.8 J/mol·K
อะตอมคู่: CV=(5/2)R≈20.8 · CP=(7/2)R≈29.1 J/mol·K
หลายอะตอม: CV=3R≈24.9 · CP=4R≈33.3 J/mol·K
หาจาก CV = (1/n)dU/dT = (f/2)R แล้ว CP = CV+R · ค่าจริงของหลายอะตอมในตารางสไลด์สูงกว่า (เช่น CO₂ = 28.5) เพราะโมเลกุลสั่นด้วย
γ = CP/CV = 1.67 (เดี่ยว) ≈ 1.40 (คู่) ≈ 1.33 (หลายอะตอม)
γ (แกมมา) อัตราส่วน CP/CV ไม่มีหน่วย
ที่ความดันคงที่ ความร้อนส่วนหนึ่งกลายเป็นงานขยายตัว จึงต้องใช้ความร้อนมากกว่า CP > CV อยู่ R

📝 ตย.1 รางรถไฟเหล็กขยายตัว

โจทย์ให้
ยาว Li = 30.000 m · T: 0 → 40 °C · α = 11×10⁻⁶ °C⁻¹ · Y = 20×10¹⁰ N/m²
โจทย์ถาม
ก) ความยาวที่เปลี่ยน ข) ความเค้นถ้าปลายยึดแน่น ค) ถ้าเย็นลงเป็น −40 °C
  1. เลือกสูตร ถามความยาวเปลี่ยน → ΔL = αLiΔT
  2. หา ΔT = 40 − 0 = 40 °C
  3. แทนค่า ΔL = (11×10⁻⁶)(30.000)(40) = 0.0132 ≈ 0.013 m (ยาวขึ้น 1.3 cm)
  4. ข) ปลายยึดแน่น รางอยากยืด 0.013 m แต่ยืดไม่ได้ จึงเกิดความเค้น σ = Y·(ΔL/L₀) = (20×10¹⁰)(0.013/30) = 8.7×10⁷ N/m²
  5. ค) ΔT = −40 − 0 = −40 °C → ΔL = −0.013 m (ขนาดเท่ากัน แต่ หด เป็น 29.987 m)
คำตอบ
ก) ΔL = 0.013 m (Lf = 30.013 m) · ข) σ = 8.7×10⁷ N/m² · ค) หดลง 0.013 m
จำไว้
ΔL มีเครื่องหมาย: T เพิ่ม → ขยาย (+) · T ลด → หด (−)

📝 ตย.3 แก๊สในกระบอกสูบ (ลูกสูบเคลื่อนที่อิสระ)

โจทย์ให้
ลูกสูบมวล 8,000 g · พื้นที่หน้าตัด 5.00 cm² · n = 0.200 mol · T: 20.0 → 300.0 °C
โจทย์ถาม
งานที่เกิดกับแก๊ส
  1. อ่านเงื่อนไข ลูกสูบเคลื่อนที่อิสระ ความดันคงที่ตลอด → Isobaric
  2. เลือกสูตร W = −PΔV และเพราะ PV = nRT จะได้ W = −nR(Tf−Ti) (ไม่ต้องรู้ P!)
  3. ΔT = 300 − 20 = 280 (ผลต่างเท่ากันทั้ง °C และ K)
  4. แทนค่า W = −(0.200)(8.314)(280) = −465.6 J
  5. ตีความ W ติดลบ = แก๊สร้อนขึ้นแล้วขยายตัว ทำงานดันลูกสูบขึ้น
คำตอบ
W ≈ −466 J (ระบบทำงาน 466 J)
จำไว้
มวลลูกสูบและพื้นที่เป็นข้อมูลล่อ ใช้หา P ได้ (P = mg/A) แต่ข้อนี้ไม่จำเป็น

📝 ตย.4 อัดแก๊สที่ความดันคงที่

โจทย์ให้
P = 0.800 atm (คงที่) · V: 9.00 L → 2.00 L · ความร้อนออก 400 J
โจทย์ถาม
ก) งานที่กระทำต่อแก๊ส ข) พลังงานภายในที่เปลี่ยน
  1. แปลงหน่วย P = 0.8 × 1.013×10⁵ = 81,040 Pa · ΔV = (2−9) L = −7×10⁻³ m³
  2. ก) W = −PΔV = −(81,040)(−7×10⁻³) = +567 J (บวก เพราะเราอัดแก๊ส งานทำต่อระบบ)
  3. ระวังเครื่องหมาย Q ความร้อน "ออก" จากระบบ → Q = −400 J
  4. ข) ΔU = Q + W = −400 + 567 = +167 J
คำตอบ
W ≈ +567 J · ΔU ≈ +167 J (อุณหภูมิสูงขึ้น)
จำไว้
สไลด์ปัดใช้ 1 atm ≈ 10⁵ Pa จึงได้ W = 560 J และ ΔU = 160 J ใช้ตามที่อาจารย์เฉลย

📝 ตย.5 แก๊สขยายตัวที่อุณหภูมิคงที่

โจทย์ให้
n = 1.0 mol · T = 0 °C = 273 K (คงที่) · V: 3.0 → 10 L
โจทย์ถาม
ก) งานระหว่างขยายตัว ข) ความร้อนที่ถ่ายเท ค) ถ้ากลับ 3 L ด้วยความดันคงที่ ต้องทำงานเท่าไร
  1. Isothermal → W = −nRT ln(Vf/Vi)
  2. ก) W = −(1)(8.314)(273) ln(10/3) = −2,269.7 × 1.204 = −2,733 J (ใช้ ln ฐาน e และ V หน่วยเดียวกันก็ได้)
  3. ข) ΔU = 0 (T คงที่) → Q = −W = +2,733 J ความร้อนไหลเข้าเท่ากับงานที่ออก
  4. ค) หา P ที่ V = 10 L: P = nRT/V = 2,269.7/0.010 = 226,970 Pa
  5. แทน W = −P(Vf−Vi) = −(226,970)(0.003−0.010) = +1,589 J
คำตอบ
ก) −2,733 J · ข) +2,733 J · ค) +1,589 J
จำไว้
งานขึ้นกับเส้นทาง: ไป 2,733 J กลับ 1,589 J ต่างกัน เพราะเส้นทางต่างกัน

📝 โจทย์ข้อ 1 ความดันเปลี่ยนตามปริมาตร P = αV²

โจทย์ให้

W ≈ −1.18×10⁶ J (แก๊สขยายตัว ทำงานออก)
จำไว้

  1. ตีความ "ให้ความร้อนจนความดันเพิ่ม" โจทย์ไม่บอกกระบวนการ จึงสมมติ ปริมาตรคงที่ (ถ้าอาจารย์บอกต่างไป ให้บอกผมได้)
  2. ก) V = nRT/P = (2)(8.314)(300)/(0.4×1.013×10⁵) = 4,988/40,520 ≈ 0.123 m³ (123 L) V คงที่ จึงเท่าเดิมตอนจบ
  3. ข) V คงที่ → dV = 0 → W = 0
  4. ค) หา T สุดท้าย V คงที่ P ∝ T → T₂ = 300 × (1.2/0.4) = 900 K
  5. ΔU = Q (เพราะ W = 0) = nCVΔT = (2)(12.5)(900−300) = 15,000 J
