จำนวนจริง (Real Numbers, ℝ) คือเซตของจำนวนทั้งหมดที่อยู่บนเส้นจำนวน ประกอบด้วยชั้นย่อยดังนี้

ℕ
จำนวนนับ
{1, 2, 3, 4, ...}
ℤ
จำนวนเต็ม
{..., −2, −1, 0, 1, 2, ...}
ℚ
จำนวนตรรกยะ
p/q เมื่อ p, q ∈ ℤ, q ≠ 0
ℚ'
จำนวนอตรรกยะ
√2, π, e, √3, ...
ℝ
จำนวนจริง
ℚ ∪ ℚ' = ℝ
ความสัมพันธ์ระหว่างเซต
ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ
ℚ ∩ ℚ' = ∅ (ไม่มีจำนวนใดที่เป็นทั้งตรรกยะและอตรรกยะพร้อมกัน)
ℚ ∪ ℚ' = ℝ (จำนวนจริงทุกตัวเป็นตรรกยะหรืออตรรกยะอย่างใดอย่างหนึ่ง)
📏
เส้นจำนวนจริง (Real Number Line)

จำนวนจริงทุกตัวสามารถแสดงได้บนเส้นตรงที่เรียกว่าเส้นจำนวน โดยจำนวนที่มากกว่าอยู่ทางขวา และน้อยกว่าอยู่ทางซ้าย

💡 สมบัติของเส้นจำนวน
ระหว่างจำนวนจริงสองตัวใดๆ มีจำนวนจริงอยู่อีกมากมายอย่างไม่สิ้นสุด (ทั้งตรรกยะและอตรรกยะ)
เส้นจำนวนจริงไม่มีช่องว่าง — แตกต่างจากเส้นจำนวนเต็ม ℤ

⚖️
สมบัติการบวกและการคูณ

การสลับที่ (Commutative)

a + b = b + a
a × b = b × a

การเปลี่ยนหมู่ (Associative)

(a+b)+c = a+(b+c)
(a×b)×c = a×(b×c)

การแจกแจง (Distributive)

a(b+c) = ab + ac
a(b-c) = ab - ac

เอกลักษณ์ (Identity)

a + 0 = a
a × 1 = a

อินเวอร์ส (Inverse)

a + (−a) = 0
a × (1/a) = 1, a≠0

การคูณด้วยศูนย์

a × 0 = 0
ถ้า ab = 0 แล้ว a=0 หรือ b=0
📐
สมบัติการอุปมา (Order Properties)
สมบัติการเปรียบเทียบ (Trichotomy)
สำหรับ a, b ∈ ℝ มีกรณีใดกรณีหนึ่งต่อไปนี้เกิดขึ้นเสมอ:
a < b หรือ a = b หรือ a > b

สมบัติการถ่ายทอด (Transitive)

ถ้า a < b และ b < c
แล้ว a < c

การบวกกับอสมการ

ถ้า a < b
แล้ว a+c < b+c

การคูณค่าบวก

ถ้า a < b และ c > 0
แล้ว ac < bc

การคูณค่าลบ (เปลี่ยนทิศ!)

ถ้า a < b และ c < 0
แล้ว ac > bc
⚠️ จุดที่สับสนบ่อย — เครื่องหมายกลับทิศ
เมื่อคูณหรือหารอสมการด้วยจำนวนลบ ต้องเปลี่ยนเครื่องหมาย < เป็น > หรือ ≤ เป็น ≥ เสมอ
เช่น: −2x < 6 → x > −3 (หารด้วย −2 ทิศกลับ!)
🔢
สมบัติของการยกกำลังและรากที่สอง
a² ≥ 0 สำหรับทุก a ∈ ℝ
√(a²) = |a| (ไม่ใช่ a เสมอไป!)
ถ้า a ≥ 0: √a × √a = a
√(ab) = √a × √b (เมื่อ a, b ≥ 0)
√(a/b) = √a / √b (เมื่อ a ≥ 0, b > 0)
⚠️ ข้อผิดพลาดที่พบบ่อย
√(a + b) ≠ √a + √b (ผิดเสมอ!)
ตัวอย่าง: √(9 + 16) = √25 = 5 ≠ √9 + √16 = 3 + 4 = 7

√(a²) = |a| ไม่ใช่ a เสมอ เพราะถ้า a = −3 จะได้ √(9) = 3 = |−3|
หัวข้อ 3 · ค่าสัมบูรณ์
|x|
นิยามค่าสัมบูรณ์
นิยาม
|a| = a ถ้า a ≥ 0
|a| = −a ถ้า a < 0

ความหมายทางเรขาคณิต: |a| คือระยะทางจาก a ไปยัง 0 บนเส้นจำนวน
|a − b| คือระยะทางระหว่าง a และ b บนเส้นจำนวน
ตัวอย่าง
|5| = 5, |−3| = 3, |0| = 0
|2 − 7| = |−5| = 5
|−4 − (−1)| = |−3| = 3
📐
สมบัติของค่าสัมบูรณ์
1. |a| ≥ 0 (ค่าสัมบูรณ์ไม่เป็นลบ)
2. |a| = 0 ก็ต่อเมื่อ a = 0
3. |−a| = |a|
4. |ab| = |a||b|
5. |a/b| = |a|/|b| (b ≠ 0)
6. |a + b| ≤ |a| + |b| (Triangle Inequality)
7. |a² | = a² (ค่าสัมบูรณ์ของกำลังสองเท่ากับตัวมันเอง)
💡 สมบัติข้อ 6 — Triangle Inequality
|a + b| ≤ |a| + |b| สำคัญมากในการพิสูจน์และการประมาณค่า
เครื่องหมาย = เกิดขึ้นก็ต่อเมื่อ a และ b มีเครื่องหมายเดียวกัน (หรือตัวใดตัวหนึ่งเป็นศูนย์)
🔍
การแก้สมการและอสมการค่าสัมบูรณ์
กรณีสมการ |f(x)| = k
หลักการ
ถ้า k > 0: |f(x)| = k ⟺ f(x) = k หรือ f(x) = −k
ถ้า k = 0: |f(x)| = 0 ⟺ f(x) = 0
ถ้า k < 0: |f(x)| = k ไม่มีคำตอบ (ค่าสัมบูรณ์ไม่เป็นลบ)
ตัวอย่าง — สมการ |2x − 3| = 5
กรณีที่ 1: 2x − 3 = 5 → x = 4
กรณีที่ 2: 2x − 3 = −5 → x = −1
คำตอบ: x = 4 หรือ x = −1
กรณีอสมการ |f(x)| < k
หลักการ (น้อยกว่า = ช่วงเดียว)
|f(x)| < k ⟺ −k < f(x) < k
|f(x)| ≤ k ⟺ −k ≤ f(x) ≤ k
ตัวอย่าง — |x − 2| < 3
−3 < x − 2 < 3
−1 < x < 5
คำตอบ: x ∈ (−1, 5)
กรณีอสมการ |f(x)| > k
หลักการ (มากกว่า = สองช่วง)
|f(x)| > k ⟺ f(x) > k หรือ f(x) < −k
|f(x)| ≥ k ⟺ f(x) ≥ k หรือ f(x) ≤ −k
ตัวอย่าง — |x + 1| ≥ 4
x + 1 ≥ 4 → x ≥ 3
x + 1 ≤ −4 → x ≤ −5
คำตอบ: x ∈ (−∞, −5] ∪ [3, +∞)
💡 เทคนิคจำ — น้อยกว่า AND / มากกว่า OR
|f(x)| < k → ช่วงเดียว (AND / ระหว่าง)
|f(x)| > k → สองช่วง (OR / สองข้าง)

นิยามช่วง (Interval)

ช่วงคือเซตย่อยของ ℝ ที่เขียนแทนด้วยสัญลักษณ์วงเล็บหรือวงเล็บเหลี่ยม

สัญลักษณ์เงื่อนไขชื่อ
(a, b)a < x < bช่วงเปิด
[a, b]a ≤ x ≤ bช่วงปิด
[a, b)a ≤ x < bช่วงครึ่งเปิด (เปิดขวา)
(a, b]a < x ≤ bช่วงครึ่งเปิด (เปิดซ้าย)

(−∞, +∞)x ∈ ℝเส้นจำนวนทั้งหมด

∞ ไม่ใช่จำนวนจริง จึงไม่มี [∞ หรือ ∞] — ใช้ (∞ เสมอ
🔗
การดำเนินการบนช่วง

ยูเนียน ∪

รวมค่าทุกตัวจากทั้งสองช่วง

(1,3) ∪ (2,5) = (1,5)

อินเตอร์เซกชัน ∩

เฉพาะค่าที่อยู่ในทั้งสองช่วง

(1,3) ∩ (2,5) = (2,3)
ตัวอย่าง
[−2, 4] ∩ (1, 6) = (1, 4]
(−∞, 3) ∪ [5, ∞) ← ช่วงที่ไม่ต่อเนื่อง (ต้องเขียนแยก)
[2, 3] ∩ [4, 5] = ∅
📐
การแก้อสมการพหุนาม
วิธีแก้อสมการกำลังสอง
ขั้นตอน
1. ย้ายทุกพจน์ไปด้านเดียว (ให้ฝั่งขวาเป็น 0)
2. แยกตัวประกอบหรือหารากของสมการ
3. วาดแผนภาพเส้นจำนวนหรือใช้ตารางเครื่องหมาย
4. เลือกช่วงที่ทำให้สมการเป็นจริง
ตัวอย่าง — x² − x − 6 > 0
แยกตัวประกอบ: (x − 3)(x + 2) > 0
รากคือ x = 3 และ x = −2

ตารางเครื่องหมาย:
x < −2: (−)(−) = (+) ✓
−2 < x < 3: (+)(−) = (−) ✗
x > 3: (+)(+) = (+) ✓

คำตอบ: x ∈ (−∞, −2) ∪ (3, +∞)
ตัวอย่าง — x² − 5x + 6 ≤ 0
แยกตัวประกอบ: (x − 2)(x − 3) ≤ 0
รากคือ x = 2 และ x = 3
ผลคูณ ≤ 0 เมื่อ 2 ≤ x ≤ 3
คำตอบ: x ∈ [2, 3]
💡 ทางลัด — อสมการกำลังสอง ax² + bx + c < 0
ถ้า a > 0 และมีรากสองตัว r₁ < r₂:
• ax² + bx + c < 0 ⟺ r₁ < x < r₂ (ช่วงระหว่างราก)
• ax² + bx + c > 0 ⟺ x < r₁ หรือ x > r₂ (นอกช่วงราก)
หัวข้อ 5 · จำนวนตรรกยะและอตรรกยะ
ℚ
จำนวนตรรกยะ (Rational Numbers)
นิยาม
จำนวน r เป็นจำนวนตรรกยะ ก็ต่อเมื่อ r = p/q เมื่อ p, q ∈ ℤ และ q ≠ 0
รูปแบบของทศนิยม

ทศนิยมสิ้นสุด (Terminating)

1/4 = 0.25
3/8 = 0.375
7/20 = 0.35

เกิดเมื่อตัวส่วน (ในรูปเต็มที่สุด) มีตัวประกอบเฉพาะเป็น 2 และ/หรือ 5 เท่านั้น

ทศนิยมไม่สิ้นสุดแต่ซ้ำ (Repeating)

1/3 = 0.333...
2/7 = 0.285714...
5/6 = 0.8333...

จำนวนตรรกยะทั้งหมดมีทศนิยมสิ้นสุดหรือซ้ำ

💡 แปลงทศนิยมซ้ำเป็นเศษส่วน
ให้ x = 0.333...
10x = 3.333...
10x − x = 3 → 9x = 3 → x = 1/3 ✓

ให้ x = 0.142857142857...
1000000x − x = 142857 → x = 142857/999999 = 1/7 ✓
ℚ'
จำนวนอตรรกยะ (Irrational Numbers)
นิยาม
จำนวนอตรรกยะคือจำนวนจริงที่ไม่ใช่จำนวนตรรกยะ
ทศนิยมของจำนวนอตรรกยะ: ไม่สิ้นสุดและไม่ซ้ำ
ตัวอย่างจำนวนอตรรกยะที่สำคัญ
√2 ≈ 1.41421356...
√3 ≈ 1.73205080...
√5 ≈ 2.23606797...
π ≈ 3.14159265...
e ≈ 2.71828182... (ค่าคงที่ธรรมชาติ)
⚠️ พิสูจน์ว่า √2 เป็นอตรรกยะ (สำคัญ!)
สมมติ √2 = p/q เมื่อ p, q ∈ ℤ และ gcd(p,q) = 1
จะได้ 2 = p²/q² → p² = 2q² → p² เป็นจำนวนคู่ → p เป็นจำนวนคู่
ให้ p = 2k → 4k² = 2q² → q² = 2k² → q เป็นจำนวนคู่
แต่ทั้ง p และ q เป็นจำนวนคู่ ขัดแย้งกับ gcd(p,q) = 1
ดังนั้น √2 เป็นอตรรกยะ ■
➕
การดำเนินการบนจำนวนตรรกยะและอตรรกยะ
การดำเนินการผลลัพธ์ตัวอย่าง
ตรรกยะ ± ตรรกยะตรรกยะ1/2 + 1/3 = 5/6
ตรรกยะ × ตรรกยะ (≠0)ตรรกยะ3/4 × 2/3 = 1/2
ตรรกยะ ± อตรรกยะอตรรกยะ1 + √2 = อตรรกยะ
ตรรกยะ(≠0) × อตรรกยะอตรรกยะ2√3 = อตรรกยะ
อตรรกยะ ± อตรรกยะไม่แน่√2 + (−√2) = 0 (ตรรกยะ!)
อตรรกยะ × อตรรกยะไม่แน่√2 × √2 = 2 (ตรรกยะ!)
⚠️ ระวัง — อตรรกยะ × อตรรกยะ อาจเป็นตรรกยะ
√2 × √8 = √16 = 4 (ตรรกยะ)
√3 × √3 = 3 (ตรรกยะ)
แต่ √2 × √3 = √6 (อตรรกยะ)
หัวข้อ 6 · รากที่ n และเลขยกกำลัง
ⁿ√
รากที่ n (nth Root)
นิยาม
ⁿ√a = b ก็ต่อเมื่อ bⁿ = a

สำหรับ n เป็นจำนวนคู่: กำหนด a ≥ 0, ⁿ√a ≥ 0 เสมอ
สำหรับ n เป็นจำนวนคี่: ⁿ√a นิยามได้สำหรับ a ∈ ℝ ทุกค่า

n คู่ (เช่น √, ⁴√)

√4 = 2 (ไม่ใช่ ±2)
⁴√16 = 2
√(−4) ไม่นิยามใน ℝ

n คี่ (เช่น ³√, ⁵√)

³√8 = 2
³√(−8) = −2
⁵√(−32) = −2
💡 สูตรสำคัญ
ⁿ√a × ⁿ√b = ⁿ√(ab) (a,b ≥ 0 ถ้า n คู่)
ⁿ√a / ⁿ√b = ⁿ√(a/b) (b ≠ 0)
(ⁿ√a)ⁿ = a
ⁿ√(aᵐ) = aᵐ/ⁿ
📐
สมบัติเลขยกกำลังจำนวนตรรกยะ
นิยาม aᵐ/ⁿ
aᵐ/ⁿ = ⁿ√(aᵐ) = (ⁿ√a)ᵐ เมื่อ ⁿ√a นิยามได้
กฎการยกกำลัง:
aᵐ × aⁿ = aᵐ⁺ⁿ
aᵐ / aⁿ = aᵐ⁻ⁿ (a ≠ 0)
(aᵐ)ⁿ = aᵐⁿ
(ab)ⁿ = aⁿbⁿ
(a/b)ⁿ = aⁿ/bⁿ (b ≠ 0)
a⁰ = 1 (a ≠ 0)
a⁻ⁿ = 1/aⁿ (a ≠ 0)
ตัวอย่าง — ทำให้ง่าย
8²/³ = (³√8)² = 2² = 4
27⁻²/³ = 1/(27²/³) = 1/(³√27)² = 1/9
(4/9)³/² = (√(4/9))³ = (2/3)³ = 8/27
⚠️ ข้อควรระวัง — เลขยกกำลังจำนวนลบ
(−8)²/³ = ³√((−8)²) = ³√64 = 4
แต่ (−4)¹/² ไม่นิยามใน ℝ เพราะรากที่สองของจำนวนลบไม่ใช่จำนวนจริง
✂️
การทำให้เศษส่วนสมเหตุผล (Rationalization)

การกำจัดรากออกจากส่วน โดยคูณด้วยนิพจน์ที่เหมาะสม

รูปแบบ 1/√a

1/√2 = √2/2
(คูณ √2/√2)

รูปแบบ 1/(a+√b)

1/(3+√2)
= (3−√2)/((3+√2)(3−√2))
= (3−√2)/7
💡 คอนจูเกต (Conjugate)
คอนจูเกตของ (a + √b) คือ (a − √b)
(a + √b)(a − √b) = a² − b (ไม่มีราก!)
คอนจูเกตของ (√a + √b) คือ (√a − √b)

log_b(a) = c ก็ต่อเมื่อ bᶜ = a

เงื่อนไข: b > 0, b ≠ 1, a > 0

ลอการิทึมสามัญ (log)

log(a) = log₁₀(a)
log(100) = 2
log(0.01) = −2

ลอการิทึมธรรมชาติ (ln)

ln(a) = logₑ(a)
ln(e) = 1
ln(e²) = 2
ตัวอย่าง — แปลงระหว่าง log และ exp
log₂(8) = 3 เพราะ 2³ = 8
log₅(125) = 3 เพราะ 5³ = 125
log₃(1/9) = −2 เพราะ 3⁻² = 1/9
📐
สมบัติของลอการิทึม
1. log_b(mn) = log_b(m) + log_b(n)
2. log_b(m/n) = log_b(m) − log_b(n)
3. log_b(mⁿ) = n·log_b(m)
4. log_b(b) = 1
5. log_b(1) = 0
6. log_b(bⁿ) = n
7. b^(log_b(a)) = a
8. เปลี่ยนฐาน: log_b(a) = log_c(a) / log_c(b)
ตัวอย่าง — ทำให้ง่าย
log 6 + log 5 − log 3 = log(6×5/3) = log 10 = 1
log₂ 48 − log₂ 3 = log₂(48/3) = log₂ 16 = 4
2log 3 + log 4 = log(3²×4) = log 36
💡 สูตรเปลี่ยนฐาน — ใช้บ่อยมาก!
log₅ 8 = log 8 / log 5 = ln 8 / ln 5
ใช้เมื่อต้องการคำนวณลอการิทึมฐานอื่นด้วยเครื่องคิดเลข
🔍
สมการและอสมการลอการิทึม
⚠️ ตรวจสอบโดเมนเสมอ!
ก่อนแก้สมการ log: ต้องตรวจว่าค่าในวงเล็บ > 0 ทุกพจน์
ต้องตรวจคำตอบย้อนกลับว่าทำให้อาร์กิวเมนต์เป็นบวกด้วย
ตัวอย่าง — log₂(x+3) + log₂(x−1) = 5
log₂[(x+3)(x−1)] = 5
(x+3)(x−1) = 2⁵ = 32
x² + 2x − 3 = 32
x² + 2x − 35 = 0
(x+7)(x−5) = 0
x = −7 หรือ x = 5

ตรวจ: x = −7: x+3 = −4 < 0 ❌ ตัดทิ้ง
x = 5: x+3 = 8 > 0, x−1 = 4 > 0 ✓
คำตอบ: x = 5
ตัวอย่าง — อสมการ log₃(2x−1) > 2
2x − 1 > 3² (ฐาน 3 > 1 ทิศไม่เปลี่ยน)
2x − 1 > 9
x > 5
ตรวจโดเมน: 2x − 1 > 0 → x > 1/2
คำตอบ: x > 5
💡 ทิศของอสมการลอการิทึม
ฐาน b > 1: log_b(f) > log_b(g) ⟺ f > g (ทิศเดิม)
ฐาน 0 < b < 1: log_b(f) > log_b(g) ⟺ f < g (ทิศกลับ!)
หัวข้อ 8 · สมบัติความสมบูรณ์และขอบเขต
∞
ขอบบนและขอบล่าง
นิยาม
ขอบบน (Upper Bound): M คือขอบบนของเซต S ถ้า x ≤ M สำหรับทุก x ∈ S
ขอบล่าง (Lower Bound): m คือขอบล่างของเซต S ถ้า x ≥ m สำหรับทุก x ∈ S

ซูพรีมัม (Supremum / Least Upper Bound): sup S = ขอบบนน้อยที่สุด
อินฟิมัม (Infimum / Greatest Lower Bound): inf S = ขอบล่างมากที่สุด
ตัวอย่าง
S = (0, 1]
sup S = 1 (1 ∈ S → max S = 1 ด้วย)
inf S = 0 (0 ∉ S → ไม่มี min S)

T = {1/n : n ∈ ℕ} = {1, 1/2, 1/3, 1/4, ...}
sup T = 1 = max T
inf T = 0 (0 ∉ T → ไม่มี min T)
🌟
สมบัติความสมบูรณ์ (Completeness Property)
สมบัติความสมบูรณ์ของ ℝ
ทุกเซตย่อยที่ไม่ว่างของ ℝ ที่มีขอบบน จะต้องมีซูพรีมัมอยู่ใน ℝ

สมบัตินี้คือสิ่งที่ทำให้ ℝ สมบูรณ์กว่า ℚ — ในจำนวนตรรกยะ √2 ไม่มีอยู่ แต่ใน ℝ มี

ℚ ไม่สมบูรณ์

เซต {q ∈ ℚ : q² < 2} มีขอบบนใน ℚ (เช่น 2) แต่ไม่มีซูพรีมัมใน ℚ เพราะ √2 ∉ ℚ

ℝ สมบูรณ์

เซตเดียวกันมีซูพรีมัม = √2 ∈ ℝ — ℝ ไม่มีช่องว่างบนเส้นจำนวน

💡 ทำไมจึงสำคัญสำหรับ A-Level
สมบัติความสมบูรณ์รับประกันว่า:
• ลิมิตของลำดับที่ลู่เข้ามีค่าอยู่จริงใน ℝ
• สมการทุกรูปแบบ (เช่น x² = 2) มีคำตอบใน ℝ (ถ้ามีคำตอบจริง)
• เส้นจำนวนจริงต่อเนื่องสมบูรณ์ ไม่มีช่องว่าง
📋
สรุปสูตรสำคัญ — จำนวนจริง A-Level
ค่าสัมบูรณ์:
|ab| = |a||b|, |a/b| = |a|/|b|
|a+b| ≤ |a|+|b| (Triangle Inequality)
|a| < k ⟺ −k < a < k
|a| > k ⟺ a > k หรือ a < −k

เลขยกกำลัง:
aᵐ·aⁿ = aᵐ⁺ⁿ, (aᵐ)ⁿ = aᵐⁿ, (ab)ⁿ = aⁿbⁿ
a⁻ⁿ = 1/aⁿ, aᵐ/ⁿ = ⁿ√(aᵐ)

ลอการิทึม:
log(mn) = log m + log n
log(m/n) = log m − log n
log(mⁿ) = n log m
log_b(a) = log a / log b (เปลี่ยนฐาน)
b^(log_b a) = a
