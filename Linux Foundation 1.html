Syntax — วิธีเขียน Arguments
⌨️ รูปแบบ Flag และ Option
-x Short flag — ขีดเดียว + ตัวอักษรตัวเดียว
เช่น -l, -a, -h, -S
--word Long flag — สองขีด + คำเต็ม
เช่น --color=yes, --help, --version
-lah Combined flags — รวมหลาย short flag ในครั้งเดียว
-lah = -l -a -h ลำดับไม่มีผลกับผลลัพธ์

⚠️ Case-Sensitive: -S (เรียงตาม Size) ≠ -s (แสดง block size) และ -R (Recursive) ≠ -r (Reverse) — ต้องระวังพิมพ์ตัวพิมพ์เล็ก-ใหญ่ให้ถูกต้อง

System Commands
🖥️ คำสั่งระบบพื้นฐาน
clear ล้างหน้าจอเทอร์มินัล — หรือกด Ctrl + L
date แสดงวันและเวลาของระบบ
ls --version เช็กเวอร์ชันของโปรแกรม ls ที่ติดตั้งอยู่
ls --help เปิดคู่มือการใช้งาน ls ทั้งหมด (สั้นกว่า man ls)
man ls เปิด manual page ฉบับสมบูรณ์ (กด q เพื่อออก)
Listing Files
📁 การแสดงไฟล์และโฟลเดอร์
ls แสดงไฟล์ในไดเรกทอรีปัจจุบัน
ls /path แสดงไฟล์ใน path ที่กำหนด เช่น ls /home/user
ls -a All — แสดงทุกอย่าง รวมไฟล์ซ่อน, . และ ..
ls -A Almost All — แสดงไฟล์ซ่อน แต่ ซ่อน . และ .. ไว้ (สะอาดกว่า)
ls . . (จุดเดียว) = ไดเรกทอรีปัจจุบัน
ls .. .. (สองจุด) = ไดเรกทอรีแม่ (parent directory)

ไฟล์ที่ขึ้นต้นด้วย . เช่น .bashrc, .gitignore จะถูกซ่อนโดยอัตโนมัติ — ต้องใช้ ls -a หรือ ls -A เพื่อดู

Color Options
🎨 การจัดการสีผลลัพธ์
ls --color=auto เปิดสีอัตโนมัติ — ค่า default บนระบบส่วนใหญ่
ls --color=yes บังคับเปิดสีเสมอ แม้จะ redirect output ไปยังไฟล์
ls --color=no ปิดสี — แสดงผลเป็นข้อความธรรมดาทั้งหมด
📟 ผลลัพธ์ ls -l (ตัวอย่าง)
-rw-r--r-- 1 alice devs 4096 Jun 15 09:30 report.txt
drwxr-xr-x 2 alice devs 4096 Jun 14 18:00 projects/
lrwxrwxrwx 1 root root 11 Jun 01 12:00 link -> /etc/hosts
#คอลัมน์ตัวอย่างความหมาย
1Permissions-rw-r--r--สิทธิ์การเข้าถึง: ประเภท + Owner + Group + Others
2Hard Links1จำนวน hard link ที่ชี้มายังไฟล์นี้ (ไฟล์ทั่วไป = 1)
3Owneraliceชื่อผู้ใช้ที่เป็นเจ้าของไฟล์
4Groupdevsกลุ่มผู้ใช้ที่มีสิทธิ์จัดการไฟล์
5Size4096ขนาดไฟล์ หน่วย Bytes (ใช้ -h เพื่ออ่านง่ายขึ้น)
6TimestampJun 15 09:30วันเวลาที่แก้ไขเนื้อหาล่าสุด (mtime)
7File Namereport.txtชื่อไฟล์, โฟลเดอร์ หรือ symlink → target
🔒 Permission String: drwxrwxrwx
ตัวที่ 1
d / - / l
ประเภท
ตัวที่ 2–4
rwx
Owner
ตัวที่ 5–7 / 8–10
rwx rwx
Group / Others
d = directory  ·  - = regular file  ·  l = symbolic link
r = read  ·  w = write  ·  x = execute  ·  - = ไม่มีสิทธิ์
🔢 UID และ GID
ls -n เหมือน ls -l แต่แสดง Owner/Group เป็นตัวเลข UID/GID
UID = User Identifier
GID = Group Identifier
มีประโยชน์ในการเขียนสคริปต์ parse
🔗 Inode
ls -li แสดงเลข Inode ที่คอลัมน์แรก
Inode = รหัสประจำตัวไฟล์ในระบบ filesystem ไฟล์ที่มี inode เดียวกัน = hard link เดียวกัน
⚙️ Flags เสริมที่ใช้บ่อยร่วมกับ -l
ls -lhHuman-readable size: K, M, G โดยใช้ฐาน 1024
ls -l --siHuman-readable size ฐาน 1000 (มาตรฐาน SI — ตัวเลขจะน้อยกว่า -h)
ls -lQครอบชื่อไฟล์ด้วย "เครื่องหมายคำพูด"
ls -ld .แสดงข้อมูลตัวโฟลเดอร์ ไม่เปิดดูไฟล์ข้างใน — ใช้ debug permission
ls -l --time-style=isoแสดงวันเวลาฟอร์แมต ISO: 2025-06-15 09:30
ls -lRRecursive — แสดงทุกไฟล์ในโฟลเดอร์ย่อยทุกชั้น
⏱ 3 ประเภท Timestamp ใน Linux
mtime
Modification Time เวลาที่ เนื้อหาข้างในไฟล์ ถูกแก้ไขล่าสุด (เขียนข้อมูลใหม่) → ls -lt เรียงตามนี้ (default) | ls -lt --time=mtime
atime
Access Time เวลาที่ไฟล์ถูกเปิดอ่านหรือเข้าถึงล่าสุด (cat, less, cp) → ls -ltu เรียงตามนี้ | u = use access time
ctime
Change Time เวลาที่ Metadata เปลี่ยนล่าสุด: chmod, chown, rename, mv → ls -ltc เรียงตามนี้ | c = use change time

Unix Epoch: ทุก timestamp คือจำนวนวินาทีที่นับตั้งแต่ 1 มกราคม 1970 00:00:00 UTC เรียกว่า "Unix Time" หรือ "POSIX Time" — ลองทดสอบด้วย date +%s

🔃 การเรียงลำดับตาม Timestamp
ls -ltเรียงตาม mtime — ไฟล์แก้ไขล่าสุดขึ้นก่อน (ใช้บ่อยมาก)
ls -ltuเรียงตาม atime — ไฟล์เข้าถึงล่าสุดขึ้นก่อน
ls -ltcเรียงตาม ctime — ไฟล์เปลี่ยน metadata ล่าสุดขึ้นก่อน
ls -ltrเรียงตาม mtime แบบ Reverse — ไฟล์เก่าสุดขึ้นก่อน (ดู log เก่าๆ)
ls -altrรวมไฟล์ซ่อน + ยาว + reverse mtime — debug pattern มาตรฐาน

⚠️ กับดักข้อสอบ: ls -lt ใช้ mtime เป็นค่า default อยู่แล้ว — ถ้าถามว่า "เรียงตามการแก้ไขเนื้อหาไฟล์" ไม่ต้องเพิ่ม flag อื่น! -u เปลี่ยนไปใช้ atime ไม่ใช่ mtime

📋 Cheat Sheet ฉบับสมบูรณ์
ls -lLong format — แสดง 7 คอลัมน์: perm, links, owner, group, size, time, name
ls -lhLong + human-readable size (K/M/G ฐาน 1024)
ls -l --siLong + human-readable size ฐาน 1000 (SI)
ls -aAll — รวมไฟล์ซ่อน, ., ..
ls -AAlmost All — ไฟล์ซ่อน แต่ไม่แสดง . ..
ls -ltเรียงตาม mtime ล่าสุดก่อน
ls -ltuเรียงตาม atime ล่าสุดก่อน
ls -ltcเรียงตาม ctime ล่าสุดก่อน
ls -lSเรียงตาม Size ใหญ่สุดก่อน
ls -rReverse — กลับด้านการเรียงลำดับ
ls -alSrไฟล์ซ่อน + ยาว + เรียง size + reverse — ไฟล์เล็กสุดขึ้นก่อน
ls -altrไฟล์ซ่อน + ยาว + reverse mtime — Debug pattern มาตรฐาน
ls -1บรรทัดละ 1 ไฟล์ (ตัวเลข หนึ่ง ไม่ใช่ L)
ls -mแสดงเรียงแนวนอน คั่นด้วย comma
ls --format=commasเทียบเท่า -m แบบ long form
ls -Qครอบชื่อไฟล์ด้วย "เครื่องหมายคำพูด"
ls -1Qบรรทัดละ 1 ไฟล์ + มี quotes ครอบชื่อ
ls -RRecursive — เปิดดูทุกโฟลเดอร์ย่อยทุกชั้น
ls -iแสดงเลข Inode ที่คอลัมน์แรก
ls -ld .ดูข้อมูลโฟลเดอร์ตัวเอง ไม่เปิดข้างใน
ls -nเหมือน -l แต่ Owner/Group เป็น UID/GID ตัวเลข
ls -l --time-style=isoแสดงวันเวลาฟอร์แมต YYYY-MM-DD HH:MM
ls --color=noปิดสีทั้งหมด (plain text output)
💡 Engineer Tips — ใช้งานจริง
→
เพิ่ม alias alias ll='ls -alh' ใน ~/.bashrc หรือ ~/.zshrc เพื่อใช้งานสะดวก
→
ใช้ ls -altr ดูไฟล์ที่ถูกแก้ไขล่าสุด — debug pattern มาตรฐาน เมื่อต้องหาว่าไฟล์ไหนถูกเปลี่ยนล่าสุด
→
ใช้ ls -n แทน ls -l ในสคริปต์ เพราะ UID/GID ตัวเลข parse ได้ง่ายกว่า username
→
ใช้ ls -ald /path/to/dir เพื่อตรวจ permission ของโฟลเดอร์โดยตรง — ใช้บ่อยมากเมื่อเจอ "Permission denied"
→
Combine flags เสมอ: ls -lahS แทน ls -l -a -h -S — ประหยัดเวลา
→
ใช้ ls -lh --time-style=iso เมื่อ copy ผลลัพธ์ไปใส่ report — อ่านง่ายและ format ชัดเจน
