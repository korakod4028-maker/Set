บทที่ 1 · ลำดับ (Sequences)
🔗
ลำดับคืออะไร?

ลำดับ (Sequence) คือ ฟังก์ชันที่มีโดเมนเป็นเซตของจำนวนนับ เขียนแทนพจน์ต่าง ๆ เรียงกันตามลำดับ

นิยาม
ลำดับ คือ กลุ่มของจำนวนที่เรียงกันอย่างมีระบบ เรียกแต่ละจำนวนว่า พจน์ (Term) เขียนแทนพจน์ที่ n ด้วย aₙ
ตัวอย่าง
2, 4, 6, 8, 10, ... → a₁=2, a₂=4, a₃=6, ...
1, 4, 9, 16, 25, ... → aₙ = n²

ลำดับจำกัด (Finite)

มีจำนวนพจน์จำกัด เช่น 1, 3, 5, 7, 9 (5 พจน์)

ลำดับอนันต์ (Infinite)

มีพจน์ไม่สิ้นสุด เช่น 1, 3, 5, 7, 9, ...

🧮
การหาพจน์ทั่วไป aₙ

การหาสูตรพจน์ทั่วไป ต้องสังเกตรูปแบบความสัมพันธ์ระหว่างตำแหน่ง n กับค่าของพจน์

ตัวอย่างที่ 1
ลำดับ 3, 5, 7, 9, ... สังเกตว่าเพิ่มขึ้นทีละ 2 และเริ่มจาก 3
aₙ = 2n + 1 (ตรวจสอบ: a₁=3, a₂=5, a₃=7 ✓)
ตัวอย่างที่ 2
ลำดับ 1, 4, 9, 16, ... คือกำลังสองของตำแหน่ง
aₙ = n²
💡 เทคนิคหาสูตร
ลองหาผลต่างระหว่างพจน์ที่ติดกัน ถ้าผลต่างคงที่ → ลำดับเลขคณิต
ลองหาอัตราส่วนระหว่างพจน์ที่ติดกัน ถ้าอัตราส่วนคงที่ → ลำดับเรขาคณิต
🔁
ลำดับที่นิยามแบบเวียนเกิด (Recursive)
นิยาม
ลำดับเวียนเกิด คือ ลำดับที่กำหนดพจน์แรก (หรือหลายพจน์แรก) แล้วนิยามพจน์ถัดไปจากพจน์ก่อนหน้า
ตัวอย่าง
กำหนด a₁ = 2 และ aₙ₊₁ = aₙ + 3 (n ≥ 1)
a₁=2, a₂=2+3=5, a₃=5+3=8, a₄=8+3=11, ...
⚠️ ข้อควรระวัง
ต้องไล่คำนวณทีละพจน์จากพจน์เริ่มต้นเสมอ ไม่สามารถกระโดดข้ามไปหาพจน์ที่ต้องการได้โดยตรง เว้นแต่จะแปลงเป็นสูตรปิด (closed form) ได้ก่อน
หัวข้อ 2 · ลำดับเลขคณิต (Arithmetic Sequence)
➕
นิยามและสูตรพจน์ทั่วไป
นิยาม
ลำดับเลขคณิต คือ ลำดับที่ ผลต่างระหว่างพจน์ที่ติดกันคงที่เสมอ เรียกค่าคงที่นี้ว่า ผลต่างร่วม (common difference) แทนด้วย d
d = aₙ − aₙ₋₁ (ค่าคงที่ทุกคู่พจน์ที่ติดกัน)
aₙ = a₁ + (n − 1)d
ตัวอย่าง
3, 7, 11, 15, ... → a₁ = 3, d = 4
a₁₀ = 3 + (10−1)(4) = 3 + 36 = 39
💡 เทคนิคหา d
d = a₂ − a₁ = a₃ − a₂ = ... เลือกคู่ที่คำนวณง่ายที่สุด
🔍
การหา a₁ และ d เมื่อรู้สองพจน์
ตัวอย่าง
กำหนด a₃ = 11 และ a₇ = 23 จงหา a₁ และ d

วิธีทำ: a₇ − a₃ = 4d (ห่างกัน 4 ตำแหน่ง)
23 − 11 = 4d → d = 3
a₃ = a₁ + 2d → 11 = a₁ + 6 → a₁ = 5
⚠️ ข้อควรระวัง
จำนวนช่วง (ผลต่างของ d) ระหว่างพจน์ที่ m และพจน์ที่ n คือ |n − m| ไม่ใช่ n − m + 1
⚖️
ค่าเฉลี่ยเลขคณิต (Arithmetic Mean)
นิยาม
ค่าเฉลี่ยเลขคณิตระหว่าง a และ b คือ ค่ากึ่งกลางที่ทำให้ a, A, b เป็นลำดับเลขคณิต
A = (a + b) / 2
ตัวอย่าง
ค่าเฉลี่ยเลขคณิตระหว่าง 8 และ 20 คือ (8+20)/2 = 14
การแทรกค่าเฉลี่ยเลขคณิตหลายค่า

ถ้าต้องการแทรกค่าเฉลี่ยเลขคณิต k ค่า ระหว่าง a และ b จะได้ลำดับทั้งหมด k+2 พจน์ (รวม a และ b)

d = (b − a) / (k + 1)
ตัวอย่าง
แทรกค่าเฉลี่ยเลขคณิต 3 ค่า ระหว่าง 5 และ 25 (รวมเป็น 5 พจน์)
d = (25−5)/(3+1) = 20/4 = 5
ลำดับ: 5, 10, 15, 20, 25 → ค่าที่แทรกคือ 10, 15, 20
หัวข้อ 3 · ลำดับเรขาคณิต (Geometric Sequence)
✖️
นิยามและสูตรพจน์ทั่วไป
นิยาม
ลำดับเรขาคณิต คือ ลำดับที่ อัตราส่วนระหว่างพจน์ที่ติดกันคงที่เสมอ เรียกค่าคงที่นี้ว่า อัตราส่วนร่วม (common ratio) แทนด้วย r
r = aₙ / aₙ₋₁ (ค่าคงที่ทุกคู่พจน์ที่ติดกัน, aₙ₋₁ ≠ 0)
aₙ = a₁ · rⁿ⁻¹
ตัวอย่าง
2, 6, 18, 54, ... → a₁ = 2, r = 3
a₆ = 2 · 3⁵ = 2 · 243 = 486
⚠️ ข้อควรระวัง
r อาจเป็นค่าลบได้ (ทำให้เครื่องหมายของพจน์สลับ + / −) หรือเป็นเศษส่วนก็ได้ (ทำให้ค่าพจน์ลดลงเรื่อย ๆ)
🔍
การหา a₁ และ r เมื่อรู้สองพจน์
ตัวอย่าง
กำหนด a₂ = 6 และ a₅ = 48 จงหา a₁ และ r

วิธีทำ: a₅ / a₂ = r³ (ห่างกัน 3 ตำแหน่ง)
48 / 6 = r³ → r³ = 8 → r = 2
a₂ = a₁ · r → 6 = a₁ · 2 → a₁ = 3
⚖️
ค่าเฉลี่ยเรขาคณิต (Geometric Mean)
นิยาม
ค่าเฉลี่ยเรขาคณิตระหว่าง a และ b (ที่มีเครื่องหมายเดียวกัน) คือค่า G ที่ทำให้ a, G, b เป็นลำดับเรขาคณิต
G = ±√(ab) (เลือกเครื่องหมายให้สอดคล้องกับ a และ b)
ตัวอย่าง
ค่าเฉลี่ยเรขาคณิตระหว่าง 4 และ 100 (ค่าบวก) คือ √(4×100) = √400 = 20
💡 เทคนิคจำ
เปรียบเทียบ: ค่าเฉลี่ยเลขคณิต A = (a+b)/2 (การบวก-หาร) แต่ค่าเฉลี่ยเรขาคณิต G = √(ab) (การคูณ-ถอดราก) — เข้าคู่กับชื่อของลำดับแต่ละแบบ
หัวข้อ 4 · สัญลักษณ์แทนการบวก (Σ)
Σ
ความหมายของสัญลักษณ์ผลบวก
นิยาม
Σᵢ₌₁ⁿ aᵢ หมายถึง ผลบวกของพจน์ a₁ + a₂ + a₃ + ... + aₙ
ตัวอย่าง
Σᵢ₌₁⁵ i = 1+2+3+4+5 = 15
Σᵢ₌₁⁴ (2i) = 2+4+6+8 = 20
📐
สมบัติของสัญลักษณ์ผลบวก
Σᵢ₌₁ⁿ c = cn (c เป็นค่าคงที่)
Σᵢ₌₁ⁿ (aᵢ + bᵢ) = Σaᵢ + Σbᵢ
Σᵢ₌₁ⁿ (k·aᵢ) = k·Σaᵢ (k เป็นค่าคงที่)
ตัวอย่าง
Σᵢ₌₁¹⁰ (2i + 1) = 2·Σᵢ₌₁¹⁰i + Σᵢ₌₁¹⁰1 = 2(55) + 10 = 120
🧾
สูตรลัดผลบวกที่ต้องจำ
ผลบวกสูตร
Σᵢ₌₁ⁿ in(n+1)/2
Σᵢ₌₁ⁿ i²n(n+1)(2n+1)/6
Σᵢ₌₁ⁿ i³[n(n+1)/2]²
ตัวอย่าง
Σᵢ₌₁⁵ i² = 5(6)(11)/6 = 55 (ตรวจสอบ: 1+4+9+16+25 = 55 ✓)
💡 เทคนิคการใช้งาน
เมื่อเจอผลบวกที่มีพจน์ผสม เช่น Σ(3i² − 2i + 1) ให้แยกเป็นผลบวกย่อยแต่ละส่วนแล้วใช้สูตรลัดทีละส่วน
บทที่ 2 · อนุกรมเลขคณิต (Arithmetic Series)
Σ
อนุกรมคืออะไร?
นิยาม
อนุกรม (Series) คือ ผลบวกของพจน์ในลำดับ เขียนแทนผลบวก n พจน์แรกด้วย Sₙ
Sₙ = a₁ + a₂ + a₃ + ... + aₙ
📐
สูตรผลบวก n พจน์แรกของอนุกรมเลขคณิต
Sₙ = n/2 (a₁ + aₙ)
Sₙ = n/2 [2a₁ + (n−1)d]
ตัวอย่าง
1 + 4 + 7 + 10 + ... (20 พจน์แรก) → a₁=1, d=3
a₂₀ = 1 + 19(3) = 58
S₂₀ = 20/2 (1 + 58) = 10 × 59 = 590
💡 เทคนิคเลือกสูตร
ถ้ารู้ a₁ กับ aₙ อยู่แล้ว ใช้สูตรแรก (เร็วกว่า) — ถ้ารู้แค่ a₁ กับ d ใช้สูตรที่สอง
🔗
ความสัมพันธ์ระหว่าง Sₙ และ aₙ
สูตรสำคัญ
aₙ = Sₙ − Sₙ₋₁ (สำหรับ n ≥ 2)
ตัวอย่าง
กำหนด Sₙ = n² + 2n จงหา a₅
S₅ = 25+10 = 35, S₄ = 16+8 = 24
a₅ = S₅ − S₄ = 35 − 24 = 11
🔎
การหาจำนวนพจน์ (n) จาก Sₙ
ตัวอย่าง
อนุกรมเลขคณิต a₁ = 5, d = 3 มี Sₙ = 440 จงหาค่า n

วิธีทำ: Sₙ = n/2[2(5)+3(n−1)] = n/2[3n+7] = 440
n(3n+7) = 880 → 3n² + 7n − 880 = 0
แยกตัวประกอบ/ใช้สูตร: n = 16 (ค่า n ต้องเป็นจำนวนนับ ปฏิเสธคำตอบที่ติดลบ)
⚠️ ข้อควรระวัง
เมื่อแก้สมการกำลังสองได้สองคำตอบ ต้องเลือกเฉพาะ n ที่เป็นจำนวนนับ (บวกและเป็นจำนวนเต็ม) เท่านั้น
หัวข้อ 6 · อนุกรมเรขาคณิต (Geometric Series)
📐
สูตรผลบวก n พจน์แรกของอนุกรมเรขาคณิต
Sₙ = a₁(1 − rⁿ) / (1 − r) เมื่อ r ≠ 1
หรือเทียบเท่า Sₙ = a₁(rⁿ − 1) / (r − 1)
ตัวอย่าง
3 + 6 + 12 + 24 + ... (6 พจน์แรก) → a₁=3, r=2
S₆ = 3(2⁶ − 1)/(2 − 1) = 3(63)/1 = 189
💡 เทคนิคเลือกสูตร
ถ้า r > 1 มักใช้รูป (rⁿ−1)/(r−1) เพื่อให้ตัวเศษและส่วนเป็นบวกทั้งคู่ คำนวณง่ายกว่า
⚠️ กรณีพิเศษ r = 1
ถ้า r = 1 ทุกพจน์มีค่าเท่ากับ a₁ ดังนั้น Sₙ = n·a₁ (ใช้สูตรเดิมไม่ได้ เพราะส่วนเป็น 0)
🔎
การหาจำนวนพจน์ (n) จาก Sₙ
ตัวอย่าง
อนุกรมเรขาคณิต a₁ = 3, r = 2 มี Sₙ = 381 จงหาค่า n

วิธีทำ: Sₙ = 3(2ⁿ−1)/(2−1) = 3(2ⁿ−1) = 381
2ⁿ − 1 = 127 → 2ⁿ = 128 = 2⁷ → n = 7
หัวข้อ 7 · อนุกรมอนันต์ (Infinite Series)
∞
อนุกรมเรขาคณิตอนันต์ที่ลู่เข้า
นิยาม
เมื่อ n เพิ่มขึ้นไม่มีที่สิ้นสุด ผลบวก Sₙ ของอนุกรมเรขาคณิตจะลู่เข้าสู่ค่าคงที่ค่าหนึ่ง ได้ก็ต่อเมื่อ |r| < 1
S = a₁ / (1 − r) เมื่อ |r| < 1
ตัวอย่าง
8 + 4 + 2 + 1 + ... → a₁ = 8, r = 1/2
S = 8 / (1 − 1/2) = 8 / (1/2) = 16
⚠️ กรณีลู่ออก (Divergent)
ถ้า |r| ≥ 1 อนุกรมจะไม่มีผลบวกจำกัด (ไม่ลู่เข้า) จึงหาค่า S แบบนี้ไม่ได้
🔢
การเขียนทศนิยมซ้ำเป็นเศษส่วน

ทศนิยมซ้ำสามารถมองเป็นอนุกรมเรขาคณิตอนันต์ได้

ตัวอย่าง
0.777... = 7/10 + 7/100 + 7/1000 + ...
a₁ = 7/10, r = 1/10
S = (7/10) / (1 − 1/10) = (7/10)/(9/10) = 7/9
💡 เทคนิคจำ
ทศนิยมซ้ำ 1 ตำแหน่งซ้ำ (0.ẋ) → เศษส่วนที่มีตัวส่วนเป็น 9 (เช่น 0.7̇ = 7/9)
🏀
โจทย์ประยุกต์ — ระยะทางลูกบอลกระดอน
ตัวอย่าง
ปล่อยลูกบอลจากความสูง 20 เมตร แต่ละครั้งที่กระดอนขึ้นจะสูงเป็น 1/2 ของครั้งก่อน จงหาระยะทางรวมทั้งหมดที่ลูกบอลเคลื่อนที่จนหยุดนิ่ง

แนวคิด: ระยะตกครั้งแรก = 20 ม.
หลังจากนั้นลูกบอลจะกระดอนขึ้น-ลง ซ้ำ ๆ ด้วยความสูงที่ลดลงเป็นอัตราส่วนเรขาคณิต จึงนับระยะขึ้น-ลงรวมเป็น 2 เท่าของผลบวกอนันต์ของความสูงที่กระดอน

ระยะทางรวม = 20 + 2 × [20(1/2) / (1 − 1/2)] = 20 + 2(20) = 60 เมตร
บทที่ 3 · โจทย์ประยุกต์ลำดับและอนุกรม
🏦
ดอกเบี้ยทบต้น (Compound Interest)

เงินฝากที่ได้ดอกเบี้ยทบต้นจะเติบโตแบบลำดับเรขาคณิต เพราะแต่ละปีคูณด้วยอัตราเติบโตคงที่

Aₙ = A₀(1 + i)ⁿ
ตัวอย่าง
ฝากเงิน 10,000 บาท ดอกเบี้ยทบต้น 5% ต่อปี หลังจาก 3 ปี จะมีเงินเท่าใด

A₃ = 10,000 × (1.05)³ = 10,000 × 1.157625 ≈ 11,576 บาท
👥
การเติบโตของประชากร

ถ้าประชากรเพิ่มขึ้นเป็นอัตราร้อยละคงที่ทุกปี ก็จัดเป็นลำดับเรขาคณิตเช่นกัน

ตัวอย่าง
เมืองหนึ่งมีประชากร 5,000 คน เพิ่มขึ้นปีละ 4% หลังจาก 2 ปี ประชากรจะมีประมาณเท่าใด

P₂ = 5,000 × (1.04)² = 5,000 × 1.0816 = 5,408 คน
🎫
โจทย์การจัดเรียง / เวียนเกิด
ตัวอย่าง
กำหนด a₁ = 2 และ aₙ₊₁ = aₙ + 3n จงหาค่า a₅

a₁=2
a₂ = a₁ + 3(1) = 2+3 = 5
a₃ = a₂ + 3(2) = 5+6 = 11
a₄ = a₃ + 3(3) = 11+9 = 20
a₅ = a₄ + 3(4) = 20+12 = 32
💡 เทคนิคโจทย์เวียนเกิด
ไล่คำนวณทีละพจน์อย่างมีระบบ เขียนตารางหรือรายการกำกับไว้กันสับสน โดยเฉพาะเมื่อสูตรเวียนเกิดมีตัวแปร n ปนอยู่ด้วย
🧩
โจทย์ผสม Sₙ สองค่า
ตัวอย่าง
อนุกรมเลขคณิตมี S₃ = 15 และ S₆ = 66 จงหา a₁, d และ S₁₀

S₃ = 3/2(2a₁+2d) = 3(a₁+d) = 15 → a₁+d = 5
S₆ = 6/2(2a₁+5d) = 3(2a₁+5d) = 66 → 2a₁+5d = 22

แทน a₁ = 5−d: 2(5−d)+5d = 22 → 10+3d = 22 → d = 4, a₁ = 1
