🔊 คลื่นเสียง

  • เป็นคลื่นตามยาว อัตราเร็วขึ้นกับสมบัติของตัวกลาง
  • การกระจัด: y(x,t) = A sin(kx − ωt) (ทิศการกระจัดขนานกับทิศคลื่น)
  • มองเป็นการแปรผันความดัน: เฟสต่างจาก y หนึ่งในสี่รอบ → ที่ขณะใดๆ การกระจัดสูงสุด ณ ตำแหน่งที่ความผันผวนความดัน = 0
p(x,t) = −B·k·A·cos(kx − ωt)
p_max = B·k·A

B = บัลก์มอดุลัส (การเปลี่ยนปริมาตรสัมพัทธ์ต่อการเปลี่ยนความดัน) : p = −B ∂y/∂x

⚡ ความเร็วเสียง

v = √(B/ρ)  (แก๊ส/ของเหลว, 3 มิติ)
v = √(T/μ)  (เชือก, 1 มิติ)
v = √(สมบัติยืดหยุ่น / สมบัติเฉื่อย)
v = 331·√(1 + T_C/273) m/s  หรือ  v = 331 + 0.6·t
v = fλ

331 m/s = เสียงในอากาศที่ 0°C · ที่ 20°C ≈ 343 m/s

EX (สไลด์ 30)
B = 1.3×10⁵ Pa, ρ = 1.2 kg/m³ → v = √(1.3×10⁵/1.2) ≈ 329 m/s
หน่วย: √(Pa·m³/kg) = √(m²/s²) = m/s ✓

🎻 การสั่นพ้อง

ความถี่แรงขับ = ความถี่นอร์มอลโหมด → แอมพลิจูดบังคับสูงสุด ถ้าไม่สูญเสียพลังงานแอมพลิจูดเพิ่มไม่สิ้นสุด (เช่น แก้วแตกด้วยเสียง)

📈 ระดับเสียง (dB)

β = 10·log(I / I₀)    I₀ = 1.00×10⁻¹² W/m²
I = P / (4πr²)  (แหล่งกำเนิดจุด)
  • I₀ = ความเข้มน้อยที่สุดที่คนได้ยิน (0 dB)
  • เริ่มเจ็บหู: I = 1.0 W/m² → 120 dB
  • เกิน 90 dB ควรใส่ที่อุดหู
  • ความเข้มเพิ่ม 10 เท่า → ระดับเสียงเพิ่ม 10 dB · เพิ่ม 2 เท่า → เพิ่มแค่ ≈ 3 dB
EX (สไลด์ 22–23) I = 2.0×10⁻⁷ W/m² ต่อเครื่อง
(a) 1 เครื่อง: 10 log(2.0×10⁵) = 53 dB
(b) 2 เครื่อง: I = 4.0×10⁻⁷ → 56 dB
(c) ดังเป็น 2 เท่า ≈ +10 dB → I₂ = 10 I₁ → ต้องใช้ 10 เครื่อง

🎺 ท่อออร์แกน

ท่อปลายเปิด (2 ข้าง)ท่อปลายปิด (1 ข้าง)
ปลายท่อเปิด = แอนตินอดการกระจัด (A)ปิด = โหนดการกระจัด (N), เปิด = A
λ ที่ฮาร์มอนิก nλₙ = 2L/nλₙ = 4L/n
ความถี่fₙ = n·v/(2L)fₙ = n·v/(4L)
n1, 2, 3, …1, 3, 5, … (เลขคี่เท่านั้น)
พื้นฐานL = λ/2L = λ/4
fₙ = n·f₁
จำ
ท่อปิดไม่มีฮาร์มอนิกคู่ (2f₁, 4f₁ …) · ใช้ v = fλ และ v = 331 + 0.6t หา v ก่อนเสมอ
⚠ เช็กก่อนอ่าน
ในสไลด์หัวข้อ "การแทรกสอดของคลื่น" (หน้า 14) ถูกขีดฆ่า มีโน้ตลายมือด้วย แนะนำเช็กกับอาจารย์ว่าออกสอบไหม ส่วนบีตส์ไม่มีรอยขีดฆ่า

🌊 การแทรกสอด (ลำโพง 2 ตัว เฟสตรงกัน)

เสริม: Δd = nλ    หักล้าง: Δd = (n + ½)λ
EX (สไลด์ 16) v = 350 m/s, Δd = 3.00 m
เสริม: f = n·v/Δd = 117n Hz
หักล้าง: f = (n+½)·117 Hz

🥁 บีตส์ (Beats)

คลื่น 2 ขบวน แอมพลิจูดเท่ากัน ความถี่ต่างกันเล็กน้อย → ความดังขึ้นลงเป็นจังหวะ

f_beat = |f_a − f_b|

ที่มา: T_beat = nT_a = (n−1)T_b → f_beat = 1/T_a − 1/T_b

🚓 ปรากฏการณ์ดอปเปลอร์

f' = f_s · (v ± v_o) / (v ± v_s)
กรณีเครื่องหมายบน (ตัวเศษ v_o)ตัวส่วน v_s
เข้าหากัน (f' มาก)+−
ออกจากกัน (f' น้อย)−+
  • แหล่งหยุดนิ่ง ผู้ฟังเข้าหา: f' = f(v+v_o)/v · ออกห่าง: f(v−v_o)/v
  • ผู้ฟังหยุดนิ่ง แหล่งเข้าหา: f' = f·v/(v−v_s) · ออกห่าง: f·v/(v+v_s)
  • λ หน้าแหล่ง = (v−v_s)/f
EX สไลด์ 27–29
f = 300 Hz, v = 340, v_s = 30 m/s
หน้ารถ: 300·340/(340−30) ≈ 329 Hz (λ = 310/300 ≈ 1.03 m)
หลังรถ: 300·340/(340+30) ≈ 276 Hz (λ ≈ 1.23 m)
ผู้ฟังขับออกห่างด้วย 30 m/s (แหล่งนิ่ง): 300·(340−30)/340 = 273.53 Hz
EX 7 (สไลด์ 30) เข้าหากัน 20 m/s ทั้งคู่, f = 1000 Hz
v = 329 m/s → f' = 1000·(329+20)/(329−20) = 1000·349/309 ≈ 1129.45 Hz

✈️ คลื่นกระแทก (Shock waves)

  • v_s < v: λ หน้าแหล่ง = (v − v_s)/f_s
  • v_s > v (เร็วกว่าเสียง): สันคลื่นวงกลมแทรกสอดเสริมกันเป็นกรวย (ซอนิกบูม)
sin α = vt / v_s t = v / v_s = 1/M    M = v_s / v (เลขมัค)
EX (สไลด์ 34) Mach 1.75, สูง 8000 m, v = 320 m/s
sin α = 1/1.75 → α ≈ 34.8°
v_s = 1.75×320 = 560 m/s
ระยะแนวนอน x = 8000/tan α ≈ 11,490 m → t = x/v_s ≈ 20.5 วินาที หลังเครื่องบินผ่านเหนือหัว
