การเคลื่อนที่ในระบบไฟล์

pwd, cd และ path แบบ absolute / relative

13 คำสั่ง/แนวคิด
4 ข้อสอบ
Cloud Engineer Edition

คำสั่งหลัก

pwd
แสดงตำแหน่งปัจจุบัน (Print Working Directory)
cd /var/log
ไปยัง absolute path
cd project
ไปยัง relative path จากตำแหน่งปัจจุบัน
cd ..
ขึ้นไปหนึ่งชั้น (parent directory)
cd ~
กลับ home directory (หรือพิมพ์ cd เฉยๆ)
cd -
กลับไปโฟลเดอร์ก่อนหน้า (สลับไปมาได้)
cd ../..
ขึ้นสองชั้น
echo $HOME
ดู path ของ home

แนวคิด Path

/
Root ของระบบไฟล์ — path ที่ขึ้นต้นด้วย / คือ absolute
.
ไดเรกทอรีปัจจุบัน
..
ไดเรกทอรีแม่
~user
home ของผู้ใช้ที่ระบุ เช่น ~root
Tab
กด Tab เพื่อเติมชื่อ path อัตโนมัติ

⚠️ กับดักข้อสอบ

Linux แยกตัวพิมพ์เล็ก-ใหญ่: /Home ≠ /home และชื่อที่มีเว้นวรรคต้องใส่ quotes เช่น cd "My Docs"

💡 Engineer Tips

  • ใช้ cd - สลับระหว่างสองโฟลเดอร์ที่ทำงานอยู่บ่อยๆ
  • Absolute path ปลอดภัยกว่าใน script เพราะไม่ขึ้นกับตำแหน่งที่รัน
