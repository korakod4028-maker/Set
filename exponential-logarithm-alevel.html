บทที่ 1 · เลขยกกำลังและฟังก์ชันเอกซ์โพเนนเชียล
📐
กฎเลขยกกำลัง — ทบทวนก่อนเรียน

ก่อนเรียนฟังก์ชันเอกซ์โพเนนเชียล ต้องจำกฎพื้นฐานให้แม่น

aᵐ · aⁿ = aᵐ⁺ⁿ
aᵐ ÷ aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ
(ab)ⁿ = aⁿbⁿ
a⁰ = 1 (a ≠ 0)
a⁻ⁿ = 1/aⁿ
a^(1/n) = ⁿ√a
a^(m/n) = ⁿ√(aᵐ)
💡 เทคนิค A-Level
ข้อสอบมักให้ ลดรูป หรือ เปรียบเทียบ นิพจน์ที่ซับซ้อน — ฝึกใช้กฎหลายข้อพร้อมกัน เช่น (2³)² = 2⁶ = 64
ตัวอย่าง — ลดรูป
ลดรูป: (8^(2/3) × 16^(1/4)) ÷ 4^(3/2)

8^(2/3) = (2³)^(2/3) = 2² = 4
16^(1/4) = (2⁴)^(1/4) = 2¹ = 2
4^(3/2) = (2²)^(3/2) = 2³ = 8

ผลลัพธ์ = (4 × 2) ÷ 8 = 8 ÷ 8 = 1
📈
ฟังก์ชันเอกซ์โพเนนเชียล f(x) = aˣ
นิยาม
ฟังก์ชันเอกซ์โพเนนเชียล คือ f(x) = aˣ โดย a > 0, a ≠ 1 และ x ∈ ℝ
โดเมน (Domain) = ℝ = (-∞, +∞)
เรนจ์ (Range) = (0, +∞)

a > 1 → ฟังก์ชันเพิ่ม

เช่น f(x) = 2ˣ, 3ˣ, 10ˣ

  • เมื่อ x เพิ่ม → f(x) เพิ่ม
  • กราฟวิ่งขึ้นซ้ายไปขวา
  • ผ่านจุด (0, 1) เสมอ
  • asymptote แนวนอน: y = 0

0 < a < 1 → ฟังก์ชันลด

เช่น f(x) = (1/2)ˣ, (1/3)ˣ

  • เมื่อ x เพิ่ม → f(x) ลด
  • กราฟวิ่งลงซ้ายไปขวา
  • ผ่านจุด (0, 1) เสมอ
  • asymptote แนวนอน: y = 0

กราฟฟังก์ชันเอกซ์โพเนนเชียล — ทั้งสองผ่านจุด (0, 1)

⚠️ ข้อควรระวัง — กับดักข้อสอบ
ฟังก์ชันเอกซ์โพเนนเชียล ไม่เคยเป็นศูนย์ และ ไม่เคยเป็นลบ
aˣ > 0 เสมอ สำหรับทุกค่า x

หัวข้อ 2 · จำนวน e และฟังก์ชัน eˣ
🔢
จำนวน e คืออะไร?
นิยาม
e (ค่าคงที่ออยเลอร์) คือจำนวนอตรรกยะที่สำคัญที่สุดในคณิตศาสตร์
e ≈ 2.71828182845...

นิยามอย่างเป็นทางการ:
e = lim(n→∞) (1 + 1/n)ⁿ
💡 เทคนิคจำ
จำแค่ e ≈ 2.718 พอสำหรับการประมาณค่า
ข้อสอบ A-Level มักให้ตอบในรูป e ไม่ต้องแทนค่าตัวเลข
📈
ฟังก์ชัน f(x) = eˣ

เป็นกรณีพิเศษของ aˣ เมื่อ a = e เรียกว่า ฟังก์ชันเอกซ์โพเนนเชียลธรรมชาติ

f(x) = eˣ
f(0) = e⁰ = 1
f(1) = e¹ = e ≈ 2.718
f(-1) = e⁻¹ = 1/e ≈ 0.368
f(x) > 0 สำหรับทุก x ∈ ℝ
ตัวอย่าง — คำนวณค่า
ถ้า f(x) = 2e^(3x) จงหาค่า f(0) และ f(1)

f(0) = 2e^(3×0) = 2e⁰ = 2 × 1 = 2
f(1) = 2e^(3×1) = 2e³ ≈ 2 × 20.086 ≈ 40.17
บทที่ 2 · ฟังก์ชันลอการิทึม
📖
ลอการิทึมคืออะไร?

ลอการิทึมคือ ฟังก์ชันผกผันของฟังก์ชันเอกซ์โพเนนเชียล

นิยาม
loga b = c ⟺ aᶜ = b
(อ่านว่า "log ฐาน a ของ b เท่ากับ c")
โดย a > 0, a ≠ 1, b > 0
ตัวอย่าง — แปลงรูป
log₂ 8 = 3 ⟺ 2³ = 8 ✓
log₃ 81 = 4 ⟺ 3⁴ = 81 ✓
log₅ (1/5) = -1 ⟺ 5⁻¹ = 1/5 ✓
log₁₀ 1000 = 3 ⟺ 10³ = 1000 ✓
⚠️ เงื่อนไขที่ต้องจำ
loga b หาค่าได้เมื่อ: b > 0 เท่านั้น
ห้าม log ของจำนวนไม่เป็นบวก! เช่น log(-3) ไม่นิยาม, log(0) ไม่นิยาม
📈

หัวข้อ 4 · กฎสำคัญของลอการิทึม
📋
กฎลอการิทึม 5 ข้อ (ต้องจำให้ขึ้นใจ!)
กฎ 1 logₐ(MN) = logₐ M + logₐ N
กฎ 2 logₐ(M/N) = logₐ M − logₐ N
กฎ 3 logₐ(Mⁿ) = n · logₐ M
กฎ 4 logₐ(ⁿ√M) = (1/n) · logₐ M
กฎ 5 logₐ M = logₐ M (ตัวตั้ง M ต้องเป็นบวก!)
⚠️ ข้อผิดพลาดที่พบบ่อยมาก
❌ logₐ(M + N) ≠ logₐ M + logₐ N
❌ logₐ(M − N) ≠ logₐ M − logₐ N
❌ logₐ M × logₐ N ≠ logₐ(MN)

✅ logₐ(MN) = logₐ M + logₐ N (คูณ→บวก)
✅ logₐ(M/N) = logₐ M − logₐ N (หาร→ลบ)
✏️
ตัวอย่างการใช้กฎ
ตัวอย่าง 1 — ขยาย (Expand)
log₂(8x³/y) = log₂ 8 + log₂ x³ − log₂ y
              = 3 + 3·log₂ x − log₂ y
ตัวอย่าง 2 — รวม (Condense)
2·log 3 + log 4 − log 6
= log 3² + log 4 − log 6
= log(9 × 4) − log 6
= log 36 − log 6
= log(36/6) = log 6
ตัวอย่าง 3 — หาค่า
หาค่า log₂ 32 − log₂ 4
= log₂(32/4) = log₂ 8 = log₂ 2³ = 3
💡 เทคนิคสอบ — จำค่า log ที่ใช้บ่อย
log 2 ≈ 0.301    log 3 ≈ 0.477    log 5 = 1 − log 2 ≈ 0.699
log 7 ≈ 0.845    log 6 = log 2 + log 3 ≈ 0.778
หัวข้อ 5 · สูตรเปลี่ยนฐาน
🔄
สูตรเปลี่ยนฐาน (Change of Base)
สูตรหลัก
logₐ b = log_c b / log_c a

ในทางปฏิบัติ เปลี่ยนเป็นฐาน 10 หรือฐาน e:
logₐ b = log b / log a = ln b / ln a
ตัวอย่าง — เปลี่ยนฐาน
หาค่า log₈ 32

วิธี 1 — เปลี่ยนฐาน:
log₈ 32 = log 32 / log 8 = log 2⁵ / log 2³ = 5 log 2 / 3 log 2 = 5/3

วิธี 2 — ให้ log₈ 32 = x แล้วแก้:
8ˣ = 32 → (2³)ˣ = 2⁵ → 3x = 5 → x = 5/3
สูตรอื่นที่ใช้บ่อยในข้อสอบ
logₐ b × log_b c = logₐ c (Chain Rule)

logₐ b = 1 / log_b a (สลับฐากับตัวตั้ง)

log_{a^n} b^m = (m/n) · logₐ b
💡 Chain Rule — ใช้บ่อยในข้อสอบ
log₂ 3 × log₃ 4 × log₄ 8 = log₂ 8 = 3
(ยกเลิกฐาตรงกลาง เหลือแค่ log₂ 8)
หัวข้อ 6 · ln และ log (ลอการิทึมพิเศษ)
ln
Natural Logarithm — ln x
นิยาม
ln x = log_e x
คือลอการิทึมฐาน e (e ≈ 2.718)
เรียกว่า "ลอการิทึมธรรมชาติ"
ln 1 = 0
ln e = 1
ln eˣ = x
e^(ln x) = x (x > 0)
ln(1/x) = −ln x
ตัวอย่าง
แก้สมการ: e^(2x) = 5
ln(e^(2x)) = ln 5
2x = ln 5
x = (ln 5)/2 ≈ 1.609/2 ≈ 0.805
log
Common Logarithm — log x
นิยาม
log x = log₁₀ x
คือลอการิทึมฐาน 10
เมื่อไม่เขียนฐาน หมายถึงฐาน 10 โดยทั่วไป
log 1 = 0
log 10 = 1
log 100 = 2
log 1000 = 3
log 0.1 = −1
log 0.01 = −2
💡 ตาราง log ฐาน 10 ที่ต้องจำ
log 2 ≈ 0.3010   log 3 ≈ 0.4771   log 7 ≈ 0.8451
log 5 = log(10/2) = 1 − log 2 ≈ 0.6990
🔗
ความสัมพันธ์ระหว่าง eˣ กับ ln

f(x) = eˣ และ g(x) = ln x

เป็นฟังก์ชันผกผันกัน
กราฟสมมาตรกันผ่านเส้น y = x

f(g(x)) = e^(ln x) = x
g(f(x)) = ln(eˣ) = x

โดเมนและเรนจ์

eˣ: Domain = ℝ, Range = (0,∞)
ln x: Domain = (0,∞), Range = ℝ

สังเกต: Domain กับ Range สลับกัน เพราะผกผันกัน

หัวข้อ 7 · สมการและอสมการเอกซ์โพเนนเชียล/ลอการิทึม
⚡
สมการเอกซ์โพเนนเชียล
หลักการแก้สมการ
ถ้า aˣ = aʸ และ a > 0, a ≠ 1 แล้ว x = y
(ทำให้ฐานเท่ากัน แล้วเทียบเลขชี้กำลัง)
ตัวอย่าง 1 — ทำฐานให้เท่ากัน
แก้สมการ: 4ˣ = 32
(2²)ˣ = 2⁵
2^(2x) = 2⁵
2x = 5 → x = 5/2
ตัวอย่าง 2 — ทำฐานให้เท่ากันไม่ได้ ใช้ log แทน
แก้สมการ: 3ˣ = 7
log 3ˣ = log 7
x · log 3 = log 7
x = log 7 / log 3 = log₃ 7 ≈ 1.771
ตัวอย่าง 3 — สมการที่ซับซ้อน
แก้สมการ: 4ˣ − 5·2ˣ + 4 = 0
แทน u = 2ˣ (u > 0) → 4ˣ = (2ˣ)² = u²
u² − 5u + 4 = 0
(u − 1)(u − 4) = 0
u = 1 → 2ˣ = 1 → x = 0
u = 4 → 2ˣ = 4 → x = 2
∴ x = 0 หรือ x = 2
🔍
สมการลอการิทึม
หลักการแก้สมการ
ถ้า logₐ M = logₐ N แล้ว M = N (M, N > 0)
ต้องตรวจสอบโดเมน: ตัวตั้ง log ต้องเป็นบวก!
ตัวอย่าง 1
แก้ log₂(x + 3) = 4
x + 3 = 2⁴ = 16
x = 13  ✅ (ตรวจ: x+3 = 16 > 0 ✓)
ตัวอย่าง 2 — ต้องตรวจโดเมน
แก้ log(x) + log(x−3) = 1
log[x(x−3)] = 1
x(x−3) = 10
x² − 3x − 10 = 0
(x−5)(x+2) = 0
x = 5 หรือ x = −2

ตรวจโดเมน: x > 0 และ x − 3 > 0 → x > 3
x = 5 ✅    x = −2 ❌ (ตัดออก)
∴ x = 5
⚠️ ต้องตรวจสอบ — กับดักข้อสอบ!
เมื่อแก้สมการ log ได้คำตอบแล้ว ต้องตรวจว่าตัวตั้ง log ทุกตัวในสมการเดิมเป็นบวกเสมอ
ถ้าตัวตั้งไม่เป็นบวก → คำตอบนั้นไม่ถูกต้อง ตัดออก
≥
อสมการลอการิทึม
กฎสำคัญ
ถ้า a > 1:   logₐ x > logₐ y ⟺ x > y
ถ้า 0 < a < 1:   logₐ x > logₐ y ⟺ x < y
(ฐาน 0<a<1 → พลิกเครื่องหมาย!)
ตัวอย่าง 1 — ฐาน > 1
แก้ log₂(x−1) > 3
x − 1 > 2³ = 8
x > 9
ตรวจโดเมน: x − 1 > 0 → x > 1 ✅
∴ คำตอบคือ x > 9
ตัวอย่าง 2 — ฐาน 0<a<1 (พลิกเครื่องหมาย)
แก้ log_(1/3) x ≥ −2
x ≤ (1/3)⁻² = 3² = 9 ← พลิกเครื่องหมาย
ตรวจโดเมน: x > 0
∴ คำตอบคือ 0 < x ≤ 9
หัวข้อ 8 · การประยุกต์ใช้งาน
📊
การเติบโตและการสลาย (Growth & Decay)
สูตรหลัก
การเติบโต:   A(t) = A₀ · eᵏᵗ   (k > 0)
การสลาย:   A(t) = A₀ · e⁻ᵏᵗ   (k > 0)
หรือ:   A(t) = A₀ · aᵗ   (a > 0, a ≠ 1)

A₀ = ปริมาณเริ่มต้น, t = เวลา, k = อัตราการเปลี่ยนแปลง
ตัวอย่าง — ดอกเบี้ยทบต้น
ฝากเงิน 10,000 บาท อัตราดอกเบี้ย 5% ต่อปี ทบต้นรายปี
หลัง 10 ปี มีเงินเท่าใด?

A = 10,000 × (1 + 0.05)¹⁰ = 10,000 × 1.05¹⁰
≈ 10,000 × 1.6289
≈ 16,289 บาท
ตัวอย่าง — ครึ่งชีวิต (Half-life)
ธาตุกัมมันตรังสีมีมวล 200 กรัม ครึ่งชีวิต 3 ปี
หลัง 9 ปี เหลือมวลเท่าใด?

t = 9 ปี = 3 × ครึ่งชีวิต
A = 200 × (1/2)³ = 200 × 1/8 = 25 กรัม
🌍
ระดับเสียง ความเข้มแผ่นดินไหว pH

ระดับเสียง (dB)

β = 10 · log(I/I₀)
I₀ = 10⁻¹² W/m² (ขีดการได้ยิน)

ริกเตอร์ (แผ่นดินไหว)

M = log(A/A₀)
แต่ละระดับ = 10 เท่าของแอมพลิจูด

pH (ความเป็นกรด-ด่าง)

pH = −log[H⁺]
pH < 7 = กรด, pH > 7 = ด่าง

การหาเวลา

เมื่อทราบสมการ A(t) = A₀·eᵏᵗ
หา t ด้วย ln: t = ln(A/A₀)/k
