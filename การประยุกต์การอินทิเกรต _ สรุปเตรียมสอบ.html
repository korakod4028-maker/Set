หัวข้อ 1 · อินทิกรัลจำกัดเขต
📐
ทฤษฎีบทหลักของแคลคูลัส

ถ้า f ต่อเนื่องบนช่วง [a, b] และ F เป็นปฏิยานุพันธ์ของ f (นั่นคือ F′(x) = f(x)) แล้ว

∫ba f(x) dx = F(b) − F(a)
ตัวอย่าง
∫31 2x dx = [x²] จาก 1 ถึง 3 = 3² − 1² = 8
📋
คุณสมบัติที่ต้องจำ
คุณสมบัติสูตร
ค่าคงที่ 1∫ba 1 dx = b − a
ดึงค่าคงที่ออก∫ba k·f(x) dx = k ∫ba f(x) dx
บวก / ลบ∫ba [f(x) ± g(x)] dx = ∫ba f dx ± ∫ba g dx
แยกช่วง∫ba f dx = ∫ca f dx + ∫bc f dx
ขอบเขตเท่ากัน∫aa f(x) dx = 0
สลับขอบเขต∫ba f dx = − ∫ab f dx
💡 เทคนิค
ถ้า f เป็นฟังก์ชันคู่: ∫a−a f dx = 2 ∫a0 f dx
ถ้า f เป็นฟังก์ชันคี่: ∫a−a f dx = 0
⚠️ ระวัง
∫ba f(x)·g(x) dx ไม่เท่ากับ (∫ba f dx)(∫ba g dx) — คุณสมบัติบวก/ลบใช้ได้ แต่ไม่มีสมบัติคูณแบบนี้
หัวข้อ 2 · การหาพื้นที่
📈
พื้นที่ระหว่างเส้นโค้งกับแกน X
สูตร
ถ้า y = f(x) ≥ 0 บนช่วง [a, b]
A = ∫ba f(x) dx

ถ้า f(x) ติดลบบางช่วง พื้นที่จริงต้องเป็นบวก ให้แยกช่วงที่ f ≥ 0 กับ f ≤ 0 แล้วอินทิเกรต |f(x)| ทีละช่วง

ตัวอย่าง: พื้นที่ใต้ y = x² จาก x = 0 ถึง 3
A = ∫30 x² dx = [x³/3] จาก 0 ถึง 3 = 27/3 = 9 ตารางหน่วย
🔀
พื้นที่ระหว่างเส้นโค้งสองเส้น
สูตร
ถ้า f(x) ≥ g(x) บนช่วง [a, b]
A = ∫ba [f(x) − g(x)] dx
  1. วาดกราฟทั้งสองเส้น แล้วระบายบริเวณที่โจทย์ถาม
  2. หาจุดตัด (ให้ f(x) = g(x)) เพื่อได้ขอบเขต a, b
  3. ดูว่าในช่วงนั้นเส้นไหนอยู่ บน เส้นไหนอยู่ ล่าง
  4. ตั้ง A = ∫ (บน − ล่าง) dx แล้วคำนวณ
ตัวอย่าง: พื้นที่ปิดล้อมด้วย y = x และ y = x²
จุดตัด: x = x² → x = 0 หรือ x = 1
ในช่วง (0, 1) เส้น y = x อยู่บน y = x²
A = ∫10 (x − x²) dx = [x²/2 − x³/3] จาก 0 ถึง 1 = 1/2 − 1/3 = 1/6
⚠️ ระวัง
ถ้าเส้นโค้งตัดกันกลางช่วง เส้นบน/ล่างจะสลับกัน ต้องแยกอินทิกรัลเป็นช่วงๆ ไม่งั้นส่วนที่ติดลบจะหักล้างกัน
หัวข้อ 3 · ปริมาตรทรงตัน: วิธีแบบจาน (Disk)
💿
หลักการ

หมุนพื้นที่รอบแกน แล้วหั่นทรงตันเป็นแผ่นบางๆ ตั้งฉากกับแกนหมุน แต่ละแผ่นเป็นจาน (วงกลมตัน) ปริมาตรจานหนึ่งแผ่น = π × (รัศมี)² × ความหนา

หมุนรอบแกน x

V = π ∫ba [f(x)]² dx

หมุนรอบแกน y

V = π ∫ba [f(y)]² dy
เมื่อไหร่ใช้จาน
พื้นที่ที่หมุนติดแกนหมุนตลอดช่วง ทรงตันที่ได้ไม่มีรูตรงกลาง
✏️
ตัวอย่างจากสไลด์
ตัวอย่าง 1: y = 0 และ y = 16 − x² หมุนรอบแกน x
จุดตัด: 16 − x² = 0 → x = ±4 รัศมี = 16 − x²

V = π ∫4−4 (16 − x²)² dx = π ∫4−4 (256 − 32x² + x⁴) dx
= 2π [256x − 32x³/3 + x⁵/5] จาก 0 ถึง 4
= 2π (1024 − 2048/3 + 1024/5) = 16384π/15
⚠️ สไลด์เฉลยผิด
สไลด์เขียนเฉลยเป็น 256π/3 ซึ่งมาจากการอินทิเกรต (16 − x²) โดยไม่ยกกำลังสอง สูตรจานต้องยกกำลังสองรัศมีเสมอ คำตอบที่ถูกคือ 16384π/15 ≈ 1092.3 (ถ้าอาจารย์เฉลยในห้องต่างจากนี้ ให้ถามอาจารย์อีกที)
ตัวอย่าง 2: y = 2√x, y = 0, x = 9
(a) หมุนรอบแกน x
รัศมี = 2√x → V = π ∫90 (2√x)² dx = π ∫90 4x dx = π[2x²] จาก 0 ถึง 9 = 162π

(b) หมุนรอบเส้น x = 9
เปลี่ยนเป็น x = y²/4 ช่วง y จาก 0 ถึง 6 รัศมี = 9 − y²/4 (วัดจากเส้นหมุนมาถึงขอบพื้นที่)
V = π ∫60 (9 − y²/4)² dy = π [81y − 3y³/2 + y⁵/80] จาก 0 ถึง 6 = 259.2π = 1296π/5

หลักคิด: ถ้าเส้นหมุนไม่ใช่แกน ให้วัดรัศมีเป็น ระยะจากเส้นหมุนถึงขอบพื้นที่ เช่น 9 − y²/4 ไม่ใช่ y²/4

หัวข้อ 4 · ปริมาตรทรงตัน: วิธีแบบวงแหวน (Washer / Ring)
🍩
หลักการ

เหมือนวิธีจาน แต่พื้นที่ไม่ติดแกนหมุน ทำให้มีรูตรงกลาง แต่ละแผ่นเป็นวงแหวน ปริมาตร = ปริมาตรวงกลมใหญ่ − ปริมาตรวงกลมเล็ก

หมุนรอบแกน x

V = π ∫ba ([R(x)]² − [r(x)]²) dx

หมุนรอบแกน y

V = π ∫ba ([R(y)]² − [r(y)]²) dy
R และ r
R = รัศมีนอก (ขอบพื้นที่ที่ไกลจากแกนหมุน)
r = รัศมีใน (ขอบพื้นที่ที่ใกล้แกนหมุน)
⚠️ จำให้ขึ้นใจ
ต้องยกกำลังสอง แต่ละรัศมีก่อน แล้วค่อยลบ: R² − r² ไม่ใช่ (R − r)²
✏️
ตัวอย่างจากสไลด์
ตัวอย่าง 1: y = 1 และ y = 3 − x²/2 หมุนรอบแกน x
จุดตัด: 1 = 3 − x²/2 → x² = 4 → x = ±2
R = 3 − x²/2 (ไกลแกน x), r = 1

V = π ∫2−2 [(3 − x²/2)² − 1²] dx
= π ∫2−2 (8 − 3x² + x⁴/4) dx
= π [8x − x³ + x⁵/20] จาก −2 ถึง 2
= π(9.6 + 9.6) = 19.2π = 96π/5
ตัวอย่าง 2: y = x, y = 4, x = 1
(a) หมุนรอบเส้น y = 5
R = 5 − x (ขอบ y = x ไกลกว่า), r = 5 − 4 = 1
V = π ∫41 [(5 − x)² − 1²] dx = π ∫41 (24 − 10x + x²) dx = π [24x − 5x² + x³/3] จาก 1 ถึง 4 = 18π

(b) หมุนรอบแกน y
เขียนใหม่ในรูป y: R = y, r = 1, y จาก 1 ถึง 4
V = π ∫41 (y² − 1) dy = π [y³/3 − y] จาก 1 ถึง 4 = 21π
หัวข้อ 5 · ปริมาตรทรงตัน: วิธีเปลือกทรงกระบอก (Shell)
📝 หมายเหตุ
หน้าสไลด์ของอาจารย์ในหัวข้อนี้ยังว่างอยู่ เนื้อหาด้านล่างจึงเติมตามหลักทั่วไป ให้เทียบกับที่อาจารย์สอนในห้องอีกครั้ง
🥫
หลักการ

หั่นพื้นที่เป็นแถบบางๆ ขนานกับแกนหมุน เมื่อหมุนแถบหนึ่งแถบจะได้เปลือกทรงกระบอก ปริมาตร ≈ (เส้นรอบวง) × (ความสูง) × (ความหนา)

V = 2π ∫ba (รัศมีเปลือก) × (ความสูงเปลือก) d(ตัวแปร)

หมุนรอบแกน y

V = 2π ∫ba x·f(x) dx

ระหว่างสองเส้น: ความสูง = f(x) − g(x)

หมุนรอบแกน x

V = 2π ∫ba y·f(y) dy

ความสูงวัดตามแนวนอน

💡 หมุนรอบเส้น x = k
รัศมีเปลือก = |x − k| (ระยะจากเส้นหมุนถึงแถบ)
✏️
ตัวอย่าง
ตัวอย่าง 1: y = x², y = 0, 0 ≤ x ≤ 2 หมุนรอบแกน y
รัศมีเปลือก = x, ความสูง = x²
V = 2π ∫20 x·x² dx = 2π [x⁴/4] จาก 0 ถึง 2 = 2π(4) = 8π
ตัวอย่าง 2: ระหว่าง y = x และ y = x² หมุนรอบแกน y
ความสูง = x − x²
V = 2π ∫10 x(x − x²) dx = 2π [x³/3 − x⁴/4] จาก 0 ถึง 1 = 2π(1/12) = π/6
ตัวอย่าง 3: พื้นที่เดิมของตัวอย่าง 1 หมุนรอบเส้น x = 3
รัศมีเปลือก = 3 − x
V = 2π ∫20 (3 − x)x² dx = 2π [x³ − x⁴/4] จาก 0 ถึง 2 = 2π(4) = 8π
หัวข้อ 6 · เลือกวิธีให้ถูก & เทคนิคทำข้อสอบ
🧭
สรุปเปรียบเทียบสามวิธี
วิธีแถบที่หั่นใช้เมื่อสูตรหลัก (รอบแกน x)
จานตั้งฉากแกนหมุนติดแกนหมุน ไม่มีรูπ∫ R² dx
วงแหวนตั้งฉากแกนหมุนไม่ติดแกน มีรูπ∫ (R² − r²) dx
เปลือกขนานแกนหมุนฟังก์ชันกลับยาก หรือหมุนรอบแกนตั้งฉากกับตัวแปร2π∫ y·h dy

ถ้าหมุนรอบแกน y ตัวแปรจะสลับกัน: จาน/วงแหวนใช้ dy ส่วนเปลือกใช้ dx เลือกวิธีที่เขียนฟังก์ชันได้ง่าย ไม่ต้องกลับฟังก์ชัน

✅
เช็กลิสต์ทำข้อสอบ
  1. วาดกราฟก่อนเสมอ ระบายพื้นที่ แล้วขีดเส้นแกนหมุน
  2. หาจุดตัด เพื่อได้ขอบเขตการอินทิเกรต
  3. ถามตัวเองว่า "มีรูตรงกลางไหม" มี = วงแหวน ไม่มี = จาน
  4. รัศมี = ระยะจากเส้นหมุนถึงขอบพื้นที่ (ถ้าไม่ใช่แกน ต้องลบหรือบวกค่าคงที่)
  5. ยกกำลังสองรัศมี และอย่าลืม π (หรือ 2π ในวิธีเปลือก)
  6. ใช้สมมาตรช่วยลดงาน และตรวจว่าคำตอบเป็นบวก
