บทที่ 1 · อุณหภูมิและการวัด
🌡️
อุณหภูมิคืออะไร?

อุณหภูมิ (Temperature) เป็นปริมาณที่บ่งบอกถึง ระดับพลังงานจลน์เฉลี่ยของโมเลกุล ในสสาร ยิ่งโมเลกุลเคลื่อนที่เร็วเฉลี่ยมากเท่าไร อุณหภูมิก็ยิ่งสูงขึ้นเท่านั้น

กฎข้อที่ศูนย์ของอุณหพลศาสตร์
ถ้าวัตถุ A อยู่ในภาวะสมดุลความร้อนกับวัตถุ B และวัตถุ B อยู่ในภาวะสมดุลความร้อนกับวัตถุ C แล้ว วัตถุ A ย่อมอยู่ในภาวะสมดุลความร้อนกับวัตถุ C ด้วย — เป็นหลักการที่ทำให้เทอร์โมมิเตอร์ใช้วัดอุณหภูมิได้

เมื่อวัตถุสองชิ้นที่มีอุณหภูมิต่างกันสัมผัสกัน ความร้อนจะถ่ายเทจากวัตถุที่ร้อนกว่าไปยังวัตถุที่เย็นกว่า จนกระทั่งทั้งสองมีอุณหภูมิเท่ากัน เรียกว่า ภาวะสมดุลความร้อน (thermal equilibrium)

📏
มาตราวัดอุณหภูมิ
มาตราจุดเยือกแข็งของน้ำจุดเดือดของน้ำ
เซลเซียส (°C)0 °C100 °C
ฟาเรนไฮต์ (°F)32 °F212 °F
เคลวิน (K)273 K373 K
สูตรแปลงหน่วย
T(K) = T(°C) + 273
T(°F) = (9/5)T(°C) + 32
T(°C) = (5/9)[T(°F) − 32]
ตัวอย่าง
อุณหภูมิร่างกายปกติ 37°C แปลงเป็นเคลวินและฟาเรนไฮต์
K = 37 + 273 = 310 K
°F = (9/5)(37) + 32 = 66.6 + 32 = 98.6 °F
💡 เทคนิคจำ
เคลวินคือ "เซลเซียสบวก 273" เสมอ ไม่มีค่าลบ (0 K คืออุณหภูมิต่ำสุดที่เป็นไปได้ เรียกว่า Absolute Zero) — ในสูตรฟิสิกส์เกี่ยวกับแก๊สต้องแปลงเป็นเคลวินก่อนเสมอ
🧪
เทอร์โมมิเตอร์และการเทียบมาตราส่วน

เทอร์โมมิเตอร์บางชนิดใช้มาตราส่วนสมมติ (เช่น มาตรา X ใด ๆ) ซึ่งเทียบกับมาตราเซลเซียสได้แบบเชิงเส้น โดยใช้อัตราส่วนระยะห่างจากจุดอ้างอิงสองจุด

(T_X − จุดเยือกแข็ง_X) / (จุดเดือด_X − จุดเยือกแข็ง_X)
= (T_C − 0) / (100 − 0)
⚠️ ข้อควรระวัง
การเทียบมาตราส่วนต้องใช้ "สัดส่วนระยะห่างจากจุดเยือกแข็ง" ให้เท่ากันทั้งสองมาตรา ห้ามใช้ตัวเลขอุณหภูมิเทียบตรง ๆ โดยไม่หักจุดเริ่มต้นออกก่อน
หัวข้อ 2 · การถ่ายเทความร้อน
🔥
ความร้อนคืออะไร?
นิยาม
ความร้อน (Heat, Q) คือ พลังงานที่ถ่ายเทจากวัตถุที่มีอุณหภูมิสูงกว่าไปยังวัตถุที่มีอุณหภูมิต่ำกว่า มีหน่วยเป็นจูล (J) หรือแคลอรี (cal)
1 cal = 4.186 J

ความร้อนถ่ายเทได้ 3 กลไกหลัก ได้แก่ การนำความร้อน การพาความร้อน และการแผ่รังสีความร้อน

➡️
การนำความร้อน (Conduction)
นิยาม
การถ่ายเทความร้อนผ่านการสั่นสะเทือนและการชนกันของอนุภาคในตัวกลาง โดยตัวกลางไม่เคลื่อนที่ไปด้วย — เกิดได้ดีในของแข็ง โดยเฉพาะโลหะ
อัตราการนำความร้อน:
Q/t = kA(ΔT)/L

เมื่อ k = สภาพนำความร้อน (W/(m·K)), A = พื้นที่หน้าตัด, ΔT = ผลต่างอุณหภูมิระหว่างสองปลาย, L = ความยาว/ความหนาของตัวกลาง

ตัวอย่าง
ด้ามช้อนโลหะที่จุ่มปลายหนึ่งในน้ำร้อน อีกไม่นานปลายอีกด้านก็ร้อนตามไปด้วย เพราะโลหะมีค่า k สูง นำความร้อนได้ดี
🌀
การพาความร้อน (Convection)
นิยาม
การถ่ายเทความร้อนโดยการเคลื่อนที่ของ "ของไหล" (ของเหลวหรือแก๊ส) เอง โดยส่วนที่ร้อนจะมีความหนาแน่นต่ำลอยตัวขึ้น ส่วนที่เย็นจมลง เกิดเป็นการหมุนเวียน

การพาแบบธรรมชาติ

เกิดจากความแตกต่างของความหนาแน่น เช่น การต้มน้ำในหม้อ ลมบก–ลมทะเล

การพาแบบบังคับ

มีอุปกรณ์ช่วยเร่งการไหล เช่น พัดลม เครื่องปรับอากาศ ปั๊มหมุนเวียนน้ำหล่อเย็น

☀️
การแผ่รังสีความร้อน (Radiation)
นิยาม
การถ่ายเทความร้อนในรูปคลื่นแม่เหล็กไฟฟ้า (ส่วนใหญ่เป็นรังสีอินฟราเรด) ไม่ต้องอาศัยตัวกลาง จึงเดินทางผ่านสุญญากาศได้ เช่น ความร้อนจากดวงอาทิตย์เดินทางมาถึงโลก

วัตถุสีเข้ม/ผิวขรุขระ ดูดกลืนและแผ่รังสีความร้อนได้ดีกว่าวัตถุสีอ่อน/ผิวมันวาว

💡 เทคนิคจำแยก 3 กลไก
นำ (Conduction) = สัมผัสกันโดยตรง ตัวกลางไม่เคลื่อนที่
พา (Convection) = ตัวกลาง (ของไหล) เคลื่อนที่ไปพร้อมความร้อน
แผ่รังสี (Radiation) = ไม่ต้องมีตัวกลางเลย เดินทางเป็นคลื่นแม่เหล็กไฟฟ้า
หัวข้อ 3 · ความร้อนจำเพาะและแคลอรีมิเตอร์
📐
ความร้อนจำเพาะ (Specific Heat)
นิยาม
ความร้อนจำเพาะ (c) คือ ปริมาณความร้อนที่ทำให้สาร 1 หน่วยมวล มีอุณหภูมิเปลี่ยนไป 1 หน่วย มีหน่วยเป็น J/(kg·K)
Q = mcΔT

เมื่อ Q = ความร้อนที่ถ่ายเท (J), m = มวล (kg), c = ความร้อนจำเพาะ, ΔT = การเปลี่ยนแปลงอุณหภูมิ

สารc (J/(kg·K))
น้ำ4,186
อะลูมิเนียม~900
เหล็ก~450
ทองแดง~387
💡 ทำไมน้ำจึงเย็นตัว/ร้อนตัวช้า
น้ำมีค่า c สูงมากเมื่อเทียบกับสารอื่น จึงต้องใช้ความร้อนมากในการเปลี่ยนอุณหภูมิ — เป็นเหตุผลที่พื้นที่ใกล้ทะเลมีอากาศไม่แปรปรวนรุนแรงเท่าพื้นที่ในแผ่นดิน
🧯
ความจุความร้อน (Heat Capacity)
นิยาม
ความจุความร้อน (C) คือ ปริมาณความร้อนที่ทำให้วัตถุทั้งก้อนมีอุณหภูมิเปลี่ยนไป 1 หน่วย
C = mc   (หน่วย J/K)
ตัวอย่าง
น้ำมวล 2 kg อุณหภูมิเพิ่มจาก 20°C เป็น 80°C ใช้ความร้อนเท่าไร
Q = mcΔT = 2 × 4,200 × 60 = 504,000 J = 504 kJ
⚖️
หลักการแคลอรีมิเตอร์
หลักการอนุรักษ์พลังงานความร้อน
เมื่อวัตถุร้อนและวัตถุเย็นสัมผัสกันในภาชนะที่ไม่สูญเสียความร้อนออกสู่ภายนอก ความร้อนที่วัตถุร้อนคายออกจะเท่ากับความร้อนที่วัตถุเย็นดูดกลืนเข้าไป
Q_คาย = Q_ดูด
ตัวอย่างโจทย์
น้ำร้อน 200 g ที่ 80°C ผสมกับน้ำเย็น 300 g ที่ 20°C จงหาอุณหภูมิสมดุล

วิธีทำ: m₁c(T₁−T_f) = m₂c(T_f−T₂)
200(80−T_f) = 300(T_f−20)
16,000 − 200T_f = 300T_f − 6,000
22,000 = 500T_f  →  T_f = 44°C
⚠️ ข้อควรระวัง
ถ้าสารที่ผสมกันไม่ใช่ชนิดเดียวกัน ต้องใช้ค่า c ที่แตกต่างกันของแต่ละสารในสมการ ไม่ใช่ c ตัวเดียวกันทั้งสองข้าง
หัวข้อ 4 · การเปลี่ยนสถานะและความร้อนแฝง
🧊
การเปลี่ยนสถานะของสสาร
☃️→💧
หลอมเหลว (Melting)
ของแข็ง → ของเหลว
💧→☃️
แข็งตัว (Freezing)
ของเหลว → ของแข็ง
💧→💨
กลายเป็นไอ (Vaporization)
ของเหลว → แก๊ส
💨→💧
ควบแน่น (Condensation)
แก๊ส → ของเหลว

นอกจากนี้ยังมี การระเหิด (ของแข็ง → แก๊ส โดยตรง เช่น น้ำแข็งแห้ง) และ การระเหิดกลับ (แก๊ส → ของแข็งโดยตรง)

🔥
ความร้อนแฝง (Latent Heat)
นิยาม
ความร้อนแฝง (L) คือ ปริมาณความร้อนต่อหนึ่งหน่วยมวลที่ใช้ในการเปลี่ยนสถานะ โดยอุณหภูมิไม่เปลี่ยนแปลงระหว่างกระบวนการ
Q = mL
ความร้อนแฝงของน้ำค่า
L_f (การหลอมเหลว ที่ 0°C)334,000 J/kg
L_v (การกลายเป็นไอ ที่ 100°C)2,260,000 J/kg
ตัวอย่าง
น้ำแข็งมวล 500 g ที่ 0°C ต้องการความร้อนเท่าไรเพื่อหลอมเป็นน้ำทั้งหมดที่ 0°C
Q = mL_f = 0.5 × 334,000 = 167,000 J
📈
กราฟความร้อน–อุณหภูมิ (Heating Curve)

เมื่อให้ความร้อนแก่น้ำแข็งอย่างต่อเนื่องตั้งแต่อุณหภูมิต่ำกว่า 0°C จนกลายเป็นไอน้ำ กราฟจะแบ่งเป็นช่วง ๆ ดังนี้

  1. อุณหภูมิน้ำแข็งเพิ่มขึ้น (ใช้ Q = mc_iceΔT)
  2. น้ำแข็งหลอมเหลวที่ 0°C — อุณหภูมิคงที่ (ใช้ Q = mL_f)
  3. อุณหภูมิน้ำเพิ่มขึ้นจนถึง 100°C (ใช้ Q = mc_waterΔT)
  4. น้ำเดือดกลายเป็นไอที่ 100°C — อุณหภูมิคงที่ (ใช้ Q = mL_v)
  5. อุณหภูมิไอน้ำเพิ่มขึ้นต่อไป (ใช้ Q = mc_steamΔT)
💡 กับดักข้อสอบ
ช่วงที่กำลังเปลี่ยนสถานะ (หลอมเหลว/เดือด) เส้นกราฟจะราบขนานกับแกนเวลา เพราะพลังงานที่ใส่เข้าไปทั้งหมดถูกใช้สลายพันธะระหว่างโมเลกุล ไม่ได้ทำให้อุณหภูมิสูงขึ้น
หัวข้อ 5 · การขยายตัวเนื่องจากความร้อน
📏
การขยายตัวเชิงเส้น
นิยาม
เมื่ออุณหภูมิของแท่งวัตถุแข็งเพิ่มขึ้น ความยาวของมันจะเพิ่มขึ้นตามสัมประสิทธิ์การขยายตัวเชิงเส้น (α) ของวัสดุ
ΔL = L₀αΔT
L = L₀(1 + αΔT)
ตัวอย่าง
แท่งเหล็กยาว 10 m ที่ 20°C (α = 12×10⁻⁶ /°C) อุณหภูมิเพิ่มเป็น 45°C
ΔL = 10 × 12×10⁻⁶ × 25 = 0.003 m = 3 มม.
◻️
การขยายตัวเชิงพื้นที่และเชิงปริมาตร

เชิงพื้นที่

ΔA = A₀(2α)ΔT

เชิงปริมาตร (ของแข็ง)

ΔV = V₀(3α)ΔT

สำหรับของเหลว มักใช้สัมประสิทธิ์การขยายตัวเชิงปริมาตร β โดยตรง (ของเหลวไม่มีรูปทรงตายตัว จึงไม่ใช้ α)

ΔV = V₀βΔT
วัสดุα (×10⁻⁶ /°C)
เหล็ก~12
อะลูมิเนียม~24
แก้ว~9
ทองแดง~17
ตัวอย่าง — ของเหลวล้นภาชนะ
ถังแก้วบรรจุน้ำมันเต็มพอดีที่ 10°C ปริมาตร 2 L (2,000 mL)
β_น้ำมัน = 9×10⁻⁴ /°C, β_แก้ว = 2.7×10⁻⁵ /°C
อุณหภูมิเพิ่มเป็น 60°C น้ำมันจะล้นออกเท่าไร?

วิธีทำ: ใช้สัมประสิทธิ์สุทธิ β_สุทธิ = β_น้ำมัน − β_แก้ว = 8.73×10⁻⁴ /°C
ΔV = 2,000 × 8.73×10⁻⁴ × 50 = 87.3 mL
💧
พฤติกรรมพิเศษของน้ำ
⚠️ ข้อยกเว้นสำคัญ
น้ำมีความหนาแน่นสูงสุดที่ 4°C ไม่ใช่ที่ 0°C — ระหว่าง 0–4°C น้ำจะหดตัวเมื่ออุณหภูมิสูงขึ้น (พฤติกรรมผิดปกติ) แล้วจึงขยายตัวตามปกติเมื่อสูงกว่า 4°C นี่คือเหตุผลที่น้ำแข็งลอยน้ำได้ และทำให้สิ่งมีชีวิตใต้น้ำรอดในฤดูหนาว
หัวข้อ 6 · กฎของแก๊ส
📦
ตัวแปรสถานะของแก๊ส

สถานะของแก๊สปริมาณคงที่ (ไม่มีการรั่วไหลหรือเติมเข้า) อธิบายได้ด้วยตัวแปร 3 ตัว คือ ความดัน (P) ปริมาตร (V) และอุณหภูมิสัมบูรณ์ (T หน่วยเคลวิน)

⚠️ กฎเหล็กของโจทย์แก๊ส
ต้องแปลงอุณหภูมิเป็นเคลวินเสมอก่อนแทนค่าในทุกสูตร ห้ามใช้องศาเซลเซียสตรง ๆ
🔄
กฎของบอยล์ (Boyle's Law)
นิยาม
เมื่ออุณหภูมิคงที่ ความดันของแก๊สแปรผกผันกับปริมาตร
P₁V₁ = P₂V₂   (T คงที่)
ตัวอย่าง
แก๊สปริมาตร 4 L ความดัน 2 atm ถูกอัดจนความดันเป็น 8 atm ที่อุณหภูมิเดิม
2×4 = 8×V₂  →  V₂ = 1 L
📈
กฎของชาร์ล (Charles's Law)
นิยาม
เมื่อความดันคงที่ ปริมาตรของแก๊สแปรผันตรงกับอุณหภูมิสัมบูรณ์
V₁/T₁ = V₂/T₂   (P คงที่)
ตัวอย่าง
ลูกโป่งปริมาตร 3 L ที่ 27°C (300 K) ความดันคงที่ อุณหภูมิเพิ่มเป็น 87°C (360 K)
3/300 = V₂/360  →  V₂ = 3.6 L
🌡️
กฎของเกย์-ลูสแซก (Gay-Lussac's Law)
นิยาม
เมื่อปริมาตรคงที่ ความดันของแก๊สแปรผันตรงกับอุณหภูมิสัมบูรณ์
P₁/T₁ = P₂/T₂   (V คงที่)
ตัวอย่าง
ถังแก๊สปิดสนิท ความดันเริ่มต้น 2 atm ที่ 27°C (300 K) อุณหภูมิเพิ่มเป็น 127°C (400 K)
2/300 = P₂/400  →  P₂ = 8/3 ≈ 2.67 atm
🧮
กฎรวมของแก๊ส (Combined Gas Law)
นิยาม
รวมกฎทั้งสามเข้าด้วยกัน ใช้ได้เมื่อทั้งความดัน ปริมาตร และอุณหภูมิเปลี่ยนแปลงพร้อมกัน (ปริมาณแก๊สคงที่)
P₁V₁/T₁ = P₂V₂/T₂
ตัวอย่าง
แก๊สปริมาตร 2 L ความดัน 1 atm ที่ 27°C (300 K) ถ้าความดันเพิ่มเป็น 3 atm และปริมาตรลดเหลือ 1 L จงหาอุณหภูมิสุดท้าย
(1×2)/300 = (3×1)/T₂  →  T₂ = 450 K
💡 เทคนิคจำ
กฎย่อยทั้งสามคือกรณีพิเศษของกฎรวม เมื่อตัวแปรใดตัวหนึ่งคงที่ ให้ตัดตัวแปรนั้นออกจากทั้งสองข้างของสมการ
หัวข้อ 7 · แก๊สอุดมคติและทฤษฎีจลน์
⚗️
สมการสถานะแก๊สอุดมคติ
นิยาม
แก๊สอุดมคติ (Ideal Gas) คือแบบจำลองแก๊สที่โมเลกุลไม่มีปริมาตรและไม่มีแรงกระทำระหว่างกัน ยกเว้นขณะชนกัน — แก๊สจริงที่ความดันต่ำและอุณหภูมิสูงจะมีพฤติกรรมใกล้เคียงแก๊สอุดมคติ
PV = nRT
PV = NkT
สัญลักษณ์ความหมายค่า
Rค่าคงที่แก๊สสากล8.314 J/(mol·K)
kค่าคงที่บอลต์ซมันน์1.38×10⁻²³ J/K
N_Aเลขอาโวกาโดร6.022×10²³ /mol

โดย n = จำนวนโมล, N = จำนวนโมเลกุล (N = nN_A)

ตัวอย่าง
ถังบรรจุแก๊สออกซิเจน (M = 32 g/mol) ปริมาตร 10 L ความดัน 5 atm อุณหภูมิ 27°C (300 K) จงหามวลแก๊ส (R = 0.0821 L·atm/(mol·K))
n = PV/RT = (5×10)/(0.0821×300) ≈ 2.03 mol
มวล = n×M ≈ 2.03×32 ≈ 65 g
💨
ทฤษฎีจลน์ของแก๊ส (Kinetic Theory)
สมมติฐานหลัก
• โมเลกุลแก๊สเคลื่อนที่อย่างสุ่มและต่อเนื่องเป็นเส้นตรง
• การชนระหว่างโมเลกุลและกับผนังภาชนะเป็นการชนแบบยืดหยุ่นสมบูรณ์
• ปริมาตรของโมเลกุลเองน้อยมากเมื่อเทียบกับปริมาตรภาชนะ
• ไม่มีแรงดึงดูด/ผลักระหว่างโมเลกุล ยกเว้นขณะชนกัน
พลังงานจลน์เฉลี่ยต่อโมเลกุล:
KE_เฉลี่ย = (3/2)kT
อัตราเร็ว rms:
v_rms = √(3kT/m) = √(3RT/M)
ตัวอย่าง
พลังงานจลน์เฉลี่ยของโมเลกุลแก๊สที่ 27°C (300 K)
KE = (3/2)(1.38×10⁻²³)(300) ≈ 6.21×10⁻²¹ J
💡 ข้อสังเกตสำคัญ
พลังงานจลน์เฉลี่ยขึ้นอยู่กับอุณหภูมิเท่านั้น ไม่ขึ้นกับชนิดของแก๊ส แต่อัตราเร็ว rms ขึ้นกับมวลโมลาร์ด้วย — แก๊สที่เบากว่าจะเคลื่อนที่เร็วกว่าที่อุณหภูมิเดียวกัน
หัวข้อ 8 · กฎข้อที่หนึ่งของอุณหพลศาสตร์
⚡
งานและพลังงานภายใน
นิยาม
พลังงานภายใน (Internal Energy, U) คือ ผลรวมพลังงานจลน์และพลังงานศักย์ของโมเลกุลทั้งหมดในระบบ สำหรับแก๊สอุดมคติแบบอะตอมเดี่ยว U ขึ้นกับอุณหภูมิเท่านั้น
U = (3/2)nRT

งานที่แก๊สทำขณะขยายตัวด้วยความดันคงที่: W = PΔV

🔁
กฎข้อที่หนึ่งของอุณหพลศาสตร์
นิยาม
การเปลี่ยนแปลงพลังงานภายในของระบบ เท่ากับความร้อนที่ระบบได้รับ ลบด้วยงานที่ระบบทำให้สิ่งแวดล้อม (เป็นการอนุรักษ์พลังงานรูปแบบหนึ่ง)
ΔU = Q − W
ตัวอย่าง
แก๊สอุดมคติได้รับความร้อน 500 J ขณะขยายตัวด้วยความดันคงที่และทำงานให้สิ่งแวดล้อม 200 J
ΔU = 500 − 200 = 300 J
🔀
กระบวนการทางอุณหพลศาสตร์แบบต่าง ๆ

Isobaric (P คงที่)

W = PΔV, ทั้ง Q, W, ΔU มีค่าไม่เป็นศูนย์

Isochoric (V คงที่)

W = 0 (ไม่มีการขยาย/หด) → ΔU = Q ทั้งหมด

Isothermal (T คงที่)

ΔU = 0 (แก๊สอุดมคติ) → Q = W ทั้งหมด

Adiabatic (Q = 0)

ไม่มีการถ่ายเทความร้อน → ΔU = −W

⚠️ ข้อควรระวัง
เครื่องหมายของ Q และ W ขึ้นกับทิศทาง: Q เป็นบวกเมื่อระบบรับความร้อน, W เป็นบวกเมื่อระบบทำงานให้สิ่งแวดล้อม (แก๊สขยายตัว)
🎯 แบบฝึกหัดเตรียม A-Level — ระดับ 1→3
