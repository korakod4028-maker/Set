ภาพรวมของ Linux Directory System
ก่อนจะลงคำสั่ง ต้องเข้าใจโครงสร้างก่อน — ทำไม Linux ถึงต่างจาก Windows
🌳 Filesystem Tree — โครงสร้างแบบต้นไม้ของ Linux
/ ← Root Directory (จุดสูงสุด, ไม่มีอะไรอยู่เหนือกว่านี้)
├── bin/ ← คำสั่งพื้นฐาน (ls, cd, mkdir, ...)
├── etc/ ← ไฟล์ config ของระบบ
├── home/ ← โฮมของ users ทั่วไป
│ ├── alice/ ← home ของ alice: /home/alice
│ └── bob/
├── root/ ← home ของ root user: /root ⚠️ ต่างจาก /
├── tmp/ ← ไฟล์ชั่วคราว
├── var/ ← log, cache, spool
│ └── log/
│ └── syslog
└── usr/ ← โปรแกรมที่ติดตั้งเพิ่ม
💡

Linux ใช้ / (forward slash) เป็น separator — ต่างจาก Windows ที่ใช้ \ (backslash) และทุกอย่างเริ่มจาก / ไม่มี C:\, D:\ แบบ Windows

⚠️ root กี่ความหมาย? — จุดสับสนที่ Engineer ต้องรู้
คำหมายถึงตัวอย่าง
/ Root Directory — ไดเรกทอรีสูงสุดของระบบ ls /
root user Superuser / Admin ของระบบ (มีสิทธิ์ทุกอย่าง) login เป็น root
/root Home directory ของ root user (ไม่ใช่ /) cd /root
bash — root@server
root@server:/root$ cd root ← Relative: เข้าโฟลเดอร์ชื่อ "root" ที่อยู่ใน /root
root@server:/root/root$ cd /root ← Absolute: วาร์ปไปที่ /root เสมอ
root@server:/root$ _

🏗️ Create Directories — mkdir
$ mkdir mydir # สร้างโฟลเดอร์ทั่วไป
$ mkdir dir1 dir2 dir3 # สร้างหลายอันพร้อมกัน
$ mkdir -p parent/child/grandchild # สร้าง nested ลึกๆ ทีเดียว
$ mkdir testdir{1..10} # testdir1 ถึง testdir10
$ mkdir testdir{01..100} # Zero Padding → เรียง ls ได้สวย
$ mkdir hello{001..100} # hello001 ถึง hello100
⚠️

Zero Padding ทำไมถึงสำคัญ? ถ้า mkdir testdir{1..10} จะได้ testdir1, testdir10, testdir2... (ls เรียงตามตัวอักษร 1 ตามด้วย 10) — การใส่ 01..10 บังคับให้ตัวเลขมีหลักเท่ากัน ทำให้ระบบเรียงถูก

bash — brace expansion
$ mkdir -p /opt/app/config/nginx
สร้างทุก directory ในเส้นทาง แม้ยังไม่มี
$ mkdir server{01..05}
$ ls
server01 server02 server03 server04 server05
🗑️ Delete Directories — rmdir & rm
$ rmdir emptydir # ลบได้เฉพาะโฟลเดอร์ว่าง
$ rmdir -p parent/child # ลบ child แล้วลบ parent ถ้าว่าง
$ rmdir /directory/* # ลบ subdirectory ว่างทุกอัน
$ rm myfile.txt # ลบไฟล์ (ใช้กับโฟลเดอร์ตรงๆ ไม่ได้)
$ rm -rf somedir # ลบโฟลเดอร์ + ทุกอย่างข้างใน ทันที
Flagความหมายใช้กับ
-rRecursive — ลบลงไปทุกชั้นrm
-fForce — ไม่ถาม ไม่แจ้งเตือนrm
-rfรวมทั้งสอง → ลบทุกอย่างทันทีrm
-pRemove parents — ลบ parent ด้วยถ้าว่างrmdir
-iInteractive — ถามยืนยันทีละไฟล์ (ปลอดภัยกว่า)rm
🚨

NEVER RUN: rm -rf / — สั่งลบทุกอย่างบนระบบ ตั้งแต่รากฐาน ระบบพังทันที (Linux รุ่นใหม่จะบล็อกและเตือน แต่อย่าลอง)

⚠️

Best practice บน Production: ใช้ rm -ri แทน rm -rf เวลาไม่แน่ใจ — flag -i จะถามยืนยันทีละไฟล์ ป้องกัน human error

Absolute vs Relative Path
แนวคิดนี้ใช้ทุกวันใน Linux, scripting, networking config — ต้องแม่น 100%

🔵 Absolute Path — เส้นทางสัมบูรณ์

ขึ้นต้นด้วย / เสมอ
วาร์ปจากจุดสูงสุดของระบบไปเป้าหมายโดยตรง ไม่สนว่าตอนนี้อยู่ที่ไหน

cd /var/log/nginx
cd /home/alice/projects
cat /etc/hosts

🟢 Relative Path — เส้นทางสัมพัทธ์

ไม่ขึ้นต้นด้วย /
นับจากตำแหน่งปัจจุบันที่ยืนอยู่ ต้องรู้ว่าตัวเองอยู่ที่ไหน

cd config/nginx
cd ../../var
cd ../alice
🧭 Special Path Symbols
Symbolหมายถึงตัวอย่าง
/ Root directory (จุดเริ่มต้นของ Absolute path) cd /
. (จุดเดียว) Current directory (ที่ฉันอยู่ตอนนี้) ./script.sh
.. (สองจุด) Parent directory (ชั้นนอก 1 ชั้น) cd ..
~ Home directory ของ user ปัจจุบัน cd ~/Desktop
- Previous directory (ที่เพิ่งมา) cd -
* Wildcard — แทนทุกอย่าง rmdir /tmp/*

SCENARIO 1

SCENARIO 3

ต้องการไปที่ home แล้วต่อไปที่ app/tests ในทีเดียว

$ cd $HOME/app/tests

$ cd ~/app/tests

🔑 Key Concepts Summary
Conceptคำอธิบายจำไว้ว่า
/ (Root) จุดสูงสุดของ Linux filesystem ทุก path เริ่มจากนี่
Absolute Path ขึ้นต้นด้วย / เสมอ ใช้ได้จากทุกที่ ไม่ขึ้นกับ cwd
Relative Path นับจาก current directory ไม่มี / นำหน้า
Zero Padding mkdir dir{01..10} แทน {1..10} บังคับให้ ls เรียงถูก
-p flag mkdir: สร้าง parent ให้ด้วย / rmdir: ลบ parent ด้วย ใช้กับทั้ง mkdir และ rmdir

QUESTION 04 / 20 — Zero Padding

QUESTION 15 / 20 — Brace Expansion

A
rm -rf [directory]
B
rm -r [directory]
C

D
rmdir [directory]
rm -ri — -i (interactive) จะถามยืนยันก่อนลบทุกไฟล์ ป้องกัน human error บน production. -rf อันตรายที่สุดเพราะลบทันที. -r อาจถามบ้างแต่ไม่สม่ำเสมอ. rmdir ใช้ได้แค่กับ directory ว่าง
