เวกเตอร์คืออะไร?

เวกเตอร์ (Vector) คือปริมาณที่มี ทั้งขนาดและทิศทาง ต่างจากสเกลาร์ (Scalar) ที่มีแค่ขนาดอย่างเดียว

สเกลาร์ (Scalar)

มีแค่ขนาด ไม่มีทิศทาง

  • อุณหภูมิ 30°C
  • มวล 5 กิโลกรัม
  • ระยะทาง 100 เมตร

เวกเตอร์ (Vector)

มีทั้งขนาดและทิศทาง

  • แรง 10 นิวตัน ไปทางเหนือ
  • ความเร็ว 60 กม./ชม. ไปทางตะวันออก
  • การกระจัด 5 เมตร ทำมุม 30°
นิยาม
เวกเตอร์ในระนาบ 2 มิติ เขียนแทนด้วย v⃗ = (a, b) หรือ v⃗ = aî + bĵ
โดย a คือองค์ประกอบแนวแกน x และ b คือองค์ประกอบแนวแกน y
ตัวอย่าง
เวกเตอร์ v⃗ = (3, 2) หมายถึงเวกเตอร์ที่เริ่มจากจุดกำเนิด
ไปในทิศทางที่ขยับ 3 หน่วยในแนวแกน x และ 2 หน่วยในแนวแกน y
🔤
สัญลักษณ์และรูปแบบการเขียน
v⃗
เวกเตอร์ v
เขียนตัวหนังสือพร้อมลูกศรด้านบน หรือตัวหนา v
|v⃗|
ขนาด (Magnitude)
ค่าสัมบูรณ์ของเวกเตอร์ คือความยาวของลูกศร
î, ĵ, k̂
เวกเตอร์หน่วย
î=(1,0,0), ĵ=(0,1,0), k̂=(0,0,1)
−v⃗
เวกเตอร์ตรงข้าม
ขนาดเท่ากัน แต่ทิศทางตรงข้าม
รูปแบบ 2 มิติ: v⃗ = (a, b) = aî + bĵ
รูปแบบ 3 มิติ: v⃗ = (a, b, c) = aî + bĵ + ck̂
💡 เทคนิค A-Level
เวกเตอร์ AB⃗ (จาก A ไป B) คือ B − A
เช่น A = (1,2), B = (4,6) → AB⃗ = (4−1, 6−2) = (3, 4)
📌
ประเภทของเวกเตอร์

เวกเตอร์ศูนย์ (Zero Vector)

0⃗ = (0, 0)

ขนาดเป็น 0 ไม่มีทิศทางที่แน่นอน

เวกเตอร์หน่วย (Unit Vector)

เวกเตอร์ที่มีขนาดเท่ากับ 1

û = v⃗ / |v⃗|

เวกเตอร์เท่ากัน

ขนาดเท่ากัน และทิศทางเดียวกัน (ตำแหน่งไม่สำคัญ)

เวกเตอร์ขนาน

u⃗ ∥ v⃗ เมื่อ u⃗ = kv⃗ สำหรับบางสเกลาร์ k ≠ 0

หัวข้อที่ 2 · การดำเนินการกับเวกเตอร์
➕
การบวกและลบเวกเตอร์
สูตร
ถ้า u⃗ = (a, b) และ v⃗ = (c, d) แล้ว
u⃗ + v⃗ = (a+c, b+d)
u⃗ − v⃗ = (a−c, b−d)
ตัวอย่าง
u⃗ = (2, 3) และ v⃗ = (−1, 4)
u⃗ + v⃗ = (2+(−1), 3+4) = (1, 7)
u⃗ − v⃗ = (2−(−1), 3−4) = (3, −1)

คุณสมบัติของการบวกเวกเตอร์:

  • สมบัติสลับที่: u⃗ + v⃗ = v⃗ + u⃗
  • สมบัติการเปลี่ยนหมู่: (u⃗ + v⃗) + w⃗ = u⃗ + (v⃗ + w⃗)
  • เอกลักษณ์การบวก: v⃗ + 0⃗ = v⃗
  • อินเวอร์สการบวก: v⃗ + (−v⃗) = 0⃗
✖️
การคูณด้วยสเกลาร์
สูตร
ถ้า v⃗ = (a, b) และ k เป็นสเกลาร์ แล้ว
kv⃗ = (ka, kb)
ตัวอย่าง
v⃗ = (2, −3)
3v⃗ = (6, −9) → ยาวขึ้น 3 เท่า ทิศทางเดิม
−2v⃗ = (−4, 6) → ยาวขึ้น 2 เท่า ทิศทางตรงข้าม
½v⃗ = (1, −1.5) → ยาวลดเหลือครึ่ง
⚠️ ข้อควรระวัง
ถ้า k > 0: ทิศทางเดิม
ถ้า k < 0: ทิศทางตรงข้าม
ถ้า k = 0: ได้เวกเตอร์ศูนย์ 0⃗
หัวข้อที่ 3 · ขนาดและทิศทางของเวกเตอร์
📏
ขนาดของเวกเตอร์ (Magnitude)
|v⃗| = √(a² + b²) (2 มิติ)
|v⃗| = √(a² + b² + c²) (3 มิติ)
ตัวอย่าง
v⃗ = (3, 4)
|v⃗| = √(3² + 4²) = √(9 + 16) = √25 = 5

u⃗ = (1, 2, 2)
|u⃗| = √(1² + 2² + 2²) = √(1 + 4 + 4) = √9 = 3
🧭
เวกเตอร์หน่วย (Unit Vector)
นิยาม
เวกเตอร์หน่วย คือเวกเตอร์ที่มีขนาดเท่ากับ 1 ใช้บอกทิศทางล้วน ๆ
หาได้จาก: û = v⃗ / |v⃗|
û = (a/|v⃗|, b/|v⃗|) โดยที่ |û| = 1 เสมอ
ตัวอย่าง
v⃗ = (3, 4), |v⃗| = 5
û = (3/5, 4/5) = (0.6, 0.8)
ตรวจสอบ: |û| = √(0.36 + 0.64) = √1 = 1 ✓
📐
ทิศทางของเวกเตอร์ใน 2 มิติ
มุมของเวกเตอร์
เวกเตอร์ v⃗ = (a, b) ทำมุม θ กับแกน x โดย
tan θ = b/a หรือ θ = arctan(b/a)
ตัวอย่าง
v⃗ = (1, √3)
tan θ = √3/1 = √3
θ = arctan(√3) = 60°
💡 เทคนิค A-Level — ระวัง Quadrant!
arctan ให้มุมในช่วง (−90°, 90°) เท่านั้น
ต้องพิจารณา quadrant ของเวกเตอร์ด้วย เช่น v⃗ = (−1, 1) → θ = 135° ไม่ใช่ −45°
หัวข้อที่ 4 · ผลคูณจุด (Dot Product)
•
นิยามผลคูณจุด
สูตร
u⃗ · v⃗ = a₁a₂ + b₁b₂ (2 มิติ)
u⃗ · v⃗ = a₁a₂ + b₁b₂ + c₁c₂ (3 มิติ)
u⃗ · v⃗ = |u⃗||v⃗|cos θ
(ผลคูณจุดเป็นสเกลาร์ ไม่ใช่เวกเตอร์!)
ตัวอย่าง
u⃗ = (2, 3) และ v⃗ = (4, −1)
u⃗ · v⃗ = (2)(4) + (3)(−1) = 8 − 3 = 5
📐
หามุมระหว่างเวกเตอร์
cos θ = (u⃗ · v⃗) / (|u⃗| × |v⃗|)
θ = arccos[(u⃗ · v⃗) / (|u⃗||v⃗|)]
ตัวอย่าง — หามุมระหว่าง u⃗ = (1, 0) และ v⃗ = (1, 1)
u⃗ · v⃗ = (1)(1) + (0)(1) = 1
|u⃗| = 1, |v⃗| = √2
cos θ = 1 / (1 × √2) = 1/√2
θ = arccos(1/√2) = 45°
เวกเตอร์ตั้งฉากกัน
u⃗ ⊥ v⃗ ⟺ u⃗ · v⃗ = 0
ถ้าผลคูณจุดเป็น 0 แสดงว่าสองเวกเตอร์ตั้งฉากกัน (θ = 90°)
⚠️ ข้อควรระวัง
ผลคูณจุด u⃗ · v⃗ > 0 → มุมแหลม (θ < 90°)
ผลคูณจุด u⃗ · v⃗ = 0 → ตั้งฉาก (θ = 90°)
ผลคูณจุด u⃗ · v⃗ < 0 → มุมป้าน (θ > 90°)
🔽
การฉายเวกเตอร์ (Projection)
สูตรการฉาย
การฉาย u⃗ ลงบน v⃗:
proj_v⃗ u⃗ = (u⃗ · v⃗ / |v⃗|²) × v⃗
ความยาวของการฉาย (scalar projection):
comp_v⃗ u⃗ = u⃗ · v⃗ / |v⃗|
ตัวอย่าง
u⃗ = (3, 4), v⃗ = (1, 0)
u⃗ · v⃗ = 3, |v⃗|² = 1
proj_v⃗ u⃗ = (3/1)(1, 0) = (3, 0)
(การฉาย u⃗ ลงบนแกน x ได้ (3, 0) ถูกต้อง)
หัวข้อที่ 5 · ผลคูณไขว้ (Cross Product)
✕
นิยามผลคูณไขว้

ผลคูณไขว้ใช้ได้เฉพาะในระบบ 3 มิติ และผลลัพธ์เป็น เวกเตอร์ ที่ตั้งฉากกับทั้ง u⃗ และ v⃗

u⃗ × v⃗ = |u⃗||v⃗|sin θ n̂
โดย n̂ คือเวกเตอร์หน่วยตั้งฉากกับระนาบของ u⃗ และ v⃗
สูตรคำนวณ (Determinant Form)
ถ้า u⃗ = (a₁, b₁, c₁) และ v⃗ = (a₂, b₂, c₂) แล้ว
u⃗ × v⃗ = (b₁c₂ − c₁b₂, c₁a₂ − a₁c₂, a₁b₂ − b₁a₂)
u⃗ × v⃗ = | î ĵ k̂ | | a₁ b₁ c₁ | | a₂ b₂ c₂ | = î(b₁c₂ − c₁b₂) − ĵ(a₁c₂ − c₁a₂) + k̂(a₁b₂ − b₁a₂)
ตัวอย่าง
u⃗ = (1, 2, 3) และ v⃗ = (4, 5, 6)
u⃗ × v⃗ = î(2×6 − 3×5) − ĵ(1×6 − 3×4) + k̂(1×5 − 2×4)
= î(12 − 15) − ĵ(6 − 12) + k̂(5 − 8)
= (−3, 6, −3)
📐
คุณสมบัติผลคูณไขว้
คุณสมบัติสูตร
สลับที่u⃗ × v⃗ = −(v⃗ × u⃗)
เวกเตอร์ขนานกันu⃗ × v⃗ = 0⃗
ขนาด = พื้นที่สี่เหลี่ยม|u⃗ × v⃗| = |u⃗||v⃗|sin θ
ตั้งฉากกับทั้งคู่(u⃗ × v⃗) · u⃗ = 0, (u⃗ × v⃗) · v⃗ = 0
💡 เทคนิค A-Level — กฎมือขวา
ชี้นิ้วชี้ไปทาง u⃗ งอนิ้วไปทาง v⃗ นิ้วหัวแม่มือจะชี้ไปทาง u⃗ × v⃗
หัวข้อที่ 6 · เวกเตอร์ในระบบ 3 มิติ
🧊
พิกัดและระยะทางใน 3 มิติ
ระยะห่างระหว่าง A = (x₁, y₁, z₁) และ B = (x₂, y₂, z₂):
d = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²]
ตัวอย่าง
A = (1, 2, 3) และ B = (4, 6, 3)
d = √[(4−1)² + (6−2)² + (3−3)²]
= √[9 + 16 + 0] = √25 = 5
🔄
สมการเส้นตรงในรูปเวกเตอร์
สมการเส้นตรง (Vector Form)
เส้นตรงผ่านจุด A = (x₀, y₀, z₀) ในทิศทาง d⃗ = (a, b, c):
r⃗ = A + t·d⃗ เมื่อ t เป็นพารามิเตอร์จริง
(x, y, z) = (x₀ + ta, y₀ + tb, z₀ + tc)

รูปสมมาตร (Symmetric form):
(x − x₀)/a = (y − y₀)/b = (z − z₀)/c = t
ตัวอย่าง
เส้นตรงผ่าน (1, 2, 3) ในทิศทาง d⃗ = (2, −1, 4):
r⃗ = (1, 2, 3) + t(2, −1, 4)
r⃗ = (1 + 2t, 2 − t, 3 + 4t)
🟦
สมการระนาบ
สมการระนาบ
ระนาบที่มีเวกเตอร์ตั้งฉาก (Normal vector) n⃗ = (A, B, C) และผ่านจุด (x₀, y₀, z₀):
A(x − x₀) + B(y − y₀) + C(z − z₀) = 0
หรือเขียนเป็น Ax + By + Cz = D
ตัวอย่าง
ระนาบผ่าน (1, 2, 3) มี n⃗ = (2, −1, 1):
2(x − 1) + (−1)(y − 2) + 1(z − 3) = 0
2x − 2 − y + 2 + z − 3 = 0
2x − y + z = 3
หัวข้อที่ 7 · การประยุกต์ใช้เวกเตอร์
⚡
ฟิสิกส์และแรง

เวกเตอร์ใช้ในการหาแรงลัพธ์ ความเร็ว และการกระจัด

ตัวอย่าง — แรงลัพธ์
แรง F₁⃗ = (3, 4) นิวตัน และ F₂⃗ = (−1, 2) นิวตัน
แรงลัพธ์ F⃗ = F₁⃗ + F₂⃗ = (2, 6) นิวตัน
ขนาดแรงลัพธ์ |F⃗| = √(4 + 36) = √40 = 2√10 นิวตัน
📐
พื้นที่สามเหลี่ยมและสี่เหลี่ยมด้านขนาน
พื้นที่สี่เหลี่ยมด้านขนาน = |u⃗ × v⃗|
พื้นที่สามเหลี่ยม = ½|u⃗ × v⃗|
ตัวอย่าง
สามเหลี่ยมมีจุดยอด A(0,0,0), B(1,2,0), C(0,1,3)
u⃗ = AB⃗ = (1,2,0), v⃗ = AC⃗ = (0,1,3)
u⃗ × v⃗ = (2×3 − 0×1, 0×0 − 1×3, 1×1 − 2×0) = (6, −3, 1)
|u⃗ × v⃗| = √(36 + 9 + 1) = √46
พื้นที่สามเหลี่ยม = ½√46
🔑
สรุปสูตรสำคัญ
สูตรความหมาย
|v⃗| = √(a²+b²+c²)ขนาดเวกเตอร์
û = v⃗/|v⃗|เวกเตอร์หน่วย
u⃗·v⃗ = a₁a₂+b₁b₂+c₁c₂ผลคูณจุด (สเกลาร์)
cos θ = u⃗·v⃗/(|u⃗||v⃗|)มุมระหว่างเวกเตอร์
u⃗·v⃗ = 0 ⟺ u⃗ ⊥ v⃗เงื่อนไขตั้งฉาก
|u⃗×v⃗| = |u⃗||v⃗|sin θขนาดผลคูณไขว้
พื้นที่ = ½|u⃗×v⃗|พื้นที่สามเหลี่ยม
