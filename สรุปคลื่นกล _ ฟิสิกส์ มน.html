คลื่นกล

สรุปเตรียมสอบปลายภาค: ชนิดคลื่น • ฟังก์ชันคลื่น • อัตราเร็ว • การรวมกัน • คลื่นนิ่ง

คลื่นคืออะไร

คลื่นเกิดเมื่อระบบถูกรบกวนจากสมดุล และการรบกวนนั้นเคลื่อนที่ (propagate) ไปยังบริเวณอื่น ส่งผ่านเฉพาะพลังงาน อนุภาคตัวกลางไม่ได้เคลื่อนที่ไปกับคลื่น (แค่สั่นรอบจุดสมดุล)

แบ่งตามความจำเป็นของตัวกลาง

  • คลื่นกล ต้องอาศัยตัวกลาง: คลื่นในเส้นเชือก คลื่นเสียง คลื่นน้ำ
  • คลื่นแม่เหล็กไฟฟ้า ไม่ต้องใช้ตัวกลาง: แสง คลื่นวิทยุ รังสี UV รังสีเอ็กซ์

แบ่งตามการสั่นของอนุภาคตัวกลาง

คลื่นตามยาวคลื่นตามขวาง
อนุภาคสั่นแนวเดียวกับทิศคลื่นตั้งฉากกับทิศคลื่น
ตัวอย่างเสียง, การอัดลวดสปริงพัลส์ในเชือก, คลื่นน้ำ (โดยประมาณ)
3 ปัจจัยการเกิดคลื่นกล: (1) ต้นกำเนิดการรบกวน (2) ตัวกลางที่รับการรบกวน (3) อันตรกิริยาระหว่างอนุภาคที่อยู่ใกล้กัน ทำให้ส่งต่อพลังงานได้

คลื่นดล (Pulse)

รูปร่างพัลส์ไม่เปลี่ยนตามเวลา จึงเลื่อนไปเป็นระยะ vt

ไปทางขวา: y(x,t) = f(x − vt)
ไปทางซ้าย: y(x,t) = f(x + vt)
Ex.2 y = 4/[(x−2t)²+1] → ที่ t=0 ค่ามากสุดที่ x=0 ได้ A = 4 cm
ความกว้างพัลส์ วัดที่ครึ่งของ A (y=2): (x²+1)=2 → x = ±1 → กว้าง 2 cm

คลื่นรูปไซน์

y = A sin(kx ∓ ωt + φ)
ลบ → ไปทางขวา (+x) | บวก → ไปทางซ้าย (−x)
ปริมาณความหมาย / สูตร
λความยาวคลื่น (สัน→สัน หรือ ท้อง→ท้อง)
T, fคาบ (s), ความถี่ f = 1/T (Hz)
kเลขคลื่น k = 2π/λ
ωความถี่เชิงมุม ω = 2π/T = 2πf
v (เฟส)v = λ/T = fλ = ω/k
φค่าคงที่เฟส หาจากเงื่อนไขที่ x=0, t=0
40 160 0.4

เลื่อนแถบดูว่า A, λ, f เปลี่ยนรูปคลื่นอย่างไร (หน่วยสมมติ)

อัตราเร็ว/อัตราเร่งของอนุภาค

vy = ∂y/∂t = −ωA cos(kx − ωt)
ay = ∂²y/∂t² = −ω² y
vy,max = ωA   ay,max = ω²A
อย่าสับสน: vy คือความเร็วการสั่นของอนุภาค (ตามแกน y) ส่วน v = ω/k คือความเร็วที่คลื่นแผ่ไป
vy สูงสุดที่ y = 0 | ay สูงสุดที่ y = ±A (ไม่พร้อมกัน)

อัตราเร็วคลื่นในเส้นเชือก

v = √(T/μ)   T = แรงตึง (N), μ = มวลต่อความยาว (kg/m)

แรงตึงมาก → คลื่นเร็วขึ้น | เชือกหนัก (μ มาก) → คลื่นช้าลง

การรวมกัน (Superposition)

คลื่นตั้งแต่ 2 ขบวนมาพบกันในบริเวณเดียวกัน ผลลัพธ์ y = y₁ + y₂ (บวกแบบพีชคณิตทีละจุด) แล้วเคลื่อนผ่านกันไปโดยรูปร่างเดิมไม่เปลี่ยน

y₁ = A sin(kx−ωt), y₂ = A sin(kx−ωt+φ)
y = 2A cos(φ/2) · sin(kx − ωt + φ/2)
ต่างเฟส φแอมพลิจูดรวมเรียกว่า
0°2Aแทรกสอดแบบเสริม
180°0แทรกสอดแบบหักล้าง
0° < φ < 180°0 ถึง 2Aกึ่งกลาง

คลื่นนิ่ง (Standing wave)

เกิดจากคลื่น 2 ขบวนที่ A, f, λ เท่ากัน เคลื่อนสวนทางกัน

y = (2A sin kx) cos ωt
  • ไม่มีเทอม (kx − ωt) จึงไม่มีการเคลื่อนที่ของรูปคลื่น
  • อนุภาคทุกตำแหน่งสั่นด้วย ω เท่ากัน แต่แอมพลิจูด 2A sin kx ขึ้นกับตำแหน่ง
บัพ (node) แอมพลิจูด = 0: sin kx = 0 → x = nλ/2, n = 0,1,2,…
ปฏิบัพ (antinode) แอมพลิจูดสูงสุด 2A: x = nλ/4, n = 1,3,5,…

เชือกตรึงสองปลาย (นอร์มอลโหมด)

L = nλ/2  →  fn = n·v/(2L) = n f₁  (n = 1,2,3,…)
f₁ = ความถี่หลักมูล (ฮาร์มอนิกที่ 1), f₂ = โอเวอร์โทนที่ 1

Ex.2 พัลส์บนเส้นเชือก

โจทย์
พัลส์คลื่นหนึ่งกำลังแผ่ไปทางขวาตามแกน x บนเส้นเชือก ฟังก์ชันคลื่นคือ y(x,t) = 4 / [(x − 2t)² + 1] โดย y, x เป็นเซนติเมตร และ t เป็นวินาที จงหาแอมพลิจูดและความกว้างของพัลส์
สูตรที่ใช้
แอมพลิจูด = ค่า y สูงสุด (เกิดเมื่อตัวส่วนน้อยสุด)
ความกว้างพัลส์ = ระยะระหว่างสองจุดที่ y = A/2

วิธีทำ

  1. ที่ t = 0: y = 4/(x²+1) ค่าสูงสุดเมื่อ x = 0 → y = 4/1 = 4 cm
  2. ครึ่งหนึ่งของ A คือ 2 cm → 4/(x²+1) = 2
  3. x² + 1 = 2 → x² = 1 → x = +1 และ −1
  4. ความกว้าง = 1 − (−1) = 2 cm
ตอบ A = 4 cm, ความกว้างพัลส์ = 2 cm

Ex.3 คลื่นรูปไซน์บนเส้นเชือก

โจทย์
คลื่นบนเส้นเชือกมีสมการการกระจัด (หน่วยเมตร) เป็น y = 15 sin[(π/16)(2x + 64t)] จงหา
ก) แอมพลิจูด ความยาวคลื่น และคาบ
ข) ความเร็วเฟส
ค) อัตราเร็วของอนุภาคเชือกที่ตำแหน่ง x = 6 m ที่เวลา t = 0.25 s
ง) อัตราเร็วสูงสุดและอัตราเร่งสูงสุดของอนุภาคเชือก
สูตรที่ใช้
y = A sin(kx ∓ ωt)  |  k = 2π/λ  |  ω = 2π/T
v = ω/k  |  vy = dy/dt  |  vy,max = ωA  |  ay,max = ω²A

วิธีทำ

  1. จัดรูปให้เป็น y = 15 sin(π/8·x + 4π·t) → A = 15 m, k = π/8, ω = 4π
  2. ก) λ = 2π/k = 2π/(π/8) = 16 m, T = 2π/ω = 2π/4π = 0.5 s
  3. ข) v = ω/k = 4π/(π/8) = 32 m/s (เครื่องหมาย + แปลว่าไปทางซ้าย)
  4. ค) vy = dy/dt = 15(4π) cos(kx + ωt) = 60π cos(3π/4 + π) = 60π cos(7π/4) = 60π(√2/2) = 30√2 π ≈ +133 m/s
    (สไลด์ใช้ kx − ωt จึงได้ −30√2π ถ้าเฉลยอาจารย์ต่างกัน ให้ถามอาจารย์)
  5. ง) vy,max = ωA = 4π × 15 = 60π m/s, ay,max = ω²A = (4π)² × 15 = 240π² m/s²
ตอบ A = 15 m, λ = 16 m, T = 0.5 s, v = 32 m/s, vy ≈ 133 m/s, vy,max = 60π m/s, ay,max = 240π² m/s²

Ex.4 หาสมการคลื่นจากกราฟ

โจทย์
คลื่นรูปไซน์บนเส้นเชือกเคลื่อนที่ไปทางขวา แอมพลิจูด 15.0 cm ความยาวคลื่น 40.0 cm ความถี่ 8.00 Hz ที่เวลา t = 0 การกระจัดที่ x = 0 มีค่า 15 cm (เป็นสันคลื่นพอดี)
ก) จงหา k, T, ω, v
ข) จงหาค่าคงที่เฟสและเขียนฟังก์ชันคลื่น
สูตรที่ใช้
k = 2π/λ  |  T = 1/f  |  ω = 2πf  |  v = fλ
ไปทางขวา: y = A sin(kx − ωt + φ)

วิธีทำ

  1. k = 2π/40 = 0.157 rad/cm (= π/20)
  2. T = 1/8.00 = 0.125 s
  3. ω = 2π(8.00) = 50.3 rad/s (= 16π)
  4. v = fλ = 8.00 × 40.0 = 320 cm/s
  5. ใส่ x = 0, t = 0, y = 15: 15 = 15 sin φ → sin φ = 1 → φ = π/2
  6. แทนค่า: y = 15 sin(πx/20 − 16πt + π/2)
ตอบ k = 0.157 rad/cm, T = 0.125 s, ω = 50.3 rad/s, v = 320 cm/s, φ = π/2

Ex.5 เปรียบเทียบสามคลื่น

โจทย์
มีคลื่นสามขบวนบนเชือกที่ต่างกัน: (1) y = 2 sin(4x − 2t) (2) y = sin(3x − 4t) (3) y = 2 sin(3x − 3t)
ก) เรียงความเร็วเฟสจากมากไปน้อย
ข) เรียงอัตราเร็วสูงสุดของอนุภาคตัวกลางจากมากไปน้อย
สูตรที่ใช้
อ่านค่าจาก y = A sin(kx − ωt): ได้ A, k, ω
v = ω/k  |  vy,max = ωA

วิธีทำ

  1. คลื่น 1: A=2, k=4, ω=2 → v = 2/4 = 0.5, vy,max = 2×2 = 4
  2. คลื่น 2: A=1, k=3, ω=4 → v = 4/3 ≈ 1.33, vy,max = 4×1 = 4
  3. คลื่น 3: A=2, k=3, ω=3 → v = 3/3 = 1, vy,max = 3×2 = 6
ตอบ ก) 2 > 3 > 1   ข) 3 > (1 = 2) คลื่น 1 และ 2 เท่ากันที่ 4

Ex.6 คลื่นนิ่งจากคลื่นสองขบวน

โจทย์
คลื่นสองขบวนบนเชือกเคลื่อนที่สวนทางกันจนเกิดคลื่นนิ่ง โดย y₁ = 4.0 sin(3.0x − 2.0t) และ y₂ = 4.0 sin(3.0x + 2.0t) (y, x เป็น cm, t เป็น s)
ก) แอมพลิจูดสูงสุดของคลื่นนิ่ง
ข) แอมพลิจูดของคลื่นนิ่งที่ x = 2.3 cm
ค) ตำแหน่งบัพและปฏิบัพ
สูตรที่ใช้
y = y₁ + y₂ = (2A sin kx) cos ωt
บัพ: sin kx = 0 → x = nλ/2  |  ปฏิบัพ: x = nλ/4 (n = 1,3,5,…)  |  λ = 2π/k

วิธีทำ

  1. อ่านค่า A = 4, k = 3, ω = 2 → y = 8 sin(3x) cos(2t)
  2. ก) แอมพลิจูดสูงสุด = 2A = 8 cm
  3. ข) แอมพลิจูดที่ x = 2.3: |8 sin(3 × 2.3)| = 8 sin(6.9) = 8(0.579) ≈ 4.6 cm (เครื่องคิดเลขโหมดเรเดียน)
  4. ค) λ = 2π/3 ≈ 2.09 cm → บัพ x = nλ/2 = nπ/3 = 0, 1.05, 2.09, … cm และปฏิบัพ x = nλ/4 = π/6, π/2, 5π/6, … cm (≈ 0.52, 1.57, 2.62)
ตอบ 8 cm, ≈ 4.6 cm, บัพที่ x = nπ/3, ปฏิบัพที่ x = π/6, π/2, 5π/6, …
