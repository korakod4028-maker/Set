🌳 Linux Filesystem Hierarchy (FHS)
/ ← Root Directory (ใหญ่ที่สุดในระบบ 👑)
├── bin/ คำสั่งพื้นฐาน (ls, cp, mv, cat...)
├── sbin/ คำสั่งสำหรับ Admin เท่านั้น
├── etc/ ไฟล์ config ทั้งหมดของระบบ
├── home/ บ้านรวมของผู้ใช้ทุกคน
│ ├── alice/ ← Home Directory ของ alice
│ │ ├── .bashrc ไฟล์ซ่อน (dotfile)
│ │ └── Documents/
│ └── bob/ ← Home Directory ของ bob
├── root/ Home ของ root user (superuser)
├── var/ ข้อมูลที่เปลี่ยนแปลงบ่อย (logs, databases)
├── tmp/ ไฟล์ชั่วคราว (ลบเมื่อ reboot)
├── usr/ โปรแกรมที่ติดตั้งเพิ่มเติม
├── lib/ Library ที่โปรแกรมต้องการ
├── dev/ อุปกรณ์ฮาร์ดแวร์ (disk, usb...)
├── proc/ ข้อมูล process ที่กำลังรันอยู่ (virtual)
└── mnt/ จุด mount ชั่วคราว (USB, NFS...)

Linux ใช้โครงสร้าง ต้นไม้ต้นเดียว (Single Tree) — ไม่มี Drive C: D: เหมือน Windows ทุกอย่างเริ่มจาก /

Directories ที่สำคัญ
/ (Root)
จุดเริ่มต้นของทุกอย่างในระบบ — ใหญ่ที่สุด ไม่มี parent directory
/home
โฟลเดอร์บ้านรวม เก็บ home directory ของผู้ใช้ทุกคน
~
ย่อมาจาก Home Directory ของผู้ใช้ปัจจุบัน เช่น /home/alice
/root
Home Directory ของ root user (superuser) — แยกออกจาก /home
/etc
ไฟล์ config ทั้งหมด เช่น /etc/passwd, /etc/hosts, /etc/fstab
/var/log
Log files ทั้งหมด — แหล่ง debug สำคัญสำหรับ Engineer
/tmp
ไฟล์ชั่วคราว ทุกคนเขียนได้ ถูกลบเมื่อ reboot
/proc
Virtual filesystem — ข้อมูล kernel และ process แบบ real-time
Path และ Navigation
🧭 Absolute Path vs Relative Path
/home/alice/file.txt Absolute Path — เริ่มจาก / เสมอ ใช้งานได้จากทุกที่
./file.txt Relative Path — อิงกับ directory ปัจจุบัน (. = current dir)
../file.txt Relative Path — ขึ้นไป 1 ชั้น (.. = parent dir) แล้วเปิดไฟล์
~/Documents Tilde Expansion — ~ แทน Home Directory ของ user ปัจจุบัน

⚠️ จุดสำคัญ: . = โฟลเดอร์ปัจจุบัน · .. = โฟลเดอร์แม่ (parent) · ~ = Home Directory ของคุณ

⌨️ คำสั่ง Navigation พื้นฐาน
pwd Print Working Directory — แสดง path ที่คุณอยู่ตอนนี้
cd /path Change Directory — ไปยัง path ที่กำหนด (absolute)
cd ~ กลับไปยัง Home Directory ของตัวเอง
cd .. ขึ้นไปยัง parent directory 1 ชั้น
cd - กลับไปยัง directory ก่อนหน้า (toggle ระหว่าง 2 ที่)
cd / ไปยัง Root Directory
คำสั่ง man คืออะไร
📖 man — Manual Pages

คำสั่ง man เปิดคู่มือการใช้งาน (manual page) ของคำสั่งต่างๆ ใน Linux แบบ offline — เพื่อนแท้ของ Engineer ที่ไม่ต้องเปิด Google

man ls เปิดคู่มือฉบับเต็มของคำสั่ง ls
man 1 intro เจาะจงเปิดหมวดที่ 1 — man [section] [command]
man passwd ดูคู่มือ passwd (อาจมีหลาย section — ระบุเลข section ถ้าต้องการ)

ใน man page โครงสร้างมาตรฐานจะมี: NAME (ชื่อ), SYNOPSIS (วิธีใช้), DESCRIPTION (อธิบาย), OPTIONS (flags ทั้งหมด), EXAMPLES, SEE ALSO

การควบคุมหน้าต่าง man
⌨️ Keyboard Controls ใน man page
q Quit — ออกจาก man page (สำคัญที่สุด!)
↑ / ↓ เลื่อนขึ้น/ลงทีละบรรทัด
Space / PgDn เลื่อนลงทีละหน้า
b / PgUp เลื่อนขึ้นทีละหน้า (back)
/keyword ค้นหาคำ ภายใน man page (กด Enter แล้วกด n เพื่อไปผลถัดไป)
n / N ไปผลค้นหาถัดไป / ย้อนกลับ
g / G กระโดดไปหัว / ท้าย ของ man page
h เปิด help ของ pager (man ใช้ less เป็น pager)
9 Sections ของ man
📚 Man Page Sections
§หมวดตัวอย่าง
1User Commands (คำสั่งทั่วไป)ls, cd, cp, cat
2System Calls (เรียกใช้ kernel โดยตรง)open(), read(), fork()
3Library Functions (ฟังก์ชัน C library)printf(), malloc()
4Special Files (device files)/dev/null, /dev/sda
5File Formats & Configuration/etc/passwd, crontab
6Games—
7Miscellaneous (conventions, protocols)regex, glob, signal
8System Admin Commands (root only)mount, iptables, fdisk
9Kernel Routines—

⚠️ หมวดที่ต้องจำ: 1 = User commands · 5 = Config files · 8 = Admin commands — ข้อสอบออกบ่อย!

คำสั่งค้นหาด่วน
🔍 Quick Lookup Commands
whatis ls คำอธิบายสั้น 1 บรรทัด ว่า ls ทำอะไร — เทียบเท่า man -f ls
man -f ls เหมือน whatis ls — แสดงทุก section ที่มีคำสั่งนี้
man -k keyword ค้นหา ทุก man page ที่มีคำนี้ในชื่อหรือคำอธิบาย — เทียบเท่า apropos keyword
apropos network ค้นหา man pages ทั้งหมดที่เกี่ยวกับ network
man -w ls แสดง path ของไฟล์ man page บนเครื่อง
man 5 passwd เปิดคู่มือ passwd ในหมวด 5 (format ของไฟล์) ไม่ใช่หมวด 1 (คำสั่ง)

whatis = man -f และ apropos = man -k — จำคู่นี้ไว้ มักออกข้อสอบในรูปแบบ "คำสั่งใดเทียบเท่ากัน"

apropos networkเหมือน man -k — ค้นหา man pages
man -w lsแสดง path ไฟล์ man page ของ ls

💡 Engineer Tips
→
ไม่รู้จะใช้คำสั่งไหน ใช้ man -k keyword หรือ apropos keyword เพื่อค้นหาก่อนเสมอ
→
ใช้ man 5 passwd ดู format ของ /etc/passwd — แตกต่างจาก man passwd (section 1 = คำสั่ง)
→
ใน man page กด /OPTIONS แล้ว Enter เพื่อกระโดดไปหัวข้อ OPTIONS ทันที ไม่ต้องเลื่อนหา
→
man hier — เปิดคู่มือโครงสร้าง Linux Filesystem ทั้งหมด มีประโยชน์มากสำหรับ Engineer ใหม่
→
Log files อยู่ที่ /var/log/ เสมอ — เมื่อเจอปัญหา ให้ดู ls -altr /var/log/ เพื่อหา log ล่าสุด
→
Config ทั้งหมดอยู่ใน /etc/ — เมื่อต้องการแก้ไข service ให้มองหาที่นี่ก่อน
