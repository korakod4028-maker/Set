บทที่ 1 · ตัวแปรสุ่ม (Random Variable)
🎲
ตัวแปรสุ่มคืออะไร?

ตัวแปรสุ่ม (Random Variable) คือ ฟังก์ชันที่กำหนดค่าตัวเลขให้กับแต่ละผลลัพธ์ ในปริภูมิตัวอย่าง (Sample Space) ของการทดลองสุ่ม

นิยาม
ตัวแปรสุ่ม มักเขียนแทนด้วยตัวอักษรพิมพ์ใหญ่ เช่น X, Y ส่วนค่าที่ตัวแปรสุ่มรับ มักเขียนแทนด้วยตัวพิมพ์เล็ก เช่น x
ตัวอย่าง
โยนเหรียญ 2 เหรียญ ปริภูมิตัวอย่าง S = {HH, HT, TH, TT}
ให้ X = จำนวนหัวที่ได้ → X(HH)=2, X(HT)=1, X(TH)=1, X(TT)=0
📊
ประเภทของตัวแปรสุ่ม

ตัวแปรสุ่มไม่ต่อเนื่อง (Discrete)

รับค่าเป็นจำนวนที่นับได้ (มักเป็นจำนวนเต็ม) เช่น จำนวนหัว จำนวนลูกค้า จำนวนของเสีย

ตัวแปรสุ่มต่อเนื่อง (Continuous)

รับค่าเป็นจำนวนที่วัดได้ ในช่วงของจำนวนจริง เช่น ส่วนสูง น้ำหนัก เวลา อุณหภูมิ

💡 เทคนิคจำ
นับได้ (0,1,2,3,...) → ไม่ต่อเนื่อง | วัดได้ (ค่าใดก็ได้ในช่วง) → ต่อเนื่อง
บทนี้จะเน้น ตัวแปรสุ่มไม่ต่อเนื่อง เป็นหลัก และกล่าวถึงการแจกแจงปกติซึ่งเป็นตัวแปรสุ่มต่อเนื่องในหัวข้อสุดท้าย
🪙
ตัวอย่างการสร้างตัวแปรสุ่มจากปริภูมิตัวอย่าง

โยนเหรียญ 3 เหรียญ (แต่ละเหรียญไม่เที่ยงตรง P(H) = P(T) = 1/2) ให้ X = จำนวนหัวที่ได้

S = {HHH, HHT, HTH, THH, HTT, THT, TTH, TTT} (8 แบบ ความน่าจะเป็นเท่ากันแบบละ 1/8)
ผลลัพธ์HHHHHTHTHTHHHTTTHTTTHTTT
X (จำนวนหัว)32221110

จะเห็นว่า X รับค่าได้ 4 ค่า คือ 0, 1, 2, 3 — ตัวอย่างนี้จะถูกใช้ต่อในหัวข้อถัดไป

หัวข้อ 2 · การแจกแจงความน่าจะเป็นของตัวแปรสุ่มไม่ต่อเนื่อง
📋
ตารางแจกแจงความน่าจะเป็น
นิยาม
การแจกแจงความน่าจะเป็น (Probability Distribution) ของตัวแปรสุ่มไม่ต่อเนื่อง X คือ ตารางหรือฟังก์ชันที่แสดง ค่าที่ X รับได้ คู่กับ ความน่าจะเป็นที่ X จะรับค่านั้น เขียนแทนด้วย P(X = x)
⚠️ สมบัติที่ต้องเป็นจริงเสมอ
1) 0 ≤ P(X = x) ≤ 1 สำหรับทุกค่า x
2) Σ P(X = x) = 1 (ผลรวมความน่าจะเป็นของทุกค่าต้องเท่ากับ 1)
🧮
ตัวอย่างการสร้างตารางแจกแจง

ต่อจากตัวอย่างการโยนเหรียญ 3 เหรียญ (X = จำนวนหัว) จากหัวข้อที่แล้ว

P(X=0) = 1/8 (มีแบบเดียวคือ TTT)
P(X=1) = 3/8 (HTT, THT, TTH)
P(X=2) = 3/8 (HHT, HTH, THH)
P(X=3) = 1/8 (มีแบบเดียวคือ HHH)
x0123รวม
P(X=x)1/83/83/81/81
💡 ตรวจสอบเสมอ
1/8 + 3/8 + 3/8 + 1/8 = 8/8 = 1 ✓ สอดคล้องกับสมบัติข้อ 2
Σ
การหาค่า k ในตารางแจกแจง

โจทย์มักให้ตารางแจกแจงที่มีค่าคงที่ k ปนอยู่ แล้วให้หาค่า k จากสมบัติ Σ P(X=x) = 1

ตัวอย่าง
กำหนดตารางแจกแจงความน่าจะเป็นของ X ดังนี้
x1234
P(X=x)k2k3k4k
จงหาค่า k

วิธีทำ: ใช้สมบัติ Σ P(X=x) = 1
k + 2k + 3k + 4k = 1
10k = 1
k = 0.1 ✓
หัวข้อ 3 · ค่าคาดหมาย E(X)
🎯
นิยามค่าคาดหมาย (Expected Value)
นิยาม
ค่าคาดหมาย E(X) คือ ค่าเฉลี่ยถ่วงน้ำหนักด้วยความน่าจะเป็น ของตัวแปรสุ่ม X บอกว่าโดยเฉลี่ยแล้ว X มีค่าประมาณเท่าใด
E(X) = Σ x · P(X = x)

บางตำราเขียนแทนด้วย μ (มิว) หรือ μX

🧮
ตัวอย่างการคำนวณ E(X)

จากตารางแจกแจงของ X = จำนวนหัวจากการโยนเหรียญ 3 เหรียญ

x0123
P(X=x)1/83/83/81/8
E(X) = 0(1/8) + 1(3/8) + 2(3/8) + 3(1/8)
= 0 + 3/8 + 6/8 + 3/8
= 12/8 = 1.5
💡 ความหมาย
โดยเฉลี่ยแล้ว เมื่อโยนเหรียญ 3 เหรียญซ้ำ ๆ กันหลายครั้ง จำนวนหัวที่ได้เฉลี่ยจะอยู่ที่ประมาณ 1.5 หัวต่อครั้ง (ไม่จำเป็นต้องเป็นค่าที่ X รับได้จริง)
📐
สมบัติของค่าคาดหมาย
E(aX + b) = a·E(X) + b (เมื่อ a, b เป็นค่าคงที่)
E(a) = a (ค่าคาดหมายของค่าคงที่ คือค่าคงที่นั้นเอง)
ตัวอย่าง
จากตัวอย่างข้างต้น E(X) = 1.5 จงหา E(2X + 3)
E(2X+3) = 2(1.5) + 3 = 3 + 3 = 6 ✓
หัวข้อ 4 · ความแปรปรวนและส่วนเบี่ยงเบนมาตรฐาน
📏
ความแปรปรวน Var(X)
นิยาม
ความแปรปรวน (Variance) วัดการกระจายตัวของค่า X รอบค่าคาดหมาย ยิ่งค่ามาก ยิ่งกระจายตัวมาก
Var(X) = E(X²) − [E(X)]²

โดยที่ E(X²) = Σ x² · P(X = x)

🧮
ตัวอย่างการคำนวณ Var(X)

ต่อจากตัวอย่างเดิม X = จำนวนหัวจากการโยนเหรียญ 3 เหรียญ (E(X) = 1.5)

E(X²) = 0²(1/8) + 1²(3/8) + 2²(3/8) + 3²(1/8)
= 0 + 3/8 + 12/8 + 9/8
= 24/8 = 3
Var(X) = E(X²) − [E(X)]² = 3 − (1.5)² = 3 − 2.25 = 0.75
ส่วนเบี่ยงเบนมาตรฐาน SD(X)
SD(X) = √Var(X) = √0.75 ≈ 0.866
📐
สมบัติของความแปรปรวน
Var(aX + b) = a² · Var(X) (ค่าคงที่ b ที่บวกเพิ่มไม่มีผลต่อการกระจายตัว)
Var(a) = 0 (ค่าคงที่ไม่มีการกระจายตัวเลย)
⚠️ ข้อควรระวัง
การบวกค่าคงที่ b เข้าไปใน X (เลื่อนตำแหน่งข้อมูล) ไม่เปลี่ยนการกระจายตัว จึงไม่มี b ปรากฏในสูตร Var(aX+b) — ต่างจากสูตร E(aX+b) ที่มี b ติดมาด้วย
ตัวอย่าง
จาก Var(X) = 0.75 จงหา Var(4X − 5)
Var(4X−5) = 4² × 0.75 = 16 × 0.75 = 12 ✓
หัวข้อ 5 · การแจกแจงทวินาม (Binomial Distribution)
🎯
การทดลองแบบเบอร์นูลลี (Bernoulli Trial)
นิยาม
การทดลองที่มีผลลัพธ์เพียงสองแบบ คือ "สำเร็จ" (Success) กับ "ไม่สำเร็จ" (Failure)
ให้ p = ความน่าจะเป็นที่จะสำเร็จ, q = 1 − p = ความน่าจะเป็นที่จะไม่สำเร็จ

เมื่อทำการทดลองแบบเบอร์นูลลีซ้ำกัน n ครั้งอย่างอิสระต่อกัน โดยความน่าจะเป็นสำเร็จ p คงที่ทุกครั้ง เรียกว่า การทดลองทวินาม

📊
สูตรการแจกแจงทวินาม
นิยาม
ถ้า X = จำนวนครั้งที่สำเร็จจาก n ครั้ง เรียก X ว่ามีการแจกแจงทวินาม เขียนแทนด้วย X ~ B(n, p)
P(X = x) = C(n, x) · px · qn−x , x = 0, 1, 2, …, n

โดยที่ C(n, x) = n! / [x!(n−x)!] คือจำนวนวิธีเลือกว่าครั้งใดสำเร็จบ้าง

💡 เงื่อนไขของการแจกแจงทวินาม (ต้องครบทั้ง 4 ข้อ)
1) ทำซ้ำ n ครั้งที่แน่นอน
2) แต่ละครั้งมีผลลัพธ์แค่ 2 แบบ (สำเร็จ/ไม่สำเร็จ)
3) ความน่าจะเป็นสำเร็จ p คงที่ทุกครั้ง
4) แต่ละครั้งเป็นอิสระต่อกัน
🧮
ตัวอย่างการคำนวณ
ตัวอย่าง
โยนเหรียญเที่ยงตรง 5 ครั้ง ให้ X = จำนวนครั้งที่ออกหัว จงหา P(X = 3)

ที่นี่ n = 5, p = 0.5, q = 0.5, x = 3
P(X=3) = C(5,3) · (0.5)³ · (0.5)²
C(5,3) = 10
P(X=3) = 10 × 0.125 × 0.25 = 0.3125 ✓
📐
ค่าคาดหมายและความแปรปรวนของการแจกแจงทวินาม

สำหรับ X ~ B(n, p) ไม่ต้องคำนวณจากตารางทีละค่า สามารถใช้สูตรลัดได้เลย

E(X) = np
Var(X) = npq
SD(X) = √(npq)
ตัวอย่าง
จากตัวอย่างโยนเหรียญ 5 ครั้ง (n=5, p=0.5, q=0.5)
E(X) = 5 × 0.5 = 2.5
Var(X) = 5 × 0.5 × 0.5 = 1.25
⚠️ ข้อควรระวัง
สูตรลัด E(X)=np และ Var(X)=npq ใช้ได้เฉพาะเมื่อ X มีการแจกแจงทวินามจริง ๆ (ครบเงื่อนไขทั้ง 4 ข้อ) เท่านั้น หากเป็นการหยิบโดยไม่ใส่คืน (ไม่อิสระ) จะใช้สูตรนี้ไม่ได้
หัวข้อ 6 · การแจกแจงปกติ (Normal Distribution)
🔔
ลักษณะของการแจกแจงปกติ
นิยาม
การแจกแจงปกติ คือการแจกแจงความน่าจะเป็นของตัวแปรสุ่มต่อเนื่อง ที่มีกราฟรูประฆังคว่ำ (Bell-shaped) สมมาตรรอบค่าเฉลี่ย μ เขียนแทนด้วย X ~ N(μ, σ²)
  • สมมาตรรอบค่าเฉลี่ย μ (μ = มัธยฐาน = ฐานนิยม)
  • พื้นที่ใต้กราฟทั้งหมดเท่ากับ 1
  • รูปร่างกว้าง-แคบขึ้นกับส่วนเบี่ยงเบนมาตรฐาน σ (σ มาก → กราฟแบนกว้าง, σ น้อย → กราฟสูงแคบ)
💡 กฎเชิงประจักษ์ (Empirical Rule) 68-95-99.7
ประมาณ 68% ของข้อมูลอยู่ในช่วง μ ± σ
ประมาณ 95% ของข้อมูลอยู่ในช่วง μ ± 2σ
ประมาณ 99.7% ของข้อมูลอยู่ในช่วง μ ± 3σ
Z
การแจกแจงปกติมาตรฐาน (Standard Normal)

เนื่องจากค่า μ, σ ของแต่ละปัญหาไม่เท่ากัน จึงต้องแปลงค่า X ให้เป็นมาตรฐานเดียวกันก่อนเปิดตาราง โดยใช้คะแนนมาตรฐาน Z

Z = (X − μ) / σ

เมื่อแปลงแล้ว Z จะมีการแจกแจงปกติมาตรฐาน คือ Z ~ N(0, 1) ซึ่งมี μ = 0 และ σ = 1 เสมอ ทำให้สามารถเปิดตารางค่า Z มาตรฐานเพื่อหาพื้นที่ใต้กราฟ (ความน่าจะเป็น) ได้

ตัวอย่างค่า P(Z < z) จากตารางมาตรฐาน (บางส่วน)
z−2.00−1.000.001.002.00
P(Z < z)0.02280.15870.50000.84130.9772

ในข้อสอบจริง โจทย์จะแนบตาราง Z มาให้เสมอ ไม่ต้องท่องจำค่า แต่ควรฝึกอ่านตารางให้คล่อง

🧮
ตัวอย่างการคำนวณด้วยการแจกแจงปกติ
ตัวอย่างที่ 1
กำหนด X ~ N(50, 100) (หมายถึง μ=50, σ²=100 ดังนั้น σ=10) จงหา P(X < 60)

แปลงเป็น Z: Z = (60 − 50)/10 = 1
P(X < 60) = P(Z < 1) = 0.8413 ✓
ตัวอย่างที่ 2
จากข้อมูลเดิม (μ=50, σ=10) จงหา P(40 < X < 60)

Z₁ = (40−50)/10 = −1 , Z₂ = (60−50)/10 = 1
P(40<X<60) = P(−1<Z<1) = P(Z<1) − P(Z<−1) = 0.8413 − 0.1587 = 0.6826 ✓
⚠️ ข้อควรระวัง
อย่าสับสนระหว่าง σ² (ความแปรปรวน) กับ σ (ส่วนเบี่ยงเบนมาตรฐาน) — สัญกรณ์ N(μ, σ²) ระบุความแปรปรวนไว้ในวงเล็บเสมอ ต้องถอดรากที่สองก่อนนำไปหาร Z
