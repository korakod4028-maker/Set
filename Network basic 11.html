1. Static vs Dynamic IPv4

หัวข้อStaticDynamic (DHCP)
ใครกำหนดNetwork Administrator ตั้งเองDHCP Server แจกอัตโนมัติ
เหมาะกับServer, Printer, Router, SwitchPC, Laptop, มือถือ
ข้อดีIP คงเดิม หาเครื่องเจอเสมอลดงาน Admin, กรอกผิดน้อย, นำ IP กลับมาใช้ซ้ำ
ข้อเสียตั้งทีละเครื่อง, ผิดง่าย, ต้องจดทะเบียน IPIP เปลี่ยนได้เมื่อ Lease หมด
ข้อมูลที่ต้องตั้ง: IP Address (เครื่องไหน) · Subnet Mask (Network ไหน) · Default Gateway (ทางออกไป Network อื่น) · DNS Server (แปลงชื่อโดเมนเป็น IP)
ในสรุป Module 11 ไม่ได้ระบุ DNS ไว้ในรายการขั้นต่ำ แต่ในงานจริงต้องมี DNS ด้วยเสมอ ไม่อย่างนั้นเข้า google.com ไม่ได้ทั้งที่ ping 8.8.8.8 ผ่าน เพิ่มเติม

คำความหมาย

        ┌──────▼───────┐

        │               │  LAN: DHCP Server  (แจก Private IP)
        └──┬─────┬────┬─┘
        Laptop  Phone  PC    ← DHCP Clients (192.168.x.x)
NAT คือตัวที่ทำให้ Private IP ด้านในออกเน็ตผ่าน Public IP เดียวของ Router ได้ เพิ่มเติม
ISP ไทยหลายเจ้าใช้ CGNAT ทำให้ WAN IP ของ Router เป็น 100.64.0.0/10 ไม่ใช่ Public จริง ตรวจได้โดยเทียบ WAN IP กับ IP ที่เว็บ "what is my ip" แสดง ถ้าไม่ตรงกัน แสดงว่าอยู่หลัง CGNAT (มีผลกับการ port forward และ self-host)

4. DORA — จำลองทีละขั้น

กด "ขั้นต่อไป" เพื่อดู field ของแต่ละแพ็กเก็ต หา → เสนอ → ขอ → ยืนยัน

DHCP Client
DHCP Server
ข้อสอบชอบหลอก
• DISCOVER ไม่ได้ส่งหา Server ตรง ๆ ต้องเป็น Broadcast เพราะ Client ยังไม่รู้ว่า Server อยู่ไหน
• ทุก Host ใน Broadcast Domain ได้รับเฟรม แต่มีเฉพาะ DHCP Server ที่ตอบ
• FF-FF-FF-FF-FF-FF คือ Destination MAC ไม่ใช่ Source
• Client ส่ง DISCOVER และ REQUEST · Server ส่ง OFFER และ ACK
REQUEST ปกติถูกส่งแบบ Broadcast ด้วย เพื่อบอก Server อื่นที่ส่ง OFFER มาว่า "ไม่ได้ถูกเลือก" และ DISCOVER มี Source IP เป็น 0.0.0.0 เพราะ Client ยังไม่มี IP เพิ่มเติม

5. ส่วนที่งานจริงต้องรู้ เพิ่มเติม

Lease renewal

เวลาเกิดอะไรขึ้น
50% ของ Lease (T1)Client ส่ง REQUEST แบบ Unicast ไป Server เดิมเพื่อต่ออายุ
87.5% (T2)ถ้า Server เดิมเงียบ Client Broadcast REQUEST หา Server ใดก็ได้ (Rebind)
100%Lease หมด Client ต้องเลิกใช้ IP แล้วเริ่ม DORA ใหม่

ข้อความ DHCP อื่น ๆ

ข้อความใครส่ง / ใช้ทำอะไร
DHCPNAKServer ปฏิเสธ เช่น IP ไม่ถูกต้องกับ Network นี้
DHCPDECLINEClient พบว่า IP ที่ได้ซ้ำกับเครื่องอื่น
DHCPRELEASEClient คืน IP ก่อนหมด Lease
DHCPINFORMClient ตั้ง IP เองแล้ว แต่ขอ config อื่น เช่น DNS

Port และ Protocol

DHCP ใช้ UDP · Server ฟังที่พอร์ต 67 · Client ใช้พอร์ต 68

APIPA (169.254.0.0/16)

ถ้า Windows ขอ DHCP แล้วไม่มีใครตอบ จะตั้ง IP ให้ตัวเองเป็น 169.254.x.x ใช้คุยได้เฉพาะวงเดียวกัน เห็น IP นี้ = DHCP มีปัญหา เป็นอาการแรกที่ต้องเช็กเวลาลูกค้าบอกว่าเน็ตใช้ไม่ได้

DHCP Relay

Broadcast ข้าม Router ไม่ได้ ถ้า DHCP Server อยู่คนละ VLAN/Subnet ต้องตั้ง Relay บน Router/L3 Switch ด้วยคำสั่ง ip helper-address <IP Server> ที่ Interface ฝั่ง Client

DHCP Reservation และ Excluded range

Reservation ผูก MAC → IP ให้ Printer/กล้อง ได้ IP เดิมเสมอโดยยังรับจาก DHCP · ส่วน Static IP ของ Gateway/Server ให้วางไว้ นอก Pool หรือกัน IP นั้นด้วย excluded-address ไม่งั้นอาจเกิด IP ซ้ำ

ความเสี่ยงด้านความปลอดภัย

Rogue DHCP Server — เครื่องปลอมแจก Gateway/DNS ผิดเพื่อดักข้อมูล · DHCP Starvation — ยิง DISCOVER ด้วย MAC ปลอมจน Pool หมด · วิธีป้องกันบน Switch คือ DHCP Snooping (อนุญาต Offer เฉพาะ Trusted port)

IPv6 ใช้ SLAAC หรือ DHCPv6 แทน ไม่มี Broadcast (ใช้ Multicast) ไว้ศึกษาต่อในโมดูลถัด ๆ ไป

Lab: Configure DHCP on a Wireless Router (Packet Tracer)

โครงสร้าง
Wireless Router 192.168.5.1 (Gateway + DHCP Server) → PC0 .126 · PC1 .127 · PC2 .128 (DHCP Clients) · Mask 255.255.255.0
ขั้นทำอะไร
1ต่อ PC0–PC2 เข้า Router ด้วยสาย Straight-through
2ที่ PC: Desktop → IP Configuration → เลือก DHCP
3เปิด Web Browser เข้า IP ของ Default Gateway · login admin / admin
4เปลี่ยน Router IP เป็น 192.168.5.1 → Save Settings (หน้าเว็บ Error ได้ เพราะ Browser ยังใช้ IP เก่า ไม่ใช่ความผิดเรา)
5ที่ PC สลับ Static → DHCP เพื่อขอ IP ใหม่ แล้วเข้า Router ที่ 192.168.5.1
6ตั้ง Starting IP = 192.168.5.126, Maximum users = 75 → Save
7ตรวจด้วย ipconfig และทดสอบด้วย ping 192.168.5.1, ping 192.168.5.127

คำนวณ Pool

Start . จำนวนผู้ใช้
สูตร: End = Start + Users − 1 → 126 + 75 − 1 = 200

ทำเหมือนกันบน Cisco IOS เพิ่มเติม

Router(config)# ip dhcp excluded-address 192.168.5.1 192.168.5.125
Router(config)# ip dhcp pool LAN5
Router(dhcp-config)# network 192.168.5.0 255.255.255.0
Router(dhcp-config)# default-router 192.168.5.1
Router(dhcp-config)# dns-server 8.8.8.8
Router(dhcp-config)# lease 1            # 1 วัน

Router# show ip dhcp binding           # ใครได้ IP ไหน
Router# show ip dhcp pool
Router# show ip dhcp conflict

ลำดับสำคัญ: กัน excluded-address ก่อน เพื่อให้ Pool เริ่มที่ .126 ได้ผลเทียบเท่าการตั้ง Start IP ใน GUI

คำสั่งฝั่ง Client เพิ่มเติม

ipconfig /all        # ดู IP, Gateway, DNS, DHCP Server, Lease เริ่ม/หมด
ipconfig /release    # คืน IP
ipconfig /renew      # ขอใหม่ (เริ่ม DORA)
ping <Gateway>       # เช็กวงเดียวกัน
ping 8.8.8.8         # เช็กออกเน็ต (ไม่พึ่ง DNS)
ping google.com      # เช็ก DNS
