Wired High-Speed Internet

Cable และ DSL เป็นการเชื่อมต่อความเร็วสูงแบบมีสาย

Dial-up = ช้า ไม่จัดเป็น High-Speed
📶

Wireless Internet

Satellite และ Cellular เป็นการเชื่อมต่ออินเทอร์เน็ตแบบไร้สาย

เทคโนโลยีลักษณะการใช้งานตัวอย่าง
Bluetoothเชื่อมต่อระยะสั้น จับคู่อุปกรณ์ (Pairing) มักต้องใช้ PINหูฟังไร้สายฟังเพลงจากมือถือ
NFCเชื่อมต่อระยะประชิดมาก ใช้แลกเปลี่ยนข้อมูลจำนวนน้อยอย่างรวดเร็วแตะจ่ายเงินที่เครื่อง POS
Wi-Fiเครือข่ายไร้สายระยะกลาง เชื่อมต่ออินเทอร์เน็ตในบ้าน/ที่ทำงานเชื่อมต่อผ่านเราเตอร์ไร้สาย
Cellularเครือข่ายมือถือระยะไกล ให้บริการอินเทอร์เน็ตนอกบ้าน3G/4G/5G ขณะเดินทาง
📲 Tethering คือการแชร์สัญญาณอินเทอร์เน็ตจากมือถือไปยังอุปกรณ์อื่น — วิธีหลักที่มือถือเชื่อมต่ออินเทอร์เน็ตคือ Cellular และ Wi-Fi

MODULE 5.3
TCP/IP Model และ OSI Model
Protocol Model (ใช้งานจริง) เทียบกับ Reference Model (ใช้อธิบาย)

TCP/IP Model — 4 Layer (Protocol Model)

  • 4. Application — HTTP, HTTPS, DNS, FTP, SMTP, DHCP
  • 3. Transport — TCP, UDP
  • 2. Internet — IPv4, IPv6, ICMP
  • 1. Network Access — Ethernet, Wi-Fi

OSI Model — 7 Layer (Reference Model)

  • 7. Application — Browser, Email
  • 6. Presentation — เข้ารหัส/บีบอัด
  • 5. Session — จัดการ Session
  • 4. Transport — Segment/Reassemble
  • 3. Network — Routing, IP Address
  • 2. Data Link — Frame, MAC Address
  • 1. Physical — Bit, สาย/Fiber/Wi-Fi
OSI Model (7 Layer)TCP/IP Model (4 Layer)
Application + Presentation + SessionApplication
TransportTransport
NetworkInternet
Data Link + PhysicalNetwork Access
จำให้แม่น: OSI = 7 Layer ใช้อธิบาย/สอน (Reference Model)  |  TCP/IP = 4 Layer ใช้งานจริงบนอินเทอร์เน็ต (Protocol Model)
